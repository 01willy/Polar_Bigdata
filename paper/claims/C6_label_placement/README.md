# C6 관측 위치 선택 근거 묶음

**성격**: 논문 색인 폴더(`paper/`)의 주장별 근거 묶음이다. 기존 스크립트·자료·문서는 옮기거나 고치지 않았고, 원천 표의 사본과 그 해시만 `tables/` 에 두었다(`tables/MANIFEST.csv`). 작성일은 2026-10-04 이다.

**수치 규칙**: 2절 근거 표의 모든 수치는 원천 CSV 를 pandas 로 직접 읽어(스레드 1) 소수 둘째 자리로 반올림한 값이다. 산문 문서의 수치를 옮겨 적지 않았다. 2.1–2.8 의 표를 다시 만드는 코드는 `extract_evidence.py`(이 폴더, `tables/` 사본을 읽는다)다. 2.10 의 추가 행(G1–G23)은 이 코드가 만들지 않는다. 같은 사본(`tables/wf_tests.csv`)에서 각 행의 '행 필터' 로 읽어 같은 형식으로 적었다. 1·5·6절의 산문에 나오는 수치는 2절 표의 행 번호나 문서 경로를 함께 적었다. 확인하지 못한 내용은 [미확인] 으로 표시했다. 2026-10-04 에 원천 표와 다시 대조해 고쳤다(8절).

**대비의 정의**: Δ = RMSE(전략) − RMSE(S1, 셀 무작위 추출), 단위 cm. 음수면 그 전략이 무작위보다 오차가 작다. L43 은 Δ = RMSE(블록 분산) − RMSE(셀 무작위)다(`docs/EXPERIMENT_PLAN_WRAPUP_2026-09-30.md` 4절). 판정어는 4분 판정이다. 우세·열세는 셀 가중과 블록 등가중 두 95 % CI 가 모두 같은 쪽일 때, 동등은 두 CI 가 모두 ±0.5 cm 안일 때, 미결정은 그 밖이다(`docs/QA_FINAL_REVIEW_2026-10-02.md` 머리말).

### 1.4 QA 문서가 요구한 좁힘의 적용

- **'안전' 표현**: `docs/QA_FINAL_REVIEW_2026-10-02.md` 의 Sci Rep 리뷰어 평가 표(400행)는 'C2(재보정 혼입), 안전 표현, WF 의 사후 설계' 를 지적 대상으로 적었다. WF8-b 는 열세 판정의 부재를 보는 규칙이고 비열등 검정이 아니다. `docs/EXPERIMENT_PLAN_WRAPUP_2026-09-30.md` 11.2(711행)는 '배포 레시피는 오차를 키우지 않았다(비열등 판정 없이 열세가 없다는 이유만으로)' 를 쓰지 않을 문장으로 정했다. WF8-b 의 '열세 없음' 에서 '안전', '나빠지지 않는다' 를 끌어내는 것도 같은 구조다. C6 에는 '안전' 을 쓰지 않는다. 등록 가설의 '(안전성)'(WF 계획서 124행)은 등록 기록이므로 고치지 않고, 원고로 옮기지 않는다. 쓰려면 비열등 한계(0.5 cm)와 추출 변동을 포함한 CI 로 새로 등록한 시험이 필요하다(6절 XD).
- **WF 사후 설계 표지**: 원천 표의 WF2·WF8 행은 `design_note` 가 '결과 열람 뒤 설계' 이고 `confirmatory` 가 False 다(`tables/wf_tests.csv`, `tables/wf2b_tests.csv`). 등록 커밋은 WF2 4168331, WF8 1b42b4d 다(`tables/wf_meta.json`, `tables/wf2b_meta.json` 의 `plan_commit`). 원고의 C6 문장에는 '결과 열람 뒤 설계(실행 전 등록)' 표지를 붙인다.
- **C2 좁힘과의 연결**: QA Q7(191–193행)은 '라벨을 더 얻을 곳' 을 두 단계로 적었다. 1단계(어느 지역에 투자할지)의 근거 ρ 0.38(WF4-c)은 P0 대비 이득이라 재보정 몫을 포함한다. QA 의 C2 점검(43행)은 '재보정을 넘어선 ML 몫(최선 ML − P1)과 계수 오차의 순위상관 −0.08(p 0.67, 30대상)' 이라고 적었으나, 괄호의 부호 정의가 값과 맞지 않는다. `data/processed/wf/wf0_misspec.csv`(사본 `tables/wf0_misspec.csv`, 30행)로 다시 계산했다. 이 표의 `P1` 열은 P0 대비 RMSE 차(P1 − P0, 캐나다\|x 는 +4.64 이고 `sig_P1` 이 worse)이고, `recal_gain` 은 그 부호를 바꾼 값(P0 − P1, 재보정 이득)이다. `ml_vs_p1` 은 `ml_best_delta` − `P1` = 최선 ML − P1 이다(두 관계 모두 30행에서 일치 확인). 재보정을 넘어선 ML 의 추가 이득(P1 − 최선 ML = −`ml_vs_p1`, 양수가 이득)과 재보정 이득(`recal_gain`)의 Spearman 순위상관은 −0.082(p 0.666)다. 괄호대로 '최선 ML − P1'(`ml_vs_p1`)을 쓰면 +0.082 다. 재보정 이득 대신 절댓값 |P0 − P1| 을 쓰면 추가 이득과 +0.157, `ml_vs_p1` 과 −0.157(p 0.407)이다. 어느 정의로도 상관은 없다는 결론은 같다. 원고에는 '재보정을 넘어선 ML 의 추가 이득(P1 − 최선 ML, 양수가 이득)과 재보정 이득(P0 − P1)의 순위상관 −0.08(p 0.67, 30대상)' 으로 쓴다. 따라서 1단계 문장은 '라벨을 쓰는 보정(재보정 + 잔차)의 이득' 으로 쓰고 'ML 이득' 으로 쓰지 않는다. 2단계(지역 안 어디를 잴지)의 근거인 WF2·WF8 은 같은 방법(R1, λ 0.25)끼리 라벨 집합만 바꾼 대비라 이 혼입과 관계가 없다.
- **L43 범위**: WRAPUP 4절 '원고 제한' 과 11.2 는 '어디를 재야 하는지 제시한다' 와 관측 우선순위 문장을 금지하고 방법 수준 지침만 허용한다. `docs/EXPERIMENT_PLAN_FINAL_PAPER_2026-09-26.md` (f) 행은 '라벨은 여러 블록에 흩어야 한다', '무작위가 안전하다' 를 금지한다. `docs/NOVELTY_POSITIONING_2026-09-29.md` 422행은 이 금지를 L43 범위로 한정했다. 다만 같은 행은 L43 을 '블록 분산 추출의 무효(L43)' 라고 적었다. 1. **사후 설계**: WF2·WF8 은 LG 계열 결과를 연 뒤 설계했다(실행 전 커밋). `confirmatory` 는 False 다. L43 은 결과 열람 전 등록이지만 비맹검 부분(a2_spread, a2 블록 분산 추출, h29b)을 포함한다(LT `blind` 열).
2. **이득의 지역 집중**: 2.5 cm 이상의 이득은 캐나다 하나에서 나왔다. '이질적 지역에서 이득' 이라는 일반화의 근거는 독립 지역 1개다. QA C2 점검(43행)은 캐나다를 '라벨 위치 이질성 때문에 P1 자체가 나쁜 곳' 으로 적었다. S2·S4 의 이득이 이 이질성과 관련된다는 해석은 시험하지 않았다 [미확인].
3. **레나**: 분할당 채점 블록이 5개로 적다. 레나에서 S2 의 점 추정은 지역 내(G1·A16–A19, +1.47 – +1.98)와 전이(D3, D14, E10, +1.89 – +2.18)에서 모두 양수였다. 원인은 분석하지 않았다 [미확인].
4. **가중 의존**: 알래스카 S2·S4 는 셀 가중과 블록 등가중의 점 추정 방향이 반대다. 블록 등가중 CI 는 모두 0 미만이고, 셀 가중 CI 는 A31 을 빼면 0 을 포함한다(A23–A25, A29–A31, G4–G7). 레나에서 S2 의 Δ 는 모든 라벨 수(20–500)에서 +1.47 – +1.98 cm 였고 셀 가중 CI 가 모두 0 보다 컸다(G1, A16–A19). 4분 판정의 열세는 n 100(+1.65 cm, A17)이다. 전이 조건 러시아 E S4 n 10 은 반대로 블록 등가중 CI 만 0 보다 크다(D10). 셀 가중은 채점 셀이 많은 블록에 무게를 두고, 블록 등가중은 블록마다 같은 무게를 둔다.
5. **추출 조건부 CI**: WF2·WF8 의 CI 는 `h42.region_stats` 가 부르는 `h40.contrast` 로 계산했다(`scripts/3_deep_learning/h42_label_grid_ext.py` 2332–2334행). WRAPUP 4절 '대비' 행에 따르면 이 CI 는 추출 번호로 짝짓고 채점 블록만 재표집하므로, 라벨 집합이 서로 다른 배치 대비에서는 추출 변동을 빠뜨린다. 2.8 에서 L43 2단 CI 로 보면 러시아 W P1 n 10 의 판정이 우세에서 미결정으로 바뀐다. WF8-a 의 캐나다 S4 행(D1)과 WF2 의 S4 행은 2단 CI 를 계산하지 않았다 [미확인: 2단 CI 에서 판정 유지 여부].
6. **효과의 상대 크기(표 값으로 계산)**: 캐나다 S1 RMSE(`rmse_B`) 31.01–31.29 cm 대비 지역 내 이득 2.54–3.21 cm 는 8.1–10.2 % 다(A2, A3, A6, A7. 상한은 반올림 전 값 3.2062 / 31.2922 = 10.25 % 로 계산했다). WF8-a 의 2.39 cm 는 31.16 cm 대비 7.7 % 다(D1). 알래스카 하위 지역의 0.32–0.77 cm 는 1.9–5.4 % 다(A9–A13, A15).
7. **S4 의 공변량 공간**: S4 는 x25(표준화, 변수 가중 없음)의 거리에 의존한다. 다른 공변량 집합, 변수 가중, 고해상 입력에서는 시험하지 않았다.
8. **추출 짝의 예외**: WF 계획서 개정 이력 2026-10-01 하네스 구현 항목 3 은 'S5 는 결정적이라 첫 추출만 적합하고 S1 의 추출 평균과 비교한다' 고 적었다. 실제로는 같은 라벨 집합의 중복 추출을 전략과 관계없이 건너뛰고, S5 의 저장 추출 수는 (분할, n)마다 1–5개다(2.0, 3.1). 추출이 2–4개 남은 분할이 있는 행은 S1 도 그 추출 번호로 제한되어 `rmse_B` 가 다른 전략 행과 다르다. S5 24행 가운데 18행(예: F1 14.35 대 A24 14.33), S4 의 A11(16.55 대 16.50), S7 의 G23(16.74 대 16.73)이다. 이 행들의 Δ 는 다른 행과 같은 짝 구조가 아니므로 전략 사이의 직접 비교에 쓸 때 이 점을 적는다.
9. **레시피 범위**: C6 의 근거는 R1(λ 0.25) 대비다. 같은 전략의 P1·D1 대비는 W 와 W2 에 보조 행으로 있으나 이 묶음에서 요약하지 않았다.
10. **플랫폼**: 모두 CatBoost CPU 와 해석식이다. 신경망·GPU 학습기 결과와 섞지 않는다.
