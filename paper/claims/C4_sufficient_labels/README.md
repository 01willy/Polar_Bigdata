# C4 충분 라벨 지역 안의 이득

**성격**: 주장 C4 의 근거 색인이다(2026-10-04 작성, 같은 날 점검 지적 반영 개정, 8절). 기존 스크립트·자료·문서는 고치지 않았다. 이 폴더에는 이 README, 근거 수치 추출 스크립트 `extract_evidence.py`, 그 산출 `evidence_values.csv`(1,008행), 원천 집계 표 사본 `tables/`(목록과 sha256 은 `tables/MANIFEST.csv`)만 있다.

**수치 규칙**
- 2절의 수치는 원칙적으로 `extract_evidence.py` 가 `tables/` 사본에서 읽은 값이다. 소수 둘째 자리 반올림이다. 문서 문장에서 옮긴 수치는 없다. 예외는 두 가지다.
  - O7 은 스크립트가 저장소 원천 `results/rescale_lg/data/processed/lg/lg_curve.csv` 를 직접 읽는다. 7.1 MB 라 사본을 두지 않았고, sha256 과 크기는 `tables/MANIFEST.csv` 의 사본 없음 행에 적었다.
  - 2026-10-04 개정(8절)에서 더한 값은 해당 행에 적은 원천(사본이 있으면 사본)에서 이번 점검 때 직접 읽었고 `evidence_values.csv` 에는 없다. `lg_targets.csv` 도 사본 없이 원천을 읽었고 sha256 을 `tables/MANIFEST.csv` 에 적었다.
- 파생값(줄일 수 있는 오차 비율, RMSE 개선률, 순위상관)은 원천 열의 산술이고 계산식을 함께 적었다.
- '이번 점검(사후)'은 이 폴더를 만들며 원천 열에서 읽거나 계산한 값이다. 판정이 아니다.
- Δ(A − B) = RMSE(A) − RMSE(B)(cm)이다. 음수면 A 가 더 정확하다.
- 4분 판정(WRAPUP 0.5, WF 계획서 1절)
  - 우세·열세: 셀 가중 95 % CI 와 블록 등가중 95 % CI 가 모두 0 의 같은 쪽에 있다.
  - 동등: 우세·열세가 아니면서 네 끝값의 절댓값이 모두 0.5 cm 이하다(WRAPUP 0.5 '그 밖에서'). 따라서 네 끝값이 모두 0.5 cm 이하여도 두 CI 가 0 의 같은 쪽이면 우세·열세다(이 README 의 표에서는 E1.R2.n200·n500 우세, E7.D1x34.n500 열세. E7.D1x34.n1000 은 셀 가중 CI 상한이 0.53 이라 해당하지 않는다).
  - 미결정: 그 밖이다. '구별하지 못함'이며 '효과 없음'이 아니다.
- 재표집은 10,000회다(`tables/wf2b_meta.json` 의 `nboot`).

**기호**

| 기호 | 뜻 |
|---|---|
| P0 | 다른 지역 원천 계수의 Stefan 식(지역 내 시험에서는 참조) |
| P1 | 같은 라벨로 재보정한 Stefan 식(κ 10 수축) |
| Pbest | P1, P2, Pk, Pc 가운데 라벨 안 교차검증으로 고른 물리 보정식 |
| R1 | 재보정 앵커 + 잔차 CatBoost(`catboost_lo`). λ cv 는 라벨 안 교차검증으로 고른 잔차 가중 |
| R2 | 물리 증강 + 앵커 + 잔차 |
| Re | Stefan·CCI 평균 앵커 + 잔차(대회 최선 구성) |
| D0 | 직접 ML(`catboost`, 기본 용량) |
| D1 | 물리 증강 직접 ML |
| x25, x34 | 공통 공변량 25종, SAR 9열을 더한 34종 |

### 1.3 권고 문장

**국문**
> 라벨이 수천 개인 알래스카에서 0.5° 블록의 절반을 채점에 남긴 지역 내 시험(분할 25회)을 했다. 재보정 앵커 위의 잔차 ML(R1, 잔차 가중 교차검증)은 같은 라벨로 재보정한 Stefan 식(P1)보다 라벨 1,000개에서 RMSE 가 0.54 cm 작았다(14.41 → 13.87 cm, 두 가중 우세). 오차 하한 11.31 cm 위의 줄일 수 있는 오차 제곱으로는 19 % 를 줄였다. 라벨 500개와 전량에서도 0.39·0.52 cm 작았다(두 가중 우세). 다만 분할 간 독립을 가정하지 않는 보조 CI 에서는 구별되지 않았다. 레나(라벨 약 1,500개)와 캐나다(약 380개)에서는 P1 과 구별되지 않았다. 알래스카에서 SAR 공변량 9열을 더해도 R1 의 오차는 라벨 500–5,000개(분할 5회)에서 ±0.5 cm 안으로 같았다. 이 시험은 첫 시험(분할 5회, 최선 물리 보정식 대비, 라벨 1,000개 이상, R1·R2)이 기각된 뒤 설계한 검정력 보강 시험이다. 첫 시험에서 비교 상대(최선 물리 보정식에서 P1 로), 분할 수(5회에서 25회로), 레시피 집합(Re·D0 추가), 라벨 수 범위(200·500개 추가)를 바꿨다.

**영문 초안(원고용)**
> In a within-region test in label-rich Alaska (half of the 0.5° blocks held out for scoring, 25 splits), the residual model on a recalibrated Stefan anchor (R1, cross-validated residual weight) reduced RMSE relative to the Stefan model recalibrated on the same labels (P1) by 0.54 cm at 1,000 labels (14.41 to 13.87 cm; both weightings). This removed 19% of the squared error above the error floor of 11.31 cm. Reductions at 500 and all labels (0.39 and 0.52 cm) were also significant under both primary weightings but not under the auxiliary common-resampling interval. In Lena (about 1,500 labels) and Canada (about 380 labels), R1 and P1 were indistinguishable. Adding nine SAR covariates left R1 error unchanged within ±0.5 cm at 500–5,000 labels (5 splits). This power-boosting test was designed after a first test (5 splits, against the best cross-validated physics calibration, 1,000 or more labels, R1 and R2) had been rejected. Relative to that test, it changed the comparator (to P1), the number of splits (5 to 25), the recipe set (Re and D0 added) and the label range (200 and 500 labels added).

## 5. 단서와 쓰지 않을 문장

### 5.1 단서

1. **지역 수**
   - 지역 내 시험 대상은 3곳이다. 우세가 나온 곳은 알래스카 1곳이다.
   - 레나·캐나다의 라벨 전량은 약 1,480개, 380개다(O6).
   - 하위 지역 AL-2 의 우세(2.4)는 서술 대상이고 분할 5회다.
2. **사후 설계**: 1.2 (c). WF1-a 기각 뒤 비교 상대, 분할 수, 레시피 집합, 라벨 수 범위를 바꾼 시험이다.
3. **비교 상대 의존**
   - P0 대비로는 알래스카 R1 이 셀 가중으로 낫고 블록 등가중으로 나빠 미결정이다(O2).
   - 블록 등가중에서는 P1 자체가 P0 보다 1.18 cm 나쁘다.
   - 캐나다는 지역 내에서 P1 과 주 대비 레시피(R1·R2·Re 의 λ cv)와 D0 가 모두 P0 보다 나빴다(n 200·전량, O3). Pbest(n 200), Pc 계열, Pk, λ 0.5 의 일부 행은 P0 와 미결정이다. C2 점검의 '캐나다는 P1 자체가 나쁜 곳(라벨 위치 이질성)'과 같은 현상이다(1.2 (a)).
4. **CI 방식 의존**: n 500·전량의 우세는 공통 재표집 CI 에서 유지되지 않는다(O1).
5. **크기**
   - 우세 행의 크기는 0.39–0.54 cm 다.
   - R2 는 0.20–0.42 cm 이고 모두 '0.5 cm 미만' 표지가 붙었다.
   - 하한 11.31 cm 는 v3 알래스카 셀 13,333개로 추정한 공변량 조건부 값이다(DEM 계열 입력 제외, LG 6A.3 N2).
   - 대회 수치(`s4_residual_results.csv` 의 `n` 13,606)에 같은 하한을 쓰는 것은 같은 라벨 집합을 가정한 근사다.
6. **대회 수치의 성격**
   - 대회 13.33 cm 는 `D_indomain` 에서 λ > 0 인 56행(E8.contest.nrows_lam_pos) 가운데 최솟값이다(E8.contest.min). 선택 낙관이 들어 있다.
   - Stefan 14.46 cm 는 λ 0 행이다.
7. **λ 교차검증**: 레나·캐나다에서는 고정 λ 0.25 보조 행이 두 주 가중에서 우세이고 교차검증 λ 주 행은 미결정이다(O4). 고정 λ 0.25 행도 공통 재표집 CI 에서는 레나 n 200 과 캐나다 전량이 미결정이다(O4). 교차검증으로 λ 를 고르는 잡음이 이득을 지웠을 수 있다[해석]. 사후에 본 차이이므로 주 판정을 바꾸지 않는다.
8. **직접 ML 과 R2 전량**
   - D0 − P1 은 셀 가중 CI 가 0 위, 블록 등가중 CI 가 0 아래다(n 500·1,000·전량). 두 가중이 반대 방향으로 갈려 미결정이다.
   - R2 전량도 같다(0.70 [0.06, 0.90] 대 −0.48 [−0.88, −0.08]).
   - 큰 블록에서는 나쁘고 작은 블록들에서는 낫다는 뜻이다[해석].
9. **Stefan·CCI 앵커(Re)**
   - 알래스카 지역 내 n 200–1,000 에서 P1 보다 열세다.
   - 캐나다는 셀 가중 −2.13 / 블록 등가중 +2.17 로 갈려 미결정이고, P0 대비로는 열세다(O3).
10. **SAR**
    - 판정은 R1 에 SAR 을 더한 효과에 한정된다.
    - 물리 증강 직접 ML(D1)에 더하면 n 500–5,000 에서 0.24–0.81 cm 열세였다(보조).
11. **이득의 출처**: 알래스카 지역 내 이득의 대부분이 격자 사이 성분이라는 분해(WF9)는 C8 폴더에 둔다. C4 에서는 인용만 한다.
12. **전이 조건과의 관계**
    - '전이 조건에서는 알래스카 라벨을 다 써도 P1 과 구별되지 않는다'는 원천 가중 기본(α 1) 행에만 맞는다.
    - 원천 가중 α 10·100·cont 곡선 행은 두 CI 가 모두 0 아래다(O7, 판정 아님).
