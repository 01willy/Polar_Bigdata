## 3. 미해결 항목(정정하지 않음)

1. **P 기호 표기**: intro.tex 는 `$P = 0.001$`(수식 기울임), results_*.tex 는 `\textit{P}` 를 쓴다. 렌더 결과는 둘 다 기울인 대문자 P 이지만 원고 조립(numbers.tex 매크로) 때 한 가지로 통일할 항목이다.
2. **도 기호 표기**: intro.tex 는 `$^{\circ}$`, results_*.tex 는 유니코드 `°` 를 쓴다. xelatex·pdflatex(utf8) 모두 컴파일되나 조립 때 통일할 항목이다.
3. **단어 수**: 결과 절 합계 약 3045단어로 명세 목표 2800 을 넘는다. 명세 10절은 렌더 PDF 기준 측정을 요구하므로 이 기록의 수치는 참고값이다.
4. **티베트 R1 − P2 의 CI 원천**: 원고는 L38 행(SI_learners README)을 쓴다. C2 README TB3 는 L4e PE2 행을 인용하며 CI 끝값이 다르다(5.7 대 6.1, 30.1 대 30.2, −11.8 대 −12.1, 16.8 대 17.0). 명세 4.7 표는 두 README 를 함께 인용하므로 어느 행을 정본으로 할지 build_numbers.py 에서 정해야 한다. 판정(미결정)과 점추정(19.1)은 같다.
