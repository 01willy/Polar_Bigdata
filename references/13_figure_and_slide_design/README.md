# 13 · 그림·슬라이드 설계 문헌

학술지 그림 규격, 색지도, 자료 표현, 연구 발표 슬라이드 설계의 근거 문헌이다. 규칙 정리와 인용문은 `docs/research/2026-10-04/figure_slide_standards.md` 에 있다. PDF 는 git 에서 제외된다(`references/**/*.pdf`).

## 읽는 순서

1. 그림 일반: Rougier 2014 → Midway 2020(링크) → Weissgerber 2015
2. 색: Crameri 2020 → Thyng 2016 → Stoelzle & Stein 2021 → Kovesi 2015 → Nuñez 2018 → Crameri 2018(GMD, 색지도 원 출처)
3. 영상·지도 그림: Jambor 2021
4. 슬라이드: Alley & Neeley 2005 → Alley et al. 2006 → Garner & Alley 2013 → Naegle 2021 → Bourne 2007 → Lortie 2017
5. 슬라이드 인지 근거(심화): Garner et al. 2009 → Kosslyn et al. 2012 → Garner & Alley 2016
