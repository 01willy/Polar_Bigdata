# 저널급 원고·그림·보고 덱 양식 지침

작성 2026-10-04, 1차 개정 2026-10-04(적대 점검 2건 반영, 내용은 끝의 '개정 이력'). 이 문서는 다음 산출물이 따라야 하는 구속 지침이다.
- Scientific Reports(이하 Sci Rep) 투고 원고(영문판, 국문판)
- 본문 그림 7개와 표 1개, SI 그림·표
- 보고 덱(국문)

새 산출물은 이 문서를 따른다. 기존 프로젝트 규칙과 충돌하면 0.3절의 결정을 따른다. 사용자 전역 지침(`~/.claude/CLAUDE.md`, `~/.claude/rules/visual-artifacts.md`, `~/.claude/rules/writing-tone.md`)과 사용자의 직접 지시는 이 문서보다 우선한다. 사용자가 확정한 덱 문법(`deck/deck_spec_final.json`의 `meta.style_tokens`, 개정 이력 v2–v9, digest 2절의 [사용자] 규칙)도 사용자 지시로 본다. 이 문서가 확정 문법과 다르게 정한 항목은 5.0절 표에 모두 적었다. 표에서 '제안'인 항목은 사용자 확인 전까지 확정 문법을 따른다. '변경(보고)'인 항목은 사용자 지시가 아니라 기록 토큰(meta 값)을 근거와 함께 바꾼 것이며, 첫 시안과 함께 사용자에게 보고하고 사용자가 되돌리면 확정값으로 돌아간다. 슬라이드 원형별 좌표와 덱 배치 예시는 `design/slide_archetypes.md`에 둔다.

표기 규칙
- **[미확인]**: 원문으로 확인하지 못한 값이다.
- **[판단]**: 근거 문헌이 수치를 직접 주지 않아 이 문서가 정한 값이다.
- **[측정]**: 이 문서를 쓰면서 직접 잰 값이다.
- **[검토 보고]**: 2026-10-04 적대 점검 보고가 잰 값으로, 이 문서가 다시 재지 않은 값이다.
- 근거 약호는 0.5절에 있다. 사용자 지적 번호(SL-01, PF-01 등)는 `design/user_feedback_digest.md` 2절의 번호이다.
- **내부 약호**: P0(원천 계수 Stefan), P*(연도 정합 Stefan), P1(재보정 Stefan), R1(재보정 앵커 + 잔차 ML), D0(직접 ML), D1(물리 유사라벨 증강), W(대상 라벨 교차검증 선정 규칙)는 `paper/claims/`의 내부 약호이다. 이 문서 안에서만 쓰고 그림, 슬라이드, 원고 본문에는 쓰지 않는다(H3). 원고의 결과 절 번호는 방법 약호 R1과 구분하려고 '결과 절 R1'처럼 '결과 절'을 붙여 쓴다. 0.3절의 결정 번호는 'R-01'처럼 하이픈을 붙인다.

### 0.4 작업 순서

1. **주장 문장 확정**: `paper/claims/Cx_*/README.md`의 축소판 제안 문장(영문 한 문장, 국문 한 문장)을 쓴다. 그림 설명문 첫 문장, 결과 소절 첫 문장, 슬라이드 결론 줄은 이 문장을 옮긴다. 한정어(학습기 수, 풀 지역, 사후 서술, 분할 독립 가정 의존)를 빼지 않는다.
2. **스펙 작성**: 그림은 `figures/figure_spec.json`에 v3 항목을 둔다. 항목에는 메시지, 주장 ID, mm 배치, 주 패널 면적 비율, 원천 표, 참고한 모범 그림, QA 결과를 적는다. 덱은 `deck/<행사명>/deck_spec.json`에 쪽마다 원형, 제목, 부제, 결론 줄, 근거 그림, 노트, 출처를 적는다. 결과 지도 계획(1.2절 표)을 그림 스펙에 먼저 적는다.
3. **생성**: 그림은 코드로만 만든다. 그림 함수는 매체 인자(`medium="paper"` 또는 `"slide"`)를 받고, 같은 자료·색표·범위로 두 매체를 그린다.
4. **렌더**: 논문 그림은 PDF·SVG·PNG, 덱은 PPTX와 PDF(한글·라틴 자동 간격을 끈 LibreOffice 경로, 5.6절)로 낸다.
5. **QA**: 7절 점검을 돌린다. 시각 검토는 최종 인쇄 크기(그림 170 mm, 슬라이드 원본 크기)에서 한다.
6. **수정**: 결함을 고친 뒤에만 완료로 보고한다.

## 1. 원칙

### 1.1 주장 우선

- 그림 하나, 슬라이드 하나, 결과 문단 하나는 주장 하나를 전한다.
- 주장은 그리기 전에 쓴다. 주장이 정해지지 않은 그림은 만들지 않는다.
- 주장의 자리는 매체마다 하나다. 원고 그림은 설명문 첫 문장, 결과 소절은 첫 문장, 슬라이드는 결론 줄(문법 V)이다. 세 문장은 같은 원천(0.4절 1)에서 옮긴다.
- 그림 안에는 주장을 쓰지 않는다. 그림은 주장의 근거만 보인다.
- 주장을 직접 뒷받침하지 않는 패널은 SI로 보낸다.
- **서술 방향**: 원고와 덱의 중심은 라벨 수에 따른 새 지역 워크플로(학습·평가·추가 관측)와 물리 증강·물리 잔차 결합의 라벨 수별 능력이다. '라벨 0에서 직접 ML이 물리식보다 나쁘다'와 '무작위 분할은 과대평가한다'는 중심에 두지 않고 워크플로의 근거로 배치한다(framing P7, MS-02, MS-03). 첫 결과 문장과 첫 결과 쪽은 이 원칙을 따른다(4.2절, 5.8절).

### 1.2 근거 우선과 결과 지도

- 주장에는 그 주장을 판정할 수 있는 최소 근거를 함께 보인다. 최소 근거는 기준선(원천 계수 Stefan의 0선 또는 재보정 Stefan), 정의를 밝힌 불확실성, 단위 수(라벨 수 n, 지역 수)이다.
- **결과 지도**: 공간 결과는 지도로 보인다(PF-02, framing P3 '절대원칙'). 결과 절마다 지도를 2종 이상 둔다(본문 또는 SI). 본문 그림 가운데 결과 지도를 조건 없이 포함하는 그림은 3개 이상이다(Fig 5, Fig 6, Fig 7). 자료·설계 지도(Fig 1)는 이 수에 넣지 않는다. 결과 지도는 아래 표대로 계획하고, 조건부 지도는 이 수에 넣지 않는다.
- 결과 지도는 관측 우선순위(어디를 재야 하는지)를 순위로 보이지 않는다. 등록 규칙에 따라 이 지도는 내지 않는다(C6 README, WF 계획서 5.1).
- 모든 수치는 원천 표에서 생성한다. 원고는 `numbers.tex` 매크로, 그림은 `source_data` CSV를 거친다. 손으로 옮긴 수치는 0개이다(PF-08).
- 개념 설명도 실제 자료 위에 그린다(2.10절).

### 2.2 글꼴과 글자

- **글꼴**: Arial 계열 한 가지이다. 이 서버에는 Arial이 없으므로 Liberation Sans(Arial 메트릭 호환)를 쓴다 [측정: `fc-list`]. `pdffonts` 결과의 글꼴 계열은 그림마다 1개, 원고 전체에서 1개이다. Type 3 글꼴은 0개이다. `pdf.fonttype 42`, `svg.fonttype none`.
- **크기**: 모든 글자를 7 pt 한 가지로 쓴다. 축 라벨, 눈금, 직접 라벨, 범례, 컬러바, 패널 문자가 모두 7 pt이다. Sci Rep의 "Use the same typeface in the same font size for all figures"를 그대로 따른다.
- **패널 문자**: 7 pt 굵은 직립 소문자(a, b, c)이다. 위치는 각 패널 슬롯의 왼쪽 위 끝이고 같은 행의 패널 문자는 같은 높이에 둔다. 패널 문자는 읽는 순서(위 행 왼쪽에서 오른쪽, 다음 행)대로 매긴다.
- **첨자**: 그림 안에서는 0개이다. matplotlib 수식 첨자는 7 pt × 0.7 = 4.9 pt가 되어 Nature 하한 5 pt보다 작다. Liberation Sans에는 유니코드 아래첨자 숫자(U+2080–2089)도 없다 [측정: fontTools cmap]. 그림에서는 기호 대신 이름("Source coefficient")을 쓰고, 기호의 정의는 설명문에서 LaTeX 첨자로 쓴다(R-26). 지수가 든 단위는 풀어 쓴다(예: "E (cm per √(°C d))").
- **굵게와 기울임**: 굵게는 패널 문자에만 쓴다. 기울임은 한 글자 변수(n, E, z)에만 쓴다.
- **대소문자**: 라벨은 첫 글자만 대문자이다("Target labels, n").
- **글자 색**: 검정 #000000이 기본이다. 마스크 영역 이름 같은 보조 표지와 방향 표지만 #4d4d4d(흰 바탕 대비 8.5:1)를 쓴다. 그 밖의 회색 글자와 색 글씨는 쓰지 않는다(Nature "Coloured text").
- **숫자**: 네 자리 수는 쉼표 없이(1000, 3037), 다섯 자리 이상은 쉼표를 쓴다(13,606). 음수는 U+2212(−)이다. 숫자와 단위 사이는 한 칸이다(13.3 cm, −1.5 °C). 백분율은 붙여 쓴다(95%) [판단: Nature 문체]. 좌표는 "70° N"으로 쓴다.
- **그림 안 수치**: 눈금, 컬러바 눈금, 축척 길이, 크기 열쇠 값만 둔다(R-25).
- **글자 겹침**: 글자끼리, 글자와 자료가 겹치는 곳은 0곳이다. 복잡한 영상 위에 글자를 얹지 않는다.

### 2.3 선과 마커

모든 선은 최종 크기에서 1.0 pt 이상이다(Sci Rep 원문). 가늘게 보여야 하는 선은 굵기를 줄이지 않고 색을 옅게 한다. 게재된 Sci Rep 그림의 축과 틀 선은 약 0.24–0.72 pt로 측정되었다(Khanal 2023, Fisher 2023, 301 ppi JPEG 근사) [검토 보고]. 1 pt 규칙은 문구대로 지키되, 밀집한 선 요소는 개수를 줄여 그림이 무거워지지 않게 한다.

- **색각 검증**: 위 7색(#4d4d4d, #2b5c8f, #9a7bc9, #568f72, #6b7280, #ad921a, #84480c)의 모든 쌍을 정상, 1형(prot), 2형(deut), 3형(tritan) 색각 모사(Machado 2009 severity 1.0) 뒤 CIEDE2000으로 비교했다. 최소 ΔE00은 14.1(#2b5c8f와 #6b7280, 1형)이다 [측정: `src/polar/cvd.py` + 3형 행렬]. 흰 바탕 대비는 모두 3:1 이상이다(가장 낮은 #ad921a 3.04:1). 초판 색 #2e6b2e는 3형에서 #2b5c8f와 ΔE00 7.8이라 바꾸었다(R-23).
- **흑백 판독**: 흑백에서는 명도가 비슷한 쌍(#9a7bc9 L* 57과 #568f72 L* 55, #2b5c8f L* 38과 #84480c L* 37)이 있다. 이 쌍은 선 모양이 다르고, 계열이 5개 이하인 패널은 선 끝 직접 라벨로 이름을 단다. 흑백 렌더에서 모든 계열을 선 모양과 라벨로 구분할 수 있어야 한다(F-09).
- **모양**: 모양은 지역만 뜻한다(2.5절). 방법 곡선의 측정점은 모두 같은 원 마커이다. 배치 전략은 선 모양과 직접 라벨로 구분한다(6.5절). 따라서 같은 모양이 그림마다 다른 뜻을 갖지 않는다.
- **이름**: 그림에는 '그림 짧은 이름'을 쓰고 원고 Methods에서 영문 원고 이름과 한 번 대응시킨다. 원고 본문은 영문 원고 이름이나 그 줄임(예: "the recalibrated Stefan model")을 쓰고 내부 약호를 쓰지 않는다(H3).
- **주황**: 덱 강조색 #EA851B는 자료 표현에 쓰지 않는다.
- **새 방법**: 본문 그림에 새 방법을 넣으려면, 색을 정하기 전에 공존하는 모든 색과의 4종 색각 모사 ΔE00 12 이상과 흰 바탕 대비 3:1 이상을 확인하고 이 표에 적는다. `src/polar/cvd.py`에는 3형 행렬이 없으므로 더한다(8절 3). 이 7색과 검정에 새 색을 더하면 4종 색각 ΔE00 12를 넘는 후보가 거의 없다 [측정: RGB 8단계 격자 탐색 최댓값 12.7]. 다원천 적층(XB)은 기존 색 가운데 같은 계열 색 + 다른 선 모양을 우선 검토한다.

### 2.7 불확실성

- **정의**: 모든 설명문에 구간의 종류, 재표집 단위와 횟수, 가중 방식을 적는다(Sci Rep "Include a description of the statistical treatment of error analysis in the figure legend").
- **포레스트**: 점, 셀 가중 CI(굵게), 블록 등가중 CI(가늘게), 0선, ±0.5 cm 동등 띠를 그린다. 등록 4분 판정은 이 요소에서 읽힌다. 두 CI가 0의 같은 쪽에 있으면 오차 감소 또는 증가, 두 CI가 띠 안에 있으면 동등, 그 밖은 미결정이다. 굵은·가는 막대와 띠의 뜻은 그림 안 열쇠 한 줄로 보인다(4.4절).
- **판정 표시**: 판정 기호, 판정표, AB·L 표지는 본문 그림에 두지 않는다. Holm 보정처럼 그림에서 읽을 수 없는 판정은 설명문 한 문장과 SI 판정표에 둔다.
- **곡선**: 중앙값 또는 평균 선과 CI 띠를 그린다. 띠는 패널당 2개 이하이다. 나머지 계열의 띠는 SI 짝 그림에 둔다.
- **소표본**: 지역 4–7개의 평균에는 지역별 점을 함께 그린다(Weissgerber 2015, Sci Rep "Ranges are more appropriate than standard deviations or standard errors for small data sets").
- **관측 대 예측**: 1:1 실선, 구간 막대(정의 명시)를 둔다. RMSE, 포함률 같은 통계는 설명문에 쓴다(R-25). Langer 2024 Fig 3b의 패널 안 통계 4줄은 따르지 않는다.
- **지도**: 예측과 구간 폭을 다른 패널(oslo_r, acton_r)로 그린다. 관측 잔차는 예측 지도 위 bam 원으로 겹친다(2.6절). 이변량 색표는 쓰지 않는다.
- **절단 값**: 축 범위 밖 값은 축 끝의 작은 삼각 표지(검정, 3 pt)로 표시하고 값은 설명문에 적는다(R-25). 표지가 둘 이상이면 축 범위나 패널 분리를 다시 정한다.

### 2.8 범례와 컬러바

- 계열이 5개 이하이면 선 끝이나 점 무리 옆에 직접 라벨을 단다(Biskaborn 2019 Fig 1b, Aalto 2018 Fig 2). 라벨은 검정 7 pt, 1–3 단어(2.4절 짧은 이름)이다. 직접 라벨 열 폭은 그 패널에 다는 라벨 가운데 가장 긴 것의 실측 폭 + 1.5 mm로 정한다. 2.4절 짧은 이름의 7 pt 폭은 10.5 mm("Direct ML")에서 27.5 mm("Source anchor + residual")이다 [측정: Liberation Sans 7 pt, matplotlib 렌더 폭].
- 범례가 필요하면 그림당 1개, 테두리 없이, 자료가 없는 패널 안 빈 곳이나 그림 위 한 줄에 둔다. 항목은 6개 이하이다.
- 범례를 패널마다 반복하지 않는다(Burke 2020 Fig 9 반례).
- 컬러바는 양마다 1개이다. 같은 양을 그린 패널은 컬러바 하나를 공유한다. 위치는 지도 바깥 아래(가로) 또는 오른쪽(세로)이고, 두께 2.5 mm, 길이는 공유 패널 폭 또는 높이의 60–100%, 눈금 3–5개, 라벨은 "ALT (cm)" 형식이다.
- 범북극 지도의 영구동토 구역은 지도 안 빈 구석에 견본 2개("Continuous", "Discontinuous")로 보인다. 원 크기 열쇠(3단계 중첩 원)와 같은 구석에 두고 두 열쇠의 합은 2줄 이하이다.
- v2 그림 위의 판정 기호 범례 줄(2–3줄)은 없앤다.

### 2.10 개념도와 도식

- **논문 그림**: 상자 안에 글씨를 넣지 않는다(0개). 허용하는 상자는 1.4절 H1의 세 가지(썸네일 테두리, 확대 사각형, 표 규칙선)뿐이다. DG-01이 허용한 셰브런과 네트워크 연산 블록은 논문 그림에 쓰지 않는다(Sci Rep "avoid excessive boxing", 모범 그림 관행).
- **덱 도식**: 과정을 보여야 하는 덱 도식은 사용자 확정 v7 문법을 그대로 쓴다(5.0절). 이 덱의 기본 원형(A8 개념 좌표도, A9 워크플로 경로)은 좌표와 자료 위에 그리므로 과정 상자가 필요 없다.
- **물리 개념은 실제 좌표 위에 그린다.** 예: √TDD(x)와 ALT(y, 아래로 깊어짐) 축 위에 실제 라벨 점, 원천 계수와 재보정 계수의 직선, 잔차를 뜻하는 수직 선분을 그리고 이름("Source Stefan", "Recalibrated Stefan", "Residual")을 요소 옆에 직접 단다(Burke 2020 Fig 1, Biskaborn 2019 Fig 7). 보정하는 대상(계수 E, 잔차)만 방법 색으로 칠한다(Langer 2024 Fig 1의 강조 방식).
- **평가 설계는 실제 지도 확대로 그린다**(Ploton 2020 Fig 3). 실제 지역 경계, 100 km 완충 파선, 실제 0.5° 블록(라벨 블록 #bdbdbd, 채점 블록 #737373), 라벨 점을 그린다. 확대 범위는 2.11절의 블록 폭 조건을 만족해야 한다.
- **워크플로는 실제 결과 위의 경로로 그린다**(Fig 7d, 덱 A9). x축은 라벨 수, y축은 각 구간 권고 방법의 오차 변화(원천 계수 Stefan 대비)이다. 구간마다 권고 방법의 실제 값 선분을 그 방법의 색과 선으로 그리고, 선분 옆에 방법 이름(1–3 단어)을 한 번 단다. 같은 방법이 여러 구간에 이어지면 선분 하나, 라벨 하나이다. 구간 경계에서 방법이 바뀌면 선을 잇지 않는다. 그 아래 관측 띠에 배치 전략을 구간을 가로지르는 검정 선(2.0 pt)과 라벨 하나로 보인다. 글자 칸의 격자(행 × 구간)는 쓰지 않는다. 순서도 상자, 마름모, 신호등 색, 셰브런을 쓰지 않는다(Karjalainen 2019 Fig 1, Tsai 2021 Fig 1, Hall 2026 Fig 2 반례).
- **실데이터 썸네일**: 덱에서 과정이나 요약을 보일 때는 추상 상자 대신 실제 결과 그림의 축소판을 쓴다(DG-05, deck_spec v2·v4·v5). 축소판은 배치 크기로 다시 그려 글자가 5.3절 하한을 지키거나, 글자 없는 판으로 만든다.
- **화살표**: 수평·수직 직선과 직각 꺾임만 쓴다. 종류는 2개 이하(자료 흐름 실선 1.0 pt, 덱의 학습 전용 적색 파선은 v7 문법)이고 끝이 대상 경계에 닿는다. 장거리 파선 우회, 끊긴 화살표, 떠 있는 화살표 머리를 쓰지 않는다. 관계가 멀면 화살표 대신 같은 이름과 같은 색으로 잇는다(DG-02, v6 '장거리 우회 경로 제거').
- **강조 사각형**: 지도나 영상의 강조 사각형은 시각적으로 자명한 위치(차이가 눈에 보이는 곳)에 두고, 비교 패널에서는 모든 패널의 같은 좌표에 둔다(SL-10). 지표가 가장 좋은 위치를 고르지 않는다.
- **라벨**: 요소 위나 옆에 1–3 단어로 단다. 기호는 설명문에서 정의한다.
- **원본 그림**: 사용자가 직접 저장한 그림 원본(예: 워크플로 pptx)은 다시 그리지 않고 그대로 쓴다(PR-07).
- 아이콘, 클립아트, 생성형 이미지는 0개이다.

### 2.12 축과 수치

- 축 라벨은 "Variable (unit)" 형식이다. Δ 축은 기준을 이름으로 넣는다("Error change vs source Stefan (cm)"). 기호(P0)를 쓰지 않는다.
- 한 축에는 척도 하나만 쓴다. symlog와 "log scale beyond ±2 cm" 같은 혼합 축은 쓰지 않는다(baseline 5절 우선순위 14). 범위가 크면 패널 분리로 처리하고 척도 설명은 설명문에 둔다.
- **라벨 수 축(R-24)**: n ≥ 3은 log10 축이고 눈금은 시험 격자 값(3, 10, 40, 160, 320, 1000)에만 둔다. n = 0은 왼쪽의 좁은 별도 축(폭 6 mm, y 공유, 간격 2 mm), 전량('All')은 풀 평균 패널에서만 오른쪽의 좁은 별도 축(폭 6–8 mm)에 둔다. 두 별도 축과 본 축 사이를 선으로 잇지 않는다. 지역마다 '전량'의 n이 다르므로 지역 패널에는 전량 축을 두지 않는다(값은 SI 표).
- **눈금 라벨 간격**: 눈금 라벨 사이 간격은 1.5 mm 이상이다. 폭 38 mm 안팎의 작은 다중 그림은 라벨을 10, 40, 160, 1000에만 단다(눈금은 남긴다). 7 pt '1000'의 폭은 5.5 mm, '320'은 4.1 mm이다 [측정].
- 막대그래프의 세로축을 자르지 않는다(Sci Rep).
- 원그래프, 레이더 차트, 3차원 막대, 이중 y축을 쓰지 않는다(Tsai 2021 Fig 7a, Nitzbon 2024 Fig 2 반례, DR 레이더 반례).
- 유효 숫자는 축마다 같게 둔다.

### 2.13 내보내기와 기록

- **형식**: PDF(`pdf.fonttype 42`, 글꼴 내장, 윤곽선 변환 없음)가 정본이다. SVG(`svg.fonttype none`)와 PNG 600 dpi(검토용)를 함께 낸다. EPS는 쓰지 않는다. 근거는 EPS가 alpha 투명도를 담지 못한다는 점이다(우리 그림은 CI 띠와 관측 원에 alpha를 쓴다). Sci Rep 지침은 EPS·AI 벡터를 예로 들므로, 제작부가 EPS를 요구하면 투명도를 평탄화한 변환본을 따로 만든다 [미확인: 최종본의 PDF 수용 여부]. 이 서버의 xelatex EPS 변환 실패(scirep_fmt 5.2)는 빌드 문제일 뿐 형식 결정의 근거가 아니다.

- **파일**: `outputs/figures/paper/v3/FigN_<slug>.{pdf,svg,png}`, 패널별 그림 값은 `outputs/figures/paper/source_data/v3/FigN_<panel>.csv`, 설명문은 `outputs/figures/paper/CAPTIONS.md`의 `## v3/FigN_<slug>` 절, 스펙은 `figures/figure_spec.json`의 `paper_v3_figN` 항목이다.

- S4–S6의 문구는 각 주장의 축소판 제안 문장(`paper/claims/C1_*`–`C8_*` 1.3절)에서 옮기고 한정어를 지키지 않으면 쓰지 않는다. 예: S4의 위약 대비는 AB3로 단정형이 가능하다(C1 README 2.3절). '모든 학습기(all ten learners)'는 쓰지 않는다(C1 README 5.2절, 두 CI 판정이 같은 학습기는 5종).
- S5의 알래스카 문장에 판정어를 쓰려면 WRAPUP 1.1 개정이 필요하다(C4 README, 사용자 결정 대기). 결정 전에는 판정어 없이 수치만 쓴다.
- '라벨 0에서 직접 ML이 물리식보다 나쁘다'는 초록의 첫 결과 문장으로 쓰지 않는다(1.1절 서술 방향). 넣는다면 S4 뒤에 조건과 함께 한 구절로 둔다.
- S7은 "highlight the importance", "pave the way" 같은 일반론으로 끝내지 않는다. 적용 조건이나 다음에 필요한 자료를 쓴다(scirep_ex 4.2).

### 4.3 결과 소제목과 첫 문장

**소제목**: 콜론 없는 명사구로 쓴다(0.3절 R-17). 결과의 방향이 모든 지역에서 같고 판정이 확정된 절에 한해 결과를 담은 명사구를 허용한다. 초안은 아래와 같고 결과 확정 뒤 다시 본다. 라벨 구간 이름은 시험 격자 값으로 쓴다(시험하지 않은 n = 1, 2를 포함하는 'one to ten'과 '1–10'은 쓰지 않는다).

| 결과 절 | 영문 소제목(초안) | 국문 소제목(초안) | 주장 |
|---|---|---|---|
| R1 | Evaluation design and validation ladder | 평가 설계와 검증 사다리 | C7(보조) |
| R2 | Transfer without target labels | 대상 라벨 없는 전이 | C1 |
| R3 | Coefficient recalibration with three to ten labels | 라벨 3–10개의 계수 재보정 | C2, C3 |
| R4 | Method selection with tens to hundreds of labels | 라벨 수십–수백 개의 방법 선정 | C5, C3 |
| R5 | Gains within label-rich regions | 라벨이 많은 지역 안의 이득 | C4, C8 |
| R6 | Placement of new labels | 새 라벨의 위치 | C6 |
| R7 | Independent regions | 독립 지역 | C1, C4 일반화 |
| R8 | Prediction intervals | 예측 구간 | 보조 |

**첫 문장 틀**: [Method name] [reduced/increased] [metric] relative to [baseline name] by [Δ] cm (95% CI [a] to [b]; [n] labels; [k] regions) (Fig. [N][panel]).

**문단 순서**: 주장과 수치, 근거의 세부, 조건과 예외, 다음 절과의 연결(필요할 때만 "We next asked ..."). 기전 해석은 고찰에서 한다. 유의하지 않은 결과도 같은 형식으로 쓴다("We did not find evidence that ...").

### 4.4 그림 설명문 틀

1. **제목 문장 1개**: 결과 그림은 주장을 평서문으로 쓴다(20단어 이하). 자료·설계 그림(Fig 1)과 표는 명사구를 쓴다. "This figure illustrates"로 시작하지 않는다.
2. **패널 설명**: (a)부터 순서대로 패널마다 1–2문장이다. 방법 세부는 Methods로 보낸다(Sci Rep "minimise the methodological details").
3. **기호**: 기호의 뜻은 그림 안 열쇠(직접 라벨, 열쇠 한 줄, 견본)로 보이고 설명문은 그 열쇠를 이름으로 가리킨다(Sci Rep "use visual cues rather than verbal explanations such as 'open red triangles'"). "thick bars", "open markers" 같은 모양 서술과 색 이름 서술을 쓰지 않는다. 설명문 안에 기호 자체를 넣어야 하면 LaTeX에서 TikZ로 그린 작은 기호를 쓴다. Liberation Sans에는 ◆, ✚, ★, ⬢, ⬟, ∝ 글리프가 없다 [측정: fontTools cmap].
4. **불확실성 정의**: 구간의 종류와 재표집을 쓴다. 예: "Intervals are 95% block-bootstrap confidence intervals (10,000 resamples of 0.5° blocks), weighted by cell and by block as indicated in the key; the grey band marks ±0.5 cm." 두 가중의 구분은 그림 안 열쇠가 맡는다.
5. **단위 수와 기간**: n, 지역 수, 자료 기간.
6. **통계**: 그림에서 옮긴 통계(ρ, RMSE, 포함률)와 절단된 값(2.7절).
7. **지도**: 투영과 축척 기준 위도, 해안선 자료, 영구동토 구역 자료, 소프트웨어 판.
8. **등록 판정**: 그림에서 읽히지 않는 판정(Holm 보정 등)만 한 문장으로 쓰고 SI 표 번호를 단다. 결과 열람 뒤 분석은 그 사실을 적는다.

설명문은 350단어 이하, 목표 150–250단어이다.

### 4.5 통계 보고 형식

- 형식: 차이(cm) + 95% CI + 단위 수(n, 지역 수) + 검정 이름 + 보정 방법 + 정확한 P.
- 예: "Adding residual ML to the recalibrated Stefan anchor reduced RMSE relative to the recalibrated Stefan model by [Δ] cm (95% CI [a] to [b]; 10 labels; four regions; block bootstrap, 10,000 resamples; Holm-adjusted P = [p])."
- CI는 처음에 "95% confidence interval (CI)"로 풀어 쓴다. 음수 구간은 "−3.1 to −1.8"로 쓰고 en dash를 쓰지 않는다. 표도 같은 표기를 쓴다(3.1절).
- P는 기울인 대문자 *P*로, 정확한 값으로 쓴다("*P* < 0.05"만 쓰지 않는다). 등록 대비는 보정 전과 Holm 보정 값을 모두 낸다.
- **유의 수준과 방향**: Methods에 유의 수준(α = 0.05), 양측 검정 여부, 다중 비교 보정(Holm)을 한 번 적는다(Sci Rep "the alpha level for all tests, whether the tests were one-tailed or two-tailed"). 비열등 검정은 단측이고 한계(0.5 cm)를 함께 적는다.
- **소표본**: 지역 4–7개의 비교는 지역별 값과 범위를 함께 보고하고, 블록 부트스트랩을 쓴 근거(지역 수가 아니라 블록이 재표집 단위)를 Methods에 적는다(Sci Rep "when the sample size is small (less than about 10), you should use tests appropriate to small samples or justify the use of large-sample tests").
- **평균 Δ 병기**: 여러 대상의 평균 Δ를 쓸 때는 중앙값, 유의하게 오차가 줄어든 대상 수와 늘어난 대상 수, 러시아 W를 뺀 값을 함께 쓴다(MS-04, P10). 예: "mean [Δ] cm (median [m] cm; lower error in [a] and higher error in [b] of [N] targets; [Δ'] cm without W Russia)".
- 'significant'는 P 값과 함께만 쓴다. 'robust'는 정의 없이 쓰지 않는다. 조건을 쓴다("unchanged under variants (b) and (d) to (g)").
- ± 뒤의 값이 SD인지 SE인지 적는다.
- **자릿수**: |Δ| < 1 cm는 소수 둘째 자리, 그 밖의 cm 값은 소수 첫째 자리, 상관계수는 둘째 자리, 백분율은 정수로 쓴다 [판단]. 본문, 표, 그림이 같은 자릿수를 쓴다. 신뢰구간의 끝값은 점추정과 같은 자릿수를 쓴다.
- 4분 판정 단어(lower error, higher error, equivalent within ±0.5 cm, undecided)는 Methods에서 한 번 정의하고 등록 대비에만 쓴다.
- 결과 열람 뒤 설계한 분석(WF, XA–XJ)은 해당 문단과 Methods에 그 사실을 적는다(scirep_fmt 4.8). 사후 서술(예: WF0 위험표)은 판정어 없이 쓴다.
- 단정형은 두 CI의 판정이 같은 대비에만 쓴다. 분할 독립 가정에 의존하는 판정은 그 사실을 병기한다(claims README 수치 규칙).

### 4.7 국문 원고 문체

- 사실 서술은 ~이다/~한다, 수행 서술은 ~하였다/~확인하였다로 쓴다. ~입니다/~합니다는 쓰지 않는다(KO-01).
- 한 문장에 주장 하나를 쓴다. 쉼표로 이은 긴 문장은 마침표로 나눈다. 짧은 단문만 늘어놓지 않고 "그러나", "또한"으로 문단 안 논리를 잇는다(WT-05).
- 용어는 첫 등장에서 정의한다. 예: "활동층 두께(active layer thickness, ALT)". 기호와 단위를 함께 쓴다.
- 조사는 라틴 문자, 숫자, 단위에 붙여 쓴다("13.3 cm에서", "Stefan 식보다", "ML의"). 쉼표 앞 공백과 괄호 안쪽 공백은 0개이다. 덱 PDF에서 같은 공백이 보이면 원문이 아니라 렌더 자동 간격이 원인일 수 있으므로 5.6절의 내보내기 경로로 다시 확인한다.
- 숫자 표기는 영문판과 같다. 네 자리 수에 쉼표를 쓰지 않는다(그림 숫자와 맞춘다). 숫자 나열은 '와/과'나 쉼표로 쓴다(H14).
- 용어 대응은 `paper/manuscript/shared/glossary_en_ko.csv` 하나를 쓴다. 정본 용어(KO-05, deck_spec v3·v6): 활동층 두께, 융해 도일(TDD), 원천 계수, 재보정, 물리 잔차 결합, 물리 증강, 유사라벨, 증강 비율, 위성 제품, 레나델타, 3차원(3D 아님), 블록 홀드아웃, 선정('선택' 대신), 4분 판정(오차 감소, 오차 증가, 동등, 미결정).

### 5.0 사용자 확정 덱 문법과의 관계

사용자가 확정한 덱 문법(deck_spec meta와 v2–v9, digest [사용자] 규칙)과 이 지침의 관계이다. 상태는 세 가지이다. '유지'는 확정 문법을 그대로 쓴다. '변경(보고)'는 사용자 지시가 아닌 기록 토큰을 근거와 함께 바꾼 것으로, 이 지침의 값을 첫 시안부터 쓰고 시안과 함께 보고한다. 사용자가 되돌리면 확정값으로 돌아간다. '제안'은 사용자 확인 전에는 쓰지 않는다.

| 항목 | 확정 문법(근거) | 이 지침 | 상태 |
|---|---|---|---|
| 머리 구조 | 주황 볼드 제목(좌상) + 회색 부제 1줄 + 그림 중심 본문 + 하단 한 줄 결론(meta.slide_grammar, v2·v3, SL-04) | 문법 V로 그대로 쓴다. 쪽의 주장은 결론 줄이 맡는다 | 유지 |

### 5.4 색

- 배경은 모든 쪽에서 흰색 #FFFFFF이다(SL-08).
- 주황 #EA851B는 제목 런과 쪽당 1곳에만 쓴다. 1곳은 핵심어(3단어 이하) 또는 수식·지표 라벨이다(SL-08, CO-04, v9). 주황 문장, 주황 화살표, 주황 글머리 점, 주황 결론 줄은 쓰지 않는다.
- 차트 색은 2.4절 방법 색 코드와 2.6절 색표를 그대로 쓴다. 같은 자료는 논문 그림과 같은 색표, 같은 범위를 쓴다.
- 본문 글자는 잉크 #111111이다. 방법 이름을 색 글씨로 쓰지 않는다. 방법과 선의 연결은 차트 안 직접 라벨로 한다. 판정 단어의 보조 색(#2F6B33, #96382C)은 표 안에서만 단어와 함께 쓴다(3.2절).
- 구분선은 헤어라인(0.75–0.9 pt #DDDDDD)과 v7의 파선 구분선만 쓴다.

### 5.6 차트 제작 경로

- 슬라이드 차트는 논문 그림 함수를 `medium="slide"`로 다시 그린다. 같은 자료, 같은 색표와 범위를 쓰고 선과 글자를 5.3절 값으로 키운다. 다패널 논문 그림은 패널 하나 또는 비교 쌍 하나씩 나눈다(Naegle 2021 규칙 6).
- 그림 크기는 배치 크기(in) 그대로 만든다. PPTX 안 배율은 1.00 ± 0.02이다. [측정] 현 최종 덱(v5)의 내용 그림 24개는 PNG의 dpi 정보로 환산한 배율이 0.90–2.15였고 1.00 ± 0.02인 그림은 없었다. 쪽마다 차트 글자 크기가 달랐던 원인이다(baseline 3.1).
- **경로 B(기본)**: Pretendard로 그린 PNG를 배치 크기에서 300 dpi로 저장해 넣는다. 한글이 든 차트는 모두 이 경로를 쓴다.
- **경로 A(조건부)**: matplotlib SVG를 LibreOffice로 EMF로 바꾸어 넣는다. 변환 전에 SVG의 `font: 16px 'Pretendard'` 축약 표기를 `font-size`와 `font-family`로 풀어야 Pretendard가 유지된다. [측정] 2026-10-04 시험에서 라틴 글자는 Pretendard로 남았으나 한글이 Noto Sans CJK로 대체되었다. 따라서 렌더 PDF의 `pdffonts`에 Pretendard만 나오는 차트에만 이 경로를 쓴다.
- 사진·렌더 영상 이외의 차트에 사후 크롭, 채도 보정, 덮개 패치를 쓰지 않는다.
- **PDF 내보내기**: PPTX를 LibreOffice로 바로 PDF로 바꾸지 않는다. PPTX를 ODP로 바꾸고, `styles.xml`과 `content.xml`의 모든 `style:paragraph-properties`에 `style:text-autospace="none"`을 지정한 뒤 PDF로 바꾼다. [측정] 현 최종 덱 PDF 11쪽의 "개선 , 부정확한", "( 순가치 )" 같은 공백은 원본 PPTX 텍스트에 없었다(원본 검색 0건). LibreOffice가 한글과 라틴 문자·문장부호 사이에 자동 간격을 넣은 결과이다. 2026-10-04 시제품 쪽에서 위 경로로 이 공백이 사라졌고 글꼴은 Pretendard 3종만 남았다. 내보내기 스크립트는 `deck/export_pdf.py`(제안 경로)로 둔다.

### 5.7 발표자 노트

노트는 두 부분으로 쓴다.

- **낭독 대본**: 쪽마다 250–350자(약 1분, 한국어 약 330자/분, SL-11). 순서는 다음과 같다.
  1. 새 개념이 나오는 쪽은 그 개념이 필요한 이유 한 문장(R6 1항, DG-06의 '동기, 도구, 이름' 순서)
  2. 결론 줄을 문장으로 다시 말하기
  3. 읽는 법(축과 기준선) 한 문장
  4. 근거 수치는 핵심 1–2개만 읽는다. CI, n, 검정 이름은 읽지 않는다
  5. 단서 하나, 다음 쪽 연결 한 문장
- **참고 줄**: 낭독하지 않는 줄이다. Δ, 95% CI, n, 지역 수, 근거 주장 ID와 원천 표를 적어 질의응답에 쓴다. 참고 줄의 내부 추적 정보(파일, 실험 번호)는 `deck_spec.json`에만 둔다.
- **대본 금지**(SL-11, R6): 수사 의문문과 자문자답, 메타 문구("The idea in one line", "big picture", "honesty note", "한 줄로 말하면", "큰 그림으로 보면", "정리하자면"), 콜론·세미콜론으로 이은 나열 낭독, 비용·계산 시간·파라미터 수·GPU 같은 계산 자원 수치, 좌표 낭독, 내부 코드와 파일 경로.
- 두괄식으로 쓰고 문체는 ~이다/~한다이다. 단정은 근거 강도에 맞춰 완화한다.
- 대본은 PDF로도 낸다(PR-04).

### 5.8 구성 리듬

- 쪽 수는 발표 분 수와 비슷하게 둔다(약 1분에 1쪽, Naegle 2021 규칙 2).
- **의의 먼저**: 표지 다음 쪽은 연구 의의와 차별성이다(MS-02, framing P7). 이어서 자료, 설계, 방법 개념, 결과 순으로 둔다.
- **결과 순서**: 라벨 수 구간 순서로 두되, 각 부의 결론 줄은 그 구간에서 무엇을 쓰고 어떻게 평가하는지(워크플로의 한 단계)를 쓴다. 첫 결과 쪽의 결론 줄은 '직접 ML의 실패'가 아니라 물리 정보가 줄인 손해 또는 물리 정보의 출처이다.
- **결과 지도**: 결과를 다루는 부마다 지도 쪽이 1쪽 이상 있다(H5). 워크플로 종합 부는 예외이다.
- 부 구분 쪽(큰 번호, 장식)을 두지 않는다. 부는 부제의 부 표지("2부 · 라벨 0개")로만 알린다.
- 각 부는 그 부의 주 근거 그림으로 시작한다.
- 같은 원형은 연속 2쪽까지 쓴다. A6(순차 공개)은 같은 그림의 단계이므로 예외이다. A3(그림과 보조 요소)은 덱당 2쪽 이하이고 연속하지 않는다.
- **결론과 전망**: 결론 쪽(A10)은 마지막 결과 뒤에 둔다. 결론 쪽에 한계와 전망을 섞지 않는다(SL-04). 전망은 결론 다음의 별도 한 쪽이다(MS-02, R6 '결론은 한계 나열이 아니라 전망').
- **한계**: 본편에 한계 전용 쪽을 두지 않는다(P16 '과한 정직', MS-02 '한계는 간결히'). 결과의 조건은 해당 쪽 부제와 노트에 쓰고, 한계 표(A7, 3행 이하)는 부록에 둔다.
- 덱 배치 예시는 `design/slide_archetypes.md` 3절에 있다.

### 5.9 덱 문장 규칙

- 보이는 글은 자연스러운 명사형 종결이다(KO-02). '~그침', '~곤란', '~수행' 같은 압축형은 쓰지 않는다. '~확인', '~감소', '~차이 없음', '~정보 부재', '~에서 발생'처럼 끝낸다.
- **결론 줄 문형**: 주어와 결과가 보이는 한 구절로 쓴다. 명사만 5개 이상 잇는 압축형은 쓰지 않는다(KO-02, R8 2차 피드백). 예: "물리 유사라벨이 순서를 섞은 유사라벨보다 오차 1.63 cm 감소"(좋음), "물리 유사라벨 위약 대비 순가치 1.63 cm 확인"(압축형, 쓰지 않음).
- 숫자 나열은 '와/과'나 쉼표로 쓴다(H14).
- **줄바꿈**: 한글 줄바꿈은 낱말 단위로 한다(`word-break: keep-all`에 해당). 두 줄이 되는 글은 구 경계에서 직접 나누고, 끊기면 안 되는 용어(숫자와 단위, "Stefan 식")는 줄바꿈 없는 공백(U+00A0)으로 묶는다. 한 글자나 문장부호만 다음 줄로 넘어간 고아 줄은 0개이다(TY-06, deck_spec qa_log 08-24 '고아 마침표').
- 인용은 저자-연도("Hugelius et al. 2014")이다. 참고문헌 쪽은 저자 알파벳순, 번호 없이 쓰고 원고 참고문헌과 대조한다(SL-09).
- 표지의 제목, 저자, 소속, 로고는 사용자가 준 정본만 쓴다(SL-12). 로고는 5.0절의 파일을 쓴다.
- 약어는 첫 쪽에서 정의하고, 수식이 있는 쪽에는 그림 아래 기호 열쇠 한 줄을 둔다(DG-06).
- 정본 용어는 4.7절과 같다('선정', '레나델타', '물리 잔차 결합').

### 7.5 점검 도구

아래 세 함수는 2026-10-04에 세션 스크래치 폴더에서 시험했다. 저장소에 넣을 때는 `src/polar/qa_v3.py`(제안 경로)로 옮긴다.

- `audit_v3(fig)`: 저장 직전의 matplotlib 그림에서 글자 크기 집합, 문자 수, 1.0 pt 미만 선(자료 선, 축선, 눈금), 축 제목과 suptitle, 글씨 상자(텍스트 bbox 패치와 사각 도형 안 텍스트), 내부 코드 정규식(방법 약호 포함), 네 자리 쉼표, 라벨 단어 수, 그림 안 수치(눈금 밖)를 센다. 시험(개정판): 결함 8종(글자 크기, 얇은 선, 축 제목, 글씨 상자, 내부 코드, 네 자리 쉼표, 긴 라벨, 그림 안 수치)을 넣은 85 mm 그림에서 8종을 모두 잡았고, 규칙을 지킨 85 mm 그림(세로 축 라벨과 직접 라벨 포함)에서 0건이었다 [측정].
- `pdf_audit(pdf)`: pdfminer로 최종 PDF의 쪽 크기(mm), 문자 수, 글자 크기 분포, 글꼴 계열, Type 3 여부를 잰다. 초판은 `LTChar.size`를 써서 회전 글자를 잘못 쟀다. 개정판은 `char_size()`를 쓴다. 시험: 7 pt 세로 축 라벨이 든 85 mm 그림에서 79자 모두 7.0 pt로 읽혔다(초판 함수는 1.95–7.0 pt 7종). v2 Fig 1에서 1,008자, Fig 7에서 1,744자로 baseline 3.2의 값과 같았다 [측정].
- `pptx_audit(pptx)`: 쪽마다 채움 도형(명시 채움, 테마 채움, 채운 텍스트 상자), Pretendard 밖 글꼴, 허용 밖 글자 크기(표지 별도 집합), 제목 밖 주황 런 수, 큰 숫자 런, 격자 밖 요소, 그림 배율, '다' 종결 문단을 센다. 시험: python-pptx 기본 도형(테마 채움, `fill.type` None)과 채운 텍스트 상자를 넣은 쪽에서 개정판은 2개를 모두 잡았고 초판 함수는 놓쳤다. 같은 쪽의 13 pt 런(허용 밖 크기)과 '다' 종결 문단도 잡았다. 현 최종 덱(23쪽)에서는 채움 도형 0개였다(v8에서 패널 제거) [측정].

허용 상자(실제 자료 썸네일 테두리, 지도 확대 사각형)는 `set_gid("allowed_frame")`로 표시해 `audit_v3`의 상자 검사에서 뺀다.

## 8. 미결 사항

1. **덱 머리 문법**: 기본은 확정 문법 V이다. 문법 N(상단 주장 줄)은 첫 시안의 한두 쪽을 두 문법으로 보인 뒤 사용자 확인을 받는다(5.0절 '제안'). 여백 0.667 in와 본문 18 pt는 '변경(보고)'로 첫 시안부터 쓰고 함께 보고한다.
2. `design/layout_rules.md`, `design/visual_qa_checklist.md`, `design/brand_tokens.json`을 0.3절에 맞게 고쳐야 한다. 이 작업은 이 문서의 범위 밖이라 하지 않았다.
3. `src/polar/paperstyle.py`와 `v2_style.py`의 v3 상수(2.14절), `src/polar/cvd.py`의 3형 행렬, `final_lib.py`의 글머리 점 색은 아직 구현하지 않았다.
4. **초록 수치 개수**: KO-04(핵심 1–2개)를 영문 초록에도 적용할지 사용자 확인이 필요하다. Sci Rep 예시 초록은 결과 문장에 수치를 넣는 경우가 많다(scirep_ex). 확인 전에는 결과 수치 2개 이하로 쓴다(4.2절).
5. 그림 배치는 plan B를 기준으로 썼다. 안 A(v2 배치 유지)와 plan B 가운데 무엇을 쓸지는 사용자 결정 대기이다(plan B 8절).
6. 패널 문자 7 pt(R-06)와 최소 선 1.0 pt(R-07)는 Sci Rep 원문을 따른 결정이다. 게재본에서 실제 적용 여부는 확인하지 못했다 [미확인].

### A.1 `audit_v3`(matplotlib 그림)

```python
import re
import matplotlib
matplotlib.use("Agg")
from matplotlib.text import Text
from matplotlib.lines import Line2D
from matplotlib.collections import Collection
from matplotlib.patches import Patch, Rectangle, FancyBboxPatch

METHOD_HEX = {"#4d4d4d", "#2b5c8f", "#9a7bc9", "#568f72", "#6b7280", "#ad921a", "#84480c"}
CODE_RE = re.compile(r"\b(L\d{1,2}|AB\d{1,2}|LG[A-Z]?(-[A-Z]\d)?|WF\d{1,2}|SC\d\w*|H\d{2}\w?|X[A-J]|P4|L\+C|T\d{1,3}"
                     r"|P[0-2]\*?|R[0-2]|D[01])\b|\((x|i)\)")
NUM_RE = re.compile(r"[−\-]?\d+(\.\d+)?")

def audit_v3(fig, size_pt=7.0, min_lw=1.0, max_chars=600, max_words=3, allowed_num_gids=("scale", "sizekey")):
    """글자 크기 집합, 문자 수, 최소 선 굵기, 제목, 글씨 상자, 내부 코드, 네 자리 쉼표, 라벨 단어 수, 그림 안 수치를 센다."""
    fig.canvas.draw()
    rend = fig.canvas.get_renderer()
    out = dict(sizes=set(), chars=0, thin_lines=[], titles=[], boxed_text=0, codes=[], comma4=[],
               long_labels=[], loose_numbers=[])
    texts = [t for t in fig.findobj(Text) if t.get_visible() and t.get_text().strip()]
    tick_texts = set()                                   # 눈금 라벨과 축 라벨은 수치·단어 수 검사에서 뺀다
    for a in fig.axes:
        for axis in (a.xaxis, a.yaxis):
            tick_texts.update(axis.get_ticklabels())
            tick_texts.add(axis.label)
    cbar_axes = {a for a in fig.axes if a.get_label() == "<colorbar>"}
    for t in texts:
        s = t.get_text().strip()
        out["sizes"].add(round(t.get_fontsize(), 2))
        out["chars"] += len(s.replace(" ", ""))
        if t.get_bbox_patch() is not None:
            out["boxed_text"] += 1
        if CODE_RE.search(s):
            out["codes"].append(s[:30])
        if re.search(r"(?<![\d,.])\d,\d{3}(?![\d,])", s):
            out["comma4"].append(s[:30])
        is_tick_or_axis = t in tick_texts or getattr(t, "axes", None) in cbar_axes
        if not is_tick_or_axis and len([w for w in s.split() if w != "+"]) > max_words and t.get_gid() != "category":
            out["long_labels"].append(s[:40])           # 범주 축 라벨은 gid "category"로 표시해 4단어까지 따로 본다
        if not is_tick_or_axis and NUM_RE.search(s) and t.get_gid() not in allowed_num_gids:
            out["loose_numbers"].append(s[:30])         # 그림 안 수치(R-25)
    rects = [p for p in fig.findobj(Patch) if isinstance(p, (Rectangle, FancyBboxPatch)) and p.get_visible()
             and p not in [a.patch for a in fig.axes] and p is not fig.patch and p.get_gid() not in ("allowed_frame",)]
    for p in rects:
        pb = p.get_window_extent(rend)
        if pb.width < 2 or pb.height < 2:
            continue
        for t in texts:
            tb = t.get_window_extent(rend)
            if pb.x0 <= tb.x0 and tb.x1 <= pb.x1 and pb.y0 <= tb.y0 and tb.y1 <= pb.y1:
                out["boxed_text"] += 1
    for ln in fig.findobj(Line2D):
        if ln.get_visible() and ln.get_linestyle() not in ("None", "none", "") and ln.get_linewidth() < min_lw - 1e-6:
            out["thin_lines"].append((ln.get_gid() or ln.get_label())[:20])
    for c in fig.findobj(Collection):
        lws = [w for w in (c.get_linewidths() if hasattr(c, "get_linewidths") else []) if w > 0]
        if lws and min(lws) < min_lw - 1e-6:
            out["thin_lines"].append(type(c).__name__)
    for a in fig.axes:
        vis = [sp for sp in a.spines.values() if sp.get_visible()]
        if vis and max(sp.get_linewidth() for sp in vis) < min_lw - 1e-6:
            out["thin_lines"].append("spine")
        for axis in (a.xaxis, a.yaxis):
            tk = axis.get_major_ticks()
            if tk and tk[0].tick1line.get_visible() and tk[0].tick1line.get_markeredgewidth() < min_lw - 1e-6:
                out["thin_lines"].append("tick")
        if a.get_title().strip():
            out["titles"].append(a.get_title())
    if fig._suptitle is not None and fig._suptitle.get_text().strip():
        out["titles"].append(fig._suptitle.get_text())
    out["fails"] = [k for k, bad in [("size", out["sizes"] - {size_pt} != set()), ("chars", out["chars"] > max_chars),
                    ("thin", bool(out["thin_lines"])), ("title", bool(out["titles"])), ("box", out["boxed_text"] > 0),
                    ("code", bool(out["codes"])), ("comma4", bool(out["comma4"])),
                    ("label", bool(out["long_labels"])), ("number", bool(out["loose_numbers"]))] if bad]
    return out
```

축척 막대 길이와 크기 열쇠 값은 `set_gid("scale")`, `set_gid("sizekey")`로 표시해 그림 안 수치 검사에서 뺀다. 범주 축 라벨(포레스트 행 이름 등)은 `set_gid("category")`로 표시하고 4단어 상한은 사람이 판정한다.

### A.2 `pdf_audit`(최종 PDF)

```python
import re, subprocess
from collections import Counter
from pdfminer.high_level import extract_pages
from pdfminer.layout import LTChar

def char_size(o):
    """글자 크기. LTChar.size 는 가로쓰기 글꼴에서 bbox 높이를 돌려주므로,
    90° 회전한 글자(세로 축 라벨)에서는 진행 폭이 나온다. 진행 방향이 세로이면 bbox 폭을 쓴다.
    0°와 90° 회전에서 정확하고, 그 밖의 각도는 근사이다."""
    a, b = o.matrix[0], o.matrix[1]
    return o.width if abs(b) > abs(a) else o.height

def pdf_audit(pdf, size_pt=7.0, tol=0.05, max_chars=600):
    """최종 PDF 에서 글자 크기 분포, 문자 수, 글꼴, 쪽 크기(mm)를 잰다."""
    sizes, fonts, n = Counter(), set(), 0
    def walk(o):
        nonlocal n
        if isinstance(o, LTChar):
            if o.get_text().strip():
                sizes[round(char_size(o), 1)] += 1; fonts.add(o.fontname.split("+")[-1]); n += 1
        elif hasattr(o, "__iter__"):
            for c in o:
                walk(c)
    pages = list(extract_pages(pdf))
    for p in pages:
        walk(p)
    w_mm, h_mm = pages[0].width / 72 * 25.4, pages[0].height / 72 * 25.4
    off = {s: c for s, c in sizes.items() if abs(s - size_pt) > tol}
    t3 = subprocess.run(["pdffonts", pdf], capture_output=True, text=True).stdout
    fam = {re.sub(r"-(Bold|Italic|BoldItalic|Regular)$", "", f) for f in fonts}
    return dict(width_mm=round(w_mm, 1), height_mm=round(h_mm, 1), chars=n, sizes=dict(sizes), off_size=off,
                lt5=sum(c for s, c in sizes.items() if s < 5.0), families=sorted(fam), type3="Type 3" in t3)
```

### A.3 `pptx_audit`(덱)

```python
import io, re
from pptx import Presentation
from pptx.enum.shapes import MSO_SHAPE_TYPE
from pptx.oxml.ns import qn
from PIL import Image

EMU = 914400
COL_X = [0.667, 2.717, 4.767, 6.817, 8.867, 10.917]            # 6열 격자 왼쪽 끝(in)
SIZES = {"V": {26, 18, 16, 15, 14, 12}, "N": {22, 18, 16, 12}}  # 5.3절
COVER = {32, 18, 16, 14}
TITLE_PT = {"V": 26, "N": 18}
ACCENT = "EA851B"
NUM = re.compile(r"^[\s\d.,+\-−%×~]+(cm|°C|%|m)?$")

def has_fill(sh):
    """명시 채움, 테마 채움(fillRef idx > 0), 채운 텍스트 상자를 모두 잡는다.
    python-pptx 의 fill.type 은 테마 채움 도형에서 None 을 돌려주므로 XML 을 직접 본다."""
    el = sh._element
    spPr = el.find(qn("p:spPr"))
    if spPr is None:
        return False
    if spPr.find(qn("a:noFill")) is not None:
        return False
    if any(spPr.find(qn(t)) is not None for t in ("a:solidFill", "a:gradFill", "a:pattFill", "a:blipFill")):
        return True
    st = el.find(qn("p:style"))
    if st is not None:
        fr = st.find(qn("a:fillRef"))
        if fr is not None and fr.get("idx", "0") != "0":
            return True
    return False

def _runs(sh):
    if not sh.has_text_frame:
        return []
    return [r for p in sh.text_frame.paragraphs for r in p.runs if r.text.strip()]

def pptx_audit(path, grammar="V", tol=0.03, cover_index=1):
    prs = Presentation(path)
    rep = []
    for i, s in enumerate(prs.slides, 1):
        allowed = COVER if i == cover_index else SIZES[grammar]
        v = dict(fill_shapes=0, off_font=set(), off_size=set(), accent_outside_title=0, big_num=0,
                 off_grid=0, pic_scale=[], para_end_da=0)
        for sh in s.shapes:
            x = sh.left / EMU if sh.left is not None else None
            if sh.shape_type in (MSO_SHAPE_TYPE.AUTO_SHAPE, MSO_SHAPE_TYPE.TEXT_BOX, MSO_SHAPE_TYPE.PLACEHOLDER) and has_fill(sh):
                v["fill_shapes"] += 1
            if sh.shape_type == MSO_SHAPE_TYPE.PICTURE:
                try:
                    im = Image.open(io.BytesIO(sh.image.blob))
                    dpi = (im.info.get("dpi") or (300, 300))[0]
                    v["pic_scale"].append(round((sh.width / EMU) / (im.size[0] / dpi), 2))
                except Exception:
                    pass
            if x is not None and sh.width is not None and sh.width / EMU > 1.0 and not any(abs(x - c) < tol for c in COL_X):
                v["off_grid"] += 1
            for r in _runs(sh):
                f = r.font
                if f.name and not f.name.startswith("Pretendard"):
                    v["off_font"].add(f.name)
                if f.size is not None and round(f.size.pt) not in allowed:
                    v["off_size"].add(round(f.size.pt, 1))
                try:
                    col = str(f.color.rgb) if f.color and f.color.type is not None else ""
                except Exception:
                    col = ""
                is_title = f.size is not None and round(f.size.pt) in (TITLE_PT[grammar], 32)
                if col.upper() == ACCENT and not is_title:
                    v["accent_outside_title"] += 1          # 1 이하여야 한다(쪽당 1곳, 5.4절)
                if f.size is not None and f.size.pt >= 24 and NUM.match(r.text.strip()):
                    v["big_num"] += 1
            if sh.has_text_frame:
                for p in sh.text_frame.paragraphs:
                    t = p.text.strip()
                    if t and re.search(r"(다|니다)\.?$", t):
                        v["para_end_da"] += 1
        v["pic_scale_bad"] = [k for k in v["pic_scale"] if abs(k - 1.0) > 0.02]
        v["accent_fail"] = v["accent_outside_title"] > 1
        rep.append((i, v))
    return rep
```
