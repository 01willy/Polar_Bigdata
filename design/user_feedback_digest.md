## 4. 덱·원고 제출 전 점검 목록

빈도 순서로 놓았다. 모든 항목은 렌더된 PDF·PNG에서 확인한다.

- [ ] 5.1절 대시·금지 어휘·내부 명칭 검색이 본문, 슬라이드, 그림 텍스트, 캡션, 대본에서 모두 0건이다(WT-01~WT-03, SL-06, PF-07).
- [ ] 글씨가 든 상자·카드·색 구역·회색 패널이 없다. 상자는 실데이터 이미지, 셰브런, 네트워크 연산 블록뿐이다(SL-01, DG-01).
- [ ] 통계 카드와 대형 숫자가 없고 수치는 kv 헤어라인 표나 본문에 있다(SL-02).
- [ ] 화살표가 모두 수평·수직이며 곡선·사선·끊김이 없다(DG-02).
- [ ] 논문 그림 안에 제목과 해석 문장이 없고 해석은 캡션에 있다(PF-01).
- [ ] 결과 절마다 지도 또는 공간 시각화가 있고 관측 위치가 보인다(PF-02).
- [ ] 슬라이드 가시 텍스트는 명사형 종결이고, 원고는 ~이다/~한다로 쓰며 ~입니다가 없다(KO-01, KO-02).

### 5.2 덱(pptx) 점검

```python
import re
from pptx import Presentation
from pptx.enum.shapes import MSO_SHAPE_TYPE
from pptx.util import Pt

NUM = re.compile(r"^[\s\d.,+\-−%×~]+(cm|°C|%|m)?$")

def boxed(sh):
    if sh.shape_type != MSO_SHAPE_TYPE.AUTO_SHAPE or not sh.has_text_frame:
        return False
    if not sh.text_frame.text.strip():
        return False
    try:
        fill = sh.fill.type is not None
    except Exception:
        fill = False
    try:
        line = sh.line.fill.type is not None
    except Exception:
        line = False
    return fill or line

prs = Presentation("deck/render/permafrost_final.pptx")
for i, s in enumerate(prs.slides, 1):
    boxes = [sh for sh in s.shapes if boxed(sh)]                      # SL-01
    big = [r.text for sh in s.shapes if sh.has_text_frame             # SL-02
           for p in sh.text_frame.paragraphs for r in p.runs
           if r.font.size and r.font.size >= Pt(24) and NUM.match(r.text.strip())]
    paras = [p.text.strip() for sh in s.shapes if sh.has_text_frame
             for p in sh.text_frame.paragraphs if p.text.strip()]
    ends = [t for t in paras if re.search(r"(다|니다)\.?$", t)]      # KO-02
    if boxes or big or ends:
        print(i, "boxes", len(boxes), "bignum", big, "sentence-ends", len(ends))
```

2026-10-04에 `deck/render/permafrost_final.pptx`에서 실행했다. 결과는 글씨 상자 0, 숫자 전용 대형 런 0, '다' 종결 문단 3건이며, 3건 중 '캐나다'(명사)와 '감사합니다'(마무리 장)는 판정에서 제외할 대상이고 실제 서술 종결은 20번 장 1건이다. 이 덱은 도식을 PNG로 넣었으므로 상자 점검은 5.3절로 따로 한다.

### 5.3 matplotlib 그림·도식 점검

```python
from matplotlib.patches import FancyArrowPatch
from matplotlib.text import Text

def audit_fig(fig, max_words=3):
    """글씨 상자, 곡선·사선 화살표, 문장형 라벨, 축 제목을 센다."""
    out = {"text_boxes": 0, "curved": 0, "diagonal": 0, "long_labels": [], "titles": []}
    for t in fig.findobj(Text):
        s = t.get_text().strip()
        if not s or not t.get_visible():
            continue
        if t.get_bbox_patch() is not None:                          # DG-01, SL-01
            out["text_boxes"] += 1
        if len(s.split()) > max_words or s.endswith((".", "다")):   # PF-01, DG-03
            out["long_labels"].append(s[:40])
    for p in fig.findobj(FancyArrowPatch):                           # DG-02
        cs = p.get_connectionstyle()
        if type(cs).__name__ in ("Angle3", "Arc", "Bar") or getattr(cs, "rad", 0) != 0:
            out["curved"] += 1
            continue
        ab = p._posA_posB
        if ab and abs(ab[0][0] - ab[1][0]) > 1e-9 and abs(ab[0][1] - ab[1][1]) > 1e-9:
            out["diagonal"] += 1
    out["titles"] = [a.get_title() for a in fig.axes if a.get_title().strip()]
    if fig._suptitle is not None and fig._suptitle.get_text().strip():
        out["titles"].append(fig._suptitle.get_text())
    return out
```

저장 직전에 호출하고 `text_boxes`(네트워크 연산 블록 수 이하), `curved`, `diagonal`, `titles`가 0인지 본다. 시험 그림(제목, 글씨 상자, 곡선 화살표, 사선 화살표, 수평 화살표)으로 각 항목이 하나씩 검출되는 것을 확인했다. 수식 라벨은 단어 수가 많게 잡힐 수 있으므로 `long_labels`는 목록을 사람이 판정한다. `Rectangle`·`FancyBboxPatch`를 직접 그리고 그 위에 글씨를 얹은 도식은 이 함수가 잡지 못하므로 렌더 PNG를 육안으로 확인한다.
