# 예선 분석 보고서 스펙 (main.tex 전면 개정)

갱신: 2026-07-28. 제출 main = LaTeX 논문형 보고서 `outputs/report/main.{tex,pdf}`.
보고서 산출물은 전부 `outputs/report/`에서 관리한다(docs/report에서 이전 완료).

## 목적·메시지

- 대상: 2026 극지 빅데이터·인공지능 활용 경진대회 예선 심사(외부 심사자, 프로젝트 내부 명명 모름).
- 중심 주장: 희소 관측 조건에서 영구동토 ALT의 광역 추정을 위해 물리·기계학습·지구통계를
  누설통제 하에 동일 채점한 관측기반 프레임워크. 병목 진단(공변량 정보량), 전이에서의
  물리 앵커 유효성, 보정 불확실성, KPDC 현장 검증이 4대 축.
- 분량: 10쪽 내외(현재 6쪽 → 그림·수식·설명 보강으로 확장).
- 블라인드 유지: 저자·소속·프로젝트 코드명 노출 금지.

## 문체 (사용자 초록 문체 기준)

- 종결: 사실 서술 ~이다/~한다, 수행 서술 ~하였다/~설계하였다/~확인하였다. ~입니다체 금지.
- 용어 첫 등장: 한글(English, 약어) 병기. 이후 약어 사용. 예: 활동층 두께(Active Layer Thickness, ALT).
- 흐름형 산문: 짧은 단문 나열·선언체 금지. 접속("그러나", "또한", "추가로")으로 잇는 논문형 단락.
- 금지: 과한 수사, 의문형·극적 소제목, 정직성 자기강조("담백히", "정직하게", "주장하지 않는다"),
  em-dash, AI틱 나열체, 내부 코드명(S6/S8/S11/E1/E2/Mloc/M4/pool_mlp/게이트/T-lite 등).
- 내부 방법론 세부(누설 pytest 개수, seed 관리, 스크립트명, 재실행 이력)는 본문에서 제외.

## 레이아웃 (표준 논문 양식)

- 전체 텍스트 검은색. 컬러 액센트(제목·캡션 라벨 색) 전부 제거.
- 표준 논문 구성: 제목 블록(중앙, 검정) → 초록(표준 abstract 양식: 좌우 여백 축소,
  "초록" 표제 + 본문 + 핵심어) → 2단 본문 → 참고문헌.
- 섹션 표제: 검정 볼드, 표준 번호. 장식적 색·괘선 금지.
- 본문 폰트: Noto Serif CJK KR(명조), 표제 고딕(Pretendard 검정 볼드) — 국내 학술지 관행.
- 캡션: "그림 1." 검정 볼드 라벨 + 명조 본문. 그림 내부 제목과 중복 금지(내부 제목 제거가 원칙).
- 수식: 방법 절에 번호 붙은 수식으로 제시(Stefan, 크리깅, CQR, DI, 평가지표 등, 구현 정합 확인).

## 그림 정책

- 캡션이 부제목을 대신하므로 그림 내부 suptitle/제목 텍스트는 제거 후 재렌더.
- 최종 게재 그림은 인쇄폭 기준 300dpi 이상 + 가능하면 벡터 PDF 사용.
- 냉색 규약 유지(ALT=oslo_r, 온도=vik, 오차=acton, 차이=broc), 단위·컬러바 필수.
- 신규·교체 그림 계획은 `figure_plan.md`(감사 결과 반영)에서 관리.

## 빌드

- `xelatex main.tex` 2회(또는 latexmk -xelatex). xeCJK `CJKspace=true` 유지(한글 공백 버그 방지).
- 그림 상대경로: `../figures/...`, `../maps/...`.
- 용량 상한 이슈 시 PNG 다운샘플 별도 처리.
