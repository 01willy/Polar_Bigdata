# Lena Delta label-count map sequence

**1 km active-layer thickness (ALT) of the Lena Delta as the number of label cells used by the workflow grows.** a–e, ALT with 0, 10, 40, 160 and all 3037 label cells (20 blocks of 0.5°); f–j, each map minus the all-label map (e). Label cells (black points) are the first n cells of one block-dispersed order (blocks and cells permuted with seed 0, one cell per block in turn), so each step keeps the previous cells. 0 labels: source-coefficient Stefan E0·√TDD, E0 = 1.619 from 14,429 source cells (other regions). 10 labels: recalibrated Stefan, E = 2.040 (least squares 2.461 shrunk towards E0, κ = 10). 40, 160 and all labels: recalibrated Stefan anchor plus λ·g, g a CatBoost residual model on the 25 covariates (two seeds), λ from 0.25, 0.5 and 1.0 by 0.5° block five-fold cross-validation within the labels (E = 1.915, 1.742, 1.435; λ = 1, 1, 0.5). Colour scales: ALT 35–70 cm (1st–99th percentile of e; arrows mark values beyond the ends), change ±35 cm (99th percentile of |change| over a–d). White, water; grey, no data. The 1 km grid is a display resolution; climate inputs are ERA5-Land 0.1°.
