**Coefficient recalibration: target-wise coefficient error and ten-label gain, soil-property Stefan curves and regional contrasts.** **a**, Source coefficient error, ln(E_own/E_source), where E_own is the Stefan coefficient fitted by least squares to all labels of the target and E_source the source coefficient (label-grid target table; positive, target coefficient larger). The Tibetan Plateau has no entry in this table (grey). **b**, Error change of the Stefan model recalibrated with ten target labels relative to the source coefficient (post hoc re-analysis of the label-grid curves); values below −15 cm take the end colour (Tibetan Plateau, −96.37 cm). **c**, Error change relative to the source-coefficient Stefan model for the recalibrated Stefan model and the soil-property recalibrated Stefan model by number of labels, each region treated as a new target (cell-weighted 95% intervals). **d**, Four contrasts with ten labels by region and as four-region stratified mean (abstract contrast bundle): recalibrated minus source Stefan (mean −2.45 cm; 95% CI −3.04 to −1.88), anchor plus residual ML minus recalibrated Stefan (−0.18; −0.53 to −0.01), pseudo-label augmentation added to the anchor plus residual (−0.13; −0.31 to 0.22) and residual structure minus physics-input structure (−3.74; −5.23 to −2.75). Intervals in **d**, 95% block-bootstrap confidence intervals weighted by cell (thick) and block (thin); band, ±0.5 cm. Map conventions as in Supplementary Fig. S8.
