# 희소·충분 라벨 워크플로 실험 계획 (WF, 2026-10-01)

**성격**: 추가 실험의 사전 등록 문서다. 설계 시점은 LG·LGX·LGD·LGT·LGU·LGW 결과를 연 뒤(2026-09-30 12:31–13:48)이므로 모든 가설에 '결과 열람 뒤 설계' 표지를 단다. 다만 아래 가설이 묻는 결과(지역 내 SAR 효과, 세밀한 라벨 수 격자, 라벨 위치 선택 전략, 하위 군집 계수, 워크플로 선택 규칙의 이전)는 아직 계산한 적이 없다. 실행 전에 이 문서를 커밋하고, 실행 뒤 규칙을 바꾸지 않는다.
**배경(사용자 지시, 2026-10-01)**: 연구의 주제는 물리 증강과 물리 잔차를 쓰는 ML 이 희소 라벨 지역과 충분 라벨 지역에서 라벨 수에 따라 어떤 능력을 보이는지 분석하고, 새 지역에서 학습·평가·추가 탐사를 어떻게 해야 하는지 워크플로로 제시하는 것이다. 무작위 분할의 과대평가는 보조 근거다. LG 계열은 지역 전이와 라벨 0–전량의 곡선을 주로 보았고, 다음은 다루지 않았거나 약하게 다뤘다.
1. 라벨이 많은 지역 안에서의 세밀한 라벨 수 격자(100, 200, 500, 2,000, 5,000)와 지역 전용 공변량(SAR).
2. 어디를 더 관측해야 하는지(라벨 위치 선택 전략, 순차 선택). LG 는 셀 무작위 대 블록 분산만 비교했다(L43, 효과 없음).
3. 지역 안 하위 군집별 계수와 학습.
4. 라벨 수와 진단 결과에 따라 방법을 고르는 규칙과 그 규칙의 다른 지역 이전.
5. 기존 방식의 물리 기준선 일부(공간 보간한 계수, 군집별 계수, Stefan·CCI 평균 앵커 위 잔차).

## 1. 공통 규약

- 자료: `data/processed/fidelity_base_v3.csv`(셀 단위 다년 평균 ALT, 1 km), 토양 도일 표 `e5_soil_tdd_v3.csv`. 새 지역은 LGD v4 약관 확인분 판만 쓴다.
- 입력: 전이 공통 25종(x25). 알래스카 지역 내 실험만 SAR 9열(`insar_*`, `polsar_*`)을 더한 34종(x34)을 병기한다.
- 분할과 채점: LG 와 같다. 대상 지역 블록을 반으로 나눠(A: 라벨 후보, B: 채점) 분할 5회, 채점은 B 블록 셀이다. 원천은 실험마다 정한다(아래). 라벨 n 개는 A 에서 뽑는다.
- 통계: 같은 분할·추출·seed 의 짝 대비, 셀 가중과 블록 등가중의 블록 재표집 95 % CI(재표집 10,000회), 4분 판정(우세, 열세, 동등 ±0.5 cm, 미결정), 가설 묶음 안 Holm 보정은 보조 열.
- 학습기: CatBoost(`catboost_lo` 와 기본 용량 `catboost`). 지도 규칙과 같게 GPU 학습기는 쓰지 않는다(플랫폼 재현성, LG 개정 15 (u)).
- 실행: Rescale CPU 노드. 한 작업 안에서 한 플랫폼만 쓴다. 스모크를 먼저 하고 실측 시간으로 비용을 정한다.

## 2. 실험

### WF0 재분석(계산 없음, 사후 서술)

LG·LGD 곡선(30대상)에서 이미 계산한 서술값이다. 판정어를 쓰지 않고 '사후 서술' 표지를 단다.
- 위험표: 라벨 0개에서 P0 보다 2 cm 넘게 나빠진 대상 수는 직접 ML(D0) 18/30, 잔차 가중 1.0 의 R1 13/30, 물리 증강(D1) 2/30, 증강+앵커+잔차(R2) 1/30, 잔차 가중 0.25 의 R1 5/30 이다.
- 물리 계수 오차와 ML 이득: 라벨 전량에서 재보정 이득(P0 − P1)과 최선 ML 이득의 Spearman 순위상관 0.66(p 0.0001, 30대상). 최선 ML 은 다섯 레시피 가운데 사후 선택이라 낙관적이다(WF4 가 규칙 선택으로 다시 시험한다).

### WF1 충분 라벨 지역 안의 라벨 수 곡선

- 대상: 알래스카(지역 내: 원천 = 알래스카 A 블록 라벨만, 다른 지역 원천 없음), 레나·캐나다(지역 내, 같은 방식), 알래스카 하위 지역 AL-1·AL-2·AL-6(라벨 1,000 이상).
- n: 20, 50, 100, 200, 500, 1,000, 2,000, 5,000, 전량(A 의 크기를 넘지 않는 값). 추출은 셀 무작위, n ≤ 1,000 은 5회, 그 밖은 3회.
- 방법: 물리식 P0(다른 지역 원천 계수, 참조), P1(κ 10 수축 재보정), P2(최소제곱 재적합, 기존 지역 보정 방식), Pk(계수 E = ALT/√TDD 를 라벨 위치에서 구해 정규 크리깅으로 보간, 기존 공간 보정 방식), Pc(공변량 군집별 계수, 전체 계수로 수축), R1(재보정 앵커 + 잔차, λ 0.25·0.5·1.0 과 A 안 교차검증으로 고른 λ), R2(증강 + 앵커 + 잔차), Re(Stefan·CCI 평균 앵커 + 잔차, 대회 최선 구성), D0(직접 ML), D1(물리 증강 직접 ML), RK(R1 + 잔차 크리깅).
- 가설(알래스카, 두 가중):
  - WF1-a: n ≥ 1,000 에서 최선 물리 보정식(P1, P2, Pk, Pc 가운데 A 안 교차검증으로 고른 것)보다 R1(교차검증 λ) 또는 R2 가 우세인 n 이 있다.
  - WF1-b: n ≥ 500 에서 x34 의 R1 이 x25 의 R1 보다 우세하다(SAR 정보의 가치).
  - WF1-c: 물리 기반 레시피(R1·R2·D1)의 위험: 모든 n 에서 최선 물리 보정식 대비 열세인 n 의 수가 직접 ML(D0)보다 적다.
- 레나·캐나다·하위 지역은 같은 대비를 서술한다(판정어는 붙이되 확인적 가설로 세지 않는다).

### WF2 라벨 위치 선택(어디를 더 관측할 것인가)

- 대상: 알래스카(지역 내, 후보 = A 셀), 레나, 캐나다, AL-1·AL-2.
- 예산 n: 20, 50, 100, 200, 500.
- 전략: S1 셀 무작위(기준), S2 블록 층화(블록마다 차례로 하나), S3 공변량 군집 층화(x25 표준화 k-평균, 군집 크기 비례), S4 공변량 공간 최대 최소 거리(k-중심 탐욕), S5 원천 대비 외삽 우선(원천 공변량 분포에서 먼 셀 우선, AOA 거리), S6 순차 능동 선택(20개 무작위로 시작해 20개씩, R1 잔차 모형의 예측 분산이 큰 셀을 고른다. CatBoost virtual ensemble), S7 물리 불확실성 우선(√TDD 가 큰 셀, 계수 불확실성이 ALT 에 크게 전파되는 곳).
- 평가 방법: 각 전략으로 뽑은 라벨로 P1, R1(λ 0.25), D1 을 적합해 B 블록을 채점하고 S1 과 짝 대비한다(추출 5회 × 분할 5회).
- 가설:
  - WF2-a: 알래스카에서 S2–S7 가운데 하나 이상이 n ∈ {50, 100, 200} 의 R1 에서 S1 보다 우세하다.
  - WF2-b: 알래스카에서 가장 좋은 전략(n = 100 의 R1 점 추정으로 고른다)은 레나와 캐나다에서도 S1 보다 열세가 아니다.
- 산출: 전략별 라벨 수 곡선, 레나·알래스카의 '다음 관측 우선순위 지도'(WF5).

### WF3 하위 군집별 계수와 학습

- 대상: 알래스카(지역 내), 레나. n: 100, 500, 2,000, 전량.
- 방법: 전체 계수(P1) 대 군집별 계수(Pc, k ∈ {2, 4, 8}, 계층 수축), 전체 잔차 대 군집별 잔차(R1-c), 군집 번호를 입력에 더한 R1.
- 가설 WF3-a: n ≥ 500 에서 Pc(교차검증 k)는 P1 보다 우세하다. WF3-b(방향 중립): 군집별 잔차와 전체 잔차의 차이를 보고한다.

### WF4 방법 선택 규칙과 이전

- 규칙 W(결과 전 고정): 대상의 라벨 A 만으로 5겹 블록 교차검증을 해 {P0, P1, P2, R1(λ 0.25, 1.0), R2, D1} 가운데 교차검증 오차가 가장 작은 방법을 고른다. 라벨이 10개 미만이면 P1.
- 대상: LG 의 30대상(주 4지역, 알래스카와 하위 지역, CA-2·CA-3, LE-1·LE-2, 새 지역 약관 확인분) × n ∈ {10, 40, 160, 전량}.
- 가설:
  - WF4-a: 규칙 W 는 고정 레시피 R1(λ 0.25)보다 열세가 아니다(주 4지역 평균, 두 가중, 비열등 한계 0.5 cm).
  - WF4-b: 규칙 W 는 n ≥ 160 에서 P1 보다 우세인 대상 수가 고정 R1 보다 많다.
  - WF4-c(진단): 라벨 10개로 계산한 편향 진단값(라벨 위치의 P0 평균 오차)이 라벨 전량의 ML 이득 순위와 양의 순위상관을 가진다(새 지역과 하위 지역을 포함한 대상 단위, 블록 재표집 CI).

### WF5 다음 관측 우선순위 지도

- WF2 에서 레나·알래스카 전체 라벨로 정한 전략(WF2-b 의 규칙)을 레나 격자(38,173 육지 셀)에 적용해 다음 50개, 200개 관측 위치의 우선순위와 기대 오차 감소를 지도로 낸다. 기대 오차 감소는 WF2 의 모의 결과에서 온다. 지도는 SI 로 둔다.

## 3. 결과 쓰임(결과 전 고정)

- 원고의 주 결론을 '라벨 수와 물리 계수 오차에 따라 물리 기반 ML 이 언제, 얼마나 이득을 주는가, 그리고 새 지역에서 무엇을 어떤 순서로 하는가' 로 둔다. LG 의 확인적 판정은 바꾸지 않는다.
- 워크플로 표: 라벨 수 구간(0, 1–10, 10–100, 100–1,000, 1,000 이상)마다 권장 방법, 필요한 진단, 다음 관측 전략을 WF1–WF4 판정으로 채운다. 판정이 미결정이면 그 칸은 '근거 부족' 으로 둔다.
- WF0 의 수치는 사후 서술로만 쓴다.

### WF9 격자 안 변동(공간 상세도)

- **오차 분해**: 셀 SSE = 격자 안 SSE Σ[(y − ȳ_g) − (ŷ − ŷ̄_g)]² + 격자 사이 SSE Σ n_g(ȳ_g − ŷ̄_g)². 격자 안 RMSE 는 채점 셀이 2개 이상인 묶음의 셀로 나눈다. 물리식의 격자 안 RMSE 는 그 셀들의 격자 안 실측 표준편차와 같으므로, 격자 안 RMSE 대비 Δ < 0 은 ML 의 격자 안 변동이 실측 변동과 같은 방향이라는 뜻이다. 저장은 같은 적합의 세 저장소(총, 격자 안 `<대상>~w`, 격자 사이 `<대상>~b`)다.

- **해석 규칙(결과 전 고정)**: WF9-a 또는 WF9-c 가 지지나 부분 지지이면 '물리식이 표현하지 못하는 ERA5 격자 안 변동의 일부를 물리 기반 ML 이 맞힌다(설명 비율 x %)' 를 쓰고, 총 RMSE 차가 0.5 cm 미만인 대상이 있으면 그 대상을 함께 적는다. 기각이고 열세가 없으면 '격자 안 변동에 대한 ML 의 예측은 실측 변동을 맞히지 못했다. 공간 상세도는 장점으로 주장하지 않는다', 열세가 있으면 'ML 의 격자 안 변동은 오차를 늘렸다' 를 쓴다. 격자 안 설명력의 상한은 공변량 해상도(DEM 외 공변량은 대부분 격자 안에서 같다)와 관측 잡음이 정한다는 점을 한계로 적는다.

### WF10 기후 외삽(공간 대용)

- **분할(변형 warm, cold, 분할 k = 1–10)**: 대상 셀의 0.5° 블록을 블록 평균 √TDD(토양 도일, 셀 수 가중, 공변량만 사용)로 정렬한다. warm 은 가장 따뜻한 블록부터, cold 는 가장 추운 블록부터 대상 셀 수의 25 % 이상이 될 때까지 W(외삽 채점)로 둔다(동률은 블록 이름 순). 남은 블록을 seed_of('wf10-I', 대상, 변형, k) 순열로 섞어 셀 수 25 % 이상이 될 때까지 I(보간 채점)로 둔다. 나머지 블록이 A(라벨 후보, 약 50 %)다. W 는 분할 사이에 같고 I 와 A 는 바뀐다. 채점은 W·I 블록의 eval_mask 셀이다.
- **대상**: 알래스카, 캐나다(지역 내, x25). 레나는 블록 평균 √TDD 범위가 27.7–31.0 으로 좁아 뺐다.
- **라벨과 방법**: n {100, 500, 전량}(|A| 미만), 추출 3(전량 1), seed 0·1, 추출 seed 는 h40.draw_cells(대상, 'r10' + 변형 첫 글자, 분할, n, 추출). 방법은 P1, P2, R1(교차검증 λ 와 λ 0.25·1.0), R2(교차검증 λ), D0(catboost 기본 용량과 catboost_lo), D1(catboost_lo)이다. 교차검증과 유사라벨 규약은 WF1 과 같다. 같은 적합으로 W 와 I 를 따로 채점한다(저장소 `<대상>~<변형>W`, `<대상>~<변형>I`).
- **외삽 손실**: EP(M) = Δ_W(M − P1) − Δ_I(M − P1). W 와 I 의 블록은 겹치지 않고, 두 저장소의 재표집은 서로 독립(이름별 seed)이므로 EP 의 분포는 두 재표집 분포를 같은 번호끼리 뺀 것이다. 두 대상의 층화 평균은 h42.pool_rows 로 낸다.
- **가설(warm 변형)**
  - WF10-a(주): 직접 ML(D0, catboost)의 외삽 손실이 양이다(EP 열세), 두 대상 층화 평균, n ∈ {100, 전량}. 둘 다 열세면 지지, 우세 없이 하나만 열세면 부분 지지, 그 밖은 기각.
  - WF10-b(주): 물리 잔차의 외삽 손실이 직접 ML 보다 작다. EP(R1, 교차검증 λ) − EP(D0) = Δ_W(R1 − D0) − Δ_I(R1 − D0) 가 우세, 같은 n·풀. 규칙은 WF10-a 와 같은 형식(우세 기준).
  - WF10-c(주, 비열등): W 에서 R1(교차검증 λ) − P1 의 두 가중 CI 상한이 0.5 cm 미만이다, 같은 n·풀. 둘 다 만족하면 지지, 하나면 부분 지지.
  - WF10-d(서술): cold 변형의 같은 대비, 대상별 행, D0(catboost_lo)·D1·R2·P2 의 EP, Δ_W 와 Δ_I 각각.
- **해석 규칙(결과 전 고정)**: WF10-a·b 가 지지이면 '학습 범위보다 따뜻한 지역에서 직접 ML 은 물리식 대비 성능이 더 떨어지고, 물리 잔차는 그 손실이 작다' 를 쓴다. WF10-c 가 지지이면 '물리 잔차는 학습 범위 밖의 따뜻한 지역에서도 재보정 물리식보다 0.5 cm 넘게 나빠지지 않았다' 를 쓴다. 기각은 그대로 쓴다. 이 시험은 같은 시기의 따뜻한 블록을 쓰는 공간 대용이며 시간 방향의 기후 변화 외삽을 직접 시험하지 않는다는 점을 함께 적는다.

  1. 크리깅(Pk, RK): 자체 구현 국소 정규 크리깅. 좌표는 구면 3차원 직교 좌표(km), 최근접 라벨 32개, 지수 변이도 γ(h) = c0 + c·(1 − exp(−3h/a))(a = 실용 범위, pykrige 'exponential' 과 같은 모수화). 변이도는 라벨(최대 1,500개 부분표본)의 경험 변이도(12구간, 최대 거리의 절반까지)에 √(구간 쌍 수) 가중 최소제곱으로 맞추고, a 는 60개 로그 격자, (c, c0)는 비음수 최소제곱이다. 라벨 10개 미만이거나 구간 3개 미만이면 P1 로 대체하고 표지를 남긴다. pykrige 는 Rescale 이미지에 없어 계산 경로가 플랫폼마다 달라질 수 있으므로 쓰지 않았고, 같은 변이도 모수에서 pykrige(backend loop, n_closest_points)와 예측이 같음을 시험으로 확인했다(차 < 1e-6). Pk 는 라벨 위치의 E = ALT/√TDD 를 크리깅해 Ê·√TDD 로 예측한다. RK 는 R1(λ)의 표본 안 잔차를 크리깅해 더한다(교차 적합 잔차가 아니다). RK 의 교차검증 λ 는 R1 의 교차검증 λ 를 쓴다.
  2. 군집(Pc, R1-c, R1+군집 번호, S3): A 풀 셀의 x25 를 중앙값 대체 뒤 A 풀의 평균·표준편차로 표준화(라벨 미사용), k-평균(n_init 10, 고정 seed)을 A 풀에 맞추고 B 셀은 가장 가까운 중심에 배정한다. Pc 의 계층 수축은 E_c = (n_c·E_ls,c + κ·E_n)/(n_c + κ), κ = 10(E_n 은 전체 계수의 κ 10 수축). R1-c 는 군집 라벨 20개 이상인 군집만 따로 잔차 모형을 맞추고 그 밖은 전체 g 를 쓰며 앵커는 전체 E_n·√TDD 다. 군집 번호는 원핫 k 열로 입력에 더한다. S3 는 k = 8, 군집 크기 비례(최대 나머지 방식), 군집 안 무작위다. Pc 의 k 와 최선 물리 보정식(Pbest: P1, P2, Pk, Pc 가운데)은 아래 4의 교차검증으로 고르고, Pbest 안의 Pc 는 바깥 묶음의 학습 라벨로 k 를 다시 고른다(중첩).
