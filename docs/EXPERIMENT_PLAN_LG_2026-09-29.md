# 라벨 격자 통합 재실행(LG) 계획: 사전 등록 (2026-09-29)

**목적**: 시험 범위 행렬(`docs/RESEARCH_FRAME_2026-09-29.md` B절)의 공백을 하나의 통제된 격자로 메운다. 기존 실험은 실험마다 분할 규약·추출·학습기·가중이 달라 같은 축에서 비교할 수 없었다. LG는 같은 분할·같은 라벨 추출·같은 채점으로 기법 × 라벨 수 × 지역 × 학습기를 처음부터 다시 돌린다. 알래스카에서 먼저 확인하고 다른 지역으로 옮기는 순서를 설계에 넣는다.
**실행 환경**: 스모크·사전 점검·본 실행은 CPU 부분과 GPU 부분 모두 Rescale(KR, `tools/rescale_client.py`, 설정 `configs/rescale/lg_*.yaml`)에서 한다. 로컬 서버는 공유 서버이므로 적합 수 계산(`--count-only`), 하위 지역 대응표 작성, 집계(`--summarize-only`)만 한다(사용자 지시 2026-09-29, 개정 1). 로컬 GPU 0–9는 타 사용자 점유.
**채점**: `src/polar/h4_common.py` 블록 부트스트랩(분할 안 B 블록 재표집, 방법·추출 공통 인덱스, 추출·seed 평균, 분할 분포 평균, 1,000회). 셀 가중 RMSE(주)와 블록 등가중 RMSE(보조)를 모두 저장한다. 두 가중의 CI가 모두 0을 제외할 때만 '유의'로 쓴다.
**성격**: 사전 등록. §4 가설과 판정은 결과 열람 전 고정. 실행 후에는 §7 결과만 추가한다.

## 1. 대상 27개(지역 × 원천 모드)

| 묶음 | 대상 | 원천 | 역할 |
|---|---|---|---|
| 주 지역(x) | 레나, 캐나다, 러시아 W, 러시아 E | 대상 macro 제외 전체 + 100 km 버퍼 | 확인적 평균(AB4) |
| 주 지역(x) | 러시아 C, 그린란드 | 같음 | 점 추정만 |
| 알래스카(x) | Alaska(지역 전체를 새 지역으로) | 알래스카 밖 전체 | 큰 n 참조, 알래스카 우선 검증 |
| 알래스카 하위(i) | AL-1–AL-6 | 나머지 알래스카 + 알래스카 밖 | 지역 내 모의 신규 지역 |
| 알래스카 하위(x) | AL-1–AL-6 | 알래스카 밖만 | 지역 간 모의 신규 지역 |
| 기타 하위(i·x) | CA-2, CA-3, LE-1, LE-2 | i: 상위 지역 포함, x: 상위 지역 제외 | 실패 원인 분석 |

하위 지역 정의는 h25와 같다(블록 중심 k-means, 라벨 미사용, CA-1 제외). 실행 환경에 따라 군집이 달라지지 않도록 블록 → 하위 지역 대응표(`data/processed/lg_subregion_map_v1.csv`, 블록 133개)를 고정해 업로드 묶음에 넣고 읽어 쓴다(개정 1).

러시아 C와 그린란드는 블록 CI와 n*를 계산하지 않는다. 곡선과 최소 n 표에는 점 추정과 `point_only` 표시만 싣는다(개정 1).

## 2. 분할·라벨 수·추출

- **분할**: 5회, 단일 규약(무작위 순열 후 셀 수 균형 탐욕 배정, `half_split_blocks` split_seed 1–5). 중복 분할은 첫 분할만 쓰고, 채점 블록 2개 미만 분할은 무효로 기록한다. 유효 분할이 있는 대상의 무효 분할은 실행하지 않는다(집계에 쓰이지 않는다). 유효 분할이 없는 그린란드만 무효 분할을 실행해 점 추정에 쓴다(개정 1). 채점 = B 블록의 `eval_mask` 셀.
- **라벨 수 n**: {0, 3, 10, 40, 160, 320, 1,000, 전량} 중 |A| 미만과 전량.
- **추출**: 셀 무작위(주), n마다 5회. 추출 seed는 (대상, 모드, 분할, n, 추출 번호)로 고정하고 모든 방법이 같은 추출을 쓴다(짝지음). 블록 분산 추출은 n ∈ {10, 40, 160}에서 CatBoost 기준 방법에만 추가한다.
- **학습기 seed**: 2.

## 3. 방법(한 번에 한 요인만 바꾼다)

기준 구성(★): 학습기 CatBoost(`catboost_lo`), 대상 가중 α = 1, 셀 무작위 추출, λ = 0.25. s = √TDD, E0 = 원천 최소제곱, E_n = κ = 10 수축.

| id | 방법 | 정의 |
|---|---|---|
| P0 | 물리식(원천 계수) | E0·s. 기준선 1 |
| P1 | 물리식(재보정) | E_n·s. 기준선 2(같은 라벨로 재보정한 물리식) |
| P2 | 물리식(재적합) | 대상 n개 최소제곱 E·s |
| P3 | 물리식(오프셋 MLE) | `h4_common.offset_mle_*` |
| D0 | 직접 ML | 원천 실측 ∪ 대상 n 실측으로 y 직접 학습. 물리 앵커 없음(입력 공변량에는 √TDD와 CCI ALT가 들어 있다) |
| D1 | 증강 직접 | D0 + 대상 A 풀 유사라벨 E_n·s(r = 10, 라벨 셀은 실측) |
| R0 | 원천 계수 앵커 + 잔차 | E0·s + λ·g, g = 원천 잔차 ∪ 대상 n 잔차 학습 |
| R1 | 재보정 앵커 + 잔차 | E_n·s + λ·g |
| R2 | 증강 + 앵커 + 잔차 | R1 + 대상 A 풀 유사 잔차 행(잔차 0, r = 10). M1 공변량만 조건의 결합과 같은 정의 |
| R3 | 적층 결합 | D1 예측을 앵커로 두고 잔차 학습 |
| V1 | 공변량 의존 계수 | log(y/s)를 표준화 공변량 ridge로 적합(원천 ∪ 대상 n), 앵커 = exp(ẑ)·s. V1r = V1 + 잔차 |

λ ∈ {0.25, 0.5, 1.0}은 같은 적합에서 사후 적용한다. 판정에 쓰는 기준 λ는 방법마다 하나다: P·V1은 λ 없음(0), D0·D1은 1.0, 잔차 방법(R0–R3, V1r)은 0.25(개정 1).

**요인 축**

| 축 | 수준 | 적용 범위 |
|---|---|---|
| 방법 | P0–P3, D0, D1, R0–R3, V1, V1r | 대상 27 전부, 분할 5, n 전 격자, 추출 5, seed 2 (CatBoost) |
| 대상 가중 α | 1, 10, 100, 이어 학습(원천 모델에서 대상 행만 추가 학습) | D0·R0·R1, n ≥ 3. CatBoost는 대상 27 전부(방법 축과 같은 분할·추출). MLP는 학습기 축과 같은 범위(대상 12, 분할 3, 추출 2) |
| 학습기 | ridge, MLP, RealMLP, FT-Transformer, TabM, 조건부 흐름 정합(cfm), 확산(ddpm), 정규화 흐름(nflow) | D0·R1·R2, n ∈ {0, 10, 40, 160, 전량}, 대상 12(주 7 + AL-1–3 x + CA-2·CA-3 x), 분할 3, 추출 2, seed 2 |
| 추출 배치 | 셀 무작위, 블록 분산 | P1·R1(CatBoost), n ∈ {10, 40, 160} 중 \|A\| 미만. 대상 25(러시아 C·그린란드는 \|A\|가 작아 해당 n이 없다) |

TabPFN은 가중치 배포 조건 때문에 Rescale 작업에서 제외하고 기존 B4 결과를 쓴다.

**구현 규약(개정 1)**

- α 가중: CatBoost는 표본 가중(sample_weight)이다. MLP는 검증 10 %를 고유 행에서 먼저 떼고 학습 쪽 대상 행만 α배 반복한다. 표준화 통계와 y 척도는 고유 행에서 구한다.
- 학습기 축의 R2: 유사 잔차 행(복원 추출, r·원천 행 수)을 학습 행렬에 그대로 넣는다. 신경망 학습기는 그 뒤에 검증 10 %를 떼므로 검증 행에 학습 행의 복제본이 들어간다. 채점 셀 누설은 아니다. CatBoost에는 조기 종료가 없으므로 이 차이는 신경망 학습기의 조기 종료 시점에만 영향을 준다.
- RealMLP의 epoch 수는 pytabkit 기본값 256이다(`--realmlp-epochs`). 다른 신경망의 `--epochs` 100과 별개다.
- α 중첩 선택의 후보는 L3 문구대로 {10, 100, 이어 학습}이다. α = 1은 후보에 넣지 않는다. 라벨이 10개 미만이거나 한 블록에만 있으면 선택할 수 없으므로 α = 1로 두고 표시한다.
- 예측에 비유한 값이 있는 실행은 채점에서 빼고 `lg_failed.csv`에 기록한다. 적합 실패도 같은 표에 남긴다.

## 4. 가설과 판정(결과 열람 전 고정)

| id | 가설 | 판정 |
|---|---|---|
| L1 (직접 ML) | D0는 n ≤ 40에서 물리식 P0를 넘지 못한다 | 주 4지역 가운데 n ≤ 40에서 블록 CI 상한 < 0인 지역이 1개 이하이면 지지 |
| L2 (결합) | R2 또는 R3은 R1보다 낫다 | n ∈ {10, 40, 160}에서 R2 − R1(또는 R3 − R1)의 주 4지역 층화 평균 CI 상한 < 0이면 지지. 아니면 '증강은 라벨 0 전용' |
| L3 (가중) | α 확대 또는 이어 학습이 구조 지역의 필요 라벨 수를 줄인다 | 채점 블록 ≥ 8인 구조 대상(레나·캐나다·AL-2·AL-5)에서 α ∈ {10, 100, 이어 학습} 중 A 블록 내부 교차검증으로 고른 α가 n* ≤ 40을 만드는 대상이 2개 이상이면 지지 |
| L4 (순가치) | 잔차 ML은 같은 라벨로 재보정한 물리식(P1)을 넘는다 | R1 − P1의 주 4지역 층화 평균 CI 상한 < 0인 최소 n을 보고. n ≤ 40에서 성립하면 '희소 라벨에서도 ML 순가치 있음' |
| L5 (학습기) | 신경망·생성 모델 학습기는 CatBoost와 동급이다 | R1에서 학습기별 Δ(학습기 − CatBoost)의 주 4지역 평균 CI가 0을 포함하면 동급. 상한 < 0인 학습기는 표로 보고 |
| L6 (알래스카 이전) | 알래스카에서 통과한 조합이 다른 지역에도 통한다 | 알래스카 하위 i 모드에서 n ∈ {10, 40, 160} 블록 CI 상한 < 0을 과반 대상에서 만든 (방법, α) 조합을 고른 뒤, 그 조합이 주 4지역에서 같은 n에 넘는 비율을 보고. 절반 이상이면 지지 |
| L7 (공변량 의존 계수) | V1은 지역 안 E 이질성이 큰 대상(캐나다·CA-3)의 악화를 없앤다 | 캐나다·CA-3에서 n ≥ 40의 V1(또는 V1r) − P0 점 추정이 0 이하이고 P1보다 낮으면 지지 |
| L8 (전량) | 라벨 전량에서 R1은 P0를 넘는다 | 주 4지역 층화 평균 CI 상한 < 0(두 가중 모두). 지역별 표 병기 |

최소 n*의 정의는 `h4_common.min_n`(블록 CI 상한 < 0, 분할 승률 ≥ 2/3, 추출 승률 ≥ 0.75)이다. 모든 곡선은 라벨 순가치(같은 방법의 n = 0 대비)를 함께 보고한다.

**판정 세부 규칙(개정 1, 본 실행 전 고정)**

가설과 판정 문구는 바꾸지 않는다. 아래는 위 표의 판정을 계산할 때 쓰는 조작적 정의다.

| 항목 | 규칙 |
|---|---|
| 유의 기준 | L1–L6, L8의 'CI 상한 < 0'은 머리말의 규칙대로 셀 가중과 블록 등가중의 CI가 모두 0을 제외하는 경우다. 셀 가중만 0을 제외한 경우는 보조 열로 보고하고 판정에 쓰지 않는다. L7은 표의 문구대로 점 추정 기준이다 |
| 층화 평균의 CI 풀 | 지역이 CI 풀에 들어가는 조건은 유효 분할 1개 이상, 사용 분할의 채점 블록 합집합 8개 이상이다. 분할 안 채점 블록이 8개 미만인 분할이 있으면 표시만 한다(러시아 W 분할 1은 7개) |
| 풀 지역 수 | 층화 평균 판정에는 CI 풀 지역 수를 함께 적는다. 4지역이면 확정, 2–3지역이면 '부분(지역 k/4)', 2지역 미만이면 '판정 불가'다. 러시아 W·E는 \|A\|가 14–17셀이라 n ≥ 40 행이 없으므로 n = 40, 160의 평균은 레나·캐나다 2지역 평균이다 |
| 계산 실패 | 층화 평균의 점 추정치가 백분위 CI 밖에 있으면 지역 행은 보존하고 평균은 '판정 불가'로 둔다. 기각으로 세지 않는다 |
| L1 | n ≤ 40에는 전량 행 가운데 실제 라벨 수가 40 이하인 경우(러시아 W·E)를 포함한다 |
| L3 적격 대상 | 표가 열거한 네 대상(레나, 캐나다, AL-2, AL-5)이다. '채점 블록 ≥ 8'은 사용 분할의 채점 블록 합집합 기준이다(층화 평균과 같은 기준). 분할별 최솟값(레나 5, AL-2 5, AL-5 4, 캐나다 12)은 표시 열로 남긴다. 적격 대상이 2개 미만이면 '판정 불가'다 |
| L3 주 판정 | 주 판정은 E0 고정 앵커(R0), 알래스카 하위 모드 i 한 행이다. R1과 모드 x는 보조로 보고한다. 중첩 선택의 n*가 α = 1의 n*보다 작은지도 보조 열로 적는다 |
| L4 | 최소 n은 4지역 평균인 n과 2–3지역 평균인 n을 나눠 보고한다 |
| L6 | 조합은 (방법, α ∈ {1, 10, 100, 이어 학습}) × n이고 방법별 기준 λ 한 행만 센다. 중첩 선택(nested)은 조합에 넣지 않는다. 분할 안 채점 블록이 5개 미만인 알래스카 대상을 뺀 경우와 셀 가중 CI만 쓴 경우를 보조 판정으로 병기한다 |

## 5. 산출

- `data/processed/lg/`: 작업 단위별 조각 `shards/*.csv`, 블록 SSE `*_blocksse.npz`, 집계 `lg_curve.csv`(두 기준선 Δ, 블록 CI, 두 가중, 분할·추출 승률, 라벨 순가치), `lg_minn.csv`, `lg_tests.csv`(L1–L8 판정량), `lg_timing.csv`(축·학습기·방법별 적합 시간), `lg_failed.csv`(채점에서 빠진 실행), `lg_meta.json`.
- 조각 단위(개정 1): CPU 부분은 (대상, 모드, 분할), GPU 부분은 (대상, 모드, 분할, 학습기)다. 벽시계 상한이나 학습기 하나의 실패로 다른 학습기의 결과가 버려지지 않는다.
- 중단·재개: 조각이 있고 설정 해시가 같으면 건너뛴다(`--resume`). 설정이 다르거나 이전 실행이 실패한 조각은 다시 실행한다. 집계는 조각 사이 설정 해시가 다르면 중단한다.
- 실행 순서(개정 1): 주 4지역 → Alaska → 알래스카 하위(모드 i, 모드 x) → 나머지, 그 안에서 분할 번호 순이다. GPU 부분은 빠른 학습기(MLP·cfm·ddpm·TabM)를 먼저, RealMLP를 마지막에 돈다. 벽시계 상한에 걸려도 확인적 평균의 구성 지역이 먼저 채워진다.

### 6A.2 공통 규약(조작적 정의)

LG 와 같게 두는 것: 자료(`load_base`, F4_direct 17,467셀), 대상 27개와 원천 정의(§1), 분할(`half_split_blocks` split_seed 1–5, 중복·무효 분할 규칙), 라벨 추출(`h40.draw_cells`, 같은 seed 식), 채점 셀(B 블록의 `eval_mask` 셀), 유사라벨 행 추출(seed_of('lg-ps', 대상, 모드, 분할, seed)), 학습기 seed 0·1, CatBoost 설정(`catboost_lo`, 스레드 4), 기준 λ, 유의 기준, 층화 평균의 풀 조건과 풀 지역 수 표기, 계산 실패 처리.

| 항목 | 규칙 |
|---|---|
| 기호 | s = √TDD(`e5_sqrt_tdd`), E0 = 원천 최소제곱 계수, E_n = (n·E_ls + κ·E0)/(n + κ), κ = 10, E_ls = 선택 라벨 n개의 최소제곱 계수. x25 = LG 입력 25개 |
| Δ | Δ(A − B) = RMSE(A) − RMSE(B), cm. 같은 분할·추출·seed 의 짝지음이고 음수면 A 가 낫다 |
| 주 CI | `h4_common.boot_delta_blocks`(LG 와 같은 규칙), 셀 가중과 블록 등가중. 재표집 횟수는 10,000 이다(Holm 보정 p 의 분해능 때문이다. LG 의 L1–L8 은 h40 집계의 1,000회 그대로 둔다) |
| 4분 판정 | 우세 = 두 가중의 CI 상한 < 0. 열세 = 두 가중의 CI 하한 > 0. 동등 = 우세도 열세도 아니고 두 가중의 CI 가 모두 [−δ, +δ] 안. 미결정 = 그 외. 우세·열세는 LG 의 '유의'와 같은 기준이다 |
| 동등성 한계 | 주 δ = 0.5 cm, 보조 δ = 1.0 cm(보조 열). 'CI 가 0 을 포함'을 동급으로 읽지 않는다. λ 를 곱하는 방법끼리의 동등은 기준 λ 와 λ = 1.0 에서 모두 동등일 때만 '동등'으로 쓴다 |
| 풀 | 층화 평균은 주 4지역(레나, 캐나다, 러시아 W, 러시아 E)이다. 4지역이면 확정, 2–3지역이면 '부분(지역 k/4)', 2지역 미만이면 '판정 불가'다. n ∈ {40, 160} 은 레나·캐나다 2지역 평균이다. 보조 열로 레나·캐나다·Alaska(x) 3지역 평균을 병기한다. 알래스카와 그 하위 지역은 한 풀에 함께 넣지 않는다 |
| 보조 CI | 지역 블록 공통 재표집: 대상의 사용 분할 채점 블록 합집합에 대해 재표집 다중도를 한 번 뽑고 모든 분할이 자기 채점 블록의 다중도를 읽는다. 주 판정과 다르면 '분할 독립 가정 의존'을 붙인다. 본문은 두 CI 의 판정이 같은 대비만 단정형으로 쓴다 |
| 다중 비교 | 항목별 주 대비 묶음에 Holm 보정 p(`m1_stats.holm`, 부트스트랩 p)를 보조 열로 낸다. 보정 후 p ≥ 0.05 인 우세·열세는 '보정 전 유의'로 표시한다. 동등성에는 두 한쪽 부트스트랩 p 의 최댓값을 쓴다 |
| 효과 크기 | 모든 Δ 에 cm, P0 RMSE 대비 %, 환원 가능 오차 대비 비율 (RMSE_P0 − RMSE_방법)/(RMSE_P0 − 하한)을 붙인다. 우세라도 점 추정 절댓값이 0.5 cm 미만이면 '통계적으로 구별되나 크기는 0.5 cm 미만'으로 적는다 |
| 기준 λ | 물리식·V2·V2c·기준선 = λ 없음(키 0.0). 직접 계열(D0 변형, F1a·F1k·F1n, D1 변형) = 1.0. 잔차·곱셈 계열(R0·R1·R2 변형, V2r, RM, RM0, R1s) = 0.25. λ ∈ {0.25, 0.5, 1.0} 은 같은 적합에서 사후 적용한다 |
| 방법 변형 표기 | 키 구조는 LG 와 같고 변형은 방법 문자열에 넣는다(예: `D1@r30`, `R1@k3`, `R1@ku`, `D1@shuffle`, `R1#near`). 채점 셀 집합이 달라지는 변형은 대상 이름에 표지를 붙여 저장소를 따로 둔다(예: `Alaska~noearly`) |
| 확인적 가설 | L10, L12, L15, L19, L29, L30 여섯 개다. 나머지는 보조 또는 서술이다 |

동등성 한계 0.5 cm 와 1.0 cm 의 문헌 근거(탐침 판독 분해능)는 확인하지 못했다. 원고 작성 전에 확인한다.

### 6A.3 방법 정의

기준 방법 P0, P1, P2, D0, D1, R0, R1, R2 의 정의는 §3 과 같다. 확장 하네스가 같은 식으로 다시 적합한다(6A.6).

**X1 결합 방식**(학습기 `catboost_lo`, 원천 ∪ 대상 라벨 n개로 학습)

| id | 정의 |
|---|---|
| D0t, D0c, D0m | D0 의 입력에서 각각 {e5_tdd, e5_sqrt_tdd}, {cci_alt, cci_valid}, 네 열 모두를 뺀 직접 ML(입력 23, 23, 21개) |
| F1a | D0 입력 + 열 E0·s. 후보 F1 의 정의 그대로다. x25 에 s 가 이미 있으므로 중복성 점검용이다 |
| F1k | D0 입력 + 열 2개(`p4_ku`, `p2_edaphic`). 두 열은 `load_base` 가 라벨 없이 계산한다. `p4_ku` 결측은 CatBoost 가 그대로 받고 다른 학습기는 학습 행렬 중앙값으로 대체한다 |
| F1n | D0 입력 + 열 a. 원천 행 a = E0·s, 대상 라벨 행과 채점 셀 a = E_n·s. n = 0 에서 F1a 와 같다 |
| V2 | z = log(y/s) 를 적합, ŷ = exp(ẑ)·s. ẑ 는 학습 z 의 범위로 자른다(V1 과 같은 규약). V2c = V2 × 학습 행의 평균 exp(z − ẑ)(재변환 보정, 보조 행) |
| V2r | V2 + λ·g. g 는 y − V2 의 표본 내 잔차를 학습한다(V1r 과 같은 규약) |
| RM | h = log(y/(E·s)) 를 적합(원천 행 E = E0, 대상 라벨 행 E = E_n), ŷ = E_n·s·exp(λ·ĥ). ĥ 는 학습 h 의 범위로 자른다. n = 0 에서 RM(λ = 1) = V2 다. RMc 는 λ = 1 의 재변환 보정 행이다 |
| RM0 | ŷ = E0·s·exp(λ·(ẑ − log E0)). V2 의 적합에서 계산하며 추가 적합이 없다 |
| R1@f1k | R1 의 잔차 학습기 입력을 F1k 입력으로 바꾼 것 |

후보의 M1(곱셈 보정)은 M1 마스터 실험과 이름이 겹쳐 RM 으로 바꿨다. 신경망 확인은 F1k, V2, RM 을 mlp, tabm, ftt 로 적합한다(GPU).

**X2 유사라벨**(채점은 B 블록 현장 라벨만 쓴다)

| id | 정의 |
|---|---|
| D1@r, R2@r | 유사라벨 행 수 = r × 원천 행 수, r ∈ {1, 3, 30}. r = 10 은 기준 재실행 값이다 |
| D1@shuffle | 풀의 E_n·s 값을 풀 셀 사이에서 순열한 값(수준과 분포 유지, 셀 대응 파괴). r = 10 |
| D1@const_t | 풀의 E_n·s 평균 상수(수준만 이식). r = 10 |
| D1@const_src | 원천 y 평균 상수. r = 10 |
| D1@tddlin | (E_n/E0)·(a + b·TDD), (a, b)는 원천 최소제곱. r = 10 |
| D1@ku | c_n·b_ku(재보정 Kudryavtsev, 대체 공급원). 위약이 아니며 L15 에 넣지 않는다. r = 10 |
| R1s, P1s | 선택 라벨 n개의 y 를 선택 셀 사이에서 순열한 뒤 P1·R1 과 같은 절차(E_n 도 순열 뒤 값). n ≥ 10 |
| R2@a, R1@a | 대상 라벨 행에 표본 가중 α ∈ {10, 100}. n ∈ {10, 40, 160} |
| 모방 지수 | 채점 셀에서 D1 계열 예측과 P1 예측의 RMS 차이(cm). 실행 행에 기록 |

위약의 유사라벨 행은 D1 과 같은 복원 추출 색인을 쓰고 라벨 셀은 실측으로 바꾼다. R2 의 위약은 두지 않는다(유사 잔차 0 행의 위약은 정의가 자명하지 않다). 위약의 비율 격자도 두지 않는다(r = 10 만).

**X3a 검증 사다리**(h41, 통합 자료, 채점은 `eval_mask` 셀, 각 단에서 모든 채점 셀을 한 번씩 예측)

| 단 | 분할 규칙 |
|---|---|
| V-R | 셀 무작위 5-fold, 반복 3 |
| V-P | 거친 공변량 묶음(기후 8·토양 9·CCI 2열의 값이 같은 셀 묶음, 736개) 단위 5-fold, 반복 3 |
| V-S | 0.05° 격자 묶음(437개) 단위 5-fold, 반복 3 |
| V-B | 0.5° 블록 단위 5-fold, 반복 3 |
| V-C0, V-C100, V-C500 | 공간 군집 30개(블록 중심 k-means, 라벨 미사용, 대응표 `lgx_cluster_map_v1.csv` 고정) 하나 제외. 제외 군집의 셀에서 0, 100, 500 km 안의 학습 셀을 뺀다 |
| V-G | 지역 홀드아웃(macro 7지역, LG 의 원천 정의와 100 km 버퍼, 지역 전체 채점) |

모델: PS(학습 집합 최소제곱 E·s), D0, D0m, F1k, V2, RM0, RS(E·s + λ·g). 학습기는 `catboost_lo`(주)이고 D0 와 RS 에 `catboost`(600회, 깊이 6, 학습률 0.03)와 `rf`(500그루)를 더한다. V-G 에는 N1 의 기준선도 넣는다(앵커 5종은 X9 와 같다. 연도 정합 √TDD 는 `lgx_tdd_matched_v1.csv` 를 읽는다. 개정 7). 지표는 RMSE, MAE, 편향, R²(전체, 지역 내)이고 셀 가중, 블록 등가중, 지역 등가중으로 낸다. CI 는 0.5° 블록 공통 재표집(지역 안 블록 재표집, 10,000회)이다. 반복이 같은 블록 집합을 공유하므로 분할 분포 평균 규칙을 쓰지 않는다. 주 요약은 5지역(알래스카, 레나, 캐나다, 러시아 W, 러시아 E) 층화 평균이다.

**X3b 지역 내 블록 교차검증**(h41, 알래스카·레나·캐나다 각각, 0.5° 블록 5-fold, 반복 5)
학습 집합 w2 = 지역 내 학습 fold ∪ 타 지역 원천(LG 정의), w1 = 지역 내 학습 fold 만. w2 의 방법은 P0(E0), P1w(지역 내 학습 라벨로 κ = 10 수축), P2w(재적합), D0, F1k, V2, R0, R1w, RMw 이고 D0·R1w 에 `catboost`, `rf` 를 더한다. w1 의 방법은 PSw, D0w, F1kw, V2w, RSw 다. 보조 행 R1w@nest 는 λ ∈ {0.25, 0.5, 1.0} 을 지역 내 학습 fold 안의 블록 단위 4-fold 교차검증으로 고른다(채점 fold 의 라벨은 쓰지 않는다. 선택은 seed 0 적합으로 한다). 지역 내 조건의 증강(D1, R2)은 유사라벨 풀이 채점 fold 가 되어 정의가 달라지므로 넣지 않는다.

**X3c 채점 셀 고정 근접 단**(h42, 채점 = LG 와 같은 B 채점 셀, B 를 셀 무작위 5-fold 로 나눠 fold 마다 예측)

| 단 | 대상 라벨 집합 |
|---|---|
| S_region, S_block | LG 의 n = 0, 전량(기준 재실행 값) |
| S_rand5 | A ∪ (B 의 비채점 fold). 반복 3 |
| S_randm | 라벨 수를 A 의 셀 수로 맞춘다. B 의 비채점 fold 셀을 먼저 넣고 부족분을 A 에서 무작위로 채운다. 반복 3 |
| inblk | B 의 비채점 fold 에서 n ∈ {10, 40, 160} 개를 무작위 추출. 추출 5 |
| S_buf(d) | A 에서 채점 셀 d km 안의 셀을 뺀다. d ∈ {10, 25, 50, 100, 200, 500}. 서술 통계다 |

방법은 P1(그 단의 라벨로 수축), D0, R1 이다.

**X5 셀 단위 저장과 파생 분석**
- 저장: 기준 재실행과 X1 의 D0, D1, R0, R1, R2, F1k, F1n, V2, RM 에 대해 채점 셀의 예측 성분(직접 예측 또는 g, ĥ)을 n ∈ {0, 10, 40, 160, 전량}, 전 추출·seed 로 저장한다(float32). 정적 열은 loc_id, 관측값, s, 블록, 위도, 경도, 가장 가까운 원천 셀까지의 거리다. (n, 추출)별로 가장 가까운 선택 라벨 셀까지의 거리를 저장한다.
- 거리 층: (대상, 분할, n, 추출) 안에서 채점 셀을 최근접 라벨 거리의 3분위로 나눠 층별 블록 SSE 를 저장한다(`#near`, `#mid`, `#far`).
- 구간: 점수 |log(y/ŷ)|. 라벨 n개 구간은 선택 라벨을 A 블록 단위 최대 5묶음으로 나눈 교차 적합 점수의 분위로 만든다(n ∈ {10, 40, 160, 전량}, 방법 P1·R0·R1, seed 0). n = 0 구간은 원천 지역 하나 제외 방식의 표본 밖 점수를 지역 등가중으로 합친 분위로 만든다(셀 30개 이상 원천 지역). 목표 80 %, 90 %. 블록별 미포함 셀 수와 폭 합을 저장한다.
- 변수 기여: CatBoost ShapValues 의 평균 절댓값(D0, F1k, R1 의 g. n ∈ {0, 40, 전량}, 추출 0, seed 0). 서술 산출이다.

**X6 학습기 축 보강**(GPU, 대상 12, n ∈ {0, 10, 40, 160, 전량}, 추출 2, seed 2, epochs 100, RealMLP 256)
- 분할 4·5 추가: D0·R1·R2 × 학습기 7종과 MLP α 축. h40 의 `run_unit` 을 분할 4·5 단위에만 호출한다(코드와 설정은 본 실행과 같다).
- R0 추가: 학습기 6종(realmlp, ftt, tabm, cfm, ddpm, nflow)과 ridge, 분할 1–5. MLP 의 R0 는 h40 의 α 축에 있다.
- 조각 단위는 (대상, 모드, 분할, 학습기)다. 빠른 학습기(mlp, cfm, ddpm, tabm, nflow)의 세 축(R0, 분할 4·5, X1 신경망)을 먼저 돌리고 FT-Transformer 의 세 축을 다음에 돌린다. RealMLP 는 별도 작업으로 돌린다. 벽시계 상한에 걸리면 5분할이 모두 있는 학습기만 5분할 판정을 하고 나머지는 LG 의 3분할 판정을 유지한다.

**X9 민감도**(`catboost_lo`)

| 변형 | 정의 |
|---|---|
| κ | κ ∈ {3, 30} 으로 P1, R1. 대상 하나 제외 방식의 κ·λ 선택은 집계에서 계산한다 |
| 6–7월 제외(`~noearly`) | 관측월 7월 이하 셀(비율 0.5 이상)을 원천, 라벨, 채점에서 뺀다. 추출 색인은 그대로 두고 표지 셀만 뺀다(실제 라벨 수 기록) |
| 탐침만(`~probe`) | GPR 유래 셀(비율 0.5 이상)을 같은 방식으로 뺀다 |
| 앵커 종류 | s 자리에 b(x) ∈ {토양 도일 √TDD, `p4_ku`, `p2_edaphic`, `cci_alt`, 연도 정합 √TDD}. 비유한 셀은 ρ·s 로 대체한다(ρ = 원천 셀의 b/s 중앙값, 라벨 미사용). 계수는 원천 최소제곱과 κ = 10 수축. 방법 P0@b, P1@b, R0@b, R1@b |
| 입력 집합 | CCI 2열을 뺀 입력으로 R0, R1(`@x23c`). D0 는 X1 의 D0c 다 |
| 결측 대체 통계(개정 7) | `p4_ku`, `p2_edaphic` 을 공변량 결측을 원천 셀 중앙값으로 채운 입력에서 다시 계산한다(`physics_ensemble` 을 그대로 부른다). 해석식 P0@ku_tr, P0@ed_tr, B:ku_raw_tr, B:ed_raw_tr, B:ens_tr(n = 0)과 적합 F1k@tr(n ∈ {0, 10}). 보조 행이며 가설의 판정에 쓰지 않는다 |

셀 표지는 ABoVE 원자료를 좌표 소수 4자리로 결합해 만든다(`fa_failure_analysis.attach_label_meta` 와 같은 규칙). 표지 표 `lgx_label_flags_v1.csv` 와 연도 정합 도일 표 `lgx_tdd_matched_v1.csv` 는 본 실행 전에 로컬에서 만들어 고정한다. CALM 과 레나 셀은 계절 최대 관측으로 가정한다(원자료 문서로 확인하지 못했다).

**N1 물리 기준선 사다리**(해석 계산)
S0(= P0), S-aff(원천의 a + b·s), 앵커 종류별 무보정 값(`p2_edaphic`, `p4_ku`, `cci_alt`)과 척도 보정 값(X9 의 P0@b), CCI-aff(원천의 a + b·CCI), ENS(Stefan·Kudryavtsev·CCI 척도 보정 값의 평균). 라벨 n개 조건은 척도 계수를 κ = 10 으로 재보정한다(X9 의 P1@b). `p4_ku` 결측 셀은 대체 방식과 채점 제외 방식을 모두 계산한다.

**N2 오차 하한**(집계)
거친 공변량 묶음(5셀 이상) 안의 관측 분산을 합동해 지역별(알래스카, 레나, 캐나다) 하한 RMSE 를 구한다. 이 값은 DEM 계열 입력을 뺀 공변량 조건부 값이며 효과 크기 표기의 분모로만 쓴다.

**N3 학습기 용량**(CPU, 대상 12)
학습기 `catboost`(600회, 깊이 6, 학습률 0.03), `rf`(500그루, max_features 1/3, min_samples_leaf 5, 결측은 학습 행렬 중앙값), `catboost_tuned`(깊이 {3, 6, 8} × 반복 {200, 600, 1,500}, 학습률 0.05 의 9개 설정 가운데 원천 지역 하나 제외 교차검증의 지역 등가중 RMSE 가 가장 작은 설정. 대상 라벨과 채점 셀은 쓰지 않는다). 방법 D0, R0, R1(`catboost` 는 R2 포함).

**N4 분할 확장과 지역 수준 추론**
분할 1–50 으로 D0, R0, R1(n ∈ {0, 10, 40, 전량}, 추출 2, seed 2)을, 분할 1–200 으로 해석식 P1, P2 를 계산한다. 대상은 레나, 캐나다, 러시아 W, 러시아 E, Alaska(x)와 하위 지역 10개(i)다. 집계에서 핵심 대비의 지역 단위 부호 검정, 부호 뒤집기 순열 검정, 임의효과 평균(Hartung–Knapp), 지역 하나 제외 평균, 러시아 W 제외 평균을 낸다.

### 6A.4 범위와 적합 수

적합 수는 구현의 `--count-only` 값이다(개정 7 에서 다시 셌다. 개정 5 의 값은 구현 전 추정이었다). 시간은 추정이다. CPU 시간은 사전 점검(qOkSo)의 CatBoost 실측(1배 행 약 0.3 s, 4스레드)에 (학습 행 수 / 16,700)^0.6 을 곱해 환산했다. `catboost`(2.2 s), `rf`(4.0 s), `catboost_tuned`(2.2 s)의 기준 시간은 재지 않은 가정값이다. GPU 시간은 `--count-only` 의 추정 누적 시간에 §6.1 표의 학습기별 비(실측 환산 / 개정 1 추정)를 곱한 값이다.

### 6A.5 가설과 판정(결과 열람 전 고정)

모든 대비는 기준 λ 와 4분 판정을 쓴다. 따로 적지 않으면 주 4지역 층화 평균이다.

| id | 항목 | 가설 | 판정 |
|---|---|---|---|
| L9 (중복성, 보조) | X1 | F1a 와 D0 는 구별되지 않는다 | F1a − D0 가 n ∈ {0, 10, 전량} 모두에서 동등이고 점 추정 절댓값이 0.3 cm 이하이면 지지. 문장 '√TDD 가 이미 입력에 있으므로 상수 계수 Stefan 출력의 추가는 정보를 더하지 않는다'. 아니면 구현을 점검하고 표만 싣는다 |

| L11 (라벨 0 물리 입력) | X1 | 과정 모델 출력을 입력으로 준 직접 ML 도 n = 0 에서 P0 를 넘지 못한다 | F1k − P0(n = 0)가 우세가 아니면 지지 |

| L14 (물리 관련 입력 제거, 방향 중립) | X1 | 방향을 정하지 않는다 | D0t − D0, D0c − D0, D0m − D0 를 n ∈ {0, 10, 전량} 에서 보고한다. 모두 동등이면 '직접 ML 의 전이 오차는 물리 관련 입력의 유무에 의존하지 않는다'. D0m 이 열세이면 'D0 는 물리 관련 입력을 가진 직접 ML 이다'를 방법 절에 적는다 |
| L15 (위약, 확인적) | X2 | Stefan 유사라벨 D1 은 위약 4종보다 오차가 작다 | D1 − 위약(shuffle, const_t, const_src, tddlin)을 n ∈ {0, 10} 에서 본다. 8개 모두 우세이면 '증강 이득은 물리식의 셀 단위 정보에서 온다'. 두 n 모두에서 const_src 에 우세이고 shuffle·const_t 에는 우세가 아니면 '증강 이득은 대상 지역의 수준과 분포 정보에서 오며 셀 단위 물리 정보의 추가 기여는 확인되지 않았다'. 어느 위약에도 우세가 아니면 '증강 이득은 유사라벨의 내용과 구분되지 않는다'. 그 밖은 '혼재'로 적고 n 별로 서술한다 |

| L17 (라벨 셔플 음성 대조) | X2 | R1 과 R1s 는 동등하다 | R1 − R1s 를 n ∈ {10, 전량} 에서 본다. 모두 동등이면 '대상 라벨의 기여는 수준 정보다'. 우세가 있으면 '대상 라벨의 공변량과 잔차의 관계가 기여한다'와 해당 n. 그 밖은 '확인하지 못함' |

| L19 (검증 설계, 확인적) | X3a | 무작위 분할에서는 직접 ML 이 물리식을 넘지만 지역 홀드아웃에서는 넘지 못한다 | 5지역 층화 평균의 D0 − PS 가 V-R 에서 우세이고 V-G 에서 우세가 아니면 지지. 문장 '무작위 분할의 결론은 지역 홀드아웃에서 유지되지 않는다'. V-R 에서 우세가 아니면 '역전'이라는 표현을 쓰지 않고 열화 크기만 보고한다. V-G 에서도 우세이면 L1 과 함께 재검토한다. `catboost`, `rf` 의 같은 대비는 보조다 |
| L20 (단조성) | X3a | D0 의 RMSE 는 V-R < V-B < V-C100 < V-C500 순으로 커진다 | 5지역 평균 점 추정의 순서가 맞고 V-C500 − V-R 의 CI 하한 > 0(두 가중)이면 지지. 순서가 한 곳만 어긋나면 '대체로 지지'로 적고 어긋난 단을 적는다. V-P, V-S 는 서술 단이다 |
| L21 (구조별 열화) | X3a | 검증 단을 내려갈 때 앵커 + 잔차의 열화가 직접 ML 보다 작다 | [RS(V-G) − RS(V-R)] − [D0(V-G) − D0(V-R)] 가 우세(음수)이면 지지. 기준 λ 0.25 에서는 앵커의 비중이 커서 열화가 구조적으로 작으므로 λ 1.0 의 값을 병기한다 |
| L22 (지역 내 충분 라벨) | X3b | 지역 내 조건에서 R1w 는 재보정 물리식 P1w 를 넘는다 | 학습 집합 w2 에서 R1w − P1w 가 우세인 지역 수 k/3. 3 이면 '지역 내 조건에서 잔차 ML 은 재보정 물리식을 넘는다'. 1–2 이면 지역을 명시한다. 0 이면 '지역 내 조건에서도 재보정 물리식 대비 순가치는 확인되지 않았다'. 판정은 기준 λ 0.25 로 하고 λ 1.0 과 R1w@nest 의 같은 대비를 보조로 병기한다. 알래스카는 '재현(비맹검)'이다 |
| L23 (근접 효과) | X3c | 채점 셀 가까이의 라벨은 같은 수의 먼 라벨보다 오차를 더 줄인다 | (a) D0 의 RMSE[S_rand5] − RMSE[S_block], (b) 이중 차분 [S_randm 의 (M − P1)] − [S_block 의 (M − P1)], M ∈ {D0, R1}, (c) n = 10 에서 [inblk 의 (R1 − P1)] − [A 추출의 (R1 − P1)]. 각각 4분 판정으로 보고한다. (b)의 D0 가 우세이면 '무작위 분할의 이득에는 라벨 수와 무관한 근접 성분이 있다' |
| L24 (거리 의존) | X5 | 잔차 학습의 순가치는 라벨에 가까운 셀에 집중되고 재보정 이득은 거리에 의존하지 않는다 | 적격 대상(레나, 캐나다, Alaska x, AL-2 i), n ∈ {40, 160}. Δ(R1 − P1)의 근 − 원 차이가 우세인 대상이 2개 이상이면 '잔차 학습의 순가치는 라벨 가까운 셀에 집중된다', 아니면 '거리 의존은 확인되지 않았다'. Δ(P1 − P0)의 근 − 원 차이가 우세도 열세도 아닌 대상이 3개 이상이면 '재보정 이득은 라벨과의 거리에 의존하지 않는다' |
| L25 (구간, 방향 중립) | X5 | 방향을 정하지 않는다 | 레나·캐나다·Alaska(x) × n ∈ {40, 160} 의 6칸. R1 의 90 % 구간 커버리지가 [0.85, 0.95] 인 칸 수 c1, 그 가운데 평균 폭이 R0 의 n = 0 구간보다 좁은 칸 수 c2. c2 ≥ 4 이면 '라벨이 구간을 좁힌다'. c2 < 4 이고 c1 ≥ 4 이면 '라벨은 커버리지를 맞추나 폭을 줄이지 못한다'. c1 < 4 이면 '라벨 기반 보정이 목표 커버리지를 주지 못한다'. 큰 틀의 등록안 U1(n {20, 40, 80})을 LG 격자에 맞춘 것이다 |

| L28 (판정 안정성) | X9 | 핵심 대비의 4분 판정은 변형 설정에서 기준 설정과 같다 | 핵심 대비: D0 − P0(n = 0), P1 − P0(n = 10), R1 − P1(n = 10, 전량), R1 − P0(전량). 변형마다 같으면 '강건', 우세·열세와 동등·미결정 사이의 변화는 '약화', 우세와 열세가 바뀌면 '의존'. '의존'인 변형은 한계 절에 조건을 적는다. 탐침만 변형이 '약화' 또는 '의존'이면 결론을 'GPR 유래 라벨을 포함한 원천 조건'으로 한정한다. 앵커 교체는 R1@b − R1 에 우세가 없으면 '앵커 교체의 이득 없음'. 대상 하나 제외 방식으로 고른 κ·λ 의 결과가 고정값과 0.5 cm 안이면 '사전 고정값의 선택 편향은 확인되지 않았다' |

| L30 (학습기 용량, 확인적) | N3 | 직접 ML 의 라벨 0 결과는 학습기 용량 설정에 의존하지 않는다 | n = 0 에서 D0[학습기] − P0 가 `catboost`, `rf`, `catboost_tuned` 모두 우세가 아니면 지지. 문장 '용량을 키우거나 원천 교차검증으로 조정해도 직접 ML 은 라벨 0 전이에서 물리식을 넘지 못한다'. 하나라도 우세이면 L1 의 결론을 '저용량 설정 한정'으로 적고 해당 학습기를 마스터 곡선에 더한다 |
| L31 (분할 구성) | N4 | 전량 조건의 R1 − P0 개선은 분할 구성에 강건하다 | 분할 50회에서 점 추정이 음수인 분할 비율이 0.8 이상인 주 지역이 3개 이상이면 '분할 구성에 강건', 2개 이하이면 '지역 의존'. LG 분할 5회 평균이 분포의 10–90 백분위 밖인 대상은 '분할 구성 의존'으로 표시한다. 지역 수준 검정은 판정에 쓰지 않고 p 값과 지역 수를 병기한다 |

### 6A.6 본 실행과의 관계

- 확장의 모든 대비는 확장 조각 안에서 닫는다. 기준 방법(P0, P1, P2, D0, D1, R0, R1, R2)을 확장 하네스가 같은 분할·추출·seed 로 다시 적합하고, 새 방법은 그 값과 짝을 맞춘다. 본 실행 조각과 교차 짝지음하지 않는다.
- 재현 점검: 확장의 기준 방법 값이 본 실행 조각(`data/processed/lg/shards`, 읽기 전용)과 일치하는지를 조각 단위로 대조한다. 허용 차는 물리식 1e-9 cm, CatBoost 방법 0.02 cm(키별 셀 가중 RMSE)다. 결과는 `lgx_gate.csv` 에 남긴다. 실패한 단위가 있으면 원인을 적고, 확장의 대비는 확장 조각 안의 값으로 계산한다.
- 사전 점검 단계의 재현 점검은 LG 사전 점검(qOkSo)의 조각(캐나다 x, 분할 1, n {0, 40})과 대조한다.

### 6C.1 목적과 공백

TabPFN 을 LG 와 같은 대상, 분할, 라벨 추출 seed, 채점으로 돌려 학습기 축의 빈칸을 메운다. 표형 파운데이션 모델을 시험했는지에 대한 심사 질문에 같은 규약의 결과로 답한다. 대응하는 공백은 시험 범위 행렬(`docs/COVERAGE_MATRIX_BY_REGION_2026-09-29.md`) §9 의 TabPFN 항목이다.

| 항목 | 기존 b4 | LGT |
|---|---|---|
| 라벨 수 | n ∈ {3, 10, 40} | n ∈ {0, 3, 10, 40, 160, 320, 1,000, 전량} |
| 대상 | 14(주 4지역과 하위 10지역. 하위 지역의 원천에 상위 지역 포함) | 27(§1 과 같다). 알래스카 전체, 러시아 C, 그린란드, 모드 x 를 포함한다 |

### 6C.2 공통 규약

LG, LGX 와 같게 두는 것: 자료(`load_base`), 대상 27개와 원천 정의(§1, 100 km 버퍼), 하위 지역 대응표(`lg_subregion_map_v1.csv`), 분할(`half_split_blocks` split_seed 1–5, 중복·무효 분할 규칙), 라벨 추출(`h40.draw_cells`, 같은 seed 식), 채점 셀(B 블록의 `eval_mask` 셀), 물리식 계수(E0 = 원천 전체의 최소제곱, E_n = κ = 10 수축), 학습기 seed 0·1, 기준 λ(D0 1.0, R0·R1 0.25)와 λ ∈ {0.25, 0.5, 1.0} 의 사후 적용, 키 구조(method, learner, alpha, placement, n, draw, seed, lam), Δ 의 정의, 주 CI(`h4_common.boot_delta_blocks`, 재표집 10,000회), 4분 판정, 동등성 한계(주 0.5 cm, 보조 1.0 cm), λ 를 곱하는 방법끼리의 동등 규칙, 층화 평균의 풀과 풀 지역 수 표기, 보조 CI(지역 블록 공통 재표집), Holm 보정 p(보조 열), 효과 크기 표기, 6A.5a 의 공통 규칙(분할 완결성, 판정할 수 없는 대비의 처리, 동등성 p).

| 다르게 두는 것 | LG | LGT |
|---|---|---|
| 학습 행 | 원천 전체 ∪ 대상 라벨 | 컨텍스트 상한 10,000행. 원천 행은 부분 추출한다(6C.4) |
| 학습기 | `catboost_lo` 와 신경망·생성 모델 8종 | `tabpfn`, `catboost_ctx` |
| 실행 환경 | Rescale, python 3.11, T4 | 로컬, python 3.9, RTX 3090(6C.8) |

E0 와 원천 잔차 y − E0·s 의 E0 는 부분 추출한 행이 아니라 원천 전체로 구한다. 따라서 물리식 P0, P1 의 값은 LG 와 같아야 한다(6C.8 의 재현 점검).

| `catboost_ctx` | `catboost_lo` 와 같은 초모수(반복 200, 학습률 0.05, 깊이 3, l2 3), random_seed = 학습기 seed, 입력 x25 원값. 학습 행은 같은 (n, 추출, seed)의 TabPFN 컨텍스트 행과 같다. 짝 비교 대조군이다 |

가중치 파일의 SHA-1 과 패키지 판은 조각의 설정 요약에 기록한다.

**범주형 추론(개정 12, 조작적 정의)**: 범주형 열을 지정하지 않아도 tabpfn 8.0.7 은 기본 규칙으로 열 종류를 추론한다. 컨텍스트가 100행을 넘으면 고유값이 4개 미만인 수치 열을 범주형으로 추론하고(x25 에서는 `cci_valid`), 컨텍스트가 100행 이하이면 추론하지 않는다(`inference_config` 의 MIN_NUMBER_SAMPLES_FOR_CATEGORICAL_INFERENCE = 100, MIN_UNIQUE_FOR_NUMERICAL_FEATURES = 4). 고유값이 1개 이하인 열은 상수 열로 분류된다. 추론은 적합마다(컨텍스트마다) 다시 정해진다. 이 규칙은 바꾸지 않고 그대로 쓴다. 적합 뒤 TabPFN 이 정한 열 분류(범주형 열과 상수 열의 색인)를 변형과 컨텍스트 크기(100행 이하, 초과)별로 세어 조각의 `unit.json`(`tabpfn_schema`)에 남긴다. `catboost_ctx` 는 모든 열을 수치로 쓴다(rid 변형의 지역 부호 열만 범주형).

**방법**

| id | 컨텍스트 행의 목표 | 예측 | 기준 λ |
|---|---|---|---|
| P0, P1 | 해석식 | E0·s, E_n·s. 모든 조각에 저장한다 | 없음 |
| D0 | 원천 행 y, 대상 라벨 행 y | f(x) | 1.0 |
| R0 | 원천 행 y − E0·s, 대상 라벨 행 y − E0·s | E0·s + λ·g(x) | 0.25 |
| R1 | 원천 행 y − E0·s, 대상 라벨 행 y − E_n·s | E_n·s + λ·g(x) | 0.25 |

n = 0 에서 R1 은 R0 과 같다(같은 적합을 쓴다). 세 방법은 같은 (n, 추출, seed)에서 같은 컨텍스트 행을 쓰고 목표만 다르다.

**증강 결합 R2 를 넣지 않는 이유**: LG 의 R2 는 대상 A 풀의 유사 잔차 행을 원천 행 수의 10배(r = 10) 넣는다. 원천이 14,000–17,000행이면 유사 잔차 행은 14만–17만 행이다. 컨텍스트 상한 10,000행 안에서 같은 비율을 지킬 수 없다. 상한 안에 넣으려면 유사 잔차 행이 원천 행을 밀어내야 하고 그 비율은 새 자유 모수가 된다. 어떤 비율을 골라도 LG 의 R2 와 정의가 달라 L2 와 같은 축에서 비교할 수 없다. 유사라벨 비율의 영향은 LGX 의 X2(CatBoost, r ∈ {1, 3, 10, 30})가 본다. 같은 이유로 D1 과 R3 도 넣지 않는다.

### 6C.4 컨텍스트 규칙

| 항목 | 규칙 |
|---|---|
| 상한 | 컨텍스트 총 행 수 C = 10,000. TabPFN v2 의 사전 학습 범위이며 넘기지 않는다 |
| 대상 라벨 행 | 선택 라벨 n개를 부분 추출 없이 모두 넣는다. 주 설정은 1배다(LG 기준 구성의 α = 1 에 해당한다). 대상 행 묶음의 크기 T = 중복 배수 × 라벨 수 |
| 원천 행 예산 | m = min(원천 행 수, C − max(T, 1,000)). T ≤ 1,000 인 칸은 모두 같은 예산을 쓴다(원천이 9,000행 이상이면 9,000행). 따라서 n ≤ 1,000 의 라벨 수 효과는 원천 컨텍스트의 변화와 섞이지 않는다 |
| 원천 부분 추출 | 지역(macro) 비례 층화이고 중첩 구조다. 원천 지역 j(셀 수 c_j)의 행을 seed 고정 난수로 순열하고, 순위 p(0부터)의 행에 키 u = (p + 0.5)/c_j 를 준다. 모든 원천 행을 (u, 지역 이름, p) 순으로 정렬해 앞에서 m행을 쓴다. 지역 j 의 행 수와 비례 배분 m·c_j/(원천 행 수)의 차이는 0.5·(1 − w_j) + w_j·(J − 1)/2 이하다(w_j = c_j/원천 행 수, J = 원천 지역 수. 개정 12 에서 고쳤다. 개정 9 의 문구 '1행 이내'는 이 규칙의 실제와 달랐다. 등록 범위의 `--count-only` 에서 차이의 최댓값은 2.78행이고 이론 상한을 넘는 단위는 없다). 작은 예산의 행 집합은 큰 예산의 행 집합에 포함된다 |
| 부분 추출 seed | seed_of('lgt-ctx', 대상, 모드, 분할, 학습기 seed). n, 추출 번호, 방법, 학습기와 무관하다. 학습기 seed 0 과 1 은 서로 다른 원천 부분 집합을 쓰므로 seed 평균에 부분 추출의 변동이 들어간다 |
| 부분 추출이 없는 대상 | 원천 행 수가 예산 이하인 대상(Alaska x 3,860행, 알래스카 하위 x 3,860–3,861행)은 T ≤ 6,139 인 칸에서 원천 전체를 쓴다 |
| 큰 n | n = 1,000 은 T = 1,000 이라 예산이 같다. 전량에서 \|A\| > 1,000 이면 m = min(원천 행 수, 10,000 − \|A\|)로 줄인다(예: 레나 분할 1 은 \|A\| 1,505, m 8,495. Alaska x 분할 1 은 \|A\| 7,436, m 2,564). 줄인 집합은 n ≤ 1,000 의 집합의 부분집합이다 |
| 대상 행이 상한에 가까운 경우 | T > 9,000 이면 대상 라벨 행을 9,000행으로 무작위 부분 추출하고(seed_of('lgt-tsub', 대상, 모드, 분할, n, 추출)) 원천 1,000행을 둔다. 등록 범위에서는 일어나지 않는다(\|A\| 의 최댓값 7,436) |
| 행 순서 | 원천 행(정렬 순) 다음에 대상 행이다. 두 학습기가 같은 행렬을 받는다 |
| 채점 셀 예측 | 채점 셀 전부를 한 번에 예측한다. GPU 메모리 부족 예외가 나면 그 적합만 채점 셀을 4,096행 묶음으로 나눠 다시 예측하고 표지를 남긴다 |

**민감도 설정**(주 설정에서 한 요인만 바꾼다. 두 학습기가 같은 행렬을 받는다)

| id | 바꾼 요인 | 키 표기 | 방법과 n |
|---|---|---|---|
| d3 | 대상 라벨 행 3배 중복(b4 의 규약) | alpha = '3' | D0·R1, n ∈ {3, 10, 40, 160} |
| d10 | 대상 라벨 행 10배 중복(LG α 축의 α = 10 에 해당) | alpha = '10' | D0·R1, n ∈ {10, 40, 160} |
| rid | 입력에 지역 id(원천 macro 의 정수 부호, 대상은 새 부호)를 범주형으로 더한다(b4 의 규약) | 방법 `D0@rid`, `R1@rid` | n ∈ {0, 10, 40, 160, 전량} |
| tgt | 컨텍스트에서 원천 행을 뺀다(대상 라벨 행만) | 방법 `D0@tgt`, `R1@tgt` | n ∈ {40, 160, 320, 1,000, 전량} 가운데 실제 라벨 수가 40 이상인 칸 |

중복 행은 `catboost_ctx` 에도 행 반복으로 준다(표본 가중이 아니다). d10 의 n = 160 은 T = 1,600 이라 원천 예산이 8,400행으로 줄어든다(중첩 구조의 부분집합).

### 6C.6 가설과 판정(결과 열람 전 고정)

모든 대비는 기준 λ 와 4분 판정(6A.2)을 쓴다. 따로 적지 않으면 주 4지역 층화 평균이다. T 는 `tabpfn`, C 는 `catboost_ctx` 다. LGT 의 가설은 모두 보조다. 확인적 가설 집합(6A.2 의 여섯 개)은 바꾸지 않는다.

| id | 가설 | 판정 |
|---|---|---|
| L32 (학습기 동등성) | R1 에서 TabPFN 과 같은 컨텍스트 CatBoost 의 차이는 동등성 한계 안이다 | R1[T] − R1[C] 를 n ∈ {0, 10, 40, 160, 전량} 에서 본다. 다섯 n 모두 동등(λ 0.25 와 1.0)이면 '동등(한계 0.5 cm)'. 우세와 열세가 없고 미결정이 있으면 '차이를 확인하지 못함'. 우세 또는 열세인 n 이 있으면(기준 λ 0.25 의 대비로 판정한다) n, 방향, 크기를 표로 보고하고 λ 1.0 의 대비를 병기한다. n ∈ {3, 320, 1,000} 과 D0, R0 의 같은 대비는 보조다 |
| L33 (순가치) | TabPFN 잔차(R1)는 같은 라벨로 재보정한 물리식(P1)을 넘는다 | R1[T] − P1 을 n ∈ {3, 10, 40, 160, 320, 전량} 에서 본다. 우세인 최소 n 을 4지역 평균인 n 과 2–3지역 평균인 n 으로 나눠 보고한다(L4 와 같은 형식). n ≤ 40 에서 우세이면 '희소 라벨에서도 TabPFN 잔차의 순가치가 있다'. 어느 n 에서도 우세가 아니면 'TabPFN 잔차의 재보정 물리식 대비 순가치는 확인되지 않았다'. 열세인 n 은 표로 보고한다. R1[C] − P1 을 같은 n 에서 병기하고 두 학습기의 4분 판정이 다른 n 을 표시한다 |
| L34 (라벨 0) | 라벨 0 에서 TabPFN 직접 예측(D0)은 P0 를 넘지 못한다. 잔차(R0)는 방향을 정하지 않는다 | (a) D0[T] − P0(n = 0)가 우세가 아니면 지지. 문장 '표형 파운데이션 모델을 학습기로 써도 직접 ML 은 라벨 0 전이에서 물리식을 넘지 못한다'. 우세이면 L1 의 결론을 'TabPFN 을 제외한 학습기 한정'으로 적고 TabPFN 의 곡선을 마스터 곡선에 더한다. (b) R0[T] − P0(n = 0)의 4분 판정을 보고한다. 우세이면 '라벨 0 에서 TabPFN 잔차는 원천 계수 물리식보다 오차가 작다', 열세이면 '오차가 크다', 동등이면 '구별되지 않는다(한계 0.5 cm)', 미결정이면 '차이를 확인하지 못함'. D0[C] − P0, R0[C] − P0 를 병기한다 |
| L35 (전량) | 라벨 전량에서 TabPFN R1 은 P0 를 넘는다 | R1[T] − P0(전량)가 우세이면 지지(L8 과 같은 형식). 지역별 표와 R1[C] − P0, D0[T] − P0 를 병기한다. 러시아 W·E 의 전량은 라벨 14–17개다 |
| L36 (직접 대 잔차, 방향 중립) | 방향을 정하지 않는다 | D0[T] − R1[T] 를 n ∈ {0, 10, 40, 160, 전량} 에서 보고한다(각 방법의 기준 λ). 다섯 n 모두 열세이면 'TabPFN 에서도 앵커 + 잔차 구조가 직접 구조보다 오차가 작다'. 우세인 n 이 있으면 n 을 명시하고 '그 라벨 수에서는 TabPFN 직접 예측이 앵커 + 잔차보다 오차가 작다'. 그 밖은 n 별로 서술한다 |
| L37 (컨텍스트 구성 민감도) | 핵심 대비의 4분 판정은 민감도 설정에서 주 설정과 같다 | 핵심 대비는 R1[T] − R1[C] 와 R1[T] − P1 이고 n ∈ {10, 40} 이다(tgt 는 n = 40 만). 변형(d3, d10, rid, tgt)마다 변형의 T 와 변형의 C 로 같은 대비를 계산한다. 주 설정과 4분 판정이 같거나 동등과 미결정 사이의 변화이면 '강건', 우세·열세와 동등·미결정 사이의 변화는 '약화', 우세와 열세가 바뀌면 '의존'이다(L28 과 같은 규칙). '의존'인 변형은 한계 절에 조건을 적는다. 변형 − 주 설정의 대비(변형의 R1[T] − 주 설정의 R1[T])는 방향을 정하지 않고 4분 판정을 보고한다. tgt 에서 이 대비가 우세이면 '원천 컨텍스트는 TabPFN 잔차 예측에 기여하지 않는다', 열세이면 '원천 컨텍스트가 기여한다'를 n 과 함께 적는다 |

**판정 세부 규칙**

| 항목 | 규칙 |
|---|---|
| 풀 | 주 4지역(모드 x)이다. n ∈ {0, 3, 10, 전량} 은 4지역, n ∈ {40, 160, 320} 은 레나·캐나다 2지역 평균이고 '부분(지역 2/4)'가 붙는다. n = 1,000 은 주 4지역 가운데 레나에만 있어 층화 평균을 내지 않고 지역 행(레나, Alaska x)으로 보고한다. 보조 열로 레나·캐나다·Alaska(x) 3지역 평균을 병기한다 |
| 대상별 행 | 27대상의 곡선(두 기준선 Δ, 라벨 순가치, 4분 판정)을 `lgt_curve.csv` 에 싣는다. 러시아 C 와 그린란드는 점 추정만이다 |
| 분할 완결성 | 6A.5a 와 같다. LGT 의 가설은 보조이므로 분할 미완결 대비를 쓴 판정에는 '부분(분할 k/K): '을 붙인다 |
| 판정할 수 없는 대비 | L32, L36 은 등록한 n 의 대비 가운데 4분 판정이 나오지 않은 것이 있으면 판정 불가다. 다만 L32 는 판정이 나온 대비에 우세 또는 열세가 있으면 그 n 을 보고하고 '부분(대비 k/m)'을 붙인다. L33 은 판정이 나온 n 으로 보고하고 '부분(대비 k/m)'을 붙인다. L34, L35 는 대비가 없으면 판정 불가다. L37 은 변형마다 판정하고 대비가 없는 변형은 판정 불가다 |
| Holm 묶음 | LGT 의 주 대비(L32 의 기준 λ 대비 5개, L33 의 6개, L34 의 2개, L35 의 1개)를 한 묶음으로 양측 부트스트랩 p 를 보정한다. L32 의 동등성 p 는 따로 보정한다. 보조 열이며 판정에 쓰지 않는다 |
| 맹검 표지 | 6C.7 의 표를 따른다. L32, L33 의 판정 행은 비맹검 부분(n ≤ 40)을 포함하므로 '재현(비맹검)'으로 표시하고 n ≥ 160 과 n = 0, 전량의 대비 행은 맹검으로 표시한다 |
| 실패 처리 | 비유한 예측이 있는 키는 저장하지 않고 `lgt_failed.csv` 에 남긴다(LG 와 같다). 짝의 한쪽이 실패한 키는 공통 추출 규칙에 따라 대비에서 빠진다 |
| 짝의 한쪽이 실패한 키(개정 12, 조작적 정의) | h40 의 공통 추출 규칙은 두 쪽 모두 추출이 2개 이상일 때 추출 번호만 맞추고 seed 는 보지 않는다. 그래서 위 문장을 다음과 같이 구현한다. 학습기 짝 대비(L32 의 R1, D0, R0 대비와 L37 의 R1[T] − R1[C])는 두 학습기에 모두 있는 (method, alpha, placement, n, draw, seed, lam) 키만 쓴다. 한쪽 학습기에만 있는 키는 그 대비에서 뺀다. 뺀 키 수를 대비 행의 `n_unpaired` 열과 `lgt_meta.json`(`n_unpaired_keys`, 학습기별, 단위별)에 적는다. 대비 행의 `key_set` 열에 키 집합(all, pair, d01, pair_d01)을 적는다. 같은 학습기 안의 대비(R1[T] − P1 등)와 곡선은 저장된 키 전부를 쓴다 |
| L32 의 λ 조합(개정 12, 조작적 정의) | 기준 λ 0.25 의 다섯 대비가 모두 동등이고 λ 1.0 의 대비에 우세 또는 열세가 있으면 판정 문구를 '기준 λ 0.25 에서는 동등, λ 1.0 에서는 차이가 있다(n, 방향). 동등으로 쓰지 않는다'로 적는다. 위 판정 규칙의 세 갈래에 없는 조합이다. 가설과 세 갈래의 문구는 바꾸지 않는다 |
| L37 의 기준 행(개정 12, 조작적 정의) | 주 판정의 기준 행은 위 문구대로 주 설정 조각의 추출 5개를 쓴 대비다. 변형 행은 민감도 조각(추출 2개)이다. 추출 수의 차이가 안정성 분류에 섞이는지 보기 위해 주 설정의 추출 0–1 로 제한한 보조 기준 행을 함께 계산하고, 두 기준의 안정성 분류를 `lgt_tests.csv` 의 `stability`, `stability_d01`, `stability_same` 열과 판정 행의 `stability_d01` 열에 병기한다. 두 기준의 분류가 다르면 판정 문구는 주 기준을 쓰고 결과 절에 두 분류를 함께 적는다. 재실행 없이 집계만으로 계산한다(주 설정 조각에 추출 0–1 키가 있다) |
| L37 의 분할 완결성과 tgt 문장(개정 12, 조작적 정의) | 판정 문구의 '부분(분할 k/K)' 표기에는 변형 행과 기준 행을 모두 넣는다(기준 행의 표기는 '분할 k/K(기준 행)'). 효과 크기 표기는 변형 행으로만 만든다. tgt 의 변형 − 주 설정 대비 문장('원천 컨텍스트는 … 기여하지 않는다', '원천 컨텍스트가 기여한다')은 안정성 판정과 따로 판정 행(clause '변형 − 주 설정')에 적는다. 안정성 판정이 판정 불가여도 이 대비가 유효하면 문장을 적는다. tgt 의 n = 40 은 컨텍스트가 40행이라 TabPFN 의 범주형 추론이 꺼진다(6C.3). 따라서 tgt 의 대비는 원천 행 제거 외에 입력 처리의 차이도 포함한다. 이 점을 한계 절에 적는다 |
| 맹검 표지 보충(개정 12) | L32 의 D0[T] − D0[C], R0[T] − R0[C] 보조 대비는 모든 n 에서 맹검으로 표시한다(6C.7: TabPFN 의 D0, R0 은 기존 결과가 없다) |
| 스모크 산출(개정 12) | 스모크 집계는 곡선, 최소 n, 판정 표, 교차 표를 파일로 쓰지 않고 판정 행과 Δ 를 화면에 내지 않는다. 경로 점검(같은 행렬, n = 0 의 R1 = R0, 묶음 예측 차이, CatBoost Pool 경로 차이, GPU 메모리, 장치 대응), 적합 시간, 집계 경로의 구조 수(행 수, 판정 행 수)만 낸다 |

### 6C.8 실행 환경과 교차 비교

- 로컬 환경: python 3.9.18, torch 2.6.0, tabpfn 8.0.7, catboost 1.2.10, pandas 2.1.4, numpy 1.26.4, scikit-learn 1.3.0, RTX 3090(24 GB). LG 본 실행은 Rescale(python 3.11.10, torch 2.4.1, numpy 2.4.6, catboost 1.2.10, T4)이다.
- LGT 의 모든 가설 대비는 LGT 조각 안에서 닫는다. `tabpfn` 과 `catboost_ctx` 는 같은 프로세스, 같은 스레드 제한, 같은 컨텍스트 행으로 적합한다.
- 교차 비교(보조): 집계 단계에서 본 실행 조각(`data/processed/lg/shards`, 읽기 전용)의 `catboost_lo`(원천 전체로 학습) D0, R0, R1 을 같은 (대상, 모드, 분할, n, 추출, seed) 키로 읽어 R1[T] − R1[`catboost_lo`], R1[C] − R1[`catboost_lo`] 를 계산한다(`lgt_cross.csv`). 뒤의 대비는 컨텍스트 상한이 CatBoost 에 주는 영향의 크기다. 두 대비는 실행 환경(하드웨어, python 과 라이브러리 판)과 교락되므로 가설 판정에 쓰지 않고 '교차 환경(보조)'로 표시한다.
- 재현 점검: 교차 비교에 앞서 LGT 조각과 본 실행 조각의 P0, P1 값(키별 셀 가중 RMSE)을 대조한다. 허용 차는 1e-9 cm 다. 어긋난 단위는 교차 비교에서 빼고 `lgt_gate.csv` 에 남긴다. 하위 지역 정의는 고정 대응표를 읽으므로 환경에 따라 달라지지 않는다. LGT 의 P0, P1 키 가운데 기준 조각에 없는 키의 수를 `n_missing_ref` 열에 남기고 0 이 아니면 통과로 두지 않는다(개정 12).
- 조각 상태와 재실행(개정 12, 운영 규칙): 실패가 없는 조각은 ok 다. 적합을 시도한 학습기 가운데 저장 키가 0 이거나 실패 적합(예외, 비유한 예측, 행렬 점검 실패)의 비율이 20 % 를 넘는 학습기가 있으면 failed 이고 `--resume` 이 다시 실행한다. 그 밖의 실패가 있으면 partial 이다. 같은 학습기의 학습기 실패(적합·예측 예외, 비유한 예측)가 5회 연속되면 그 단위를 중단하고 완료 표지(`unit.json`)를 쓰지 않는다. 예외 뒤 CUDA 문맥을 쓸 수 없으면 워커를 끝내 풀을 새로 만든다. 실행의 종료 코드는 중단 130, 실패 1, partial 만 있으면 2, 그 밖은 0 이다. 본 실행은 `--resume --no-summarize` 로 돌리고, partial 조각이 남으면 두 번째 통과를 같은 명령에 `--rerun-partial` 을 더해 돌린다. 완료 조각이 있는데 `--resume` 도 `--overwrite` 도 없으면 실행을 거부한다.
- GPU 확인과 실행 제어(개정 12, 운영 규칙): CUDA 장치 번호는 `CUDA_DEVICE_ORDER=PCI_BUS_ID` 로 nvidia-smi 번호와 맞춘다. 부모 프로세스는 CUDA 를 초기화하지 않는다. 워커는 작업 단위를 시작할 때마다 배정 GPU 를 nvidia-smi 로 다시 확인한다(첫 CUDA 초기화 전에는 메모리 사용 0 MiB 와 계산 프로세스 없음, 그 뒤에는 자기 외의 계산 프로세스 없음). 걸리면 그 GPU 를 빼고 풀을 다시 만든다. 첫 초기화 직후 자기 PID 가 있는 GPU 가 배정 번호와 다르면 실행 전체를 멈춘다. 풀이 깨지면 실행 중 표지로 원인 단위를 가리고 2회 깬 단위만 격리한다. Ctrl-C, SIGTERM, SIGHUP 은 워커를 종료하고 끝낸다. 워커는 부모가 죽으면 종료 신호를 받는다. 같은 tag 의 두 번째 실행은 잠금 파일로 거부한다. 워커는 단위 시작 때만 GPU 를 확인하므로 호출자는 실행 중에도 nvidia-smi 로 점유를 주기적으로 확인한다.
- 본 실행 결과를 회수하기 전에는 교차 비교와 재현 점검을 건너뛴다. 가설 L32–L37 의 판정은 본 실행 조각 없이 계산한다.
- 공유 서버 규칙: 실행 직전에 nvidia-smi 로 메모리 사용이 0 MiB 인 GPU 를 확인하고 번호가 큰 것부터 쓴다. GPU 0–4 는 남겨 두고 GPU 8(다른 사용자)은 쓰지 않는다. 쓸 수 있는 GPU 는 9, 7, 6, 5 의 4장이다. GPU 하나에 프로세스 하나, 프로세스당 스레드 2–4개(OMP, MKL, OpenBLAS, torch, CatBoost 모두)다. CPU 만 쓰는 학습은 짝 비교용 CatBoost 뿐이며 TabPFN 과 같은 프로세스 안에서 돈다.
- 로컬에서 하는 확인은 py_compile, pyflakes, `--count-only`, 스모크 1회(GPU 1장, 10분 이내)다. 스모크의 산출은 경로 확인과 시간 측정용이며 가설 판정에 쓰지 않는다.

### 6C.10 자원과 시간(추정)

- 시간의 근거는 b4 의 작업 단위별 기록(`b4_targets.csv`)이다. 컨텍스트 약 9,900행, 입력 26개, n_estimators 8, RTX 3090, 4스레드에서 TabPFN 적합과 예측 1건이 6.6–8.0 s(채점 11–1,797행), 채점 4,716–4,866행에서 9.5 s 였다. CatBoost 는 1건 0.34–0.46 s 였다.
- 추정식: TabPFN 1건 = 0.5 + (6.7 + 0.6 × 채점 행 수/1,000) × (컨텍스트 행 수/9,900) s. CatBoost 1건 = 0.4 × (컨텍스트 행 수/10,000)^0.6 s.
- 합계는 TabPFN 34.9 GPU-h 와 CatBoost 1.9 h 로 누적 약 37 h 다. GPU 4장(프로세스 4개)에서 벽시계 약 9.2 h, 추정의 2배를 잡아도 약 18.4 h 로 24시간 안이다.
- 확인하지 못한 것: 컨텍스트 행 수에 대한 시간의 의존(선형으로 가정했다), 채점 6,000–7,300행(Alaska x)의 GPU 메모리와 시간, 스레드 2개일 때의 전처리 시간. 스모크에서 잰 뒤 추정을 고친다.
- 스모크 실측(개정 12, 2026-09-30 01:29–01:36, GPU 9 한 장, 스레드 2, 러시아 W x·캐나다 x 분할 1, 적합 98건): TabPFN 적합과 예측 1건은 컨텍스트 9,000–9,400행, 채점 12–393행에서 5.6–6.3 s(tgt 의 컨텍스트 40–355행은 0.75–0.86 s)였다. 워커의 첫 적합은 가중치 적재와 초기화로 12.6–19.4 s 였다. CatBoost 1건은 0.33–0.47 s(rid 0.45–0.47 s)였다. 추정식 대비 실측 비는 TabPFN 0.92, CatBoost 1.09 다. 단위마다 적합 밖의 고정 부담은 8.5–25.5 s 였다(민감도 단위의 값에는 스모크 전용 점검 시간이 들어 있다). GPU 메모리 최댓값은 할당 1,619 MiB, 예약 5,534 MiB 였다.
- 재계산(개정 12): 등록 범위 172단위에 변형·학습기별 실측 비를 곱하고 단위 고정 부담 26 s 를 더하면 TabPFN 33.7 h, CatBoost 2.2 h, 고정 부담 1.2 h 로 합계 37.1 h 다. 등록된 실행 순서로 워커 4개에 배정하면 벽시계 약 9.4 h 다. 설계 추정(9.2 h)과 비슷하다. 스모크는 채점 393행까지만 보았으므로 채점 6,000–7,300행(Alaska x)의 시간과 메모리, 스레드 4개일 때의 시간은 여전히 확인하지 못했다. 그 부분이 추정의 2배가 되어도 벽시계는 24시간 안으로 본다.

### 6C.11 제외 항목과 확인하지 못한 것

| 항목 | 제외 이유 |
|---|---|
| R2, D1, R3(유사라벨을 넣는 방법) | 컨텍스트 상한 때문에 LG 와 같은 정의를 쓸 수 없다(6C.3) |

| 초모수 조정, 미세 조정, n_estimators 변경 | 기본 설정의 결과를 먼저 낸다 |

한계(개정 12): L37 의 tgt 대비(n = 40)는 컨텍스트가 100행 이하라 TabPFN 의 범주형 추론이 꺼진 상태에서 적합한다(6C.3). 주 설정은 컨텍스트가 100행을 넘어 `cci_valid` 가 범주형으로 추론된다. tgt 의 차이에는 원천 행 제거와 입력 처리의 차이가 함께 들어 있다.

확인하지 못한 것은 다음과 같다. 가중치 배포 조건의 원문은 이 절을 쓰면서 다시 확인하지 않았다(6A.10 의 기록을 따랐다). CatBoost 가 python 3.9 와 3.11 에서 같은 값을 내는지는 확인하지 못했다. 채점 셀을 나눠 예측한 값이 한 번에 예측한 값과 같은지는 스모크에서 확인한다. 동등성 한계의 문헌 근거는 6A.2 에 적은 대로 확인하지 못했다.

## 6B. 독립 지역 확충(LGD, 개정 사전 등록)

**성격**: 사전 등록이다(개정 10). 이 절을 쓰는 시점(2026-09-29 22:42 KST)에 본 실행(작업 ZovWo)의 결과는 회수되지 않았다(`results/rescale_lg/` 가 없다). 새 지역을 대상으로 한 실험은 한 건도 실행하지 않았고 새 입력 표(v4)도 아직 없다. 아래의 라벨 규칙, 지역 정의, 적격 규칙, 가설 L1e·L4e·L8e 와 L38–L42, 판정 규칙은 본 실행과 새 지역 실행의 결과 열람 전에 고정한다. §1–§6, 6A, 6C 의 가설, 판정 문구, 범위, 확인적 가설 집합은 바꾸지 않는다.
**근거**: 사용자 지시(2026-09-29)는 독립 지역 자료 확보가 지금 가능한 지역이 있으면 추가로 내려받아 진행한다는 것이다. 확인적 지역이 4개이고 러시아 W·E 의 채점 가능 셀이 28개와 27개라는 약점은 계산 실험으로 풀리지 않는다.
**6A.10 과의 관계**: 6A.10 은 '독립 지역 확충'을 자료 취득이 필요하다는 이유로 제외하고 투고 후 개정 단계 후보로 두었다. 이 절은 그 제외를 투고 전 실행으로 대체한다. 6A.10 의 표는 그대로 둔다. 같은 표의 '몽골·중앙아시아' 제외는 유지한다(직접 측정 자료를 찾지 못했다).
**이 절을 쓰면서 읽은 것**: 자료 탐색 5갈래의 결과(자료원별 좌표, 방법, 관측 날짜, 라벨 값의 평균과 범위)와 v3 표다. 후보 라벨의 값 분포와 계수 비 E = ALT/√TDD 의 중앙값을 보았다(6B.7). 모델 예측값과 실험 결과는 읽지 않았다.
**구현 파일**: 자료원별 파서 `scripts/1_data_prep/parse_ext_<id>.py`, 점 자료 `data/processed/ext_labels/<id>_points.csv`, 형식 정의 `data/processed/ext_labels/_schema.json`. 파서, v4 조립 스크립트, 실행 래퍼, 확장 풀 집계기는 이 절을 쓰는 시점에 아직 없다. h40, h41, h42, `src/polar/` 의 기존 모듈, `fidelity_base_v3.csv`, `e5_soil_tdd_v3.csv` 는 고치지 않는다.

### 6B.5 가설과 판정(결과 열람 전 고정)

**풀**

| 풀 | 구성 | 쓰임 |
|---|---|---|
| P4 | 레나, 캐나다, 러시아 W, 러시아 E(v3 셀, 본 실행 조각) | §4 와 6A 의 판정. 바꾸지 않는다 |
| PE1 | P4 와 적격인 얕은 레짐의 새 지역 | 확장 풀의 주 판정 |
| PE2 | PE1 과 적격인 심부 레짐의 새 지역 | 확장 풀의 병기 판정 |

PE1 을 주 판정으로 두는 이유는 두 가지다. 첫째, `fidelity.py` 의 기존 기준(2026-09-08)에서 티베트는 심부 집합이고 L1–L8 은 주 전이 집합을 대상으로 세운 가설이다. 둘째, 탐색에서 본 티베트의 계수 비는 주 전이 지역의 약 7–9배라 원천 계수 물리식의 오차가 다른 지역보다 크게 나올 것으로 본다. 그 경우 cm 단위 층화 평균은 이 한 지역이 지배한다. PE2 의 층화 평균에는 cm 단위와 상대 단위(지역별 Δ 를 그 지역의 P0 RMSE 점 추정으로 나눈 값의 지역 평균)를 함께 보고하고, 두 단위의 판정이 다르면 '척도 의존'을 붙인다.

**가설**

방법, 기호, 기준 λ, 유의 기준(두 가중의 CI), 계산 실패 처리는 §3, §4 와 같다. L1e, L4e, L8e 는 L1, L4, L8 과 같은 가설을 풀만 바꿔 다시 계산한 것이고 방향도 같다. 재표집은 L1e, L4e, L8e 가 1,000회(h40 집계와 같다), 4분 판정을 쓰는 L38–L42 가 10,000회(6A.2 와 같다)다.

| id | 가설 | 판정 |
|---|---|---|
| L1e | D0 는 n ≤ 40 에서 물리식 P0 를 넘지 못한다 | 풀의 지역 N개 가운데 n ≤ 40 에서 D0 − P0 의 블록 CI 상한 < 0(두 가중)인 n 이 있는 지역이 ⌊N/4⌋개 이하이면 지지, 넘으면 기각. 지역을 세는 방식과 전량 행의 처리(실제 라벨 수 40 이하만 포함)는 h40 의 L1 과 같다. N = 4 이면 L1 과 같은 기준이다. PE1 과 PE2 에서 각각 계산한다 |
| L4e | 잔차 ML 은 같은 라벨로 재보정한 물리식(P1)을 넘는다 | R1 − P1 의 풀 층화 평균 CI 상한 < 0 인 최소 n 을 보고한다. n 마다 풀에 들어간 지역 수 k/N 을 적는다. n ≤ 40 에서 성립하면 '희소 라벨에서도 ML 순가치 있음' |
| L8e | 라벨 전량에서 R1 은 P0 를 넘는다 | R1 − P0 의 풀 층화 평균 CI 상한 < 0(두 가중)이면 지지. 지역별 표를 병기한다 |
| L38 (새 지역 단위 재현, 보조) | 새 적격 지역 각각에서 지역 단위 판정이 가설의 방향과 같다 | 새 적격 지역 M개에 대해 (a) n ≤ 40 에서 D0 − P0 가 유의 개선인 n 이 없는 지역 수, (b) 전량에서 R1 − P0 가 우세인 지역 수, (c) n = 10 의 P1 − P0 와 R1 − P1 의 4분 판정을 표로 낸다. (a)와 (b)가 모두 M 이면 '새 지역에서 재현', 아니면 어긋난 지역의 이름과 레짐을 적는다 |
| L39 (라벨 정의, 보조) | 티베트에서 채점 라벨의 정의를 바꿔도 핵심 대비의 판정이 같다 | 대상 셀을 직접 라벨(`qtp_du_gpr`)에서 지온 유도 라벨(`qtp_fu_temp`)로 바꿔 같은 범위를 실행한다. 핵심 대비는 L28 과 같다: D0 − P0(n = 0), P1 − P0(n = 10), R1 − P1(n = 10, 전량), R1 − P0(전량). 분류도 L28 과 같다(강건, 약화, 의존). 두 라벨 집합은 위치가 다르므로 위치 효과가 섞인다는 점을 함께 적는다. 지온 유도 셀이 적격 규칙의 분할과 블록 조건을 채우지 못하면 점 추정만 싣는다 |
| L40 (확충판, 보조) | 기존 확인적 지역에 셀을 더해도 지역 단위 판정이 같다 | Russia_W, Russia_E, Canada 의 확충판(v3 셀과 새 직접 라벨 셀)에서 L1 의 지역 조건, 전량의 R1 − P0, n = 10 의 P1 − P0 를 계산해 본 실행(v3 셀)의 같은 지역 값과 비교한다. 분류는 L28 과 같다 |
| L41 (라벨 집합 변형, 보조) | 새 적격 지역의 판정은 라벨 집합의 변형에 강건하다 | 변형은 셋이다: (a) 탐침, 융해관, 동결관 셀만, (b) 8월 15일 이전의 단일 방문 셀 제외, (c) 계절 말 근거가 `dataset_statement` 인 셀 제외. 변형 뒤에도 적격인 지역만 L38 의 (a)–(c)를 다시 계산하고 L28 의 분류를 쓴다. 적격이 아니게 된 지역은 '변형 불가'로 적는다(Tibet 은 (a)와 (c)에서 대상 셀이 남지 않는다) |
| L42 (원천 구성, 보조) | 새 적격 지역의 판정은 다른 새 지역을 원천에 더해도 같다 | 주 설정의 원천은 v3 의 F4_direct 셀이다. 보조 설정은 여기에 다른 새 지역의 직접 라벨 셀을 더한다. L38 의 (a)–(c)를 두 설정에서 비교하고 L28 의 분류를 쓴다 |

**병기 규칙과 결론 문구**

| 경우 | 문구 |
|---|---|
| P4, PE1, PE2 의 판정이 같다 | '4지역의 판정이 확장 풀(지역 N개)에서 유지된다' |
| P4 와 PE1 이 같고 PE2 가 다르다 | '얕은 레짐의 확장 풀에서 유지된다. 심부 레짐(티베트)을 더하면 달라진다'. 결론을 얕은 레짐으로 한정한다 |
| P4 와 PE1 이 다르다 | '4지역의 판정은 확장 풀에서 유지되지 않는다'. 두 판정을 함께 적고 지역 일반의 문장은 쓰지 않는다 |
| 새 적격 지역이 없다 | '확장 풀을 구성하지 못했다'. 새 지역은 점 추정으로만 보고한다 |
| 풀 지역 수 미달, 계산 실패 | §4 의 판정 세부 규칙과 같다(지역 k/N 표기, 판정 불가) |

L1, L4, L8 의 판정(P4, h40 집계)은 어떤 경우에도 그대로 싣는다. 확인적 가설 집합(6A 의 여섯 개)은 바꾸지 않는다. L1e, L4e, L8e 는 L1, L4, L8 의 재계산으로 표시하고 L38–L42 는 보조다.

### 6B.6 실행 방법

| 단계 | 내용 | 환경 |
|---|---|---|
| 1 | 자료 내려받기와 파싱. 자료원마다 점 자료와 메타 파일을 만든다 | 로컬(네트워크와 가벼운 표 처리) |
| 2 | 1 km 셀 집계, 중복 제거, 공변량 부착(새 DEM 타일과 SoilGrids 창 내려받기 포함) | 로컬(프로세스 1개, 스레드 1개) |
| 3 | v4 조립: `fidelity_base_v4.csv`(v3 와 같은 45열), `e5_soil_tdd_v4.csv`, 라벨 부가 표 `fidelity_base_v4_labels.csv`(loc_id, 자료원, 방법, 라벨 정의, 계절 말 근거, 연도 범위, 대상, 하위 단위), 메타 | 로컬 |
| 4 | 적격 표 작성(`--count-only` 와 분할 구조). v4 해시와 적격 표를 개정 이력에 적는다 | 로컬 |
| 5 | 사전 점검과 본 실행. 본 실행은 새 범위이므로 사용자 확인 뒤 제출한다 | 로컬 서버(개정 13, 사용자 지시 2026-09-30). 개정 12 까지의 기재는 Rescale |
| 6 | 확장 풀 집계. 본 실행 조각(읽기 전용)과 LGD 조각을 읽어 P4, PE1, PE2 의 판정을 낸다 | 집계만 로컬 가능 |

- **범위**: 대상은 Tibet, NAtlantic, Russia_C 와 확충판 셋, 보조 라벨 대상이다. 모드는 x 다. CPU 부분의 방법 축(P0–P3, D0, D1, R0–R3, V1, V1r, CatBoost)을 분할 5, n 격자(|A| 미만과 전량), 추출 5, seed 2 로 실행한다. α 축, 배치 축, 학습기 축(GPU)은 이 개정의 등록 범위가 아니다.
- **원천**: 주 설정은 v3 의 F4_direct 셀에서 대상 macro 와 100 km 버퍼를 뺀 것이다(본 실행과 같은 원천 풀). 실행 표는 대상마다 'v3 행과 그 대상의 새 행'으로 만든다. 다른 새 지역의 셀은 L42 의 보조 설정에서만 원천에 넣는다.
- **하네스**: h40 을 고치지 않는다. h40 은 `load_base` 의 기본 파일 이름을 쓰므로 후보는 둘이다. (가) 대상별 자료 디렉터리에 실행 표를 기본 파일 이름으로 두고 `--data-dir` 로 지정한다. (나) 새 래퍼가 `load_base` 의 파일 인자를 바꾼 뒤 h40 을 불러 쓴다. 통합 단계에서 하나를 정하고 개정 이력에 적는다. h40 의 집계는 주 4지역이 고정이므로 확장 풀 집계는 새 스크립트가 h40 의 층화 평균 함수를 불러 계산한다.
- **재현 점검**: v4 에서 v3 행만 남긴 표가 v3 와 같은지 해시로 확인한다(region 을 바꾼 3행은 region 을 빼고 비교한다). 기존 지역 하나(러시아 W, 모드 x, 분할 1)를 같은 경로로 실행해 본 실행 조각과 대조한다. 허용 차는 6A.6 과 같다.
- **자원**: 적합 수와 비용은 v4 조립 뒤 `--count-only` 로 계산한다. 이 절을 쓰는 시점에는 추정값이 없다.
- **조각과 산출**: tag `lgd`, 산출 `data/processed/lgd/`.

### 6B.9 한계와 확인하지 못한 것

| 항목 | 내용 |
|---|---|

(개정 13) 티베트 자료의 탐갱 식별자 날짜 18개 가운데 6개가 10월이다(2009-10-02, 10-02, 10-05, 10-10, 10-10, 2010-10-15). 조사 기간이 10월을 포함하지만 GPR 점의 날짜는 없어 6B.3 의 10월 단일 방문 규칙을 점 단위로 적용할 수 없다. Tibet 대상 132셀은 모두 dataset_statement 이고 L41 (a)(c)에서 0셀이라 민감도를 낼 수 없다. PE2 결론에 이 한계를 병기한다 |

| 공간 군집 | 새 셀은 소수의 조사지에 몰려 있다(Russia_C 새 셀 64개가 블록 7개, NAtlantic 은 일루리사트 블록에 14셀). 블록 등가중 값을 함께 읽어야 한다. (개정 13) 확정 값: NAtlantic 대상 41셀 가운데 13셀(31.7 %)이 일루리사트 블록 13799897 이고 분할 3, 4 의 채점 셀 가운데 이 블록 비중이 86.7 %, 68.4 % 다. Russia_C 새 51셀 가운데 27셀(53 %)이 Mamontov Klyk 단일 조사(블록 3개)이고 Palmtag 16셀(블록 2개)을 더하면 84 % 다. 대상 셀을 구성 위치 사이 1 km 단일 연결로 묶으면 NAtlantic 41셀이 27묶음, Russia_C 57셀이 26묶음, Tibet 132셀이 109묶음이다 |
