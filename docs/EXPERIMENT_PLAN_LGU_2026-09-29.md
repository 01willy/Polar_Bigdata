## 1. 목적과 배경

### 1.1 목적

사용자 지시(2026-09-29)는 확산, 흐름 정합, 정규화 흐름 등 생성 모델을 물리 잔차 학습과 불확실성 표현에 쓰는 방안을 문헌으로 검토하고 적합한 실험을 추가하라는 것이다. 검토 결과는 검토 문서에 있다. 이 문서는 검토 문서의 권고 3건을 실험으로 등록한다.

| 실험 | 이름 | 질문 | 생성 모델의 자리 |
|---|---|---|---|
| A | 계층 예측 분포 사다리 | 지역·블록 오프셋의 사후 분포로 만든 예측 분포가 상수 폭 보정 구간보다 구간 점수가 낮은가 | 셀 잔차 분포(단 v, 게이트 조건부) |

| C | 공간 정보량 진단 | 공간 상관 거리, 근접 라벨 비율, SAR 제품과 탐침의 정렬이 공간 장 생성 모형의 전제를 만족하는가 | 없음(후속 안의 재심 조건 확인) |

### 1.2 검토 결론 요약

1. 생성 모델은 셀 공변량에 조건부인 p(y|x)를 더 유연하게 표현한다. 전이 오차의 주성분인 지역 수준 계수 차이를 식별할 정보는 추가되지 않는다.
2. 점 예측 오차의 개선을 기대할 근거는 내부 결과와 문헌에 없다.
3. 생성 구간의 전이 커버리지는 0.28–0.40 이고 계층 conformal(hier2_cdf)은 0.863 [0.802, 0.917] 이다.
4. 생성 모델이 맡을 수 있는 자리는 계층 conformal 의 폭 정규화기와 계층 모형 안의 셀 잔차 분포다. 두 경우 모두 이득의 출처는 지역을 집단으로 다루는 구조다.
5. 기대 효과는 오라클 상한으로 구간 점수 11–13 %, 폭 3–11 % 다(탐색값). 가장 가능성 높은 판정은 '미결정'이다.
6. 실험 A 의 주 구성은 비생성 모형이고 흐름은 게이트 조건부다. 독립 지역 확충이 생성 기법 도입보다 우선한다.

### 2.2 기호

| 기호 | 정의 |
|---|---|
| E0 | 원천 S 의 최소제곱 계수 Σ s·y / Σ s² |
| E0^(−k) | S 에서 집단 지역 k 를 뺀 셀의 최소제곱 계수 |
| E_n | (n·E_ls + κ·E0)/(n + κ), κ = 10, E_ls = 선택 라벨 n개의 최소제곱 계수. n = 0 이면 E0 |
| u | 로그 비. 대상 셀은 u = log y − log(E0·s), 집단 지역 k 의 원천 셀은 u = log y − log(E0^(−k)·s) |
| τ | 분위 수준. 격자 τ_j = j/100, j = 1, …, 99 |
| α | 구간의 명목 미포함률. 주 0.1(90 % 구간), 보조 0.2 |
| Q_i(τ) | 채점 셀 i 의 예측 분포의 τ 분위(cm) |

집단 지역의 u 를 E0^(−k) 기준으로 두는 이유는 대상의 상황을 모사하기 위해서다. 새 지역의 로그 오프셋은 그 지역을 뺀 나머지로 구한 계수에 대한 값이다. 알래스카가 원천에 있으면 E0 는 알래스카가 지배하므로, E0 기준의 알래스카 오프셋은 표본 안 값이 되어 0 에 가깝다.

### 2.3 의사 대상 모사(라벨 n개 조건의 보정)

원천의 집단 지역 k 를 가상의 대상으로 두고 대상과 같은 절차를 적용해 표본 밖 점수를 얻는다. 실험 A 의 기준선 B4 와 단 (vi), 실험 B 의 n > 0 보조 분석이 이 절차를 쓴다.

| 항목 | 규칙 |
|---|---|
| n = 0 | 지역 k 의 셀 전체(y, s 유한)를 중심 E0^(−k)·s 로 채점한다 |
| n > 0 | 지역 k 의 셀을 `half_split_blocks`(split_seed e ∈ {1, 2, 3})로 A_k, B_k 로 나눈다. A_k 에서 n개를 무작위로 뽑는다(추출 d ∈ {0, 1, 2}, seed = seed_of('lgu-emu', 대상, 모드, k, e, n, d)). 중심은 E_n^(k) = (n·E_ls + κ·E0^(−k))/(n + κ) 이고 B_k 의 셀을 채점한다 |
| 제외 | \|A_k\| ≤ n 인 지역, 채점 블록 2개 미만인 모사 분할 |
| 합동 | 지역 등가중이다. 지역 k 의 총 가중은 1/K_n 이고 지역 안에서는 (e, d, 셀) 항목을 같은 가중으로 둔다. K_n 은 그 n 에서 쓸 수 있는 집단 수다 |
| 분위 | 합동 CDF 의 수준 c 분위(plug-in, h37 의 hier2_cdf 와 같은 식) |

n ≥ 40 에서는 러시아 W·E 가 라벨을 공급하지 못하므로 집단이 2개(대상에 따라 알래스카, 레나, 캐나다 가운데 둘)다. 보정 집단이 9개 미만이므로 유한표본 보장은 없고 커버리지는 경험 평가다.

### 2.4 예측 분포의 표현

- 모든 방법의 출력은 채점 셀별 분위 격자 Q_i(τ_j)(99점, cm)로 저장한다. 구간은 격자에서 읽는다. 90 % 구간은 [Q(0.05), Q(0.95)], 80 % 구간은 [Q(0.10), Q(0.90)] 이다.
- 점 예측은 예측 분포의 중앙값 Q(0.50)이다(2.8절).
- 대칭 구간 방법(conformal)은 포함 수준 c ∈ {0.02, 0.04, …, 0.98} 의 로그 반폭 h_i(c)로 격자를 만든다. Q_i(0.5 ∓ c/2) = ŷ_i·exp(∓h_i(c)), Q_i(0.5) = ŷ_i. h 는 c 에 대해 단조가 되도록 누적 최댓값을 취한다.
- 생성 학습기 cfm 의 분위는 셀당 표본 512개의 경험 분위다. nflow 의 분위는 표본을 쓰지 않고 spline 순변환에 Φ⁻¹(τ)를 넣어 구한다.
- 분위 교차 점검: 재배열(τ 방향 정렬) 전의 격자에서 인접 분위가 역전된 셀 비율, 역전 쌍 비율, 최대 역전 폭을 기록한다. 채점은 재배열한 격자로 한다. CatBoost 다분위와 cfm 의 결정적 분위 사상(Euler 20단계, 진단용)이 점검 대상이다.
- 위치 전용 λ 규약: 로그 비 z 를 목표로 학습한 생성 학습기의 분위 q_τ(z)를 앵커와 결합할 때 log Q(τ) = log 앵커 + λ·q_0.5 + (q_τ − q_0.5) 로 둔다. λ 는 중심에만 곱하고 폭에는 곱하지 않는다. λ = 0 은 중심을 앵커에 고정한 것이다.

### 2.5 분포 점수

y 는 관측값(cm), ρ_τ(v) = v·(τ − 1{v < 0}) 이다.

| 점수 | 정의 | 단위 |
|---|---|---|
| 다분위 pinball | ρ_τ(y − Q(τ)). τ ∈ {0.05, 0.50, 0.95} 는 따로 저장 | cm |
| CRPS(격자 근사) | (2/99)·Σ_j ρ_τj(y − Q(τ_j)). 1 % 와 99 % 밖의 꼬리는 들어가지 않는다 | cm |
| CRPS(로그 척도) | 같은 식에 log y, log Q 를 넣은 값 | 로그 |
| 구간 점수 | IS_α = (U − L) + (2/α)(L − y)₊ + (2/α)(y − U)₊ | cm |
| 구간 점수 분해 | 폭 (U − L), 하한 이탈 (2/α)(L − y)₊, 상한 이탈 (2/α)(y − U)₊ | cm |
| 커버리지 | 1{L ≤ y ≤ U} | 비율 |
| 폭 | U − L(cm), 로그 반폭 (log U − log L)/2 | cm, 로그 |
| 무한 구간 | L 또는 U 가 비유한인 셀의 비율 | 비율 |
| PIT | 격자를 τ 에 대해 선형 보간한 F(y). y < Q(0.01) 은 0.005, y > Q(0.99) 는 0.995 | 서술 |
| 점 예측 오차 | 중앙값의 제곱 오차(RMSE 로 집계), 절대 오차, 편향 | cm |

집계는 셀 가중 평균(주)과 블록 등가중 평균(블록 평균의 평균)을 함께 낸다. 작업 단위마다 채점 블록별 점수 합과 셀 수를 저장한다.

### 2.6 신뢰구간

| 항목 | 규칙 |
|---|---|
| 주 CI(2단) | 전역 블록 재표집이다. 블록의 정체는 (macro 지역, 0.5° 블록)이다. 자료 전체의 블록을 macro 지역 안에서 복원 추출한다. 재표집 하나의 블록 다중도를 보정 쪽(원천)과 채점 쪽(대상)이 함께 쓴다 |
| 보정 쪽의 재계산 | 실험 A 의 초모수(σ², τ_b², 지역 오프셋, τ_r 의 사후)와 기준선 B4 의 분위, 실험 B 의 보정 분위를 다중도 가중으로 다시 계산한다 |
| 고정하는 것 | E0, E0^(−k), 학습된 모형(생성 학습기, CatBoost), 대상 라벨 추출, 의사 대상 모사의 분할과 추출 |
| 채점 쪽의 재계산 | 채점 블록의 다중도로 셀 가중 평균과 블록 등가중 평균을 다시 계산한다 |
| 결합 | 분할은 같은 재표집 번호끼리 평균한다(LG 와 같다). 지역 층화 평균은 같은 번호끼리 지역 등가중 평균이다 |
| 횟수와 구간 | 2,000회(개정 2 로 1,000회), 백분위 95 % |
| 2단 CI 를 내는 지표 | 구간 점수(α 0.1, 0.2), 커버리지, 폭, 로그 반폭, 중앙값의 RMSE |
| 보조 CI(1단) | LG 규칙(`h4_common.boot_weights`, 분할 안 채점 블록 재표집, 보정 고정). 모든 지표에 낸다. CRPS, pinball, 단 (iv)–(vi)의 대비는 1단 CI 만 있다. (개정 1) 재표집 seed 는 대상마다 다르게 둔다(실험 A `seed_of('lgu-a', 대상, 모드)`, 실험 B `seed_of('lgu-b', 대상, 범위)`). 같은 대상 안의 수준과 대비는 같은 seed 를 쓴다 |
| 1단 대비의 짝지음(개정 1) | 분할마다 A·B 의 키를 (n, 추출) 단위로 묶어 두 쪽에 모두 있는 단위만 쓴다. 단위 안에서는 seed(와 위약 순열)의 평균을 구하고 단위별 A − B 를 평균한다. 한쪽에만 있는 단위, 블록 합이 NaN 인 키(계산 실패), cpu 조각에 기록된 A·B 의 계산 실패는 짝지음 실패로 표시한다 |
| 2단 CI 가 주인 확인적 대비(개정 1) | LGU-A1 과 LGU-A3(2.6절상 2단 CI 를 내는 지표의 대비)은 2단 분포가 없으면 '판정 불가(2단 CI 없음)'이고 1단 판정은 보조 열(verdict_1stage)에만 둔다. 짝지음 실패가 있으면 '판정 불가(계산 실패)'다. LGU-B2 는 짝지음 실패가 있으면 '판정 불가(계산 실패)'다 |
| 표기 | 2단과 1단의 4분 판정이 다르면 '보정 불확실성 의존'을 붙인다. 1단 CI 만 있는 대비는 '1단'으로 표시한다 |

### 2.7 판정 규약

| 항목 | 규약 |
|---|---|
| Δ | Δ(A − B) = 점수(A) − 점수(B). 같은 분할, 추출, seed 의 짝지음이고 음수면 A 가 낫다 |
| 4분 판정 | 우세 = 두 가중의 CI 상한 < 0. 열세 = 두 가중의 CI 하한 > 0. 동등 = 우세도 열세도 아니고 두 가중의 CI 가 모두 [−δ, +δ] 안. 미결정 = 그 외 |
| 동등성 한계(점 예측) | δ = 0.5 cm(LGX 와 같다) |
| 동등성 한계(구간 점수) | 주 한계는 기준 방법 점수의 5 %, 보조 한계는 10 %(보조 열). 기준 방법 점수는 대비의 B 쪽 방법의 점 추정(같은 풀, 같은 n, 같은 가중)이다 |
| 정밀도 규칙 | 대비의 95 % CI 반폭(두 가중 가운데 큰 값)이 주 한계를 넘으면 동등 판정은 '검정 불가(정밀도 미달)'다. 우세, 열세, 미결정 판정은 그대로 낸다. 이 규칙은 반폭만 쓰고 점 추정의 부호를 쓰지 않는다 |
| 풀(실험 A) | 레나, 캐나다, 알래스카(x) 3지역 층화 평균. 레나·캐나다 2지역 평균을 병기한다. 두 평균의 판정이 다르면 '알래스카 의존'을 붙인다 |
| 풀(실험 B, n = 0) | 주 4지역 층화 평균과 러시아 W 를 뺀 3지역 평균을 병기한다 |
| 풀 조건 | 지역이 CI 풀에 들어가는 조건은 사용 분할의 채점 블록 합집합 8개 이상이다(LG 와 같다). 풀 지역 수가 모자라면 '부분(지역 k/N)', 2지역 미만이면 '판정 불가'다 |
| 러시아 W·E | n ≥ 3 의 확인적 판정에서 뺀다(\|A\| 약 15셀). CI 와 함께 서술한다. n = 0 의 범위 all(채점 셀 27–28개, 블록 18–19개)에서는 주 4지역 풀에 넣는다 |
| 다중성 | 가설마다 주 대비를 정하고 나머지는 Holm 보정 p(`m1_stats.holm`, 부트스트랩 p)를 보조 열로 낸다. 판정에는 쓰지 않는다 |
| PIT, KS | 서술 통계로만 쓴다. 군집 자료이므로 검정으로 쓰지 않는다 |
| CRPS | 중심이 같은 방법끼리만 비교한다 |
| 커버리지 조건 | 구간 점수의 우세를 문장으로 쓰려면 그 방법의 풀 평균 90 % 커버리지가 0.80 이상이어야 한다. 미달이면 '우세(커버리지 미달)'로 적고 지지 근거로 쓰지 않는다 |
| 판정할 수 없는 대비 | 행 없음과 계산 실패는 가설을 지지하는 쪽으로 세지 않는다(LGX 6A.5a 와 같다) |
| 분할 완결성(개정 1) | 풀 지역마다 사용한 분할 수를 그 지역의 기대 분할 수(중복·무효 분할을 뺀 수)와 비교한다. 지역 사이의 최솟값·최댓값을 비교하지 않는다 |
| 폭 | 폭의 감소는 모형 구조에서 자동으로 나오므로 근거로 쓰지 않는다 |
| 기존 표 | hier2_cdf, wconf 는 같은 채점 셀에서 다시 계산한다. C2 의 기존 CI 와 나란히 비교하지 않는다 |

## 3. 실험 A: 계층 예측 분포 사다리

### 3.1 모형

로그 비 u 를 지역 오프셋, 블록 오프셋, 셀 잔차의 합으로 둔다.

- u_(r,k,i) = a_r + b_(r,k) + ε_(r,k,i)
- a_r: 지역 r 의 오프셋(log E 의 지역 차). 사전분포의 위치는 0 이다(중심 E0).
- b_(r,k): 0.5° 블록 k 의 오프셋. b ~ N(0, τ_b²).
- ε: 셀 잔차. 위치 0, 밀도 f(·|x).
- 라벨 n개의 사후: p(a | 라벨) ∝ p(a)·Π_j ∫ N(b_j; 0, τ_b²)·Π_(i∈j) f(u_i − a − b_j | x_i) db_j. j 는 라벨이 있는 A 블록이다.
- 예측 분포: 채점 셀은 새 블록에 있으므로 u_i = a + b + ε_i 에서 a 는 사후, b 는 사전, ε_i 는 잔차 밀도를 따른다. n = 0 이면 사전 예측 분포다.
- 셀의 분위는 Q_i(τ) = E0·s_i·exp(q_u,i(τ)) 다.
- 초모수(σ, τ_b, τ_r)와 잔차 모형은 대상과 100 km 버퍼를 뺀 원천에서만 추정한다.

### 3.2 초모수 추정(원천만 사용)

집단 지역 k ∈ G 의 블록 j 에 대해 셀 수 n_kj, 평균 ū_kj, 블록 내 제곱합 SSW_kj 를 구한다. u 는 E0^(−k) 기준이다(2.2절).

| 초모수 | 추정식 |
|---|---|
| σ_k² | Σ_j SSW_kj / Σ_j (n_kj − 1). 자유도 Σ_j (n_kj − 1) 가 10 미만인 지역은 σ² 계산에서 뺀다 |
| σ² | 해당 지역의 σ_k² 의 평균(지역 등가중). 해당 지역이 없으면 셀 합동 값으로 두고 표시한다 |
| τ_b² | 블록 5개 이상인 지역에서 τ_(b,k)² = max(Var_j(ū_kj) − σ²·mean_j(1/n_kj), 1e-4). τ_b² 는 그 지역 평균 |
| 지역 오프셋 | w_kj = 1/(τ_b² + σ²/n_kj), ā_k = Σ_j w_kj·ū_kj / Σ_j w_kj, v_k = 1/Σ_j w_kj |
| τ_r²(대입값) | max((1/K)·Σ_k (ā_k² − v_k), 1e-4). 위치 0 기준의 2차 적률이다 |
| 단 (i)의 값 | σ_1² = 지역 셀 평균 기준 분산의 지역 등가중 평균. ā_k^cell = 지역 셀 평균. τ_r1² = max((1/K)·Σ_k ((ā_k^cell)² − σ_1²/n_k), 1e-4) |

독립 지역이 4–5개이므로 τ_r 은 식별이 약하다(검토 문서 3.5절). 단 (iii)은 τ_r 을 대입값으로 두지 않고 사후 분포로 적분한다.

### 3.3 사다리의 단

| 단 | a 의 사전분포 | 블록 효과 | 셀 잔차 | 계산 | 지위 |
|---|---|---|---|---|---|
| (i0) | `h4_common.offset_mle_prior`(셀 3개 이상 지역, 위치 log E0)의 사전 그대로 | 없음 | N(0, σ²_h4) | `offset_mle_estimate` | 참조(LG 의 P3 과 같은 중심) |
| (i) | N(0, τ_r1²) | 없음 | N(0, σ_1²) | `offset_mle_estimate` 에 3.2절의 값을 넣는다 | 기준 |
| (ii) | N(0, τ_r²) | N(0, τ_b²) | N(0, σ²) | 닫힌 형태 | 기준 |
| (iii) | Student-t(자유도 4, 척도 τ_r), τ_r 에 half-normal(척도 0.5) 초사전분포 | N(0, τ_b²) | N(0, σ²) | 1차원 격자 | 확인적 주 구성 |
| (iv) | (iii)과 같다 | N(0, τ_b²) | 이분산 Student-t, 척도 σ_i(x), 자유도 ν_ε | CatBoost 척도 모형과 2차원 구적 | 보조 |
| (v) | (iii)과 같다 | N(0, τ_b²) | nflow(위치 0 고정, 척도와 형태가 x 에 의존) | GPU | 게이트 조건부 |
| (vi) | (iii)의 구간에 원천 지역을 집단으로 둔 conformal 후보정 | | | 2.3절 모사 | 보조(표기 iii+c) |

**단 (ii)**: 라벨을 A 블록별로 묶는다. 블록 j 의 라벨 수 n_j, 평균 ū_j 에 대해 우도는 L(a) = Π_j N(ū_j; a, τ_b² + σ²/n_j) 다. 사후 정밀도 P = 1/τ_r² + Σ_j 1/(τ_b² + σ²/n_j), 사후 평균 m = [Σ_j ū_j/(τ_b² + σ²/n_j)]/P, 사후 분산 1/P. 예측 분포는 u ~ N(m, 1/P + τ_b² + σ²) 다.

**단 (iii)**:
- τ_r 의 사후: p(τ_r | 원천) ∝ HN(τ_r; 0.5)·Π_(k∈G) ∫ t_4(a_k; 0, τ_r)·N(ā_k; a_k, v_k) da_k.
- a 의 사전: p(a) = ∫ t_4(a; 0, τ_r)·p(τ_r | 원천) dτ_r.
- a 의 사후: p(a | 라벨) ∝ p(a)·L(a). L 은 단 (ii)와 같다.
- 예측 밀도: p(a | 라벨)과 N(0, τ_b² + σ²)의 합성곱. CDF 를 누적해 분위를 보간한다.
- 격자: a 는 [−2, 2] 간격 0.005(801점), τ_r 은 [0.01, 2.0] 의 로그 등간격 120점, u 는 [−4, 4] 간격 0.005.
- 격자 계산의 조작적 정의(개정 1): τ_r 사후의 적분에서 t_4(a; 0, τ_r)는 a 격자 칸의 적분 질량(Student-t CDF 의 차)으로 두고 격자 밖 질량으로 다시 정규화하지 않는다. N(ā_k; a, v_k)는 칸 평균 밀도다. a 의 사전 p(a)는 τ_r 로 적분한 주변 분포를 격자 범위 [−2 − h/2, 2 + h/2] 에서 한 번 정규화한다(주변 사전의 격자 절단).
- 단 (i)–(iii)에서는 q_u(τ)가 셀에 의존하지 않는다. 셀 사이의 폭 차이는 E0·s_i 에 비례한다.

**단 (iv)**:
- 학습 목표: 원천 집단 셀의 잔차 ẽ_i = u_i − ā_k − b̂_kj, b̂_kj = [τ_b²/(τ_b² + σ²/n_kj)]·(ū_kj − ā_k).
- 척도 모형: CatBoost(반복 200, 깊이 3, 학습률 0.05, l2 3, 스레드 4), 목표 log(\|ẽ_i\| + 0.01), 입력 x25, 행 가중 min(1, 100/블록 셀 수), seed 2.
- σ_i = c·exp(ĥ(x_i)), [0.02, 2.0] 으로 자른다. c² 는 지역 k 를 뺀 적합의 표본 밖 예측 ĥ^oos 로 구한 (ẽ_i/exp(ĥ_i^oos))² 의 지역 내 평균을 지역 등가중으로 평균한 값이다. (개정 1) 게이트(LGU-A4)에서 지역 k 를 뺀 학습 집단 G − {k} 로 단 (iv)를 학습할 때도 같은 정의를 쓴다: 학습 지역 q 마다 {k, q} 를 뺀 적합으로 ĥ^oos 를 만든다(뺀 지역 k 는 어느 적합에도 들어가지 않는다). 대상당 게이트 CatBoost 적합은 K²(K = 집단 수) 건이다.
- 잔차 밀도: f_i(e) = t_ν(e/(σ_i·κ_ν))/(σ_i·κ_ν), κ_ν = sqrt((ν − 2)/ν). ν = ∞ 는 정규다. ν_ε 의 선택은 2.8절의 규칙이다.
- 라벨 우도의 블록 적분은 b ∈ [−4τ_b, 4τ_b] 의 101점 구적이다.
- 예측: c = a + b 의 분포 p_c(사후와 N(0, τ_b²)의 합성곱)에 대해 F_i(u) = Σ_c p_c·F_ε((u − c)/σ_i). σ 를 [0.02, 2.0] 의 로그 등간격 32수준으로 두고 수준별 분위 격자를 계산한 뒤 셀의 log σ_i 로 선형 보간한다.
- 범위는 주 대상 5개다. 적합 수는 대상마다 (집단 수 + 1) × seed 2 다.

**단 (v)**:
- nflow 위치 고정 변형(2.10절), 목표 ẽ_i, seed 3. 학습 행과 행 가중은 단 (iv)와 같다.
- 라벨 우도의 log f_i 는 ε 격자([−4, 4], 간격 0.01)에 밀도 표를 만들어 선형 보간한다.
- 예측: F_i(u) = Σ_c p_c·F_(ε,i)(u − c). F_(ε,i)는 흐름의 분위 함수(200점)를 ε 격자에 보간한 CDF 다.
- 게이트(LGU-A4)를 통과한 대상에만 실행한다.

**단 (vi)**:
- 지역 k 를 의사 대상으로 두고 단 (iii)의 구간을 만든다. 이때 초모수는 G 에서 k 를 뺀 집단으로 다시 추정한다.
- 점수 s_i = max(log Q_lo,i − log y_i, log y_i − log Q_hi,i). 지역 등가중 합동 CDF 의 (1 − α) 분위가 c_n(α)다.
- 구간은 [Q_lo·exp(−c_n), Q_hi·exp(c_n)] 다. c_n 이 음수이면 구간이 좁아진다. 하한이 상한을 넘으면 둘 다 중앙값으로 둔다.
- α ∈ {0.1, 0.2} 의 구간만 낸다.

주 분석에서 빼는 항목은 검토 문서와 같다: EM 식 반복 학습, 산포 배율, 실제 지역 SBC, cfm·ddpm 핵밀도 우도, 배치 규칙 비교, 잠재 공간 재보정.

## 4. 실험 B: 정규화기 비교형 계층 conformal

### 4.1 방법 정의

- 중심은 앵커에 고정한다. n = 0 은 ŷ_i = E0·s_i, n > 0 은 ŷ_i = E_n·s_i 다. 점 예측은 정규화기에 따라 바뀌지 않는다.
- 점수: s_i = \|log y_i − log ŷ_i\| / σ_i. σ_i 는 정규화기가 주는 셀별 로그 척도다.
- 보정(n = 0): 집단 지역 k ∈ G 를 하나씩 빼고 정규화기를 학습해 지역 k 의 셀에 표본 밖 σ_i 를 준다. 지역 k 의 중심은 E0^(−k)·s 다. 지역 등가중 합동 CDF 의 수준 c 분위가 q(c)다.
- 구간: [ŷ_i·exp(−q(1 − α)·σ_i), ŷ_i·exp(q(1 − α)·σ_i)]. 분위 격자는 c ∈ {0.02, …, 0.98} 의 h_i(c) = q(c)·σ_i 로 만든다(2.4절).
- 대상의 σ_i 는 원천 S 전체로 학습한 정규화기의 예측이다.
- n > 0 에서는 정규화기를 다시 학습하지 않는다. 중심만 E_n 으로 바꾸고 2.3절의 모사로 q 를 다시 보정한다.
- 생성 학습기와 CatBoost 다분위의 목표는 로그 비 z = log y − log(E0^학습·s)다. E0^학습 은 그 학습 집합의 최소제곱 계수다.
- σ_i = (q_0.95(x_i) − q_0.05(x_i))/2, [0.02, 2.0] 으로 자른다.

두 방법은 위치 전용 λ 규약(2.4절)의 λ ∈ {0, 0.25, 1.0} 으로 낸다. λ = 1.0 이 생성 학습기의 원래 구간이다.

### 4.4 가설과 판정(결과 열람 전 고정)

| id | 지위 | 대비 | 판정 |
|---|---|---|---|
| LGU-B1 | 한계 확인(비맹검) | cqr_pool(nflow, cfm, λ = 1.0)의 90 % 커버리지, 주 4지역 평균 | 두 학습기 모두 두 가중의 점 추정이 0.85 미만이면 '원천에서 셀 교환성으로만 보정한 생성 분위 구간은 새 지역에서 목표 커버리지에 못 미친다'. 아니면 값을 그대로 보고하고 H15 서술을 고친다 |

**LGU-B2 의 판정**

'조건부 폭이 지역 간에 전이된다'를 쓰는 조건은 다음을 모두 만족하는 경우다.

1. 두 가중 규약에서 2단 CI 상한이 0 미만이다.
2. 4지역 가운데 3지역 이상에서 셀 가중 점 추정이 음수다.
3. nflow 정규화 구간의 주 4지역 평균 90 % 커버리지가 0.80 이상이다.
4. nflow 의 유효 seed 가 모든 풀 지역에서 2개 이상이다.

두 CI 가 0 을 포함하면 '미결정', 두 CI 하한이 0 을 넘으면 '악화'다. 1 을 만족하나 2–4 가운데 하나라도 어긋나면 '조건부 우세(어긋난 조건 명시)'로 적고 위 문장을 쓰지 않는다. 러시아 W 를 뺀 3지역 평균의 판정이 다르면 '러시아 W 의존'을 붙인다.

대비는 seed 짝지음이다. 위약은 같은 seed 의 σ 를 섞은 것이고 순열 10회를 평균한다.

**평균 로그 폭을 맞춘 조건(LGU-B4)**: 정규화 구간의 로그 반폭을 h_i = q_const·σ_i/mean_i(σ_i)로 둔다. mean 은 대상 채점 셀의 셀 가중 평균이다. 평균 폭을 같게 두고 셀 사이의 폭 배분만 비교한다. 대상의 공변량만 쓴다.

### 4.5 필수 진단과 지표

- 집단별 정규화 점수의 분포(분위 5, 25, 50, 75, 90, 95 %)와 분위 초과 비율(지역 k 의 점수가 q 를 넘는 비율)
- 알래스카 집단 제외 민감도(알래스카가 대상이 아닌 경우 알래스카를 보정 집단에서 뺀 q 와 점수)
- 6–7월 관측 제외 민감도, 기기 층별 값
- σ 의 분포: 대상과 집단 지역별 분위, 절단에 걸린 셀 비율
- 구간 점수와 분해, 90 %·80 % 커버리지, 폭, 로그 반폭, 무한 구간 비율, CRPS(cm, 로그 척도), PIT(서술)
- 분위 교차 점검 값(cbq, cfm 결정적 사상)과 적합 실패 기록
- 셀별 σ 와 구간(폭 지도의 입력). 대상의 `eval_mask` 셀에 한정한다. 1 km 격자 지도는 만들지 않는다(9절)

CUDA_DEVICE_ORDER=PCI_BUS_ID 이므로 이는 물리 GPU 0(다른 사용자 작업 중)이며, 첫 heavy 시험 실행(03:12–03:15)에서 약 1–2분 쓰였을 가능성이 높다. 기전은 탐침(환경 변수를 지운 채 CPU 적합 뒤 장치 수 10)으로 확인했고, 실제 GPU 0 사용 기록은 확인하지 못했다. 그 실행에서 시험 k(래퍼 재현, cfm 최대 절대 차 3.2)와 q(같은 seed 의 표본 불일치)가 실패했다. 시험 도우미 `_synth` 가 CUDA_VISIBLE_DEVICES="" 상태에서 CUDA 런타임을 먼저 초기화하고 장치 수 0 을 확인하도록 고쳤다. 다시 실행한 heavy 시험은 69개 모두 통과했고, 실행 중 시험 프로세스의 GPU 사용은 관찰되지 않았다. 하네스의 워커는 torch 를 부르기 전에 CUDA_VISIBLE_DEVICES 를 두므로 이 문제가 없다.
3. 시험 k, c 에 확정 근거 값(래퍼 재현 차, 구적 격자 차, SBC 값)을 출력하는 줄을 더했다.

본 실행 명령(호출자가 시작한다. 저장소 루트에서):
1. 사전 점검(권고, GPU 필요): `scripts/local/run_lgu_local.sh --precheck --gpu 2,1 --threads 4`. 끝나면 `lgu_precheck_decisions.csv` 의 결정을 개정 이력에 적는다.
2. 본 실행: `setsid nohup scripts/local/run_lgu_local.sh --full --gpu 2,1 --threads 4 > logs/lgu/full_nohup.out 2>&1 &`. 확정표에 따라 `--nboot 1000`(스모크표), `--s-gen 512`(기본값)가 붙는다(사전 점검표가 있으면 그 값). `--full` 은 기본으로 `--resume` 이므로 같은 명령으로 재개한다.
3. 집계만 다시 할 때: `scripts/local/run_lgu_local.sh --full --summarize-only --threads 4`.

## 10. 쓰지 않을 문장

검토 문서 부록 A 를 그대로 옮긴다.

| 문장 | 사유 |
|---|---|
| 생성 모델이 점 예측 오차를 줄인다 | 내부·문헌 근거 없음 |
| 확산 또는 흐름 정합이 분위 회귀보다 낫다 | 문헌에서 구분되지 않음 |
| 생성 학습기와 분위 회귀는 동급이다 | CI 가 0 을 포함하는 것만으로는 쓸 수 없음. LGU-B3 이 동등(주 한계)일 때만 한계를 명시해 쓴다 |
| 커버리지가 보장된 구간 | 보정 집단 2–5개 |
| 라벨이 구간을 좁힌다 | 폭 감소는 모형 구조에서 자동 발생 |
| 조건부 폭이 지역 간에 전이된다 | LGU-B2 의 조건을 모두 만족하기 전 |
| 생성 모형과 conformal 의 결합은 선례가 없다 | 인접 선행 있음(검토 문서 7.6절) |

이 문서에서 더한 문장은 다음과 같다.

| 문장 | 사유 |
|---|---|
| 계층 모형이 라벨 0 에서 목표 커버리지를 준다 | 라벨 0 의 예측 분포는 초사전분포 선택이 정한다(LGU-A5 는 민감도 표) |
| 흐름이 잔차 분포를 개선한다 | 게이트(LGU-A4)는 실행 여부의 기준이며 대상 채점의 우세가 아니다 |
| 공간 상관이 없다 | 실험 C 는 진단이며 CI 없는 변동도는 부재의 근거가 아니다 |

신규성은 방법이 아니라 평가 조건(지역 제외 × 대상 라벨 수 × 현장 관측)으로 한정한다.
