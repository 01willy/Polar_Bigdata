# 그림 설계 제안 4차 (v15.1, 2026-10-22)

## 7. 글자 · 색 · 아이콘 점검(v15.1 본문 그림 7장 + 보충 11장 + 제안 15장)

- 글자: 모두 FreeSans(Helvetica 계열 산세리프) 6.5 / 7 / 8 pt(눈금 · 주석 / 라벨 / 패널 문자). PDF 글꼴 내장 확인(각 json 의 pdf_fonts). Sci Rep 지침(단일 산세리프, 소문자 굵은 패널 문자) 충족.
- 색: 방법 3색(채도 낮춘 Okabe–Ito 파랑 · 주황 · 보라) + 회색 기준(원천 계수 Stefan). 제품은 녹회색 · 자회색 · 황갈색, 지역은 남색 · 청회색 · 청록회색으로 채도를 낮춰(paper_v15) Fig 4 · 5 의 요란함을 없앰. 지도는 oslo(순차) 와 vik(발산) 각 1벌, 바탕은 회색 육지 · 옅은 물. 색만으로 정보를 나르는 곳 없음(기호 · 선형 · 글자 병기).
- 아이콘: 없음. 상자는 Fig 2b 의 모델 블록 2개뿐(선례 Reichstein 2019 · Kochkov 2024 와 같은 문법). 화살표는 Fig 2b 의 흐름과 P2_3 의 스펙트럼 표시에만.
- 수식: 그림 안에 없음(규칙 10-20). 가중 0.5 · TDD 같은 용어만.
