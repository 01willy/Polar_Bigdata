# 입력 등록부 v5 (2026-10-10)

재설정 문서 `docs/RESET_2026-10-10_KOPRI_FEEDBACK.md` 5.1. 모든 표는 `data/processed/v5/`, 메타(규칙·해시·개수)는 같은 폴더의 `*_meta.json`. 생성 스크립트는 `scripts/1_data_prep/build_v5_*.py`.

## 1. 원칙

- 단위는 셀(v4 `loc_id`, 공변량 동일 위치)과 연도다. 라벨은 관측 연도의 값이고 강제력은 같은 해의 값이다. 기후값 판은 같은 정의의 2011–2024 평균이며 비교용이다.
- 모든 입력에 기간, 해상도, 연도 처리 규칙, 출처, 약관을 적는다. 연도가 없는 입력(지형, 토양)은 '정적' 으로 적고, 특정 해의 값(SAR 2017)은 그 해를 적는다.
- 라벨 값은 공변량·제품 추출 단계에서 읽지 않는다(좌표·연도만).

## 4. 강제력(ERA5-Land 월별, `data/raw/era5land/nh_monthly_2010-2024.nc`, 0.1°, 25–84°N, t2m·sd·stl1)

| 변수 | 정의(연도 y) | 창 |
|---|---|---|
| e5_maat | 2 m 기온 월평균의 평균 | 1–12월 y |
| e5_tdd, e5_sqrt_tdd | Σ max(T_m, 0)·d_m, √ | 1–12월 y |
| e5_twarm | 월 최고 기온 | 1–12월 y |
| e5_fdd, e5_tcold | Σ max(−T_m, 0)·d_m, 월 최저 기온 | 10월 y−1 – 4월 y(전겨울) |
| e5_stl1, e5_tdd_soil, e5_sqrt_tdd_soil | 토양 0–7 cm 온도 평균, 토양 도일 | 1–12월 y. 도일 0 이하는 결측(v3 규칙) |
| e5_swe, e5_swe_max | 적설 수당량 월평균의 평균·최대(m) | 10월 y−1 – 9월 y(수문년) |

격자: 최근접 격자가 육지(전 기간 t2m 유한)가 아니면 ±2셀, ±5셀 안 최근접 육지(직접 15,533, ±2 382, ±5 1,114, 실패 0). 2010 은 전겨울 창이 1–4월로 줄어 `winter_partial = 1`.
교차 점검: 같은 파일의 2015–2020 월 기후값으로 옛 정의를 다시 계산하면 옛 열(`e5clim1520_tdd`)과 99.93 % 셀에서 0.5 °C·d 안에서 같다(차이는 파일·육지 규칙).
옛 정의와 다른 점: 옛 fdd·tcold 는 달력년 기후값, 옛 swe 는 12개월 기후값 평균. 새 기후값 판(`clim1124_*`)은 새 정의의 다년 평균이라 연도 정합 판과 정의가 같다.
