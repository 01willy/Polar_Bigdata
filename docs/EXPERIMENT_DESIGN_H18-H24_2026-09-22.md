### 0.2 변인 통제 원칙
1. **기준 레시피 고정**: M1 ★ = (cond=covonly, dset=alaska, xset=x25, anchor=stefan, pseudo=none, resid=catboost_lo, r=10, seeds 3, splits 3). 모든 실험은 이 레시피에서 **한 요인만** 바꾼다. 두 요인을 함께 바꾼 구성은 "결합" 행으로 별도 표기하고 확인적 검정에 쓰지 않는다.
2. **같은 셀**: 새 공변량이 결측인 셀은 해당 실험의 모든 수준에서 제외한다(평가 마스크 = y ∩ CCI ∩ 토양 도일 ∩ 신규 공변량). 마스크 차이로 인한 수치 변화는 "기준 재채점" 행으로 분리한다.
3. **같은 계수 규약**: 물리 계수(E·보정식)는 항상 학습 실측(알래스카, 라벨 있음이면 A블록 포함)에서만 최소제곱. 대상 라벨은 채점 전용. 계수 대여(H21)의 공여 지역 라벨은 계수에만 쓰고 ML 학습에는 넣지 않는다.
4. **같은 난수**: seed 0–2, split 0–2, 부트스트랩 seed = crc32(가설 id). 모델 하이퍼파라미터는 M1과 동일(변경 금지).
5. **확인적 가설은 아래 §1–§7의 굵은 문장** 하나씩. 가족: {H18, H19, H20, H21}(정보·계수 가족), {H22, H23}(학습 목표 가족), {H24}(관측 설계 가족). 가족별 Holm.
6. **실패 기록 형식**: (원인 → 부족 정보 → 다음 실험) 세 줄. "안 된다"로 끝내지 않는다.
7. **조건**: 주 = 공변량만(AB4: 레나·캐나다·러시아 W·E, 분할 3회). 보조 = 정보 없음(6지역, 러시아 C·그린란드 참고). 해석적 실험(H20·H21)은 정보 없음이 주.

## 1. H18 관측 지표 강제력 (MODIS LST)

**요인**: 강제력 변수(대기 도일 → 관측 지표 도일). 나머지 고정.

### 1.1 자료·파생 변수
- MOD11C3 v061(Terra, 월별 0.05°, LST_Day_CMG·LST_Night_CMG·Clear_sky_days/nights) 2015–2020 → 월 기후값(6년 평균, ERA5 규약과 동일) → 최근접 격자 샘플.
- 파생 5종: `lst_tdd`(월평균 LST의 융해 도일, 주·야 평균), `lst_fdd`, `lst_sqrt_tdd`, `lst_nfactor` = lst_tdd / e5_tdd, `lst_amp`(최난월−최한월). 보조: `lst_nclear_summer`(청천 일수, 품질).
- 결측 규칙: 6–8월 LST 결측 격자는 ±2셀 최근접 유효 격자 폴백, 그래도 없으면 결측(마스크 제외). 폴백 사용 수 기록.
- 청천 편향(clear-sky bias)은 알려진 한계. 물리식은 편향을 E에 흡수하고, ML은 청천 일수를 입력으로 받는다.

### 1.2 수준(각각 ★에서 한 요인만 변경)

| 수준 id | 변경 요인 | 내용 |
|---|---|---|
| 18-P0 | 없음(기준) | Stefan(e5_sqrt_tdd, E_AK), λ=0 |
| 18-P1 | 강제력 | Stefan(e5_sqrt_tdd_soil, E_soil) (기존, 대조) |
| 18-P2 | 강제력 | **Stefan(lst_sqrt_tdd, E_lst)** — E_lst 알래스카 최소제곱 |
| 18-P3 | 강제력 | Stefan(√(n·TDD_air)), n = 알래스카 lst_nfactor 중앙값 × 대상 lst_nfactor/알래스카 중앙값 = 18-P2와 수학적으로 동일 → 생략, 기록만 |
| 18-P4 | 강제력 | 2-파라미터 affine Stefan(lst) (k=2 대조, 18-P0의 k=2 짝 stefan_k2와 비교) |
| 18-X1 | 입력 | ML 입력 x25 → **x25+LST5**(직접 CatBoost, pseudo=stefan r=10) |
| 18-X2 | 입력 | x25 → x25+LST5, anchor=stefan 잔차 λ 스윕 |
| 18-K1 | 앵커 | anchor=stefan → **stefan_lst**, 잔차 catboost_lo λ 스윕(입력 x25) |
| 18-Q1 | 유사라벨 공급원 | pseudo=stefan → **stefan_lst**(직접 CatBoost r=10, 입력 x25) |
| 18-C | 결합(비확인) | x25+LST5 + anchor stefan_lst + pseudo stefan_lst |

**H18(확인적)**: **정보 없음 6지역(층화 CI)과 공변량만 AB4에서 Stefan(LST) − Stefan(air) < 0 [18-P2 − 18-P0]**, 그리고 **공변량만 AB4에서 ML(x25+LST5) − ML(x25) < 0 [18-X1 − ★+pseudo stefan]**. 두 Δ 모두 CI가 0을 제외해야 A.
탐색: 18-K1·18-Q1·18-C가 Stefan(air)를 넘는지(결정 규칙 B 이상이면 원고 결과 절).
실패 시 기록: LST가 n-factor 변동을 담지 못함(청천 편향·0.05° 해상도) → 지표 온도의 연중 변동·적설 단열 정보 부족 → 8일 MOD11A2 또는 CCI 지표 온도(MAGT 부산물) 시험.

## 3. H20 시뮬레이터 상대 계수 (E_cci)

**요인**: 앵커(계수 공간 구조의 출처). 해석적(CPU).
- E_cci(x) = cci_alt / e5_sqrt_tdd. 알래스카 학습 실측으로 척도 c = E_AK / median_AK(E_cci).
- 주의(설계 시 확인): 셀 단위 E_hybrid·√TDD = c·cci_alt, 즉 **CCI의 1-파라미터 척도 보정**과 같다(기존 cci_cal은 2-파라미터 affine). 따라서 H20의 독자성은 **블록 매끄러움**에 있다: E_cci를 0.5° 블록 중앙값으로 매끄럽게 한 뒤 셀 √TDD를 곱하면 "CCI의 지역 계수 구조 + ERA5의 셀 강제력"이 된다.

| 수준 id | 내용 |
|---|---|
| 20-K0 | Stefan(E_AK) (기준) |
| 20-K1 | cci_cal(affine, 기존) |
| 20-K2 | **cci_scale**: c·cci_alt (1-파라미터) |
| 20-K3 | **cci_blockE**: c·median_block(E_cci)·√TDD(x) |
| 20-K4 | cci_blockE + stefan 등가중 |
| 20-R | 20-K3 + 잔차 catboost_lo λ 스윕 (x25) |

**H20(확인적)**: **정보 없음 6지역·공변량만 AB4에서 cci_blockE − Stefan < 0**. 20-K2가 20-K1과 같으면 H20 독자성 없음으로 기록.

## 4. H21 지역 간 계수 대여 + 물리식 조건 엄밀화

**요인**: E의 출처(알래스카 단일 → 유사 라벨 지역). 해석적(CPU, 수 분). 조건 = 정보 없음(6지역 LORO + 알래스카를 대상으로 한 역방향 1건은 참고).

### 4.1 공여 집합과 유사도
- 공여 후보: 라벨 지역 7개(알래스카·레나·캐나다·러시아 W·C·E·그린란드) 중 대상 제외. 심부 5지역은 공여·대상 모두 제외(레짐 다름).
- 공여 지역 E: 지역 최소제곱 E와 블록 8개 미만 지역의 불확실성(러시아 C·그린란드)은 κ=10 수축(알래스카 E 쪽)으로 안정화.
- 유사도 d(t, s) 3종(라벨 미사용, 공변량·좌표만):
  - `geo`: 지역 중앙 좌표 대권 거리
  - `cov`: 지역 셀 중앙값 x14(지형+기후) 표준화 유클리드 (알래스카 셀 분포로 표준화). x25판(토양 포함)은 보조.
  - `phys`: (MAAT, TDD, SWE, SOC) 4변수 표준화 거리 (Stefan 계수를 결정하는 물리 인자만)
- 추정량
  - `nearest`: E_t = E_{argmin d}
  - `kernel`: E_t = Σ w_s E_s, w_s ∝ exp(−d/τ), τ = 공여 간 거리 중앙값(라벨 미사용)
  - `shrink`: E_t = w·E_kernel + (1−w)·E_AK, w ∈ {0.25, 0.5, 0.75, 1}
  - 대조 `pooled_cell`(공여 전 셀 최소제곱 E, 알래스카 지배)·`pooled_region`(공여 지역 등가중 평균 E)·`E_AK`(기준)
- w·τ·유사도 종류의 선택은 **중첩**: 대상 t를 채점할 때 나머지 공여 지역끼리 leave-one-donor-out으로 최적 (유사도, w)를 고른 뒤 t에 적용(H12 규약).

**H21(확인적)**: **정보 없음 6지역에서 중첩 선택 계수 대여 Stefan − E_AK Stefan < 0 (층화 부트스트랩 CI, 4 지역 이상 방향 일치)**. 보조: `pooled_region` 대조가 같은 이득을 내면 "유사도"가 아니라 "알래스카 단일 계수의 편향"이 원인.
러시아 C·그린란드(블록<8)는 CI 없이 부호만 보고. 예상: 러시아 C(이웃 E 2.3 vs 1.6)·W 개선, 레나 악화 가능.

### 4.2 물리식 조건 엄밀화(탐색적, 같은 스크립트)
지역별로 (i) 멱지수 b: ALT = E·TDD^b 적합(b 자유), (ii) 토양 도일 대 대기 도일 대 LST 도일(H18 후) 중 최적 강제력, (iii) Kudryavtsev 보정 대 Stefan, (iv) n-factor 안정성(E의 블록 간 CV). 산출: 지역 × 가정 표. "규칙 → 라벨 없이 식을 고를 수 있는가"는 공변량(MAAT·SWE·SOC)으로 규칙을 만들고 중첩 선택으로 재검정(H12 규약).

## 5. H22·H23 불변 관계 학습·메타학습

**요인**: 학습 목표 함수(ERM → 불변 벌점). 모델 = M1 mlp(구조·epoch 동일). 입력 = x25(신규 공변량은 넣지 않는다: 요인 분리). GPU 1장.

### 5.1 환경 정의
- 학습 환경 = {알래스카 0.5° 블록을 지역 내 6 fold로 묶은 6 환경} ∪ {대상 제외 주 라벨 지역 각 1 환경(레나·캐나다·러시아 W·E; 러시아 C·그린란드는 셀 수 부족으로 알래스카 환경에 합류하지 않고 제외)}. 대상 지역 라벨은 절대 사용 안 함.
- 목표: 잔차 r = y − Stefan(E_AK)(앵커 고정, 수준 이식은 물리가 담당) 및 직접 y 두 가지.

### 5.2 수준

| 수준 id | 변경 요인 | 내용 |
|---|---|---|
| 22-E0 | 없음 | ERM MLP, dset=loro_main(환경 풀링) = M1 학습집합 축과 동일(재채점) |
| 22-E1 | 목표 | **IRMv1**(λ_IRM ∈ {1, 10, 100}, 워밍업 절반) |
| 22-E2 | 목표 | **V-REx**(환경 위험 분산 벌점, β ∈ {1, 10, 100}) |
| 22-E3 | 목표 | GroupDRO(최악 환경 가중) |
| 22-E4 | 목표+데이터 | **DANN**(대상 A블록 공변량을 도메인 판별기에 사용, 공변량만 조건 전용; λ_d ∈ {0.1, 1}) |
| 22-E5 | 구조 | 지역 임베딩 다중 과제(환경 id 임베딩 + 공유 몸통; 새 지역은 공변량 최근접 환경 임베딩으로 초기화 = H21의 신경망판) |
| 22-S | 특징 선택 | 안정 특징 부분집합: 환경별 잔차 CatBoost 중요도의 순위 상관이 높고 부호가 일치하는 특징만(라벨 미사용은 아님: 학습 환경 라벨 사용, 대상 라벨 미사용) → CatBoost 잔차 |

하이퍼파라미터(λ·β)는 학습 환경 leave-one-environment-out으로 중첩 선택(대상 미사용).

**H22(확인적)**: **공변량만 AB4·정보 없음 6지역에서 불변 학습 잔차 ML(중첩 선택) − Stefan < 0**, 또한 − 22-E0 < 0.

### 5.3 H23 MAML(희소 라벨)
- 에피소드 = 학습 환경 하나에서 support n=3·query 나머지. 대상 지역은 A블록 라벨 n ∈ {3, 5, 10} support(S-F 규약 그대로) → B 채점. 대조 = S-F의 E 수축(κ=10) 적합, 앵커 고정+잔차 fine-tune(사전학습 MLP를 n개로 미세조정), E 재적합.
**H23(확인적)**: **n=3에서 MAML 적응 − E 수축 적합 < 0 (AB4, 분할 3 × 반복 10)**.

## 6. H24 관측 설계 (어떤 라벨이 지역을 대표하는가)

**요인**: 라벨 선택 규칙. 추정량·n·지역 고정. CPU.

### 6.1 실전(4지역 A/B, S-F 규약 계승)
- 풀 = 대상 A블록 셀(후보 라벨), 채점 = B블록. n ∈ {3, 5, 10, 20, 40, 80}(러시아 W·E는 |A|≈15라 n ≤ 10). 분할 3 × 반복 20.
- 선택 규칙(라벨 미사용, 공변량·좌표만):
  - `random`(S-F 기준)
  - `block_rr`: 블록 순환(블록당 1개씩, 블록 순서 무작위)
  - `kmedoid`: x25 표준화 k-medoids(k=n) 대표점
  - `farthest`: 공변량 공간 최원점 우선(k-center, AOA 커버 최대화)
  - `stefan_strat`: Stefan 예측 분위 층화(예측 ALT 범위를 고르게)
  - `geo_strat`: 좌표 k-means 층화
- 추정량(고정, S-F와 동일): `shrink_k10`(E 수축), `refit`(E 재적합), `resid`(앵커 고정 + catboost_lo 잔차 λ=.25, 알래스카 잔차 ∪ 대상 n개), `both`.
- 채점: 규칙 × n × 추정량의 RMSE, 반복 짝지음 Δ(규칙 − random), 승률(Stefan 대비), 최악 반복(95 백분위).

**H24(확인적)**: **같은 n·추정량에서 `kmedoid` 또는 `block_rr` − `random` < 0 (AB4, 짝지은 반복 CI)**, 그리고 **캐나다 n=3 `refit`의 해(+4~+7)가 층화 규칙에서 Δ ≤ 0으로 사라진다**.

### 6.2 샌드박스(알래스카, 큰 n·많은 블록)
- 대상 = 알래스카 13,606셀·74블록, 공여 = 나머지 5 주 라벨 지역(정보 없음 계수 = `pooled_region` E). n ∈ {3, 5, 10, 20, 50, 100, 200}, 반복 20. 규칙·추정량 동일 + `calm_sites`(기존 CALM 62사이트 위치만)·`borehole`(GTN-P 35공 위치만) 두 현실 규칙.
- 산출: "라벨 예산 대 오차" 곡선, "최소 관측망" 지도(n=20 kmedoid 위치).
