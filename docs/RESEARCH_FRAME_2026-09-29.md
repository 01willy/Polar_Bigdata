### 2. 연구 목적·의의·기대효과

**연구 목적.** ALT 실측 라벨은 모든 지역에서 희소하다(알래스카 13,606셀, 레나 3,037, 캐나다 750, 러시아 W 31·E 30). 본 연구는 "ML이 물리식(Stefan, ALT = E·√TDD)을 넘는가"를 "대상 지역 라벨이 몇 개일 때, 어떤 물리 정보 경로로, 어느 기준선 대비 넘는가"로 바꾼다. 라벨 0, 3–320, 전량을 하나의 곡선 Δ(n)으로 통합하고 Δ를 두 기준선으로 보고한다. 원천 계수 E0 Stefan 대비 값은 배포 관점이고, 같은 라벨로 재보정한 Stefan 대비 값은 ML 순가치다. 채점은 지역 홀드아웃과 대상 A/B 블록 분할, 블록 부트스트랩 CI이며 셀 가중과 블록 등가중을 병기한다.

**의의.** 제안서가 조사한 ALT/MAGT 매핑 문헌에는 지역 홀드아웃 오차와 라벨 수 축을 함께 보고한 예가 없다(Ran 2022 거리 블록, Gautam 2025 알래스카 무작위 70/30). 본 연구의 기여는 네 가지다.

- 직접 ML의 지역 간 붕괴와 증강에 의한 회복을 대조군 사다리로 정량화한다.
- 소수 라벨의 이득을 계수 재보정과 잔차 학습으로 분리한다. 러시아 W n = 10에서 E 수축만 −10.32 cm, 수축 + 잔차 −10.66 cm로 잔차 몫은 약 0.3 cm다.
- 곡선이 대상별로 갈리고 비단조일 수 있음을 보인다. 캐나다는 E 수축에서 n = 3 +0.73, n = 320 +3.52 cm다.
- 라벨 없는 진단 지표, 선택 규칙, 우회 기법의 음성 결과를 같은 프로토콜로 보고한다.

문헌 위치는 소수 실측 라벨과 예측을 결합하는 추론 틀(PPI, PPI++), 계층 conformal(Dunn 2023), 학습 곡선의 비단조성(Viering & Loog 2023)이다.

**기대효과.** 새 지역 배포 지침을 라벨 수로 표현한다. 각 단계에 평균 Δ와 함께 악화 대상 비율과 최악 Δ를 같이 제시한다.

- 라벨 0: 물리 앵커, 계층 conformal 90 % 구간, AOA 마스크.
- 라벨 3–10: 흩어 배치한 라벨로 κ = 10 수축 E를 추정한다.
- 잔차 학습: 라벨 전량 또는 α 가중 결과(신규)에 따라 조건을 정한다.

관측 계획에는 분산 배치와 단일 블록 집중 회피라는 방법 수준의 지침만 준다. 지역·지점 우선순위는 음성 결과로 명시한다. 지도의 공간 정보는 AOA 마스크가 담고, 구간은 "90 % 배수 구간 약 2배"(q_log 0.62–0.73)로 제시한다.

### 6. 대회 발표와의 연속성

대회 발표는 알래스카 중심의 희소 라벨 프레임에서 물리 증강과 물리 잔차 ML로 물리식을 넘는 구조체를 제시했다. 확정안은 구조체와 문제의식을 유지하고, 라벨 수를 명시적 축으로 올려 대회 이후 추가된 라벨 0 기법을 같은 축의 왼쪽 끝으로 배치한다.

- **유지되는 것**: Stefan 앵커 + 잔차의 알래스카 지역 내 결과(14.46 → 13.33 cm)는 방향이 유지된다. 같은 구조체가 라벨 전량 전이에서 4지역 평균으로 물리식을 넘는다(H13 λ 0.25, Holm 0.004).
- **바뀌는 것**: CCI 결합에 의한 편향 상쇄(결과 3b)는 철회한다. 사다리의 "전 단 유의"는 정정한다. 알래스카 지역 내 이득은 가중 규약 의존으로 표기한다.
- **기록**: 이 변경은 SI 감사 이력으로 남겨 발표·보고서와 원고의 차이를 추적할 수 있게 한다.

알래스카는 "먼저 시험하는 지역"의 역할을 Alaska_f0 참조 곡선과 6-fold 결과로 유지한다. 증강 + 앵커 + 잔차 전체 워크플로의 알래스카 내 시험은 필수 실험 2·3에서 처음 수행된다.

- 대회 시기에는 '알래스카 지역 내 → 전이' 순서였고, 9월 사전 등록 실험(S-F·h25b·a2·b1–b4)은 '주 4지역 + 하위 지역'을 먼저 확인적으로 돌리고 알래스카는 샌드박스(H24)·하위 지역(AL-1~6)·fold(Alaska_f0) 형태의 참조로만 두었다. Alaska_f0는 분석에서 제외되어 Table 1·Fig 4에 없다.

## D. 희소 라벨 구간 정의와 80–320·전량 결과

### '희소 = 3–40' 의 문서 근거

1. 명시적 정의는 없다. '3–40'이라는 구간은 계획서에 다음 세 곳에서만 나타난다. FINAL §5 F1 가설("구조 지역에서 n ≤ 40으로 넘지 못하며 n ≥ 160에서만"), NEXT P3 제목("라벨 0 → 3–40개 → 판정")과 P4 배경("희소 라벨(3–40)에서는 증강 직접과 앵커+잔차를 따로만 시험"). 어느 문서도 40의 근거를 적지 않았다.
2. 격자의 유래. S-F 계획(TRANSFER 09-15 §3 F1)이 n ∈ {0,5,10,20,40,80}, 실행 시 {0,3,5,10,20,40,80}으로 3을 추가했고(H24·2단계 프로토콜의 '대표점 3개'와 맞춤), 라벨 예산 계획(09-22 §2)이 160·320을 더했다. 하한 3은 E 하나를 추정하는 최소 관측 수라는 의미이고, 상한 40은 (i) 러시아 W·E를 뺀 12대상 전부에서 |A| 미만인 가장 큰 격자값(n=40 12대상, 80–160 12대상, 320 9–10대상; Fig 3·4 캡션)이며 (ii) F1 가설의 경계(40 대 160)이자 (iii) H24에서 "n ≥ 10이면 규칙 차이가 사라진다"는 관찰 위에 놓인 값이다. 러시아 W·E는 |A| ≈ 15라 어떤 정의로도 n ≤ 10이다. 즉 '희소'의 경계는 원리가 아니라 대상 지역들의 A 크기와 가설 경계로 정해졌다.
3. 이 정의를 원고에 쓰려면 "희소 = 라벨로 E는 추정할 수 있으나 잔차 ML이 대상에 적응하지 못하는 구간"이라는 결과 기반 정의로 바꾸는 편이 맞다. 근거: F3(수준 지역 이득의 72–95 %가 E 처리 몫, n=3–10), F1(구조 8대상 중 6대상이 n ≤ 40 미달성).
