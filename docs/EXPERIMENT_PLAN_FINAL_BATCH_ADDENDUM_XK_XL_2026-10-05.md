## XK_support_scale(격자 크기별 오차)

| 항목 | 내용 |
|---|---|
| 질문 | 예측과 라벨을 더 큰 격자로 묶어 비교하면 각 방법의 오차가 어떻게 줄어드는가. 어느 크기에서 잔차 ML 과 Stefan 의 차이가 가장 큰가 |
| 자료 | v3 직접 라벨, 지역 내(알래스카, 레나, 캐나다). x25 |
| 예측 | 0.5° 블록 5겹 교차검증의 블록 밖 예측(셀 단위). 방법: P1(블록 밖 라벨로 계수 재적합), R1(λ 는 학습 겹 안 블록 교차검증, WF6 정의), 제품 원값(CCI v4 `cci_alt`, CCI v5 1997–2023 평균, Wei 2026 2000–2024 평균, 알래스카는 Yi·Kimball 2001–2015 평균) |
| 격자 크기 | 1 km 셀(원 라벨 단위), 0.05°, 0.1°(ERA5-Land 격자), 0.25°. 같은 격자 안 라벨 평균과 예측 평균을 비교한다. 라벨 셀 3개 미만인 격자는 뺀다 |
| 지표 | RMSE(cm)와 편향, 격자 수, 블록 재표집 95 % CI(셀 가중, 블록 등가중, 1,000회). 판정어는 쓰지 않는다 |
| 누설 통제 | 블록 밖 예측만 쓴다. 제품의 학습 지점 누설은 XG 의 5 km 마스크 규칙을 그대로 적용한 판을 함께 낸다 |
| 해석 규칙(결과 전 고정) | 크기가 커질수록 모든 방법의 RMSE 가 줄면 '격자 안 변동이 오차의 큰 몫이다'(WF9 와 같은 방향)라고 쓴다. R1 − P1 의 차이가 0.1° 이상에서 가장 크면 '잔차 ML 의 이득은 기후 격자 규모에서 나타난다'라고 쓰고, 1 km 에서 가장 크면 그 사실을 그대로 쓴다. 제품과의 비교는 '같은 격자 크기에서 RMSE 가 a cm 작았다/컸다' 로만 쓰고 제품의 우열 일반화는 하지 않는다(WRAPUP 10 문장 규칙) |
| 위치 | SI 표·그림 1개, 덱 1쪽 |
| 계산 | 로컬 CPU(4–8 스레드), CatBoost CPU. 적합 수 약 300건 |

## XL_map_products(지역별 고해상 ALT 지도 비교)

| 항목 | 내용 |
|---|---|
| 질문 | 우리 방법의 지도(재보정 Stefan + 잔차 ML, 라벨 전량으로 학습)는 물리식 지도와 기존 제품 지도와 공간적으로 어디서 얼마나 다른가 |
| 지역 | 알래스카 영구동토 구역(1 km, EPSG:3338), 레나 델타(1 km) |
| 비교 대상 | Stefan(같은 라벨로 재보정한 계수), CCI v5 평균, Wei 2026 평균, Aalto 2018, Yi·Kimball(알래스카) |
| 산출 | 지도 패널(우리 지도, 보정량, 90 % 구간 폭, 학습 범위 밖 표시), 제품과의 차이 지도, 영역 평균·사분위·공간 상관 표, 1 km·0.1° 두 표시 해상도의 같은 지도(정보 해상도 시연) |
| 판정 | 없음(서술). 지도에 정확도 주장을 붙이지 않는다. 정확도 비교는 XG(같은 채점 셀)와 XK 만 쓴다 |
| 해석 규칙(결과 전 고정) | '1 km 지도는 표시 해상도이고 정보 해상도는 기후 입력(약 10 km)과 토양 입력(약 5 km)에 묶인다'를 지도 설명에 쓴다. 제품과 차이가 큰 지역은 이름만 적고 원인을 단정하지 않는다 |
| 위치 | 덱 2–3쪽, 논문은 Fig 7b 대안(비교 폴더)과 SI |
| 계산 | 로컬. 예측은 CatBoost CPU, 그림은 matplotlib·Cartopy |
