## 4. LG 7.1 이 J10 에 넘긴 L3 맹검 표지의 문서 대조

LG 7.1 의 L3 행은 맹검 표지를 '맹검 여부를 문서로 대조하지 못했다(J10 에서 확인)' 로 적었다. 문서로 대조한 결과는 다음과 같다. LG 계획서는 편집 금지 대상이라 고치지 않았다. LG 7.1 에 한 줄로 옮겨 적어야 한다.

- **이전에 없던 것**: E0 고정 앵커(R0)에서 α > 1 의 결과는 결과 열람 전에 없었다(`docs/RESEARCH_FRAME_2026-09-29.md` B절 (c) 'E0 고정 앵커·CCI 앵커·Alaska_f0 에서는 미시험', `docs/COVERAGE_MATRIX_BY_REGION_2026-09-29.md` 대상 가중 α 행). L3 주 판정 행(R0, 중첩 선택 α, 알래스카 하위 모드 i)의 α 효과 자체는 새 결과다.
- **이전에 본 것 1**: 같은 네 적격 대상의 α = 1 E0 고정 + 잔차 곡선(a2): 레나 n* 320(all_blocks), 캐나다·AL-5 는 n = 0 에서 이미 물리식을 넘음, AL-2 는 320 까지 미달성(FINAL §10.1 F1 행, RESEARCH_FRAME D절).
- **이전에 본 것 2**: κ 수축 앵커(S3, R1 계열)의 α ∈ {1, 10, 100} 비교(옛 h25·H26, 행 CI). 레나·캐나다·러시아 W 의 n = 3·10 값(`docs/EXPERIMENT_LOG.md` H26 항목)과 AL-2·AL-4·LE-1·CA-2·AL-5 의 α = 100 점 추정(RESEARCH_FRAME B절 α 행)이다.
- **대조 결과**: 문서 근거로는 L3 주 판정에 '비맹검 부분 포함(a2 의 α = 1 E0 고정 곡선, 옛 h25·H26 의 κ 수축 앵커 α 비교)' 이 맞다. R1 보조 판정은 옛 h25·H26 과 같은 앵커 계열이므로 비맹검 부분이 더 크다.

## 5. 기록된 판정 사이의 불일치와 해석 여지

판정을 바꾸지 않았다. 아래는 원고 문장을 쓸 때 충돌할 수 있는 곳이다.

1. **P0 와 P1 의 강약 서술**: LG 7.1 의 n* 요약은 '원천 계수 물리식 P0 는 재보정 물리식 P1 을 포함한 대부분의 방법보다 강한 기준선이다' 라고 적는다. WRAPUP AB4 는 P1 − P0(n 10) 4지역 평균 −2.45 [−3.04, −1.88] 우세(Holm p 0.001)다. 앞의 문장은 지역별 n*(레나·캐나다·러시아 E 에서 P1 이 P0 를 넘지 못함)이고 뒤의 값은 러시아 W 가 지배하는 4지역 평균이다. 집계 방식을 밝히지 않고 인용하면 서로 반대로 읽힌다.
2. **전량의 P1* 누락**: L29 의 라벨 n개 규칙(LG 6A.5a)은 n ∈ {10, 40, 160, 전량}에서 P1* 를 정하게 한다. LG 7.1a 는 n = 10, 40·160 의 P1* 만 적고 전량은 'R1 − P1@tddm 전량 미결정' 만 적었다. 전량에서 P1 보다 우세한 재보정 기준선이 있다면 WRAPUP AB9(R1 − P1 전량 −0.40, 방향)의 '재보정 물리식을 넘는다' 는 L29 규칙상 쓸 수 없다. 지도 잠정판 선택 (c)도 전량 P1* 를 언급하지 않는다. LG 7.1a 에 전량 행 한 줄을 보완해야 한다.
3. **L3 의 '지지' 와 가설 내용**: 등록 기준(중첩 선택 α 의 n* ≤ 40 인 대상 2개 이상)은 충족했으나 중첩 선택 α 가 α = 1 보다 n* 를 줄인 대상은 0/4 다(레나는 α = 1 의 R0 도 n* 40, 캐나다는 3). 판정 이름은 '지지' 이지만 가설 문장 'α 확대가 필요 라벨 수를 줄인다' 의 근거는 없다. LG 7.1 이 이 점을 적었으나 NOVELTY 7.1 표의 미리 정한 분기는 이를 양성 문장으로 바꾸게 되어 있었다(이번에 막았다).
4. **L5 '동급' 과 L26·L32 '차이를 확인하지 못함'**: 같은 MLP·TabM 대 CatBoost 대비가 L5 에서는 등록 규칙(CI 가 0 을 포함하면 동급)에 따라 '동급(부분)', L26 에서는 동등성 한계 규칙에 따라 '차이를 확인하지 못함' 이다. LGT L32 는 '동등' 을 쓰지 않았다. 원고는 L26 문구를 쓴다(WRAPUP 1.5).
5. **L4 한 대비의 세 이름**: R1 − P1(n 10) −0.18 은 L4 에서 '희소 라벨에서도 ML 순가치 있음', LG 7.1a 에서 '우세(크기 0.5 cm 미만)', WRAPUP AB5 에서 Holm p 0.136 으로 초록 '차이를 확인하지 못했다' 이고, 확장 풀에서는 유지되지 않는다(L4e). 각 규칙은 기록되어 있으나 한 문장에 네 한정어를 모두 붙이지 않으면 서로 어긋난다.
6. **L29 의 P* 선택 규칙 문구**: 라벨 0 규칙(LG 6A.5 L29)은 '있으면 점 추정이 가장 낮은 것을 P* 로 둔다' 이고 '우세인 것 가운데' 가 없다. 라벨 n개 규칙(6A.5a)은 '우세인 것이 있으면 점 추정이 가장 낮은 것' 이다. B:ens − P0(n 0)는 −2.73(미결정, AB2)으로 P0@tddm 의 −1.00 보다 낮다. 기록된 P* = P0@tddm 은 '우세인 것 가운데' 로 읽은 결과다. 문자 그대로 읽으면 다른 답이 나온다.
7. **L6 과 AK1w**: 둘 다 '알래스카 우선 검증' 을 다루나 질문이 다르다. L6 은 알래스카에서 통과한 조합이 다른 지역에서도 통하는가(판정 불가, 통과 조합 없음), AK1w 는 알래스카 하위 지역에서 알래스카 밖 원천만으로도 넘는가(지지, 대상 단위 과반 2/5)다. 수치 충돌은 없으나 같은 문단에서 섞이기 쉽다.
8. **L1 의 학습기 범위(공백)**: L1 은 LG 학습기(`catboost_lo`) 기준이다. LGT L36 은 n = 40·160 에서 TabPFN 직접 예측이 TabPFN 잔차보다 오차가 작다고 적었으나(2지역) D0[T] − P0 의 n = 40·160 판정은 기록에 없다. 'n ≤ 40 에서 어떤 직접 ML 도 물리식을 넘지 못한다' 로 일반화하지 않는다.
