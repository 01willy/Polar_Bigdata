## 0. 요약

1. **질문 2의 답**: 현재 결과로 구성 요소별 근거가 있는 알고리즘(Algorithm P)을 정의할 수 있다. 다만 결합된 형태는 아직 시험한 적이 없다. 시험된 것은 블록 층화(S2)와 공변량 최대 최소 거리(S4)를 각각 쓴 경우뿐이다. 따라서 논문에는 Algorithm P 의 정의와 매개변수를 Methods 에 쓰고, 그 효과는 이번에 등록할 XC 확인 시험의 결과로 보고하는 구성을 권한다.
2. **배치가 이기는 곳**: S2·S4 는 캐나다(지역 내 n 50–200, R1 −1.25 – −3.21 cm, 두 가중 우세), 알래스카 하위 지역 AL-1·AL-2(우세 칸 −0.23 – −0.99 cm), 전이 조건의 알래스카(n 10·40, −0.74 – −1.19 cm)와 캐나다(n 40, −2.32·−2.39 cm)에서 무작위보다 나았다. 레나에서는 S2 가 셀 가중으로 1.5–2.2 cm 나빴다. 알래스카 지역 내에서는 S2·S4 의 셀 가중 차이(−0.01 – +0.74, 대부분 양수)와 블록 등가중 차이(−0.89 – −1.73)의 방향이 반대였다.
3. **효과의 경로(사후 서술)**: 지역 내 WF2 에서 배치에 따른 R1(λ 0.25) 변화는 물리식 P1 변화와 거의 같았다(120개 (대상, 전략, n) 칸에서 상관 0.97, 기울기 0.90). 즉 배치의 효과는 대부분 전역 계수 E 의 추정을 통해 나타났다. 예외는 전이 조건의 알래스카로, P1 은 변하지 않았고 R1 만 나아졌다.
4. **지역 특성과의 관계(사후 서술)**: 이득이 큰 캐나다는 블록이 많고(39) 계수 ln E 의 블록 사이 분산 비율이 높다(0.38). 손해가 난 레나는 유효 블록 수가 작고(3.9) 셀이 적은 블록의 계수가 셀이 많은 블록보다 체계적으로 크다(셀 가중 E 1.43, 블록 평균 E 1.97). 셀 가중 채점은 셀이 많은 블록이 지배하므로 블록 균등 배치가 계수를 그 반대쪽으로 끌어 손해가 났다.
5. **기존 문장의 정정 필요**: WF8-b 의 '어느 지역에서도 무작위보다 나빠지지 않았다'는 두 가중 4분 판정 기준의 표현이다. 레나의 셀 가중 차이는 S2 n 10 +1.89 [0.30, 3.08], n 40 +2.18 [0.84, 2.88] cm 로 신뢰구간이 0 위에 있다. '두 가중 모두에서 열세로 판정된 지역은 없었으나 레나의 셀 가중 오차는 1.9–2.2 cm 컸다'로 고쳐야 한다.
6. **XC 등록안**: Algorithm P 배치, 라벨 10개 편향 진단, 라벨 수별 방법 규칙(10개는 R1 λ 0.25, 40·160개는 규칙 W)을 차례로 적용한 워크플로를 무작위 + 고정 R1, 무작위 + P1, Algorithm P + 고정 R1 과 비교한다. 평가는 전이 모드에서 한 번도 쓰지 않은 분할 6–15 와 새 지역으로 한다. 주 가설 8개(Holm), 판정어와 해석 문장을 미리 고정한다. 계산량은 Rescale CPU 약 16–17 프로세스·시간(4스레드), 약 5–10 달러로 추정한다.
7. **XD 등록안**: 블록 제약 k-중심(S8)과 그 변형, 학습된 배치 정책(S9: GBM, DeepSets)을 개발 분할 1–5 에서 시험한다. 하위 지역이 상위 지역과 셀을 공유하므로 평가는 '계열 하나 제외'(알래스카 계열, 캐나다 계열, 레나 계열, 러시아 W, 러시아 E, 티베트, 러시아 C, 새 지역)로 한다. 독립 단위가 7개 안팎이라 결과는 SI 의 탐색 분석으로 둔다. XD 의 결과로 Algorithm P 의 매개변수를 고정한 뒤 XC 를 등록하는 순서를 권한다.

## 2. 구현된 배치 전략의 정밀 정의

### 2.1 공통 기호와 규약

- 대상 지역 셀을 0.5° 블록 단위로 반으로 나눈다(`half_split_blocks`, 분할 seed 1–5). A 반쪽은 라벨 후보 풀, B 반쪽의 `eval_mask` 셀은 채점 전용이다.
- s = √TDD(`e5_sqrt_tdd`), y = ALT(cm). E_ls(L) = Σ_{i∈L} s_i y_i / Σ_{i∈L} s_i². E0 = 원천(다른 지역) 셀의 E_ls. 수축 계수 E_n = (n·E_ls + κ·E0)/(n + κ), κ = 10.
- 표준화(S3, S4, S8): A 풀 x25 의 열 중앙값으로 결측을 채운 뒤 A 풀 평균과 표준편차(+1e-6)로 나눈다. 라벨을 쓰지 않는다. x25 = 지형 6, 기후 8, 토양 9, CCI 2(`src/polar/fidelity.py` 19–38행).
- seed_of(…) 는 인자들의 해시로 만든 정수 seed 다(`src/polar/h4_common.py` 32행). RNG(k) 는 numpy RandomState(k) 다.
- 모드: 지역 내 실험(WF2)은 'r'(학습 행 = 선택 라벨뿐), 전이 실험(WF4, WF8)은 'x'(학습 행 = 원천 행 + 선택 라벨).
- 채점: 셀 가중 RMSE = √(ΣSSE/Σ셀 수), 블록 등가중 RMSE = 블록별 RMSE 의 평균. 같은 분할·추출·seed 의 짝 대비를 분할 안 채점 블록 재표집(10,000회)으로 구간화한다. 4분 판정은 우세(두 가중 CI 상한 < 0), 열세(두 가중 CI 하한 > 0), 동등(네 끝값 절댓값 ≤ 0.5 cm), 미결정(그 밖)이다(`h42 verdict4`).

### 2.2 전략 S1–S7

```text
S1(n, d)                                    # 셀 무작위, h40.draw_cells
  if n = 0: return ∅
  if n < 0: return {0, …, |A|−1}            # 전량
  r ← RNG(seed_of(대상, 모드, 분할, n, d))
  return sort(r.choice(|A|, n, 비복원))
  # seed 에 n 이 들어가므로 n 이 달라지면 서로 다른 독립 추출이다(중첩이 아니다).

S2(n, d)                                    # 블록 층화(블록 순환 배정), h40.draw_blocks
  r ← RNG(seed_of(대상, 모드, 분할, n, d, "block"))
  U ← A 의 고유 블록(정렬), order ← r.permutation(|U|)
  for j = 0 … |U|−1: pool_j ← r.permutation(블록 U_j 의 A 셀 색인)
  sel ← [], active ← order
  while |sel| < n and active ≠ ∅:
      next ← []
      for j in active:
          if |sel| ≥ n: break
          if pool_j ≠ ∅: sel.append(pool_j.pop()); next.append(j)   # pop = 순열의 마지막 원소(블록 안 무작위 셀)
      active ← next
  return sort(sel[:n])
  # n ≤ 블록 수이면 무작위 순서의 앞 n 개 블록에서 한 셀씩, 그보다 크면 모든 블록을 돌며 한 셀씩 더한다.

S3(n, d)                                    # 공변량 군집 층화(군집 크기 비례)
  Z_A ← 표준화(X_A)
  lab ← KMeans(k = 8, n_init = 10, random_state = seed_of("wf-km", 대상, 분할, 8)).fit(Z_A)
  N_c ← 군집 크기
  a ← proportional_alloc(N, n):  q_c = n·N_c/ΣN,  a_c = min(⌊q_c⌋, N_c)
       남는 몫은 소수부가 큰 순서(안정 정렬)로 1씩, 그래도 모자라면 여유(N_c − a_c)가 가장 큰 군집에 1씩
  r ← RNG(seed_of("wf-s3", 대상, 모드, 분할, n, d))
  return sort(∪_{c=0..7} r.choice(군집 c 의 셀, a_c, 비복원))
  # 군집 크기 비례 층화 무작위 추출이므로 기대값으로는 셀 무작위와 같은 가중을 갖는다.

S4(n, d)                                    # 공변량 최대 최소 거리(탐욕 k-중심, farthest-first)
  Z_A ← 표준화(X_A)
  j0 ← RNG(seed_of("wf-s4", 대상, 분할, d)).randint(|A|)     # seed 에 모드와 n 이 없다(WF2·WF8 이 같은 순서)
  π ← [j0];  m_i ← ‖Z_i − Z_j0‖₂;  m_j0 ← −1
  while |π| < n_max:                         # n_max = 예산 격자의 최댓값
      j ← argmax_i m_i (동률은 작은 색인);  π.append(j)
      m_i ← min(m_i, ‖Z_i − Z_j‖₂);  m_j ← −1
  return sort(π[:n])                         # 중첩(앞에서 자른다)
  # 블록을 보지 않는다. 25차원 표준화 공간의 유클리드 거리, 변수 가중 없음.

S5(n, d)                                    # 원천 대비 외삽 우선(AOA 비유사도)
  표준화 통계 ← 원천(모드 x, 100 km 버퍼) x25
  dmin_i ← min_j ‖Z_A,i − Z_src,j‖₂         # k-d 트리
  d̄ ← 원천 부분표본 2,000개(seed_of("wf-aoa", 대상, 분할))의 평균 쌍 거리
  DI_i ← dmin_i / d̄
  π ← DI 내림차순(동률은 RNG(seed_of("wf-s5", 대상, 분할, d)) 난수)
  return sort(π[:n])
  # 사실상 결정적이라 같은 라벨 집합의 추출은 첫 추출만 적합·저장한다.

S6(예산 B, d)                               # 순차 능동 선택(잔차 모형의 예측 분산)
  B ← {20, 50, 100, 200, 500} ∩ (0, |A|)
  cur ← S1(min(20, min B), d)                # S1 의 n = 20 추출과 같다
  while |cur| < max B:
      n_next ← min{b ∈ B : b > |cur|};  k ← min(20, n_next − |cur|)
      E_n ← 수축 계수(cur)
      g ← CatBoost(반복 200, 깊이 3, 학습률 0.05, l2 3, posterior_sampling = True,
                   seed = seed_of("wf-s6", 대상, 분할, d, |cur|)).fit(X_cur, y_cur − E_n·s_cur)
      v_c ← 가상 앙상블 10개 예측의 분산, c ∈ A \ cur
      (선택 적합 실패 시 그 단계만 균등 난수, 표지)
      cur ← cur ∪ (v 상위 k 셀, 동률은 seed_of("wf-s6t", 대상, 분할, d, |cur|) 난수)
      |cur| ∈ B 이면 그 집합을 기록
  # 경로: 20, 40, 50, 70, 90, 100, 120, …, 500.

S7(n, d)                                    # 물리 불확실성 우선(√TDD 큰 순)
  π ← s_A 내림차순(동률은 RNG(seed_of("wf-s7", 대상, 분할, d)) 난수)
  return sort(π[:n])
```

**선택 뒤의 적합(WF2, 지역 내)**: P1 = E_n·s_B. R1 = E_n·s_B + λ·g, g = CatBoost_lo(반복 200, 깊이 3, 학습률 0.05) 를 (X_sel, y_sel − E_n·s_sel) 에 적합, 판정 λ = 0.25. D1 = CatBoost_lo 를 (X_sel, y_sel) 과 유사라벨 행(A 풀에서 round(10·n) 개 복원 추출, 값 E_n·s, 선택 라벨 셀은 실측으로 교체)에 적합. seed 0·1. **WF8(전이)** 은 R1 의 학습 행이 원천 행 (X_src, y_src − E0·s_src) 과 선택 라벨 행의 합이다(`h54` 1592–1598행).

### 2.3 규칙 W(WF4, `TUnit.select_w`)

```text
W(sel, n, d)                                # sel = 선택 라벨의 A 색인
  if |sel| < 10: return P1
  (fold, K, flag) ← cv_folds_of(블록(sel), 대상, 모드, 분할, n, d, k_max = 5)
       r ← RNG(seed_of("lgx-cv", 대상, 모드, 분할, n, d));  U ← sel 의 고유 블록
       |U| ≥ 2: K = min(5, |U|), 순열한 블록을 묶음에 돌려 배정
       |U| = 1: K = min(5, |sel|), 셀 단위 묶음(표지 cell_folds)
  if K < 2: return P1
  for j = 1 … K:
      tr, te ← sel[fold ≠ j], sel[fold = j]
      E1 ← 수축 계수(tr), E2 ← E_ls(tr)
      g1 ← CatBoost_lo(seed 0) on 원천(y − E0·s) ∪ tr(y − E1·s)
      g2 ← 같은 행 + 유사라벨 잔차 행(10 × 원천 행 수, tr 셀만 실측 잔차, 그 밖 0)
      d1 ← CatBoost_lo(seed 0) on 원천(y) ∪ tr(y) ∪ 유사라벨 행(값 E1·s)
      te 예측: P0 = E0 s, P1 = E1 s, P2 = E2 s, R1@0.25 = E1 s + 0.25 g1, R1@1.0 = E1 s + g1,
              R2@0.25 = E1 s + 0.25 g2, D1 = d1
      SSE_m += Σ_te (예측_m − y)²
  return argmin_m SSE_m (동률은 후보 순서 P0, P1, P2, R1@0.25, R1@1.0, R2@0.25, D1)
  # 고른 방법의 최종 예측은 sel 전체로 적합한 그 방법의 B 예측이다(seed 0·1 모두).
```

### 2.4 편향 진단(WF4-c)

```text
진단(대상)
  n = 10 의 각 (분할, 추출)에서 b = mean_{i∈sel}(E0·s_i − y_i)        # 원천 계수 물리식의 라벨 위치 평균 오차
  D = mean(|b|) (분할 5 × 추출 5 = 25개 평균),  부호 있는 값 = mean(b)
  이득 G = RMSE_B(P0) − RMSE_B(W), 라벨 전량
  ρ = Spearman(D, G), 대상 28개
  CI: 반복 r 마다 G_r = h40.contrast 의 블록 재표집 분포 r 번째 값, D_r = (분할, 추출) 25개를 복원 재표집한 |b| 평균,
      ρ_r 의 2.5–97.5 백분위. p_one = P(ρ_r ≤ 0)
```

- 예외: 전이 조건의 알래스카(WF8)는 P1 이 변하지 않았는데 R1 이 0.74–1.19 cm(셀 가중) 나아졌다. 원천 행이 있는 잔차 모형에서는 라벨의 공변량 덮임이 잔차 모형 자체를 바꾼다.

## 4. 질문 2 의 답: Algorithm P

### 4.1 답의 요지

- '퍼뜨린다'는 표현은 두 가지 시험된 규칙(S2: 블록 순환 배정, S4: 표준화 x25 의 탐욕 k-중심)을 가리킨다. 각각은 2.2절의 의사코드처럼 정확히 정의되어 있고 재현 가능하다. 논문에는 적어도 이 정의를 써야 한다.
- 두 규칙의 장점을 합친 결합형(블록 제약 k-중심)을 Algorithm P 로 정의할 수 있다. 각 구성 요소의 근거는 4.3절 표와 같다. 결합형 자체와 일부 매개변수(블록 순서, 블록 안 첫 셀, 배분 지수 γ, 설계 가중 계수)는 시험하지 않았다.
- 배치의 효과가 지역 구조에 따라 부호까지 바뀌므로(3.2, 3.6절), '항상 이득'이 아니라 '이질적이고 블록이 많은 지역에서 이득, 셀 많은 블록에 채점이 몰린 지역에서는 계수 추정 방식에 따라 손해 가능'으로 써야 한다.

### 4.2 Algorithm P 정의(기본 매개변수 P_default)

```text
Algorithm P  (블록 제약 공변량 덮임 배치)
입력
  C      : 후보 셀 집합(측정 가능한 1 km 셀). 모의에서는 대상 A 풀
  X_C    : x25 공변량, b(c) : 0.5° 블록 번호, N_b = 블록 b 의 후보 셀 수
  N      : 누적 예산 일정 (n_1, n_2, n_3) = (10, 40, 160)
  γ      : 블록 배분 지수, 기본 0(블록 균등)
  L_0    : 이미 있는 라벨(없으면 ∅), seed
출력
  순서 있는 목록 π. 단계 k 의 배치는 π[:n_k] 이다(중첩).

P0  표준화   Z ← (중앙값 대체 X_C − 평균_C) / (표준편차_C + 1e-6)        # C 전체 통계, 라벨 미사용
P1  블록 순서 β: 블록 중심 μ_b = mean_{c∈b} Z_c 에 탐욕 k-중심(farthest-first)을 적용한다.
               첫 블록 = seed 로 고른 블록(L_0 가 있으면 L_0 의 블록에서 시작)
P2  for k = 1 … K:
      q ← power_alloc(N_b, n_k, γ):  w_b = N_b^γ,  q_b = n_k·w_b/Σw 의 최대 나머지 배분, 상한 N_b,
           소수부 동률은 β 순서가 앞인 블록 우선            # γ = 0 이면 n_k < 블록 수일 때 β 의 앞 n_k 블록에 1개씩
      deficit_b ← max(0, q_b − |{c ∈ π ∪ L_0 : b(c) = b}|)
      while |π| < n_k − |L_0|:
          b* ← deficit 가 가장 큰 블록(동률은 β 순서)
          if b* 에 아직 라벨이 없다:  c* ← argmin_{c∈b*} ‖Z_c − μ_b*‖     # 블록의 대표 셀(medoid 근사)
          else:  c* ← argmax_{c∈b*, c∉π} min_{l∈π∪L_0} ‖Z_c − Z_l‖       # 전역 최소 거리 최대(블록 안 farthest-first)
          π.append(c*);  deficit_b* −= 1
      단계 k 의 라벨 π[:n_k] 를 측정한다
단계별 처리(워크플로, 5절 XC 와 같다)
  n_1 = 10 : 편향 진단 b10 = mean(E0·s − y). 계수 재보정 E_n(κ 10). 예측 = R1(λ 0.25)
  n_2 = 40, n_3 = 160 : 규칙 W 로 방법 선택. 다음 단계 배치는 π 를 이어서 만든다(라벨 값은 쓰지 않는다)
```

- 계산량: 단계마다 O(n_k · |C| · 25). 알래스카 A 풀(약 7,000셀)에서 n 160 까지 1초 단위다.
- 이론적 성질: 블록 제약이 없을 때 farthest-first 는 k-중심 목적(후보 셀에서 가장 가까운 라벨까지 거리의 최댓값)의 2-근사다(Gonzalez 1985). 블록 제약을 넣으면 이 보장은 성립하지 않는다. Algorithm P 는 블록 배분 안에서 덮임을 최대화하는 휴리스틱이다.
- 실제 현장 적용: C 를 대상 지역의 접근 가능한 육지 1 km 셀로 두면 같은 알고리즘이 '다음 관측 우선순위 목록'을 낸다(WF5 지도의 대체). 현장 비용을 줄이려면 블록당 m 셀 묶음(예: 2셀)을 허용하는 변형이 필요하다. 이 변형은 시험하지 않았다.

### 4.4 논문 서술안(Methods, 한국어 초안)

> 라벨 배치. 새 지역에서 라벨 n 개를 얻을 위치는 Algorithm P 로 정한다. 후보 셀의 공변량 25종을 후보 집합의 평균과 표준편차로 표준화하고, 0.5° 블록마다 라벨 할당량을 블록 균등(γ = 0)으로 정한다. 블록은 블록 중심의 최대 최소 거리 순서로 고르고, 블록 안에서는 첫 라벨을 블록 중심에 가장 가까운 셀에, 그다음 라벨을 이미 고른 라벨까지의 공변량 거리가 가장 먼 셀에 둔다. 라벨은 10, 40, 160개 단계로 늘리며 다음 단계는 이전 배치를 이어서 만든다. 선택에는 라벨 값을 쓰지 않는다. 비교를 위해 구성 요소인 블록 순환 배정(S2)과 공변량 최대 최소 거리 추출(S4), 그리고 셀 무작위(S1), 군집 비례(S3), 외삽 우선(S5), 예측 분산 기반 능동 선택(S6), √TDD 우선(S7)을 같은 시험지에서 평가했다.

## 5. XC_workflow_end_to_end 등록안(확인적, 초록용)

### 5.1 목적과 성격

- 질문: 라벨 배치(Algorithm P), 라벨 10개 편향 진단, 라벨 수별 방법 규칙을 차례로 적용한 워크플로가 새 지역에서 무작위 배치 + 고정 레시피보다 낫고, 재보정 물리식보다 나빠지지 않는가.
- 표지: '결과 열람 뒤 설계'(WF2·WF4·WF8 결과를 보고 만들었다). 확인적 성격은 다음 세 가지로 확보한다.
  1. 모든 매개변수·판정 규칙·해석 문장을 실행 전에 커밋한다.
  2. 기존 대상의 평가는 전이 모드에서 한 번도 쓰지 않은 분할(seed 6–15)로 한다. XD 는 분할 1–5 만 쓴다.
  3. 새 지역(XF 에서 약관이 확인된 곳)은 설계에 전혀 쓰이지 않은 외부 계열로 따로 판정한다.
- Algorithm P 의 고정 규칙(등록 전): XD 가 먼저 끝나면, XD 개발 분할 1–5 에서 {S2, S4, S8(γ 0), S8(γ 0.5)} 가운데 주 계열(5.2절 F1 의 대상, 모드 x) n 40 의 R1(λ 0.25) RMSE 를 셀 가중과 블록 등가중의 평균으로 계산해 가장 작은 것을 Algorithm P 로 고정한다. 설계 가중 E(6.2절)는 XD 에서 두 가중 모두 열세가 없고 하나 이상 우세일 때만 넣는다. XD 가 등록 시한까지 끝나지 않으면 P_default(4.2절)를 쓴다. 어느 경우든 고정 내용을 등록 문서에 적고 커밋한 뒤 실행한다.

### 5.2 대상, 분할, 추출

| 계열 | 대상(모드) | 역할 |
|---|---|---|
| F1 주 계열 | 레나, 캐나다, 러시아 W, 러시아 E, 알래스카(모드 x), 티베트(Tibet_LGD), 러시아 C(Russia_C~lgd, 약관 확인 판) | 주 가설의 층화 평균 |
| F2 하위 지역 | AL-1–AL-6, CA-2, CA-3, LE-1, LE-2(모드 i·x) | 대상별 서술. 상위 지역과 셀을 공유하므로 주 가설에 넣지 않는다 |
| F3 외부 계열 | XF 에서 약관·적격이 확인된 새 지역(등록 시점에 목록 고정) | 적격 지역 2곳 이상이면 H-XC1 n 10 을 별도 확인 가설로 판정, 1곳이면 서술 |

- 분할: split_seed 6–15. 분할 1–5 와 A 블록 집합이 같거나 A·B 가 뒤바뀐 분할, 6–15 안의 중복, 채점 블록 2개 미만 분할은 뺀다. 빈 자리를 다른 seed 로 채우지 않는다. 이번 계산(v3, 닫힌 형식)으로 남는 분할 수는 알래스카·레나·캐나다·러시아 W·러시아 E·AL-3·CA-2·CA-3·LE-1 10, AL-2 9, AL-1·AL-5 8, AL-6 6, LE-2 4, AL-4 1 이다. LGD·XF 표는 등록 전에 같은 규칙으로 센다. 남는 분할이 3개 미만인 대상(AL-4)은 서술만 한다.
- 라벨 수: n ∈ {0, 10, 40, 160, 전량}, n < |A| 인 값만. 따라서 n 160 의 F1 풀은 레나·캐나다·알래스카, n 40 은 여기에 티베트를 더한 4곳, n 10 은 F1 7곳이다(|A| 에 따라 등록 전 확정).
- 추출 d = 0–4(5회). 무작위 팔의 라벨은 중첩 순열 perm = RNG(seed_of("xc-rand", 대상, 모드, 분할, d)).permutation(|A|) 의 앞 n 개다. Algorithm P 팔은 seed_of("xc-P", 대상, 모드, 분할, d) 로 첫 블록을 정한다.
- 학습 seed 0·1. 규칙 W 의 교차검증은 seed 0 적합(WF4 와 같다). 재표집 10,000회.
- 사전 설계 점검(WF10 의 누락 재발 방지): 등록 전에 (대상, n)별 유효 분할 수, |A|, 채점 블록 합집합(CI 조건 8 이상)을 표로 내고, CI 를 낼 수 없는 주 대비는 등록 문서에서 미리 서술로 내린다.

### 5.3 팔(arm)

| 팔 | 라벨 집합 | 방법 | 용도 |
|---|---|---|---|
| A1 워크플로 | Algorithm P | n 10: R1(λ 0.25). n 40·160: 규칙 W. 전량: 규칙 W | 주 |
| A2 무작위 + 고정 R1 | 무작위(중첩) | R1(λ 0.25) | 주 기준 |
| A3 무작위 + P1 | 무작위 | P1(κ 10 재보정 Stefan) | 비열등 기준 |
| A4 P + 고정 R1 | Algorithm P | R1(λ 0.25) | 배치 효과 분리 |
| A5 무작위 + W | 무작위 | 규칙 W(n 10 포함) | 보조(규칙 효과 분리, WF4-a 재현) |
| A6 사후 최선 고정 방법 | 무작위 | {P0, P1, P2, R1@0.25, R1@1.0, R2@0.25, D1} 가운데 그 (대상, n)에서 B RMSE 평균이 가장 작은 것 | 참고(후회값). 실제로 쓸 수 없는 방법이다 |

- 모든 팔에서 단계 1(n 10)의 편향 진단 b10 = mean(E0·s − y) 을 저장한다(A1 은 Algorithm P 라벨, A2 는 무작위 라벨).
- n 10 에서 A1 과 A4 는 같은 예측이다. 따라서 n 10 의 배치 효과는 H-XC1 이 시험한다.

### 5.4 가설과 판정 규칙

**주 가설(Holm 가족 8개)**. 대비는 같은 (분할, 추출, seed)의 짝이고, 층화 평균은 F1 가운데 CI 를 낼 수 있는 대상의 비가중 평균이다(`h42.pool_rows`, 풀 지역 2곳 이상). 단측 부트스트랩 p 는 두 가중 가운데 큰 값을 쓴다.

| 번호 | 대비 | n | 판정 기준 |
|---|---|---|---|
| H-XC1 (3개) | A1 − A2 < 0 | 10, 40, 160 | 4분 판정 '우세'이고 Holm 보정 p < 0.05 |
| H-XC2 (3개) | A1 − A3 비열등(한계 0.5 cm) | 10, 40, 160 | 두 가중 CI 상한 < 0.5 이고 비열등 p 의 Holm 보정 < 0.05 |
| H-XC3 (2개) | A4 − A2 < 0 | 40, 160 | 4분 판정 '우세'이고 Holm 보정 p < 0.05 |

- 가설별 종합: 대상 n 모두에서 기준을 만족하면 지지, 열세 없이 일부만 만족하면 부분 지지, 열세가 하나라도 있거나 만족하는 n 이 없으면 기각, CI 를 낼 수 없는 n 이 있고 만족이 없으면 판정 불가다(WF 의 규약과 같다).
- **별도 주 가설 H-XC4(진단 재현)**: ρ(|b10|_A1, RMSE(P0) − RMSE(A1@전량)) > 0. 대상은 F1 ∪ F2 ∪ F3 이고, CI 는 계열(알래스카, 캐나다, 레나, 러시아 W, 러시아 E, 티베트, 러시아 C, XF 지역별) 단위 군집 재표집과 블록 재표집을 같은 번호로 묶어 낸다(대상 사이 의존 반영). CI 하한 > 0 이면 지지. 같은 표에 C2 정정용 보조값 ρ(|b10|, RMSE(P1) − RMSE(A1@전량)) 을 적는다(예상 0 근처, 판정어 없음).

**보조(판정어는 붙이되 확인적으로 세지 않는다)**
- S-XC1: A5 − A2(규칙 W 효과, 무작위 배치), n 10·40·160. WF4-a 의 새 분할 재현이다.
- S-XC2: A1 − A5(규칙 W 아래 배치 효과), n 40·160.
- S-XC3: 대상별 A1 − A2, A1 − A3 의 판정과 손해 표(P0 보다 2 cm 넘게 나빠진 대상 수: A1 대 A2 대 A3, WF0 위험표와 같은 정의).
- S-XC4: 후회값 A1 − A6, A2 − A6(서술).
- S-XC5: |b10| ≥ 8 cm 대상과 미만 대상의 RMSE(P0) − RMSE(A1@n 160 또는 최대 n) 비교(임계값 8 cm 는 WF4-c 사후 관찰에서 온 값이라 재현 서술로만 쓴다).
- S-XC6: b10 의 추출 사이 표준편차, Algorithm P 대 무작위(진단의 정밀도).
- S-XC7: F2 하위 지역, F3 외부 계열의 대상별 판정. F3 가 2곳 이상이면 H-XC1 n 10 을 F3 층화 평균으로 따로 판정한다(Holm 가족 밖의 별도 확인 가설 1개).

- 추정: 8만 건 × 0.74 s ≈ 16–17 프로세스·시간(약 66 코어·시간). Rescale elm(96코어, 워커 22 × 4스레드, 3.24 달러/시간)에서 계산 약 0.8 h, 설치·집계 포함 약 1.5–2 h, 약 5–7 달러다. 상한은 3 h(최악 약 10 달러)로 둔다. elm 이 노드를 못 받으면 hematite(64코어, 4.22 달러/시간)로 같은 묶음을 제출한다. 제출 전 `--count-only` 와 Rescale 스모크로 다시 잰다.
- 플랫폼: 모든 적합은 CatBoost CPU 이고 한 노드 종류의 한 작업에서 돈다. 나눠 돌리면 같은 노드 종류를 쓰고, WF9 처럼 공통 키 재현 점검(최대 |ΔSSE|)을 적는다.

## 6. XD_placement_policy 등록안(탐색적, SI)

### 6.1 목적

1. 결합형 배치(S8, 블록 제약 k-중심)와 변형이 S2·S4 와 비교해 어떤지 보고 Algorithm P 의 매개변수를 정한다(XC 의 입력).
2. 사용자 제안(DL 로 어디를 잴지 학습)을 학습된 배치 정책 S9 로 시험한다. 독립 단위가 적으므로 SI 의 탐색 분석으로 둔다.

### 6.2 팔

| 팔 | 정의 | 시험 목적 |
|---|---|---|
| S1, S2, S4 | 2.2절 그대로(같은 플랫폼 비교를 위해 다시 적합) | 기준 |
| S8a | Algorithm P, γ 0, 블록 순서 farthest-first, 블록 안 첫 셀 = 중심 근접 셀 | P_default |
| S8b | S8a 에서 블록 안 첫 셀도 farthest-first | 블록 안 규칙 |
| S8c | S8a 에서 γ 0.5 | 배분 지수 |
| S8w | S8a 의 라벨 + 설계 가중 계수 E_w = Σ w s y / Σ w s², w_i = N_b(i)/n_b(i)(후보 블록 셀 수 / 그 블록 라벨 수) | 레나형 손해의 교정 |
| S8r | S8a 의 라벨 + 블록 무작위 효과 계수(블록 E 의 무작위 효과 평균, 블록 사이 분산 τ² 는 라벨로 추정) | 셀 가중과 블록 균등 사이의 자동 절충 |
| S9-GBM | 학습된 정책, 효용 예측기 = CatBoost(CPU) | 학습 정책 |
| S9-DS | 학습된 정책, 효용 예측기 = DeepSets(GPU) | 학습 정책 |

S8w·S8r 은 라벨 위치가 S8a 와 같고 계수 추정만 다르다. 이 둘은 P1 이 닫힌 형식이라 계산이 거의 없다.

### 6.3 과제 집합과 의존성 처리

- 과제 = (대상, 모드). 지역 내(모드 r): 알래스카, 레나, 캐나다, AL-1–AL-6, CA-2, CA-3, LE-1, LE-2(13개). 전이(모드 x, 하위 지역은 i·x): 레나, 캐나다, 러시아 W, 러시아 E, 알래스카, 티베트, 러시아 C, 하위 지역 10곳(약 27개). XF 새 지역은 생기는 대로 더한다.
- 분할은 개발 분할 1–5 만 쓴다. XC 의 분할 6–15 는 XD 에서 열지 않는다.
- n ∈ {10, 20, 40, 100}, n < |A|. 추출 5, seed 2.
- **의존성**: 하위 지역은 상위 지역의 셀을 그대로 공유한다(AL-k 의 셀은 알래스카 과제의 A 풀에도 있다). 모드 i 와 x 는 같은 셀을 다른 원천으로 채점한다. 따라서 과제는 독립이 아니다. 처리 규칙은 다음과 같다.
  1. 평가 단위는 계열이다: 알래스카 계열(알래스카, AL-1–AL-6), 캐나다 계열(캐나다, CA-2, CA-3, 확충판 Canada_expanded_lic), 레나 계열(레나, LE-1, LE-2), 러시아 W, 러시아 E, 티베트, 러시아 C, XF 지역별 계열.
  2. 학습 정책은 '계열 하나 제외'로 평가한다. 시험 계열의 어떤 과제도 정책 학습과 조기 종료 검증에 쓰지 않는다.
  3. 계열 안 '과제 하나 제외' 결과는 낙관 정도를 보이는 참고값으로만 낸다(계열 제외와의 차이 = 의존성 때문에 생기는 낙관).
  4. 판정의 독립 단위는 계열이고 그 수는 7개 안팎이다. 러시아 W·E, 티베트, 러시아 C 는 n 10–40 만 있어 정책 학습 자료가 적다. 사실상 '두 큰 계열로 배워 세 번째 큰 계열에 적용'하는 시험이 된다는 한계를 등록 문서에 적는다.
  5. 학습 자료를 늘리려고 블록 일부를 뽑아 만든 가상 과제는 학습에만 쓰고 평가에는 쓰지 않는다.

### 6.4 학습 정책 S9 의 구성

- **학습 자료 생성**: 학습 과제마다 (분할, n)별로 라벨 집합 200개를 만든다. 구성은 S1 무작위 40 %, S2·S4·S8a 를 다른 seed 로 낸 집합 30 %, 그 집합의 20–50 % 를 무작위 셀로 바꾼 섭동 집합 30 % 다.
- **효용**: U(L) = RMSE_B(R1@0.25 | L) − mean_d RMSE_B(R1@0.25 | S1 추출 d)(같은 과제·분할·n, 음수가 좋다). P1 의 같은 효용(닫힌 형식)도 함께 저장해 사전학습과 비교에 쓴다. 셀 가중과 블록 등가중 효용을 둘 다 저장하고 학습 목표는 두 값의 평균으로 둔다.
- **집합 특징(라벨 미사용)**: (1) 덮임: 후보 셀에서 가장 가까운 라벨까지 표준화 공변량 거리의 평균·90 백분위·최댓값(후보 1,000개 부분표본), (2) 대표성: 후보 분포와 라벨 분포의 에너지 거리, (3) 블록: 덮은 블록 비율, 라벨 배분 엔트로피, Σ_b |라벨 비율 − 셀 비율|, (4) √TDD: 라벨의 s 평균·표준편차와 후보 대비 비, Σ s²(계수 정밀도), (5) 외삽: 라벨의 AOA 비유사도 평균(전이 모드), (6) 과제 문맥: 후보 수, 블록 수, 유효 블록 수, 공변량 블록 사이 비율, 공변량 유효 차원, 원천 대비 공변량 차이, 모드.
- **S9-GBM**: CatBoost 회귀(CPU), 목표 = 같은 (과제, 분할, n) 안에서 중심화한 U. 조기 종료는 학습 계열 안의 내부 계열 제외로 한다.
- **S9-DS**: 원소 특징 = [Z_c(25), s_c, 블록 셀 비율, DI_c, 같은 집합 안 최근접 라벨 거리], φ = MLP(32 → 128 → 128), 합·평균 풀링 결합, ρ = MLP(256 + 문맥 → 128 → 1). 손실은 같은 (과제, 분할, n) 집합 쌍의 순위 손실(RankNet 형)이다. AdamW, 최대 50 epoch, 내부 계열 제외 조기 종료, seed 3개 평균.
- **정책(탐욕)**: L 이 빈 집합에서 시작해 5개씩 더한다. 후보는 현재 L 기준 farthest-first 상위 300개와 무작위 200개(seed 고정)의 합집합이다. 각 후보 c 에 예측 효용 f(L ∪ {c}) 를 계산해 가장 작은 것부터 더한다. DeepSets 는 합 풀링을 갱신해 후보 전체를 한 번에 평가한다.
- **변형(선택)**: 라벨 10개를 얻은 뒤 블록별 잔차 표준편차로 다음 배분을 정하는 Neyman 형 재배분(S8n). 라벨을 쓰는 선택이므로 S6 의 음성 결과와 구별해 따로 보고한다.

### 6.5 평가와 판정(탐색, 결과 전 고정)

- 대비: S8 변형 − S1, S8 변형 − max(S2, S4)(비열등 한계 0.5 cm), S9 − S1, S9 − S8a. 과제·n 별 4분 판정(두 가중)과 계열별 층화 평균.
- XC 입력 규칙: 5.1절의 고정 규칙(F1 대상, 모드 x, n 40, R1 RMSE 두 가중 평균 최소)으로 Algorithm P 를 고른다. S8w·S8r 은 F1 층화 평균에서 S8a 대비 두 가중 모두 열세가 없고 하나 이상 우세일 때만 Algorithm P 에 넣는다.
- S9 의 본문 채택 규칙: 세 큰 계열(알래스카, 캐나다, 레나) 가운데 2곳 이상에서 n ∈ {20, 40} 의 S9 − S8a 가 우세이고 어느 계열에서도 열세가 없으면 '학습 정책이 단순 규칙보다 나았다'를 본문에 쓴다. 그 밖에는 SI 에 '학습 정책은 블록 제약 k-중심 규칙을 넘지 못했다(계열 k/7 에서 우세, m/7 에서 열세)'로 쓴다.
- 보고: 계열 수가 작으므로 계열을 넘는 p 값은 내지 않는다. 우세·열세 계열 수와 계열별 수치만 낸다.

### 6.6 플랫폼 규칙

- DeepSets 학습과 선택은 로컬 GPU 하나(0–4 가운데 비어 있는 것, 사용 전 nvidia-smi 확인)에서 한 번 수행하고, 선택한 색인 집합을 파일(해시 포함)로 저장한다. torch 결정적 설정과 seed 를 고정한다.
- 선택 뒤의 모든 적합(P1, R1, D1)은 Rescale CPU 한 노드 종류에서 저장된 색인을 읽어 수행한다. 따라서 S9 − S1 같은 대비는 한 CPU 플랫폼 안에서 닫힌다.
- 선택 자체의 GPU 환경 의존성은 다른 GPU 에서 선택을 한 번 더 만들어 선택 집합의 Jaccard 겹침으로 서술한다.
- S9-GBM(CatBoost CPU)은 Rescale 에서 학습·선택·평가를 모두 수행한다.

### 6.7 계산량

- 학습 자료: 과제 약 40 × 분할 5 × n 4(유효 값만) × 집합 200 ≈ 최대 16만 집합. R1 적합 1건은 지역 내 약 0.1 s, 전이 약 0.22 s(WF8: 적합 1,168건, 0.071 프로세스·시간, `wf2b_timing.csv`)이므로 합 약 6–9 프로세스·시간(4스레드)이다. Rescale elm 에서 약 0.5 h, 약 2–4 달러다. P1 효용은 닫힌 형식이다.
- 평가: 팔 10개 × 과제 약 40 × 분할 5 × n 4 × 추출 5 × seed 2 ≈ 최대 8만 건, 약 3–5 프로세스·시간이다. WF2 의 전략 하나는 적합 약 2,260건, 0.04 프로세스·시간이었다(`wf_timing.csv`).
- GPU: DeepSets 학습은 계열 제외 7–8 묶음 × seed 3, 집합 약 16만 개(원소 최대 100, 원소 특징 약 30, 메모리 약 2 GB 미만)라 GPU 한두 개로 수 시간 안이다. 로컬 RAM 55 GB 제한 안이다.
- 합계: Rescale CPU 약 10–14 프로세스·시간(약 3–6 달러), 로컬 GPU 수 GPU·시간.

## 7. 실행 순서와 다른 실험과의 관계

1. **XD 개발(분할 1–5)**: S8 변형과 계수 변형 먼저(약 1 h), S9 는 병행. Rescale CPU 와 로컬 GPU 를 함께 쓴다.
2. **Algorithm P 고정**: 5.1절 규칙으로 고정하고 XC 등록 문서를 커밋한다. XF 의 적격 새 지역 목록도 이때 고정한다.
3. **XC 실행(분할 6–15, F1·F2·F3)**: Rescale CPU 한 작업.
4. 관련 실험: XF(새 지역)는 XC 의 F3 와 XD 의 계열 수를 늘린다. XA(C2 분해)는 H-XC4 의 보조값과 같은 질문이라 문장을 맞춘다. XH(검증 사다리)는 XC 와 독립이다. XI(기후 외삽 재시험)는 Canada_expanded_lic(787셀, 58블록)를 쓰는데, 이 표는 XD 의 캐나다 계열에도 들어간다. 두 실험이 같은 셀을 쓰더라도 질문이 달라 충돌은 없다.

## 8. 열린 문제

1. WF2·WF8·XD·XC 모두 후보 풀이 '이미 측정된 셀'이다. 실제 현장의 후보(육지 격자 전체)와 분포가 달라, 모의 이득이 현장 이득으로 그대로 옮겨진다는 보장이 없다.
2. 채점 가중의 선택: 셀 가중은 측정이 몰린 사이트를, 블록 등가중은 0.5° 면적에 더 가까운 가중을 대표한다. 지도 정확도에는 블록 등가중이 더 가깝지만 등록 규칙(두 가중)을 바꾸지 않았다. 바꾸면 결과를 본 뒤의 변경이 된다.
3. 레나형 손해의 원인 서술(3.6절)은 대상 5개의 사후 관찰이다. XD 의 S8w·S8r 이 이를 시험한다.
4. XC 는 결과 열람 뒤 설계다. 새 분할과 새 지역으로 확인 성격을 확보하지만, 같은 대상을 쓰므로 대상 수준의 일반화 근거는 F3 의 크기에 달려 있다.
5. 규칙 W 는 n 10 에서 레나 +0.70 cm 열세였다. XC 는 n 10 에 고정 R1 을 쓰도록 정했다. 이 결정 자체도 WF4 결과에서 왔다.
6. 진단 임계값 8 cm 는 사후 값이다. XC 에서는 재현 서술로만 쓴다.
7. WF4-c 의 28대상에는 하위 지역의 모드 i·x 가 중복되어 있다. 원고의 ρ 0.38 에 이 의존성을 한계로 적어야 한다.
8. Bankier(1988)는 서지만 확인했고 원문을 읽지 않았다.
9. 이번 계산은 새 파일(이 보고서)만 만들었다. h54 의 새 단위 클래스와 시험은 아직 구현하지 않았다.
