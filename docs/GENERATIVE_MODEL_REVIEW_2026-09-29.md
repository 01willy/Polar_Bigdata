# 생성 모델(확산·흐름 정합·정규화 흐름) 적용 검토 (2026-09-29)

**작성 경위**: 사용자 질문("확산·흐름 정합 등으로 물리 잔차 학습과 불확실성 표현을 개선할 수 있는가")에 대해 문헌 조사 4갈래, 내부 제약 조사, 설계안 11개(세 관점), 심사 3건(통계 검증, 영구동토 모델링, 생성 모델 방법론)을 종합했다.
**쓰임**: 예측 분포 실험(LGU)의 설계 근거 문서다. 사전 등록은 `docs/EXPERIMENT_PLAN_LGU_2026-09-29.md` 에 따로 둔다.
**주의**: '탐색값'은 조사 단계에서 계산한 값이며 공식 산출이 아니다. 문헌의 확인 수준은 표에 적혀 있다.

---

- 기준일: 2026-09-29
- 근거: 설계안 11개(3각도), 심사 3건, 문헌 조사 4갈래, 내부 제약 조사
- 확인 범위: 이 자료는 위 입력의 종합이다. 학습·실험·pytest 를 실행하지 않았고, 파일을 만들거나 고치지 않았다. LG·LGX 본 실행 산출은 열지 않았다.
- 수치 표기: '탐색값'은 조사·심사 단계에서 스레드 1개로 계산한 값이며 공식 산출이 아니다. 비용은 모두 미측정 추정이다.
- 심사 표기: 심사 1·2·3 은 입력 순서다. 관점 이름(통계 검증, 영구동토 모델링, 생성 모델 방법론)은 심사 내용에서 요약한 것이다.

## 1. 결론

1. 확산·흐름 정합·정규화 흐름은 셀 공변량에 조건부인 p(y|x)를 더 유연하게 표현할 뿐이다. 전이 오차의 주성분인 지역 수준 계수 차이(공변량 25개에 없는 Y|X 이동)를 식별할 정보는 추가되지 않는다.
2. 점 예측 오차의 개선을 기대할 근거는 내부 결과와 문헌 어디에도 없다.
3. '확률 모형이므로 불확실성 표현이 쉽다'는 표본 생성에만 해당한다. 생성 구간의 전이 커버리지는 0.28–0.40 이고 계층 conformal 은 0.863 이다.
4. 생성 모델이 맡을 수 있는 자리는 두 곳이다. 하나는 계층 conformal 의 폭 정규화기이고, 다른 하나는 지역·블록 잠재 변수를 둔 계층 모형 안의 셀 잔차 분포다. 두 경우 모두 이득의 출처는 지역을 집단으로 다루는 구조이며 생성 학습기는 교체 가능한 부품이다.
5. 두 자리의 기대 효과는 오라클 상한으로도 구간 점수 11–13 %, 폭 3–11 % 다(탐색값). 현재 자료의 검출 한계보다 작을 가능성이 높아 가장 가능성 높은 판정은 '미결정'이다.
6. 권고는 범위를 줄인 실험 3개(계층 예측 분포 사다리, 정규화기 비교형 계층 conformal, 공간 정보량 진단)다. 1순위 실험의 주 구성은 비생성 모형이고 흐름은 게이트 조건부 제거 실험이다. 독립 지역 확충(티베트, GTN-P)이 생성 기법 도입보다 우선한다.

## 2. 점 예측 오차가 줄지 않는 이유

### 2.1 내부 결과

Δ 는 Stefan 대비 차(cm)이며 주 4지역 평균, 층화 블록 부트스트랩이다(m1_sc_tests.csv). 마지막 행은 2026-07 토너먼트의 RMSE(cm)다.

| 조건 | cfm | ddpm | nflow | 비교 학습기 |
|---|---|---|---|---|
| 라벨 0 직접, 정보 없음 | +12.50 [4.52, 23.23] | +8.04 [4.09, 14.18] | +19.75 [6.50, 39.81] | CatBoost +2.31 [0.76, 4.29] |
| 라벨 0 잔차 λ 0.25 | +0.90 [0.40, 1.73] | +1.03 [0.57, 1.93] | +17.88 (유효 seed 1) | CatBoost −0.04 [−0.37, 0.36] |
| 라벨 전량 잔차 λ 0.25 | −0.75 [−1.81, −0.02] | −0.73 [−1.73, 0.01] | +0.31 | catboost_lo −0.68 [−1.02, −0.28] |
| 알래스카 지역 내 RMSE | 18.31 | 17.09 | 해당 없음 | GBM 17.24 |

- 라벨 0 직접 회귀에서 생성 학습기의 악화 폭은 트리·신경망 학습기의 2–5배다.
- 라벨 전량 잔차에서는 CatBoost 와 같은 범위이나 두 가중 규약의 유의 기준을 통과하지 못한다(cfm 블록 등가중 [−1.42, 0.39]).
- 알래스카 지역 내에서는 모든 모형이 GBM 과 동률이다.
- nflow 는 발산 4건과 RMSE 157–357 cm 적합 기록이 있다. 원인은 확정되지 않았다.

### 2.2 구조적 이유

- 지역 계수 차이는 입력에 없다. 공변량으로 회귀한 E 는 지역 안 R² 0.39–0.52, 지역 홀드아웃 −3.09 다. 블록 E 와 공변량의 상관 부호가 지역마다 다르다(TDD: 캐나다 +0.73, AL-3 −0.33).
- 같은 정보를 쓰는 추정기는 κ = 10 수축을 넘지 못했다. 오프셋 최대우도, 혼합효과 부스팅(+5 에서 +12 cm), PPI, FOMAML(n = 3 +1.09, n = 10 +2.14 cm)이 해당한다.
- 목표가 1차원 스칼라다. 확산과 흐름 정합의 장점은 고차원 결합 분포에 있으며 이 설정에서는 분위 회귀나 정규화 흐름 대비 구조적 이점이 없다(심사 3).
- 고차원 방향(공간 장)은 자료 조건이 막고 있다. 상관 거리는 약 1–2 km 이고, 주 규약에서 2 km 안에 다른 블록 라벨을 가진 채점 셀은 6–18 %(러시아 W·E 는 0)다(탐색값). 알래스카에서 SAR 제품과 탐침의 블록 내 상관은 ReSALT −0.07 [−0.13, 0.05], PolSAR +0.06 [−0.10, 0.16] 이다(탐색값).

## 3. 불확실성 표현의 주의점과 해결 구조

### 3.1 분포 폭이 담는 것과 담지 못하는 것

| 불확실성 성분 | 셀 조건부 생성 모델 | 근거 |
|---|---|---|
| 원천 지역 안 셀 수준 산포(이분산, 비대칭) | 담는다 | 구현 구조 |
| 지역 간 계수 변동 | 담지 못한다 | 입력에 지역 정보 없음 |
| 블록 수준 군집 | 담지 못한다 | 셀 독립 가정, 블록 내 상관 0.21–0.38(탐색값) |
| 모형(인식적) 불확실성 | 담지 못한다 | 단일 모형, 앙상블 없음 |
| 기기·관측 시기 구성 | 원천 구성을 그대로 학습 | GPR 셀 62 %, 전부 알래스카 13블록(탐색값) |

### 3.2 내부 증거

| 방법 | 조건 | 90 % 커버리지 | 폭(cm) | 구간 점수 |
|---|---|---|---|---|
| cfm·ddpm·nflow 직접 | 알래스카 지역 내 | 0.63–0.77 | 27–36 | 89–111 |
| CQR | 알래스카 지역 내 | 0.934 | 53.6 | 68.9 |
| cfm·ddpm·nflow 직접 | 전이, 정보 없음 | 0.28–0.35 | 28–45 | 327–411 |
| 생성 잔차 λ 0.25 | 전이, 라벨 0 | 0.11–0.15 | 7–13 | 미기재 |
| 원천 보정 CQR | 전이 | 평균 0.55 | 미기재 | 미기재 |
| 셀 풀링 | 전이 | 0.728 | 56.3 | 152.9 |
| 계층 conformal(hier2_cdf) | 전이 | 0.863 [0.802, 0.917] | 80.5 | 132.0 |

- 전이에서 미포함은 한쪽 방향에 몰리고 방향은 지역마다 다르다. 수준 이동이 주성분이라는 해석과 일치한다.
- 현재 잔차 모드 규약은 분위에 λ 를 곱하므로 λ 0.25 에서 구간이 붕괴한다. 위치만 수축하는 규약은 정의된 적이 없다.
- 셀당 표본 64개에서 5 %·95 % 분위는 꼬리당 약 3개 표본으로 정해진다.
- 유사라벨 행은 잡음 없는 결정값이어서 조건부 분포를 인위적으로 좁힌다(정의에서 끌어낸 추론, 미측정).
- 하네스는 중앙값만 채점하고 표본을 버린다. 진행 중인 LG·LGX 산출로는 분포 출력을 채점할 수 없다.

### 3.3 라벨 정의 이질성(심사 2, 탐색값)

- 블록 안 로그 비 SD 는 GPR 0.24, 알래스카 탐침 0.27, 캐나다·레나 탐침 0.34–0.37, 6–7월 관측 셀 0.41–0.50 이다.
- 대상 지역(레나, 캐나다, 러시아)은 표지 표 기준 전부 탐침이다. 원천에서 학습한 잔차 분포는 탐침 대상에서 과신 방향으로 어긋난다.
- GPR 해빙 깊이는 현장 평균 전파 속도 하나로 환산되고 불확실성은 약 20 % 다(ORNL DAAC 안내서, 본문 확인). 이 오차는 현장 단위 곱셈 편향이어서 블록 효과와 구분되지 않는다.
- 전이 커버리지 0.28–0.40 가운데 이 원인의 몫은 확인되지 않았다.

### 3.4 문헌의 공통 결과

- 과소 분산이 반복 보고된다. CorrDiff(저자 명시), R2-D2(spread-skill 비 0.66–0.80), Manshausen 2025(순위 히스토그램), Zhou 2026(사전분포 유도 확산 커버리지 60.2 %)이 해당한다.
- 무작위 분할에서도 보정은 완전하지 않다. DiffGBM 의 PIT 균일성 검정 통과 비율은 전 계열 0.15–0.45 다.
- 분포 이동 아래에서는 conformal·분위 회귀·앙상블 모두 커버리지가 55–89 % 로 떨어졌다(Gustafsson 2023, 영상 회귀).
- 조사한 확산·흐름 표 회귀 문헌은 전부 무작위 분할만 썼다. 집단 제외 조건의 분포 평가는 확인되지 않았다.

### 3.5 해결 구조

지역 수준 변동을 분포에 넣는 경로는 두 가지이며 결합할 수 있다.

| 경로 | 지역 변동의 위치 | 생성 모델의 역할 | 라벨 n개의 사용 |
|---|---|---|---|
| 보정 단계 | 지역을 집단으로 둔 계층 conformal | 폭 정규화기(조건부 폭의 상대 크기) | 앵커 재보정으로 위치 이동 |
| 모형 단계 | 지역·블록 잠재 변수(log E 오프셋) | 셀 잔차 분포(척도와 형태) | 지역 효과의 사후 갱신 |

남는 한계는 다음과 같다.

- 독립 지역이 4–5개여서 지역 간 분산 τ 가 식별되지 않는다. 대상 제외 추정은 0.12–0.29 이고 자유도 3 의 SD 90 % 신뢰 비는 [0.62, 2.92] 다(심사 1).
- 라벨 0 의 예측 분포는 자료가 아니라 초사전분포 선택이 정한다.
- 보정 집단이 9개 미만이어서 유한표본 보장이 없다. 커버리지는 경험 평가다.
- 참 커버리지가 0.90 이어도 관측값이 [0.85, 0.95] 에 들 확률은 채점 셀 12–13개에서 0.37–0.38, 27–28개에서 0.64 다(독립 가정의 낙관적 값).
- 커버리지 차 0.13 인 기지의 대비(셀 풀링 대 hier2_cdf)도 구간 점수 짝지음 CI 가 4지역 중 3지역에서 0 을 포함한다. 조건부 폭의 효과는 이보다 작다.

### 5.1 1순위: A. 계층 예측 분포 사다리(HB)

**방법 정의**

- 목표 변수: u = log y − log(E0·√TDD). E0 는 대상과 100 km 버퍼를 뺀 원천의 최소제곱 계수다.
- 구조: u = a_r + b_(r,k) + ε. a_r 은 지역 오프셋, b_(r,k) 는 0.5° 블록 오프셋, ε 는 셀 잔차다.
- 사후: p(a | 라벨) ∝ p(a)·Π_k ∫ N(b_k; 0, τ_b²)·Π_i f(u_i − a − b_k | x_i) db_k. a 격자 400점, b 격자 100점의 구적으로 계산한다.
- 예측 분포: a 의 사후, 새 블록 b 의 사전, 잔차 밀도 f 의 합성이다. n = 0 이면 사전 예측 분포다.
- 초모수 τ_r, τ_b 는 대상을 뺀 원천에서만 추정한다.

| 단 | 구성 | 계산 | 지위 |
|---|---|---|---|
| (i) | 동분산 정규 잔차 + 지역 오프셋 | 닫힌 형태, h4_common.offset_mle_estimate 재사용 | 기준 |
| (ii) | + 블록 오프셋 | 1차원 구적 | 기준 |
| (iii) | + a 의 Student-t 사전분포(자유도 4, τ_r 에 half-normal) | 구적 | 확인적 주 구성 |
| (iv) | + 이분산 정규 또는 Student-t 잔차 | 척도 모형 적합 | 보조 |
| (v) | + nflow 잔차(위치 0 고정, 척도와 형태만 x 의존) | GPU | 게이트 조건부 |
| (vi) | + 원천 지역을 집단으로 둔 conformal 후보정 | CPU | 보조 |

주 분석에서 빼는 항목은 EM 식 반복 학습, 산포 배율 w, n 별 지역 수준 재보정, 실제 지역 SBC, cfm·ddpm 핵밀도 우도, 배치 규칙 비교, 잠재 공간 재보정이다.

**범위**

| 항목 | 내용 |
|---|---|
| 대상 | 주 4지역과 알래스카(참조). 하위 지역은 보충(독립 아님 표기) |
| 라벨 수 | n ∈ {0, 3, 10, 40, 160}. 러시아 W·E 는 n ≤ 10 |
| 분할과 추출 | A/B 블록 분할 3개, 추출 5회, B 의 eval_mask 셀 채점 |
| 주 기준선 | B4: E_n 중심(κ = 10) 상수 로그 폭, 원천 지역을 가상 대상으로 두어 n 별 보정 |

### 5.2 2순위: B. 정규화기 비교형 계층 conformal(NC)

**방법 정의**

- 중심은 앵커 E0·√TDD 에 고정한다. 점 예측은 바뀌지 않는다.
- 점수: s_i = |log y_i − log ŷ_i| / σ_i. σ_i 는 정규화기가 주는 셀별 로그 척도(5–95 % 분위 폭의 절반)다.
- 보정: 대상과 100 km 버퍼를 뺀 원천에서 지역 k(셀 20개 이상, h37 기준)를 하나씩 빼고 학습해 표본 밖 점수를 구한다. 지역 등가중 CDF 의 (1 − α) 분위 q 로 구간 ŷ·exp(±q·σ_i)를 만든다.
- 생성 학습기의 목표는 로그 비 잔차 z = log y − log(E0·√TDD)다.
- n > 0 에서는 생성 모델을 다시 학습하지 않고 앵커만 E_n 으로 바꾼다.

| 정규화기 | 학습 | 지위 |
|---|---|---|
| 상수(현재 hier2_cdf) | 없음 | 기준 |
| nflow 분위 폭(표본 없는 분위) | GPU | 주 후보 |
| CatBoost 다분위 폭 | CPU | 짝 비교 |
| cfm 분위 폭 | GPU | 대조 |
| 물리 사전 예측 로그 폭(GU4 게이트) | 없음 | Holm 보조 |
| 셀 사이에서 폭을 섞은 위약 | 없음 | 주 대비의 기준 |

ddpm 은 제외한다. SP0 조건부 모의 산포와 면적 평균 구간은 C 의 결과 뒤 보조 분석으로 둔다.

## 6. 기각 또는 후속으로 미룬 안

| 안 | 판정 | 이유 | 재심 조건 |
|---|---|---|---|
| GU3, FS-2(합성 과제 문맥 모형) | 보류 | n ≤ 10 에서 구적 사후가 상한, FOMAML 기각 이력, 모의기 오지정, 합성 과제가 알래스카 GPR 셀의 재조합 | A 결과 확보, 독립 지역 9개 이상, 오프셋으로 설명되지 않는 잔여 구조 확인 |
| SP1(탐침 집합 조건부 흐름 정합) | 보류 | 주 규약에서 채점 셀의 82–94 % 가 빈 맥락, 실효 블록 수 3.9–7.7 | 조건부 가우시안 모의가 근접 층에서 P1 대비 우세이고 그 PIT 가 어긋날 때 |
| GU4(물리 기저 흐름 정합) | 기각 2, 보류 1 | 학습이 완전하면 종단 분포는 출발 분포와 무관, 물성 기반 물리식이 지역 간 수준 차이를 줄이지 못함(지역 간 SD 0.27–0.30) | 게이트 계산만 B 의 정규화기 후보로 흡수 |
| FS-3(다차원 물리 매개변수 사후) | 기각 2, 보류 1 | ALT 가 √n_t 에 비례해 오프셋 a 와 완전 공선, 토양 앵커 음성 이력 | 매개변수를 분리할 관측 추가, LGX X9·N1 통과. 그 경우에도 격자 사후만 |
| SP2(SAR 격자 사전분포) | 기각 3 | 제품과 탐침의 정렬 부재, ReSALT 는 역산 산출물, 순환 평가 위험, 레나·러시아에 SAR 없음 | 하위 지역 9개 중 5개 이상에서 블록 내 상관 CI 하한 0.2 초과, 기준점과 라벨의 비중복 확인 |

본 원고에는 한계 절에 두 문장만 둔다.

- '라벨 집합을 조건으로 받는 생성 학습기는 시험하지 않았다.'
- 제품 정렬 진단 결과 1문장(C 실행 뒤).

이 검토와 별개로 확인이 필요한 사항은 다음과 같다.

- polsar_alt 열에 분류 부호가 ALT 값으로 들어갔을 가능성이 있다(99.5 이상 1,247셀, 탐색값). x25 에는 SAR 열이 없어 본 실행에는 영향이 없다. x34 와 과거 PolSAR 실험은 재확인이 필요하다.
- ReSALT 기준 지점과 본 연구 라벨의 겹침 여부는 확인되지 않았다.

## 부록 A. 쓰지 않을 문장

| 문장 | 사유 |
|---|---|
| 생성 모델이 점 예측 오차를 줄인다 | 내부·문헌 근거 없음 |
| 확산 또는 흐름 정합이 분위 회귀보다 낫다 | 문헌에서 구분되지 않음 |
| 생성 학습기와 분위 회귀는 동급이다 | CI 가 0 을 포함하는 것만으로는 쓸 수 없음 |
| 커버리지가 보장된 구간 | 보정 집단 4–5개 |
| 라벨이 구간을 좁힌다 | 폭 감소는 모형 구조에서 자동 발생 |
| 조건부 폭이 지역 간에 전이된다 | 위약 대비 우세 전 |
| 생성 모형과 conformal 의 결합은 선례가 없다 | 인접 선행 있음(7.6) |

신규성은 방법이 아니라 평가 조건(지역 제외 × 대상 라벨 수 × 현장 관측)으로 한정한다. 조사 범위의 미발견은 부재의 증명이 아니다.
