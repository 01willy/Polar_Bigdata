### 0.2 기존 계획서와의 관계

- 이 문서 자체로는 LG·LGX·LGT·LGD·LGU·LGF 의 가설, 판정 문구, 범위, 확인적 가설 집합(LGX 의 L10·L12·L15·L19·L29·L30, LGU-A1·B2, LGF-F1·N1)을 바꾸지 않는다. 7·8절의 실행 표 수정(변형 추가, 대상 셀 변경)과 실행 환경 개정은 해당 계획서의 개정으로 채택될 때 그 계획서의 범위를 바꾼다. LG 개정 13 이 7.3 (a)8, (a)9 를 채택해 LGD 의 범위를 바꿨다(7.1).
- 더하는 것은 세 가지다. (1) 보고 규칙과 보조 열(1·2·9절). (2) 추가 가설 L43, AK1w, SC1w–SC3w(3–5절)와 서술 산출(6절 지도, 10절 제품 비교). (3) 개정안(7절 새 지역, 8절 실행 환경).
- NEXT 계획서(2026-09-28)의 SC1–SC3, AK1 은 이 문서가 철회하고 SC1w–SC3w, AK1w 로 대체한다(3.1, 5절). 이 작업은 NEXT 파일을 고치지 않으므로 NEXT 개정 이력에 철회를 옮겨 적는 일은 후속 기록이다(12절).
- 충돌하면 기존 계획서의 가설·판정 문구가 우선한다. 이 문서는 보조 열과 보고 방식만 정한다. 예를 들어 L5 의 판정 문구('동급')는 기존 표에 그대로 두고, 원고에서 어떤 판정을 인용하는지만 1.5 규칙이 정한다. 1.4 (a)의 결과 문장 규칙은 LG L1–L8 의 원고 문장에만 적용하고, 다른 계획서의 가설은 각 계획서에 등록된 문장을 그대로 쓴다.
- 7·8절의 개정안 가운데 실행 범위(실행 표, 변형 추가)나 실행 환경을 바꾸는 항목은 해당 계획서의 개정 이력에 채택 기록이 있어야 효력이 있다. 표의 '적용 방법' 열에 채택 경로를 적었다. 집계 규칙과 보고 규칙만 바꾸는 항목은 이 문서의 커밋으로 효력이 생긴다.
- LG 계획서 6B 본문은 다른 작업이 고친다. 그래서 새 지역 개정안은 이 부록(7절)에 두고, LG 계획서에는 이 문서를 가리키는 줄을 개정 이력에 넣는다. 이 문서를 쓰는 작업은 LG 계획서를 고치지 않는다.

| 항목 | 규약 |
|---|---|
| Δ | Δ(A − B) = RMSE(A) − RMSE(B), cm. 같은 분할·추출·seed 의 짝지음이고 음수면 A 가 낫다 |
| 4분 판정 | 우세 = 셀 가중과 블록 등가중의 CI 상한이 모두 0 미만. 열세 = 두 CI 하한이 모두 0 초과. 동등 = 그 밖에서 네 끝값의 절댓값이 모두 δ 이하. 미결정 = 그 외. 구현은 `h42.verdict4` |

| 풀 | 주 4지역(레나, 캐나다, 러시아 W, 러시아 E, 모드 x)의 층화 평균(`h40.strat_mean`). CI 풀 지역 수 표기(4지역 확정, 2–3지역 '부분(지역 k/4)', 2지역 미만 '판정 불가'). n ∈ {40, 160} 은 레나·캐나다 2지역이다. 보조 열로 레나·캐나다·Alaska(x) 3지역 평균을 병기한다 |

| 맹검 표지 | '맹검'(같은 대비의 결과를 본 적이 없다), '비맹검 부분 포함'(규약이 다른 앞선 실험에서 방향을 보았다), '재현(비맹검)'(같은 대비의 방향을 보았다), '등록 시점에 결과 존재(미열람)'(결과 파일이 있으나 열지 않았다). 가설마다 적는다 |

LGU-B2 는 지도의 본문 배치를 정하는 조건이라 초록 판정어의 대상이 아니다. 점검 종합 2절 4번의 예시(L1, L2, L4 n = 10, L8, P1 − P0 n = 10, L10, L15, L29, L30)에서 L30 을 빼고 AB9, AB10 을 넣은 이유는 위 '선정 이유' 열과 같다.
- **p 값**: AB1–AB9 는 h39 가 LG 조각(AB1, AB4, AB5, AB6, AB8, AB9)과 LGX 조각(AB2 는 `lgx9`, AB3 은 `lgx2`, AB7 은 `lgx1`)에서 셀 가중과 블록 등가중 분포를 같은 재표집으로 함께 다시 계산한다(10,000회, seed `seed_of("lgw", 대상, 대비)`, 층화 평균은 같은 재표집 번호끼리). 두 가중 분포에서 양측 부트스트랩 p(`h4_common.boot_p`)를 각각 구해 큰 값을 쓴다. 초록용 4분 판정도 같은 분포로 낸다. h42 표(`lgx_lg_aux.csv`, `lgx_tests.csv`)의 판정과 다르면 두 판정을 모두 적고 '재표집 의존'을 붙인다. 가설 판정은 해당 계획서의 표 그대로다. h42 가 저장하는 `p_boot` 는 셀 가중 분포의 p 뿐이라(0.1) 이 재계산이 필요하다.
- **AB10 의 p**: LGU 2단 CI 분포(2,000회. 개정 2 (b)로 1,000회 정정)의 두 가중 양측 부트스트랩 p 가운데 큰 값을 쓴다. 재표집 횟수가 다른 행(10,000회 대 2,000회)과 섞이므로 p 의 분해능이 다르다(가능한 최소 p 는 각각 1e-4, 5e-4). 두 p 는 LGU 판정 표에 있어야 한다. 이는 LGU 산출에 대한 요구 사항이며 LGU 계획서 개정으로 옮겨야 효력이 있다(12절 후속 기록). LGU 표에 두 p 가 없으면 AB10 은 행 없음으로 처리한다.
- **보정**: 10개 p 에 Holm 보정(`m1_stats.holm`, 가족 오류율 0.05)을 한다. 행이 없거나 판정 불가인 대비는 p = 1 로 넣어 묶음 크기 m = 10 을 유지한다. 동등성은 10개 행 전부의 동등성 p(6A.5a 의 정의로 두 가중 가운데 큰 값. AB10 은 LGU 의 상대 한계 5 %)를 같은 방식(행 없음 p = 1, m = 10)으로 따로 Holm 보정한다. 4분 판정이 동등인 행 가운데 보정 뒤 동등성 p 가 0.025 를 넘는 행은 '보정 전 동등'으로 표시한다. 두 묶음의 크기는 결과에 따라 바뀌지 않는다.
- **초록 문장 규칙**: (a) 우세 또는 열세이고 Holm 보정 p < 0.05 이면 방향을 쓴다. (b) 우세 또는 열세이나 보정 p ≥ 0.05 이면 초록에는 '차이를 확인하지 못했다'로 쓰고 본문에 '보정 전 유의'를 적는다. (c) 동등이고 보정 뒤에도 동등이면 한계를 명시한다('0.5 cm 안에서 같다'). '보정 전 동등'이면 초록에는 '차이를 확인하지 못했다'로 쓴다. (d) 미결정이면 '차이를 확인하지 못했다'. (e) '부분(지역 k/4)'인 행은 지역 수를 초록 문장에 넣는다.
- 이 보정은 초록 문구만 정한다. 각 가설(L1, L2, L4, L8, L10, L15, L29, LGU-A1)의 지지·기각 판정은 해당 계획서의 규칙(보정 전 CI) 그대로다.
- 묶음은 결과 열람 뒤 바꾸지 않는다. 행이 없거나 판정 불가인 대비는 초록에서 빠지고 대신 넣을 대비를 고르지 않는다.

### 1.3 하위 지역 합산의 서술

- 하위 지역을 독립 대상처럼 합친 평균(예: a2 의 MEAN_ANALYSIS 12대상, b1·b2 의 14대상, LG 배치 축의 25대상)은 본문에서 CI 와 함께 인용하지 않는다.
- 대신 '대상 N개 가운데 우세 k, 열세 m, 동등 e, 미결정 j(두 가중 4분 판정, δ 0.5 cm)'로 쓴다.
- 과거 값(예: a2_spread 의 n = 40 −1.14 [−1.76, −0.77])은 SI 에서만 '하위 지역 포함 12대상 평균, 독립 지역 2개'라는 표기와 함께 싣는다.

- 열: `verdict4`(δ 0.5), `verdict4_d10`(δ 1.0), `verdict4_common`(지역 블록 공통 재표집 CI 의 4분 판정), `ci_dependence`(주 CI 와 공통 CI 의 판정이 다르면 '분할 독립 가정 의존'), `nboot`. 열 이름은 h42 의 표와 같다. L1–L8 의 판정 문구는 h40 집계 그대로다.

**(b) 과거 음성 결과(SI 음성 결과 등록표)**

- 재채점(필수 규칙): 저장 예측에 블록 id 가 있으면 반드시 `h4_common.boot_delta_blocks` 로 두 가중 CI 를 다시 계산하고 '재채점(비맹검)'으로 표시한다. 블록 id 가 없으면 하지 않는다. 확인 결과: H18·H19(`data/processed/m1/h1819_shard*_preds.npz`), H21(`h2/h21_preds.npz`), H22(`h2/h22_preds.npz`)의 예측 파일에는 `eval::…::block` 키로 블록 id 가 있다(개정 1 에서 키 이름만 확인). 따라서 네 가설은 재채점한다. H20 의 예측 파일은 찾지 못했다. 찾으면 같은 규칙을 적용하고, 없으면 H20 은 '4분 판정 불가(CI 규약 다름)'로 둔다. 산출은 `lgw_rescore.csv` 다.

### 1.5 L5 의 보고

### 1.6 분할 간 SD 와 분할 안 SE 의 비

- 정의: R = SD_between / mean(SE_within).
  - SD_between: `lgx_splitdist.csv` 의 `delta_sd`. 출처는 h42 `n4_tables` 의 `primary_source` = True 인 행이다. 같은 (대상, 대비)가 분할 50회(`source` = n4)와 분할 200회(n4a)에 모두 있으면 분할 50회 행이 주 출처다. 따라서 이 절의 대비는 모두 분할 50회 값이 주 출처이며, 대비마다 `source` 열을 표에 적는다. 분할 200회 값은 보조 열이다.
  - SE_within: LG 의 유효 분할마다 그 분할 하나만 넣은 `boot_delta_blocks`(셀 가중, 10,000회) 분포의 표준편차를 구하고 분할 평균을 낸다.
- 대상: 레나, 캐나다, 러시아 W, 러시아 E, Alaska(x).
- 표지를 붙이는 대비는 추출이 하나뿐인 대비로 한정한다. D0 − P0(n = 0), R1 − P1(전량), R1 − P0(전량), P1 − P0(전량), P2 − P0(전량)이다. n = 10 대비(P1 − P0, R1 − P1)의 R 은 서술 열로만 낸다. LGX-N4 는 분할마다 추출 2 × seed 2 의 평균이라 SD_between 에 추출 변동이 들어가지만 SE_within 은 추출을 고정한 재표집이라 추출 변동이 없다. 그래서 n = 10 에서는 분할 구성 효과가 없어도 R 이 커진다.
- 귀무값: 모형이 분할과 무관한 n = 0 대비에서 분할 간 변동은 B 블록을 대상 블록의 약 절반에서 비복원으로 뽑는 변동뿐이다. 이때 분할 간 SD 는 분할 안 부트스트랩 SE 의 약 √(1 − f) 배다(f = 대상 블록 가운데 B 블록의 비율, 유한 모집단 보정). f ≈ 0.5 이면 귀무 R 은 약 0.71 이고 1 이 아니다. 대비마다 R0 = √(1 − f̄)(f̄ 는 LG 유효 분할의 평균 B 블록 비율)를 계산해 싣는다. 전량 대비에도 같은 R0 를 기준으로 쓴다. 전량 대비에서 R0 를 넘는 부분에는 A 구성의 차이, 곧 분할 구성 효과가 들어간다.
- 표지: R / R0 > 1.5 이면 그 지역·대비의 LG CI 에 'SD/SE 비 과대(R/R0 > 1.5)'를 붙인다. 이 이름은 LGX L31 의 '분할 구성 의존'(LG 5분할 평균이 분할 분포의 10–90 백분위 밖)과 구분한다.
- 주 문장 전환: 한 지역·대비에 'SD/SE 비 과대'와 L31 형식 표지(`lgx_splitdist.csv` 의 `lg5_outside_10_90` = True)가 모두 해당할 때만 그 대비의 주 문장을 LGX-N4 의 지역 수준 값(분할 50회 평균, `lgx_region_inference.csv`)으로 쓰고 5분할 CI 는 표에 싣는다. 하나만 해당하면 표지만 붙이고 주 문장은 5분할 CI 로 쓴다.
- 한계: R0 는 RMSE 의 비선형성과 블록 크기의 차이를 무시한 근사다. SE_within 과 SD_between 의 seed 수는 같다(2). 블록 등가중 판의 R 을 보조 열로 낸다. 산출은 `lgw_splitratio.csv` 다.

### 1.7 편향·MAE 분해 표(SI, 서술)

- 정의: P0, P1, D0, R0, R1 의 n ∈ {0, 10, 전량}에서 지역별 편향, MAE, 지역 내 R², MSE = 편향² + 분산 분해.
- 입력: LGX 기준 축(`lgxb`)의 셀 단위 예측(`_cells.npz`). 분할·추출·seed 평균이다. h39 의 `bias-mae` 모드가 `--lgx-shards` 에서 읽는다(3.6).
- 가설 판정이 없는 서술 표다. 기전 문장('악화의 대부분이 수준 항이다')은 이 표의 분해 비율로만 쓴다. 산출은 `lgw_bias_mae.csv` 다.

### 2.3 추출별 단위 표

- 각 (대상, 모드, 분할, n, 추출 번호, 배치)에서 LG 가 쓴 라벨 행을 다시 만든다. 셀 무작위는 `h40.draw_cells`, 블록 분산은 `h40.draw_blocks` 이고, A 의 행 순서는 `h40.get_data` 와 `m1_core.half_split_blocks` 로 만든다. 설정은 LG 본 실행과 같게 둔다(하위 지역 대응표 `data/processed/lg_subregion_map_v1.csv`).

### 2.4 해석식 민감도 2건

모두 해석식(P0, P1, P2)만 쓰고 ML 적합이 없다. CPU 스레드 1, nice 10 이다. 판정이 없는 민감도이며 해석 규칙만 결과 전에 고정한다. 산출은 SI 표다.

**(S-a) 셀 평균 묶음**

- 대상: 레나(x), 캐나다(x), Alaska(x).
- 분할: `half_split_blocks` split_seed 1–200(LGX-N4 와 같은 규약). 분할마다 추출 5회, n ∈ {3, 10, 40}.
- 행 조건: LG 와 같이 A 의 행 n 개를 뽑는다(seed 는 `seed_of("lgw-sa-row", 대상, 분할, n, 추출)`).
- 셀 평균 조건: A 의 행을 1 km 위치(2.2)로 묶어 위치 평균 ALT 와 위치 평균 s(= √TDD)를 만들고, 위치 n 개를 뽑는다(seed 는 `seed_of("lgw-sa-cell", …)`). E_ls = Σ ȳ·s̄ / Σ s̄², E_n = (n·E_ls + 10·E0)/(n + 10). A 의 1 km 위치 수가 n 이하인 분할에서는 그 분할·n 의 셀 평균 조건을 빼고 뺀 분할 수를 적는다(캐나다는 1 km 위치가 86개라 n = 40 에서 해당할 수 있다). 행 조건은 LG 와 같이 A 의 행 수가 n 이하일 때만 뺀다.
- 채점: B 의 `eval_mask` 행(LG 와 같다). 보조로 B 도 1 km 위치 평균으로 묶은 채점을 낸다.
- 보고: 분할마다 추출 평균 Δ(P1 − P0), Δ(P2 − P0)를 구하고 두 조건의 차 Δ_unit = Δ_셀평균 − Δ_행 의 분할 분포(평균, 10·50·90 백분위)를 낸다. 러시아 W 의 같은 n 의 P1 − P0 분할 분포(행 = 지점 평균)를 참조 열로 싣는다.
- 해석 규칙(결과 전 고정):
  - 세 지역 모두 n ∈ {3, 10} 에서 |중앙값 Δ_unit| ≤ 0.5 cm 이면 '라벨 단위(점 대 1 km 위치 평균)는 소수 라벨 재보정의 이득을 바꾸지 않았다'로 쓴다.
  - 어느 지역이든 중앙값 Δ_unit < −0.5 cm 이면 '점 라벨 조건에서는 소수 라벨 재보정의 이득이 1 km 위치 평균 조건보다 작았다(지역, n, 크기)'로 쓰고 배포 지침의 라벨 단위를 '1 km 위치 평균'으로 적는다.
  - 중앙값 Δ_unit > +0.5 cm 이면 반대 방향 문장을 쓴다.
  - 셀 평균 조건에서 레나·캐나다 값의 10–90 백분위 구간이 러시아 W 의 구간과 겹치고, 같은 지역의 행 조건 구간은 러시아 W 와 겹치지 않을 때만 '지역 사이의 재보정 이득 차이 가운데 일부는 라벨 단위로 설명된다'를 덧붙인다. 행 조건에서 이미 겹치면 이 문장을 쓰지 않는다.
  - 레나와 캐나다(또는 Alaska(x))의 Δ_unit 방향이 서로 다르면 위 문장들을 한데 묶지 않고 지역별로 쓴다.

**(S-b) 러시아 W·E 의 단년 라벨**

- 대상: 러시아 W(x), 러시아 E(x).
- 원자료: `data/raw/calm/PANGAEA_972777_CALM_ALT_NH.tab` 의 지점·연도 값. v3 에는 지점 부호와 연도 열이 없으므로(개정 1 에서 열 이름으로 확인) v3 셀과 CALM 지점은 좌표로만 대응시킨다. 허용 차는 위도·경도 각 0.005° 다. 한 v3 셀에 CALM 지점이 둘 이상 대응하거나 한 지점이 둘 이상의 셀에 대응하면(다중 대응) 그 셀은 단년 대응에서 빼고 다년 평균을 그대로 쓰며 수를 적는다. 대응되지 않는 셀도 다년 평균을 그대로 쓰고 수를 적는다. 부등호 표기 값('>' 24행, '<' 10행)과 inactive 행은 뺀다.
- 절차: 분할 split_seed 1–200, 추출 5회, n ∈ {3, 10}. 뽑힌 지점마다 관측 연도 하나를 무작위로 골라(seed 는 `seed_of("lgw-sb", 대상, 분할, n, 추출, loc_id)`) 그 해의 값으로 E_ls 와 E_n 을 구한다. 채점은 B 의 다년 평균 행 그대로다. 같은 분할·추출에서 다년 평균 라벨로 구한 값과 짝짓는다.
- 보고: Δ_year = Δ(P1 − P0)_단년 − Δ(P1 − P0)_다년 의 분할 분포(평균, 10·50·90 백분위).
- 해석 규칙(결과 전 고정): 두 지역 모두 n ∈ {3, 10} 에서 |중앙값 Δ_year| ≤ 0.5 cm 이면 '단년 관측 라벨에서도 라벨 3–10개의 재보정 이득이 유지되었다'로 쓴다. 중앙값 Δ_year > +0.5 cm 인 지역이 있으면 '단년 라벨에서는 이득이 줄었다(지역, n, 크기)'로 쓰고 배포 지침의 '라벨'을 '다년 평균 지점'으로 한정한다. 중앙값 Δ_year < −0.5 cm 이면 그 값을 그대로 보고한다.

### 2.5 원고에서 n 을 쓰는 규칙

- 그림 축과 표의 n 은 2.1 의 행 수다. 모든 그림과 표에 2.2 의 지역별 단위 표를 병기하거나 참조한다.
- 지역 간 비교 문장에는 단위를 붙인다. 예: '러시아 W 는 CALM 지점 다년 평균 10개, 레나는 점 관측 10개(1 km 위치 평균 m개)'. m 은 2.3 의 평균이다.
- 배포 지침 표의 n 은 행 수와 1 km 위치 수를 함께 적는다.
- 전량은 지역마다 다르다(러시아 W·E 약 15개, 캐나다 수백 개, 레나 약 1,500개). 전량 문장은 라벨 수백 개 이상인 지역(레나, 캐나다)과 약 15개인 지역(러시아 W·E)으로 나눠 쓴다(비평 Sci Rep G5).
- '1 km 셀 단위 예측'은 격자 지도(6절)에만 쓴다. 채점 셀은 행 단위다.

### 2.6 결과 열람 전에 계산할 수 있는 이유

- 2.2–2.4 의 입력은 v3 표, 토양 도일 표, 하위 지역 대응표, CALM 원자료, h40 의 분할·추출 함수뿐이다. 모델 예측과 LG·LGX·LGT 의 조각을 읽지 않는다.
- 추출 seed 는 (대상, 모드, 분할, n, 추출 번호)만으로 정해진다(`seed_of`). 따라서 LG 가 쓴 라벨 집합을 결과 없이 다시 만들 수 있다.
- 2.4 의 두 민감도는 해석식 계산이라 LG 의 대비 값과 무관하다. 다만 해석 규칙을 먼저 고정해야 하므로 계산은 이 문서의 커밋 뒤에 한다. 계산 시각과 커밋을 개정 이력에 적는다.
- 2.3 의 대조에 쓰는 사전 점검·스모크 조각은 경로 확인용이며 판정에 쓰지 않는다. 대조는 키 열과 `n_lab`, `n_blocks_lab` 두 열만 읽는다.

### 3.2 상태와 요약값

- 칸(대상 × 단계 × 레시피)의 상태는 Δ(레시피 − P0)의 4분 판정(δ 0.5 cm, 10,000회)과 비열등 판정(0.5)이다. 점 추정, 두 가중 CI, 보조 CI, 라벨 순가치 Δ(n) − Δ(0)(같은 레시피)를 함께 싣는다. 보조 δ 1.0 cm 의 4분 판정과 비열등 판정을 병기한다.
- 단계·레시피마다 요약값: 주 4지역 층화 평균 Δ 와 CI 와 4분 판정과 비열등 판정, 3지역 보조 평균, 독립 지역 가운데 우세·동등·미결정·열세 지역 수와 비열등 지역 수, 최악 Δ(독립 지역 점 추정의 최댓값, 지역 이름, 그 지역의 CI), 라벨 순가치의 지역 평균, 하위 지역 10대상의 우세·열세 수(서술).
- 산출은 `lgw_scenarios.csv`(칸 단위)와 `lgw_scenarios_summary.csv`(단계 단위)다. 본문 Fig 7 b 패널의 입력이다.

| 항목 | 내용 |
|---|---|
| 목적 | 라벨을 3 → 10 → 40 개로 늘려 가며 A 쪽 라벨만으로 멈출지 정하는 규칙이 항상 40개를 쓰는 것보다 라벨을 아끼면서 오차를 거의 늘리지 않는지 본다. 양성 관측 규칙의 유일한 후보다(RESEARCH_FRAME §5.2) |
| 대상 | 판정: 레나, 캐나다, Alaska(x)(\|A\| > 40). 서술: 러시아 W·E(상한을 \|A\| 로 둔다), 하위 지역 x 모드 |
| 라벨 순서 | 중첩 추출이다. 분할마다 A 의 순열 π = RandomState(`seed_of("lgw-sc3", 대상, 모드, 분할, 반복)`).permutation(\|A\|)를 만들고 단계 n_k ∈ {3, 10, 40} 의 라벨을 π 의 앞 n_k 개로 둔다. 분할은 LG 의 유효 분할(split_seed 1–5), 반복 20회다. LG 의 추출(단계마다 독립)과 다르므로 LG 조각을 쓰지 않는다 |
| 멈춤 통계 | 단계 n_k ∈ {3, 10} 에서 선택 라벨의 잭나이프 표준오차 SE_jk = √((n−1)/n · Σ(log E^(−i) − 평균)²), E^(−i) = 라벨 i 를 뺀 최소제곱 계수(수축 전) |
| 멈춤 규칙 | SE_jk ≤ τ 이면 그 단계에서 멈추고 E_n(κ = 10 수축, n = 멈춘 단계)으로 P1 을 만든다. 아니면 다음 단계로 간다. 상한은 40개다. 주 τ = 0.05(로그 단위, 예측 ALT 의 약 5 %). 민감도 τ ∈ {0.025, 0.10, 0.20} 은 서술이다(0.20 은 개정 1 에서 더했다) |
| 비교 | 같은 순열의 앞 40개로 만든 P1(항상 40개). 대비 Δ_SC3 = RMSE(P1_규칙) − RMSE(P1_40), B 의 `eval_mask` 행 채점, 블록 부트스트랩 10,000회, 3지역 층화 평균과 지역별 값. 라벨 비 = 규칙이 쓴 라벨 수의 평균 / 40 |
| 판정 | 지지: (i) 라벨 비 ≤ 0.5, (ii) 3지역 평균 Δ_SC3 의 점 추정 ≤ 0.3 cm, (iii) 3지역 평균의 두 가중 CI 상한 < 0.5 cm, (iv) 지역별 Δ_SC3 가운데 열세(두 가중 CI 하한 > 0)가 없음. 부분(정밀도 부족): (i), (ii), (iv)만 만족. 규칙 비작동: 라벨 비 ≥ 0.9(규칙이 거의 항상 40개까지 간다). 기각: 그 밖 |
| 문장 | 지지: '순차 멈춤 규칙(τ 0.05)은 라벨 수를 항상 40개 대비 절반 이하로 줄이면서 오차 증가를 0.3 cm 이하로 유지했고, 오차가 커진 지역은 없었다(3지역)'. 규칙 비작동: '주 τ 0.05 에서 멈춤 규칙은 거의 작동하지 않았다(라벨 비 r)'. 이때 Δ_SC3 는 서술만 한다. 규칙 비작동과 기각이면 이 규칙을 배포 지침에 넣지 않는다 |
| 병기 | P1_규칙 − P0, P1_40 − P0, 지역별 멈춘 단계의 분포, τ 민감도별 라벨 비와 Δ_SC3(서술) |
| 기대 범위(결과 전 추정, 모의하지 않음) | 잭나이프 SE 는 대략 CV(y/s)/√n 이다(CV 는 A 라벨의 y/s 변동계수). 2.2 의 1 km 셀 안 SD 11–18 cm 와 평균 ALT 50–90 cm 에서 셀 안 변동만으로도 행 단위 CV 는 0.15 이상이다. 지역 전체 CV 는 블록 사이의 E 변동이 더해져 그보다 클 것으로 본다(개정 1 에서 본 캐나다 x 분할 1 의 블록 간 E 변동계수 0.22 와 맞는 범위다, 0.1). τ = 0.05 에서 n = 10 에 멈추려면 CV ≤ 0.16, n = 3 에 멈추려면 CV ≤ 0.09 가 대략 필요하다. 따라서 주 τ 에서는 대부분의 반복이 40개까지 가서 '규칙 비작동'이 나올 가능성이 크다. 다만 n = 3 의 잭나이프 SE 는 추정 변동이 커서 우연히 작게 나와 일찍 멈추는 반복이 있을 수 있다. τ 는 이 추정을 보고 바꾸지 않았다(대상 라벨 통계로 τ 를 정하는 일이 되기 때문이다) |
| 맹검 | 비맹검 부분 포함. b2 의 κ = 10 수축 곡선과 RESEARCH_FRAME A.2(연구 목적 절)의 캐나다 E 수축 결과(n = 3 +0.73, n = 320 +3.52 cm)를 보았다. P1 − P0 가 n 에 따라 커지는 지역이 있다는 뜻이므로 캐나다에서는 일찍 멈출수록 유리한 방향(Δ_SC3 < 0)을 예상할 수 있다. 3지역 평균만 보면 캐나다가 다른 지역의 악화를 가릴 수 있어 (iv)를 더했다. 멈춤 규칙 자체는 계산한 적이 없다 |
| 계산 시점 | LG 결과와 무관하다(해석식, v3 표와 분할 함수만 쓴다). 이 문서의 커밋 뒤에 계산한다 |

- τ = 0.05 의 근거는 약하다. 대상 평균 ALT 50–90 cm 에서 5 % 는 2.5–4.5 cm 이고, 이는 주 4지역 P0 RMSE(약 14–42 cm, `l2_noise_floor.csv` 의 M1 규약 값)보다 작고 CALM 다년 평균의 표준오차(1.6–6.0 cm, 같은 표)와 비슷한 크기다. 관례값으로 표기한다.

## 4. 배치 축 가설 L43

LG 배치 축(§3 요인 축: P1·R1(CatBoost), n ∈ {10, 40, 160} 가운데 |A| 미만, 대상 25, 셀 무작위 대 블록 분산)은 ZovWo 에서 적합 중이지만 등록 가설이 없다(비평 완결성 G3, `lg_count_cpu.csv` 의 배치 축 적합 수로 확인된 사항). 이 절은 그 판정을 결과 열람 전에 등록한다.

| 항목 | 내용 |
|---|---|
| 가설 | 라벨을 A 블록 전체에 흩어 뽑으면(블록 분산, `h40.draw_blocks`) 같은 수를 셀 무작위로 뽑을 때보다 재보정 물리식(P1)의 오차가 작다 |
| 대비 | Δ_L43(M, n) = RMSE(M, 블록 분산) − RMSE(M, 셀 무작위). 키는 (M, 학습기, α 1, 배치, n, 기준 λ) 다. 두 배치의 라벨 집합은 서로 다르다. `h40.contrast` 는 두 배치를 추출 번호(0–4)로만 짝짓고 `boot_delta_blocks` 는 추출을 고정한 채 채점 블록만 재표집한다. 방법 대비와 달리 추출 변동이 상쇄되지 않으므로 이 CI 는 추출 변동을 빠뜨린다 |
| 주 CI(2단 재표집) | 재표집마다 (1) 분할마다 채점 블록 가중을 한 번 뽑아 두 배치에 공유하고(`h4_common.boot_weights`, 같은 B 블록), (2) 배치마다 따로 그 분할의 추출 번호 5개를 복원 추출해 뽑힌 추출들의 RMSE 평균(seed 평균 뒤)을 낸다. 분할은 LG 와 같이 고정하고 같은 재표집 번호끼리 분할 평균과 층화 평균을 낸다. 셀 가중과 블록 등가중 판을 함께 낸다. 10,000회, seed `seed_of("lgw-l43", 대상, M, n)` |
| 보조 CI 와 열 | (a) `h40.contrast` 의 CI 를 '추출 조건부'로 표기해 병기한다. 두 CI 의 4분 판정이 다르면 '추출 변동 의존'을 붙인다. (b) 추출 승률: 분할마다 두 배치의 추출을 무작위로 짝지어(1,000회) 추출 단위 Δ < 0 인 비율을 구하고 분할·대상 평균을 낸다 |
| 주 판정 | M = P1, n ∈ {10, 40}, 주 4지역 층화 평균, 2단 CI 의 4분 판정(δ 0.5 cm). n = 40 은 설계상 레나·캐나다 2지역이라 항상 '부분(지역 2/4)'이다. 이 표기는 지지를 막지 않는다. 대신 n = 40 을 쓰는 문장에는 '레나·캐나다 2지역'을 넣는다 |
| 판정과 문장 | 두 n 모두 우세: 지지. '재보정 물리식에서 라벨을 여러 블록에 흩어 뽑으면 셀 무작위 추출보다 n = 10(주 4지역)과 n = 40(레나·캐나다 2지역)에서 오차가 작았다'. 한 n 만 우세이고 다른 n 이 동등 또는 미결정: 부분 지지(n 명시). 한 n 이 우세이고 다른 n 이 열세: '배치 효과는 라벨 수에 따라 방향이 바뀌었다(n, 방향)'. 우세 없이 열세가 있음: 기각. '블록 분산 추출이 불리했다(n)'. 두 n 모두 동등: '배치의 차이는 0.5 cm 안이었다'. 그 밖: '배치 효과는 확인되지 않았다' |
| 보조 | R1 의 n ∈ {40, 160}(레나·캐나다), P1 의 n = 160, Alaska(x)의 P1·R1(n ∈ {10, 40, 160}), 지역 행, 지역 블록 공통 재표집 CI, 선택 라벨의 평균 블록 수(runs 의 `n_blocks_lab`, 배치별), 하위 지역의 우세·열세 수(서술, 1.3). 주 판정의 두 대비는 항목 안 Holm 보정 p 를 보조 열로 낸다 |
| 원고 제한 | 방법 수준의 지침만 쓴다('라벨을 한 블록에 몰지 않고 여러 블록에 흩는다'). '어디를 재야 하는지 제시한다'와 지역·지점 우선순위 문장은 쓰지 않는다 |
| 지위 | 추가 가설이다. 확인적 가설 집합(LGX 6개)과 초록 묶음(1.1)에 넣지 않는다. 본문 R4 절과 Fig 5 의 배치 문장은 이 판정을 따른다. NOVELTY-N5 의 배치 문장('LG 배치 축이 두 가중에서 확인되면 별도 문장')의 조건이 이 판정이다 |
| 맹검 | 비맹검 부분 포함. a2_spread 의 '블록 전체 분산 − 한 블록 집중'(n = 40 −1.14, n = 10 +0.94, 하위 지역 포함 12대상, E 추정 레시피), a2 의 블록 분산 추출에서 레나 n = 10 의 P1 − P0 +3.7 cm(NOVELTY-N5), h29b 의 해로운 단일 블록 비율을 보았다. LG 규약의 '블록 분산 − 셀 무작위' 대비는 계산한 적이 없다. qOkSo 사전 점검 조각에 캐나다 x 분할 1 추출 0 의 P1·R1(n = 40, 두 배치) 값이 있다(미열람, 0.1) |
| 계산 | h39 `summarize` 가 LG 조각에서 계산한다. 새 적합은 없다. 산출은 `lgw_l43.csv` 와 `lgw_tests.csv` 의 L43 행이다 |

## 5. 알래스카 우선 검증 AK1w

NEXT §8.3 의 AK1 은 '알래스카 지역 내 모의(1단계)에서 넘은 조합이 지역 간 모의(2단계)에서도 넘는 비율이 절반 이상이면 알래스카에서 정한 절차가 새 지역에 이전된다를 쓴다'였다. 이 문서는 옛 AK1 을 철회하고 AK1w 로 대체한다. 사유: 옛 문장의 2단계는 같은 알래스카 하위 지역을 원천만 바꿔 다시 채점하는 설계이므로 '새 지역에 이전된다'는 설계보다 넓은 주장이다. 새 지역으로의 이전은 L6 이 본다. 철회 시점은 2026-09-30, 결과 열람 전이다. 옛 AK1 은 계산한 적이 없다(3.1 과 같은 확인). L6 은 알래스카 하위 지역 모드 i 에서 주 4지역으로의 이전만 본다. AK1w 는 같은 하위 지역 안에서 원천 구성만 바꾼 경우(모드 i → 모드 x)를 본다.

| 항목 | 내용 |
|---|---|
| 가설 | 알래스카 하위 지역에서 지역 내 원천(모드 i)으로 물리식을 넘은 조합은 알래스카 밖 원천만 쓸 때(모드 x)도 같은 하위 지역에서 물리식을 넘는다 |
| 조합 | L6 과 같다. (방법, α ∈ {1, 10, 100, 이어 학습}) × n ∈ {10, 40, 160}, 방법별 기준 λ 한 행, 셀 무작위, 학습기 CatBoost 또는 해석식. 중첩 선택(nested)과 P0 은 뺀다 |
| 통과 | Δ(M − P0)의 두 가중 CI 상한이 모두 0 미만(LG 곡선 행의 `sig_p0` = improve). 주 판정은 L6 과 같은 LG 곡선 행(h40 집계, 1,000회)을 쓴다. 10,000회 재계산은 보조 열이다 |
| 주 판정(쌍 단위) | 모드 i 에서 통과한 (AL-k, 조합) 쌍 가운데 같은 쌍이 모드 x 에서도 통과한 비율 r. 모드 i 통과 쌍이 4개 미만이거나 통과 쌍이 걸친 AL 대상이 3개 미만이면 판정 불가다. 그 밖에서 r ≥ 0.5 이면 지지. '알래스카 하위 지역에서 지역 내 원천으로 물리식을 넘은 조합의 과반은 알래스카 밖 원천만 쓸 때도 같은 하위 지역에서 물리식을 넘었다(r, 쌍 수, 대상 수)'. r < 0.5 이면 기각. '이 통과는 원천에 같은 지역 자료가 있는 조건에 의존했다(r)' |
| 보조 판정 1(기준선 공통, r') | 모드 i 통과 쌍 가운데 RMSE(M, x) − RMSE(P0, i) 의 두 가중 CI 상한이 모두 0 미만인 쌍의 비율 r'. 모드 x 의 P0 는 알래스카 밖 원천의 E0 라 모드 i 의 P0 와 다르므로, 기준선 약화로 r 이 커지는지 보기 위한 판정이다. 두 모드의 같은 분할에서 B 블록 목록과 블록별 셀 수가 같을 때만 두 저장소의 키를 한 저장소로 합쳐 `boot_delta_blocks`(10,000회)로 계산한다. 다르면 그 쌍은 r' 에서 빼고 수를 적는다. r 과 r' 의 판정(0.5 기준)이 다르면 주 판정에 '기준선 의존'을 붙인다 |
| 보조 판정 2(대상 단위) | AL 대상마다 모드 i 통과 조합 가운데 모드 x 에서도 통과한 조합이 과반인지 보고, 과반인 대상 수 / 모드 i 통과 조합이 있는 대상 수를 병기한다. 같은 AL-k 안의 α 변형 쌍은 서로 독립이 아니므로 쌍 단위 r 과 함께 읽는다 |
| 보조 판정 3(조합 단위) | L6 과 같은 방식으로 모드 i 에서 과반 대상을 통과한 조합을 고르고, 그 조합이 모드 x 의 AL 대상에서 통과한 비율 |
| 민감도 | 분할 안 채점 블록이 5개 미만인 대상(비평 기준 AL-1, AL-4, AL-6)을 뺀 판정, 셀 가중 CI 만 쓴 판정 |
| 기준선 차이 열 | RMSE(P0, x) − RMSE(P0, i)와 RMSE(M, x) − RMSE(P0, i)의 점 추정을 서술 열로 싣는다. 두 모드의 대상 셀이 같으면 B 셀도 같다(h40 의 분할은 대상 셀만 쓴다). 두 모드의 B 셀 집합이 다르면 이 열은 비운다 |
| 원고 | L6, AK1w, L22 를 한 표로 싣는다. '알래스카 내에서 넘는다'와 '알래스카에서 정한 절차가 새 지역에 이전된다'는 쓰지 않는다. 쓰는 표현은 '알래스카 하위 지역을 모의 신규 지역으로 둔 시험(지역 내 원천, 원천의 60.7–77.3 % 가 알래스카 셀)', '알래스카 밖 원천만 쓴 시험', '알래스카 전체를 새 지역으로 둔 참조 곡선(Alaska(x))' 셋이다 |
| 맹검 | 비맹검 부분 포함. h25b 의 AL-1–AL-6(모드 i 에 해당, α 1, 분할 3)과 h25x 의 상위 지역 제외 민감도(kmedoid 4–5/10, random 4/10 달성)를 보았다. 규약(분할, 추출, 원천 정의)은 다르다 |
| 계산 | h39 `summarize` 가 LG 곡선 행과 LG 조각으로 계산한다. 새 적합은 없다. 산출은 `lgw_ak1.csv` 와 `lgw_tests.csv` 의 AK1w 행이다 |

## 6. 지도 과제(MAP)

### 6.1 목적과 지위

- 사용자 틀 (3)(ALT 지도와 불확실성 지도)과 RESEARCH_FRAME §5.1 필수 6 을 충족하는 서술 산출이다. 가설은 없다.
- LG 6A.10 과 LGU §9 는 '1 km 격자 공변량이 업로드 묶음에 없다'는 이유로 지도를 별도 과제로 뺐다. 로컬 실행에서는 이 사유가 성립하지 않으므로 이 절이 그 별도 과제를 등록한다. LGU §9 의 'AOA 안팎의 조건부 커버리지'는 이 절에서도 하지 않는다(6.6 (e)의 외삽 표시로 대신한다).

### 6.2 대상과 영역

| 항목 | 내용 |
|---|---|
| 대상 | 레나, 모드 x 1곳. 원천은 LG 와 같다(F4_direct 에서 레나 macro 와 100 km 버퍼를 뺀 셀, `D.source_idx("Lena", "x")`) |
| 영역 | 71.5–73.6°N, 123.3–130.1°E(6B.4 의 레나 델타 영역 정의). 레나 라벨의 범위(71.6–73.6°N, 123.4–130.0°E, 비평 완결성 G1)를 덮는다 |
| 격자 | 6B.3 의 1 km 셀 색인(2.2 와 같다). 셀 중심 좌표에서 공변량을 붙인다. 셀 수는 마스크 전 약 5만 개로 추정하며 조립 뒤 메타에 적는다 |

### 6.3 격자 조립

- 입력은 x25 의 25열이다(DEM 6, ERA5-Land 8, SoilGrids 9, CCI 2). s = `e5_sqrt_tdd` 는 x25 안에 있다.
- 규약은 v3 와 같다. `scripts/1_data_prep/ext_cells_covariates_v1.py` 의 단계 함수(`stage_dem`, `stage_e5`, `stage_cci`, `stage_sg`)를 importlib 로 불러 쓴다. 이 모듈에는 부작용이 있다(개정 1 에서 코드로 확인). 모든 단계가 모듈 상수 `PARTS`(`data/processed/ext_labels/cov_parts`)에 `{tag}_*.csv` 를 쓰고, `stage_sg` 는 `allow_download` 기본값이 True 라 새 SoilGrids 창을 내려받고 `data/raw/soilgrids_wcs/windows_wcs_meta_v4.json` 을 다시 쓰며, `stage_tiles` 는 DEM 타일을 내려받는다. LGD 작업이 같은 폴더와 메타를 쓴다. 그래서 격자 스크립트는 다음을 지킨다. (1) import 뒤 모듈의 `PARTS` 를 `data/processed/map/cov_parts` 로 바꾸고 tag 에 `map_lena_` 접두어를 쓴다. (2) `stage_sg` 는 `allow_download=False` 로만 부른다. 이때 기존 창(`enrich_soilgrids_wcs.WINDOWS` 와 E3 창)만 읽고 SoilGrids 메타를 쓰지 않는다. (3) DEM 타일은 별도 단계에서 내려받아 `data/raw/dem/` 에 새 파일로만 더하고(기존 파일은 건드리지 않는다) 목록과 SHA-256 을 격자 메타에 적는다. 이 스크립트의 `--validate`(v3 CALM 149행 대조)에서 CCI 1행(loc 17480)이 달랐던 문제는 LG 개정 13 에서 최근접 색인의 float32 규칙으로 고친 뒤 차 0 이 되었다(`cov_validate_meta.json`).
- DEM: Copernicus DEM 33 × 33 창. 영역(71.5–73.6°N, 123.3–130.1°E)에 필요한 1° 타일은 N71–N73 × E123–E130 의 24개다. 로컬에 있는 것은 N71 E127–E130, N72 E123–E129, N73 E123–E124 의 13개이고, 없는 것은 N71 E123–E126, N72 E130, N73 E125–E130 의 11개다(개정 1 에서 파일 목록으로 다시 확인. 초판은 N72 E130 을 빠뜨렸다. 이 타일은 영역 동쪽 끝 72–73°N 의 셀에 필요하다). 공개 저장소에 해당 타일이 있는지(바다 타일은 없다) 확인하고 계정 없이 내려받는다. 24개 타일 각각의 상태(있음, 받음, 공개 저장소에 없음)를 격자 메타에 적는다. DEM 이 없는 셀은 결측으로 두고 대체하지 않는다. 레나 라벨 3,037행은 모두 로컬 타일 안에 있으므로(심사 확인) 6.4 의 대조에는 영향이 없다.
- ERA5-Land: `data/raw/era5land/nh_monthly_2015-2020.nc`(로컬에 있다), 육지 폴백 0.2° → 0.5°. 토양 도일(`e5_tdd_soil`, `e5_sqrt_tdd_soil`, v3 규칙대로 0 이하는 결측)도 같은 단계(`stage_e5`)에서 만든다. 6.5 의 마스크와 6.7 의 토양 도일 앵커에 쓴다.
- SoilGrids: `data/raw/soilgrids_wcs/lena` 창(WGS84 경계 122.9–148.0°E, 71.2–73.9°N, 330 × 43 화소)이 영역을 덮는다(메타 파일로 확인). 창 안의 유효 화소 비율은 0.46 이다. v3 레나 F4_direct 3,037행 가운데 SoilGrids 9층이 모두 결측인 행은 273행, 한 층 이상 결측인 행은 396행이다(개정 1 에서 계산). 영역 격자점의 SoilGrids 유효 비율은 약 0.84 다(바다 포함 격자점 14,280개. 심사의 계산이며 개정 1 에서 다시 계산하지 않았다).
- CCI ALT: `data/raw/cci_alt/` 의 25개 연도 파일 평균. 영역 안의 유효 화소 비율은 확인하지 못했다.

### 6.4 조립 QA(예측 전에 통과해야 한다)

- 조립 코드를 v3 의 레나 F4_direct 좌표 3,037개에서 실행해 x25 를 v3 값과 열별로 대조한다.
- 허용 차: ERA5-Land 8열, SoilGrids 9열, CCI 2열은 같은 화소를 쓰므로 절대 차 1e-6 이하. DEM 6열은 상대 차 1e-4 이하. 토양 도일은 `e5_soil_tdd_v3.csv` 와 절대 차 1e-6 이하.
- 결측 처리: 양쪽이 모두 NaN 이면 일치, 한쪽만 NaN 이면 불일치로 센다. SoilGrids 는 v3 와 같은 창 집합(`allow_download=False`)으로 조립하므로 v3 의 결측 행(9층 모두 결측 273행)은 결측으로 재현되어야 한다.
- 통과 기준: 모든 열에서 허용 차를 넘는 좌표의 비율이 1 % 이하. 넘는 열이 있으면 예측하지 않고 원인을 찾아 고친 뒤 다시 대조한다. v3 의 레나 공변량이 다른 경로(자료원, 창, 보간)로 만들어진 것이 원인이면 허용 차를 늘리지 않고 조립 경로를 v3 경로에 맞춘다. 원인과 수정은 개정 이력에 적는다.
- 보고: 열별 불일치 비율, 영역 안 셀 가운데 x25 가 모두 유효한 비율, 열별 결측 셀 수, 쓴 DEM 타일 목록과 해시. 산출은 `data/processed/map/lena_grid_qa_v1.csv`.

- 패널 (b)는 추출 하나의 예시다. 같은 분할의 추출 5개와 분할 5개에서 E_n 의 범위와 그에 따른 영역 평균 ALT 의 범위를 캡션에 적는다(해석식).

### 6.7 권장 레시피 선택 규칙(결과 열람 전 고정)

패널 (a)–(c)의 방법은 아래 규칙으로 정한다. 입력은 주 4지역 층화 평균의 4분 판정(10,000회, `lgx_lg_aux.csv` 와 `lgw_bundle.csv`. R0 − P0(n = 0)처럼 두 표에 없는 대비는 h39 `summarize` 가 `lgw_aux4.csv` 에 함께 계산한다), 레나 지역 행의 4분 판정, LGX L29 의 판정(`lgx_tests.csv`), LGU-B2 의 판정이다. 규칙이 기본 방법을 바꾸면 기본 방법의 지도는 SI 로 옮긴다. 규칙이 고르지 않은 후보의 지도는 만들더라도 본문에 쓰지 않는다. 예측 지도를 본 뒤 방법을 바꾸지 않는다.

**격자에서 계산할 수 있는 기준선(결과 전 고정)**: L29 의 기준선 가운데 격자에서 LG 와 같은 정의로 계산할 수 있는 것은 다음 목록이다. S-aff(원천의 a + b·s), CCI-aff, 무보정 `cci_alt`, P0@cci·P1@cci, P0@soil·P1@soil(토양 도일 √TDD 앵커, 6.3 의 `stage_e5` 산출), `p4_ku`·`p2_edaphic` 을 쓰는 기준선(무보정 값, P0@ku·P0@ed, P1@ku·P1@ed, B:ens)이다. 마지막 묶음은 `physics._fallback` 의 결측 대체 통계를 v3 입력 표 전체의 중앙값(LG 의 `load_base` 가 쓴 값)으로 고정해 계산하고 그 값을 메타에 적는다. 격자 셀의 공변량으로 중앙값을 다시 계산하지 않는다. 연도 정합 √TDD 앵커(tddm, P0@tddm·P1@tddm)는 관측 연도가 있어야 정의되므로 정적 격자에서 계산할 수 없어 목록에서 뺀다. L29 가 고른 P* 나 P1* 가 목록 밖이면, L29 판정 표에서 P0(또는 P1)보다 우세이고 레나 행이 열세가 아닌 목록 안 기준선 가운데 점 추정이 가장 낮은 것을 쓴다. 그런 기준선이 없으면 P0(또는 P1)를 쓴다. 대체 사실을 캡션에 적는다.

| 패널 | 규칙 |
|---|---|
| (a) 라벨 0 | R0 − P0(n = 0)가 우세이고 레나 행이 열세가 아니면 R0. L29 가 n = 0 에서 P0 보다 우세한 기준선 P* 를 정했고(목록 안으로 대체한 뒤) 레나 행의 P* − P0 가 열세가 아니면 P*. 둘 다 해당하면 층화 평균 점 추정이 낮은 쪽. 그 밖은 P0 |
| (b) 라벨 10개 | 재보정 기준 Pr 은 L29 의 라벨 n개 조건이 n = 10 에서 P1* 를 정했으면(목록 안으로 대체한 뒤) P1*, 아니면 P1 이다. R1 − P1(n = 10, AB5)이 우세이고, P1* 가 있으면 R1 − P1* 도 우세이고, 두 대비의 레나 행이 열세가 아니면 R1. 그 밖은 Pr |
| (c) 라벨 전량 | 재보정 기준 Pr 은 전량의 P1*(목록 안) 또는 P1(전량 재보정)이다. R1 − P1(전량, AB9)이 우세이고, P1* 가 있으면 R1 − P1* 도 우세이고, 두 대비의 레나 행이 열세가 아니면 R1. 그 밖은 Pr. L8 이 기각이면 캡션에 적는다 |
| (d) 구간 | 패널 (a)에서 고른 방법의 구간이다. 방법이 R0 또는 P* 이면 보정 점수를 그 방법의 원천 지역 하나 제외 예측으로 다시 만든다(CatBoost 적합은 원천 지역 수만큼, CPU) |
| 공통 | 지도는 CPU 학습기(`catboost_lo`)와 해석식 방법만 쓴다. GPU 학습기(LG 학습기 축, LGT, LGF)가 판정에서 앞서도 지도에 쓰지 않고 캡션에 그 사실과 대비 값을 적는다(자원 조건, 6.9). LGT 의 대비 값은 '등록 시점에 결과 존재(미열람)' 규칙의 대상이다(0.3) |

## 7. 새 지역(6B, LGD) 개정안

### 7.1 적용 원칙

- 이 절은 점검 3절 (a)1–12, (b), (c)의 개정안이다. 6B 본문은 다른 작업이 고치는 중이므로 개정안을 여기에 두고, LG 계획서 개정 이력에는 뒤에 '6B 개정안은 `docs/EXPERIMENT_PLAN_WRAPUP_2026-09-30.md` 7절에 있다'는 한 줄을 넣는다.
- 적용 시점은 두 가지다. '결과 회수 전'은 P4 값(LG 본 실행의 주 4지역 값)을 보기 전에 고정해야 하는 규칙이다. 이 문서의 커밋으로 효력이 생긴다. 'LGD 실행 전'은 적격 표와 v4 해시의 등록(6B.4 의 판정 시점) 전에 고정해야 하는 항목이다.
- 채택 상태(개정 1 기록): LG 개정 13(커밋 896a15e, 2026-09-30 02:35)이 (a)8, (a)9, (a)12, (b)2, (b)3·(b)4 의 기록, (c)1 을 채택했고, (a)1–7, (a)10, (a)11, (b)1 은 집계기 규칙으로 이 문서의 커밋에 효력을 맡겼다. 개정 13 은 v4 해시(sha256 4c387b2b…, 18,088행 = v3 17,572 + 새 516)와 적격 표(sha256 5b23a9a8…)를 등록했으므로 'LGD 실행 전' 항목의 적용 시점은 이미 지났다. 개정 13 은 커밋 전의 이 문서를 절 번호로 인용했다. 따라서 이 문서는 7.2–7.5 와 8.2, 8.5 의 절 번호와 항목 번호를 바꾸지 않는다. 개정 1 에서 고친 (a)3, (a)5, (a)9, (b)1, (c)2, (c)3 의 내용은 아래 각 행에 적었다.
- 적용 방법은 세 가지다. '집계기 규칙'은 6B.6 6단계의 확장 풀 집계기(아직 없다)가 구현하는 규칙이다. '실행 표 수정'은 대상별 실행 표(6B.6 3–4단계)를 바꾸는 항목이며 LG 계획서 개정 이력에 채택 기록이 있어야 효력이 있다. '기록'은 개정 이력이나 메타에 적는 항목이다.
- 6B 의 가설(L1e, L4e, L8e, L38–L42), 판정 문구, 병기 규칙은 바꾸지 않는다. 아래 규칙은 보조 열과 덧붙이는 문장만 정한다. 채택 기록이 없는 '실행 표 수정' 항목은 '미채택'으로 남고 LGD 는 6B 본문대로 실행한다.

## 8. 실행 환경 이전

### 8.1 범위

- 사용자 지시(2026-09-30 01시)에 따라 Rescale 에 예정했던 작업을 로컬로 옮긴다. 대상은 LGX 통합 집계(6A.9, 개정 8 의 `lgx_sum.yaml`), LGD 본 실행(6B.6 5단계), LGU 전체다.
- 진행 중인 Rescale 작업(ZovWo, Qjpbeb, ShFtT)은 끝까지 둔다. LGX L26 의 5분할 판정은 본 실행 분할 1–3 과 확장 분할 4–5 를 합치므로, 이 작업을 로컬에서 다시 돌려 대체하면 분할과 환경이 교락된다.
- 새 Rescale 작업(상한 초과 조각의 이어 돌리기, `lgx_sum.yaml` 제출)은 기본값이 아니다. 필요해지면 사용자 확인 전까지 대기한다(8.6).
- 이 문서는 다른 계획서를 고치지 않는다. 아래 8.2 의 문안을 각 계획서의 개정 이력에 옮겨 적을 때 효력이 생긴다(LG 6B.6 5단계 문안은 LG 개정 13 이 채택했다). 8.3–8.6 의 규칙(판 목록, 교차 환경 점검, 자원, 비교 규칙)은 이 문서의 커밋으로 효력이 생긴다.

### 8.6 상한 초과와 비교 규칙

### 9.3 해석

- 측정 잡음은 두 방법에 같이 들어간다. 잡음 σ_e 가 예측과 독립이면 RMSE_obs² = RMSE_sig² + σ_e² 이고, 작은 차이에서 Δ_obs ≈ (RMSE_sig / RMSE_obs) · Δ_sig 다. σ_e 3–8 cm, RMSE 15–40 cm 에서 이 비는 약 0.85–1.00 이다. 따라서 관측 척도의 δ 는 신호 척도의 δ 와 거의 같고, 측정 잡음이 δ 0.5 cm 를 검출 불가능하게 만들지는 않는다.
- 같은 이유로 δ 는 측정 잡음에서 유도되는 값이 아니다. 남는 근거는 둘이다. (1) 단일 탐침 판독 단위(약 1 cm, 자료에서 확인)보다 작거나(0.5 cm) 같은(1.0 cm) RMSE 차이는 지도 사용자에게 실용적 차이가 없다고 본다. (2) 주 전이 지역 P0 RMSE 의 약 1–5 % 다. 두 근거 모두 관례에 가깝다. 근거 수준은 '약함(관례값)'이다.
- 셀 안 SD(11–18 cm)는 라벨 하나의 불확실성이지 방법 사이 RMSE 차이의 한계가 아니므로 δ 의 근거로 쓰지 않는다. 대신 효과 크기 해석에 쓴다(H13 −0.68 cm 는 셀 안 SD 보다 한 자릿수 작다).

### 9.4 민감도 규칙과 원고 문장

- 세 판정을 싣는다: δ 0.5 cm(주), δ 1.0 cm(보조), 상대 한계 δ_rel = 0.02 × P0 RMSE(보조). 계수 0.02 는 지금 고정한다.
- 적용 범위는 cm 단위 RMSE Δ 의 4분 판정 행이다. LGU 의 구간 점수 대비(자체 상대 한계 5 %, 보조 10 %)와 비율·순위 형식의 행에는 붙이지 않는다.
- P0 RMSE 의 정의: 그 행과 같은 풀·n·가중에서 P0 의 RMSE 점 추정이다. 지역 행은 그 지역의 셀 가중 RMSE(분할 평균)이고, 풀 행은 층화 평균 행의 P0 RMSE(지역별 P0 RMSE 의 층화 평균)다.
- 계산 위치: h39 `summarize` 가 각 표의 CI 끝값으로 다시 판정한다. 입력은 LG·LGX 조각과 표, LGD 표다. LGT·LGF 표는 선택 입력(`--lgt-dir`, `--lgf-dir`)으로 줄 때만 붙이고 CI 끝값과 P0 RMSE 열만 읽는다. LGT 행의 δ_rel 에는 '등록 시점에 결과 존재(미열람)'를 붙인다(0.3).
- 세 판정이 다르면 '한계 의존'을 붙인다. 주 판정은 δ 0.5 cm 그대로다. 원고의 '동등' 문장은 항상 한계를 명시한다('0.5 cm 안에서 같다').
- 방법 절 문장(한계를 고정한 시점과 근거를 확인한 시점을 나눠 쓴다): '동등성 한계 0.5 cm(보조 1.0 cm)는 결과 열람 전에 고정한 관례값이며 결과를 본 뒤 바꾸지 않았다. 고정한 뒤 참고로 확인한 값으로, ABoVE 탐침 값의 92 % 가 정수 cm 였다(판독 단위 약 1 cm). 두 한계는 원천 계수 물리식 RMSE 의 약 1–5 % 에 해당한다.'
- 확인하지 못한 것: CALM 판독 단위의 원문 규정, ABoVE ALT_err 의 정의, LGX-N2 하한 값.
