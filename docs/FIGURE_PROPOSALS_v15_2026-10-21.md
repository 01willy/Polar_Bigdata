# 그림 설계 제안 3차 (v15, 2026-10-21)

2차 제안(`docs/FIGURE_PROPOSALS_v14_1_2026-10-21.md`)에 대한 사용자 판정: P3_E(블록 CV 관측 대 예측 밀도), P5_D(관측 대 예측 3 × 3 행렬), P5_F(오차 분포)는 채택, 나머지는 미채택. 채택안은 v15 본문 그림에 반영하였다(Fig 3a = P3_E, Fig 5b = P5_D, Fig 5c = P5_F). 사용자가 "그래프 · 그림 · 지도 모두에 대해 유형별 새 제안" 을 다시 요청하였으므로, 조사 문서(`docs/research/2026-10-21/map_and_figure_practice.md`)의 관행 가운데 아직 쓰지 않은 세 가지를 실제 자료로 렌더하였다. 렌더 위치 `deliverables/figure_proposals/`(원본 `outputs/figures/paper/v15_proposals/`, 스크립트 `scripts/4_visualization/paper_v15/proposals_v15_1.py`). 제안 렌더는 선택용이라 글자 QA 를 강제하지 않았다.
