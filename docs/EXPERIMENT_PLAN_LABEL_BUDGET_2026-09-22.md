# 라벨 예산 프로토콜 실험 계획 (H25–H30) — 사전 등록 (2026-09-22 오후)

**목적**: 논문 흐름 "라벨 있는 지역 → 라벨이 적은 지역 → 라벨 0 지역 → 결론"을 하나의 프로토콜로 잇는다. 라벨 수 n에 따라 어느 부품(E 재적합·물리 유사라벨 증강·잔차 ML)이 언제부터 물리식을 넘는지, 어떤 라벨을 써야 하는지, 라벨 몇 개가 필요한지를 지역과 하위 지역에서 정량화한다.
**전신**: `docs/EXPERIMENT_DESIGN_H18-H24_2026-09-22.md`(§9 결과: 정보·계수·학습 목표 축 기각, 관측 설계 채택; 09-26 감사 정정: H24 채택 철회, n=3 한정 부분 지지), `docs/EXPERIMENT_PLAN_MASTER_2026-09-16.md` 개정 09-21(채점 규약), S-F 희소 라벨 곡선(`m1_sparse_label_curve.py`), H24(`h24_obs_design.py`).
**채점(불변)**: 같은 셀에서 짝지은 ΔRMSE, 분할·반복 짝지음 부트스트랩 95% CI(지역 안; 09-26 감사 정정: 이 CI 는 (분할, 반복) 행을 iid 재표집해 채점 블록 분산이 빠진 과소 추정이었다. 재실행 `h25b` 는 분할 안 채점 블록 짝지음 부트스트랩을 주 CI 로 쓴다), 지역 층화 블록 부트스트랩(지역 평균), 세 채점 병기, 가족별 Holm, 결정 규칙 A/B/C. 절대 RMSE는 항상 채점 셀 집합을 명시한다.

## 2. 공통 설계

- **자료**: `fidelity_base_v3.csv` F4_direct, 입력 x25, 앵커 Stefan. 신규 공변량은 쓰지 않는다(H19 기각).
- **대상 지역 15개(분석 14개)**: 주 4지역(레나·캐나다·러시아 W·E) + 하위 지역 11개(알래스카 k=6, 캐나다 k=3, 레나 k=2; 0.5° 블록 중심 좌표 k-means, 라벨 미사용, 이름 = 상위 지역 약자 + 북→남 번호). |A| < 6 인 CA-1 은 분석에서 제외(→ 14). 실행 후 정정: 초판의 "13개/하위 9개"는 k 합계 오기.
- **학습 원천(LORO)**: 대상 하위 지역을 뺀 나머지 전체 라벨 셀. 대상 하위 지역 경계 100 km 이내의 원천 셀은 제외(공간 누설 완화). 앵커 E는 원천에서 최소제곱. (09-26 감사 정정: 이 정의에서는 하위 지역 대상의 원천에 같은 상위 지역 셀이 버퍼 밖에서 대량으로 남는다. 알래스카 하위 지역 6개는 원천 셀의 60.7–77.3% 가 알래스카 셀이라 사실상 지역 내 전이이고(`h25b_targets.csv` frac_src_parent), H27 은 이를 지역 간 대상과 층화 없이 풀링했다. 상위 지역 셀을 원천에서 뺀 민감도는 `h25x_*`·`h27x_*` 에 있다.)
- **A/B 분할**: 대상 안 블록을 셀 수 균형 2분할, 분할 3회(seed 0–2). 풀 = A, 채점 = B(실측·CCI·토양 도일 유효 셀). 러시아 W·E는 |A|≈15라 n ≤ 10. (09-26 감사 정정: 분할 방식이 split 0(GroupKFold 2분할)과 split 1·2(블록 무작위 순열 후 셀 수 균형 탐욕)에서 다르다. AL-4·LE-2 는 split 1 이 split 0 과 같고(중복), AL-1·AL-4·AL-6 은 한 분할이 split 0 의 A/B 를 뒤집은 거울 분할이다. 블록 CI 에 쓸 수 있는 유효 분할(중복 아님·채점 블록 ≥ 2)은 AL-4 1, AL-1·AL-6·LE-2 2, 나머지 3 이다(`h25b_meta.json`). AL-1 의 A 크기는 분할에 따라 4,716/438/288 셀이고, 레나의 A 는 1,293–1,519 셀(평균 1,439)이다(`h25b_targets.csv`). 라벨 전량(allA) 행은 분할마다 n 이 달라 옛 집계 351행 중 306행이 단일 분할이었고 CI 의 97.4% 가 비었다. h25b 는 allA 의 n 을 하나(−1)로 통일해 분할 간 결합 CI 를 낸다.)
- **n 격자**: {0, 3, 5, 10, 20, 40, 80, 160, 320} 중 |A| 미만인 값. 반복: 해석적 20, CatBoost 10 × seed 3.
- **선택 규칙**: random, kmedoid(H24 채택). (09-26 감사 정정: H24 판정은 사전 등록 조건 미충족으로 B(n=3 한정 부분 지지)로 철회되었다. 이 계획은 철회 전 판정을 승계했고, 실행 후 H27 분석은 kmedoid 규칙으로 고정되었다.) 단계(누적): ① E 수축(κ=10) ② +유사라벨 증강(대상 A 풀에 E_n·√TDD 유사라벨, 라벨 셀은 실측으로 대체, r=10) ③ +잔차 CatBoost(원천 잔차 ∪ 대상 n개 잔차, λ ∈ {0.25, 0.5}, 대상 행 가중 α ∈ {1, 10, 100}).
- **지표**: 셀 가중 RMSE(주), 블록 등가중(보조), Δ 대 물리식(알래스카 E), Δ 대 라벨 전량(A 전체, 같은 단계), 회복률 = (물리식 − 방법_n)/(물리식 − 방법_전량), 손익분기 n = 회복률이 50%를 넘는 최소 n(승률 ≥ 0.75 조건 병기). (09-26 감사 정정: 라벨 전량이 물리식보다 나쁜 대상 8개(AL-2·AL-4·AL-5·AL-6·CA-3·캐나다·LE-2·러시아 E)에서 회복률 분모가 0 이하가 되어, 회복률 정의는 물리식을 실제로 넘는 n 을 미달성으로 처리했다(`h27c_targets.csv` n_rec_den_nonpos). 재계산은 분모 ≤ 0 이면 회복률 NaN 으로 두고, 손익분기 주 정의를 '블록 CI 상한 < 0·분할 승률 ≥ 2/3·반복 승률 ≥ 0.75 인 최소 n'으로 바꾸었다(`h25b_breakeven.csv` breakeven_n_ci). 회복률 정의는 보조로 병기한다. 미달성 대상의 절단 처리는 결과 열람 후 정해졌으며, 재분석은 절단 대상을 최대 순위 동률로 둔다.)

## 3. 가설(확인적, 결과 열람 전 고정)

- **H25(계단)**: 고정 프로토콜에서 수준 오차 지역(자체 E/알래스카 E ≥ 1.3)의 손익분기 n ≤ 5, 구조 오차 지역(≤ 1.1)의 손익분기 n ≥ 40. 판정: 14 대상의 손익분기 n과 E 비의 Spearman 상관 < −0.5. (09-26 감사: 실행 결과 이 등록 지표는 kmedoid·회복률·미달성 = 2·n_max 집계에서 ρ −0.33(p 0.25), 알래스카 E 1.617 기준 −0.32(p 0.27)로 미충족이다. §7 의 |log E비| 는 사후 지표다.)
- **H26(대상 라벨 가중)**: α = 10이 n ≥ 20에서 α = 1보다 낮고(짝지음 CI 0 제외, 4 주지역 중 3), n ≤ 5에서는 높거나 같다. (09-26 감사: 러시아 W·E 의 n 격자는 10 이하라 '4 주지역 중 3' 기준은 등록 시점부터 충족될 수 없었다. 판정 기준을 '주 2지역(캐나다·레나) + 하위 지역'으로 개정한다. 등록 검정(짝지음 CI)은 실행 후 계산되지 않았다.)
- **H27(필요 라벨 수 규칙)**: 손익분기 n(log)은 라벨 없이 계산한 이질성 지표(대상 공변량 분산의 원천 대비 비, DI 중앙값, 블록 수)로 leave-one-target-out R² > 0.5로 예측된다. 라벨 기반 지표(블록 E 변동계수)는 진단용으로만 병기.
- **H28(라벨 있음 레시피)**: 라벨 있음 조건에서 중첩 선택(다른 지역에서 앵커·모델·λ 선택 → 해당 지역 채점) 레시피 − Stefan ≤ −0.7(AB4, CI 0 제외). 모델 축에서 CatBoost 잔차 − 신경망 최선 잔차의 CI가 0을 포함(신경망 우위 없음). (09-26 감사: 실행 결과 첫 부분(중첩 선택 레시피 − Stefan ≤ −0.7, CI 0 제외)은 CI 가 0 을 포함해 기각이다.)
- **H29(블록 라벨 가치)**: 블록 하나의 라벨을 추가할 때 B 오차 감소량은 그 블록의 실측 표준편차와 양의 상관(캐나다·레나), k-중심이 고르는 블록의 평균 가치가 무작위보다 높다. (09-26 감사: 고유 블록 단위 재계산에서 첫 부분은 불지지(캐나다 ρ 0.29, p 0.32; 레나 −0.35, p 0.20, 반대 방향), 둘째 부분은 캐나다 불지지·레나 지지다(`h29b_summary.csv`).)
- **H30(배포 규칙)**: AOA 밖 셀에 물리식, 안에 잔차 ML을 쓰는 규칙은 직접 ML 대비 최악 지역 오차를 줄이고(4지역 최댓값), 물리식 대비 평균은 같다(CI 0 포함).

- **H25 지표 변경.** 사전 등록 판정 지표는 부호 있는 E비(자체 E/알래스카 E)와 손익분기 n 의 Spearman < −0.5 였다. 실행 후 kmedoid·회복률·미달성 = 2·n_max 집계에서 ρ −0.33(p 0.25)로 미충족이었고, 결과 열람 후 |log(자체 E/E0)| 로 지표를 바꾸었다. 변경 사유는 수준 오차가 E비 > 1(러시아 W 1.66·AL-1 1.23)과 E비 < 1(AL-3 0.74·CA-2 0.77) 양방향으로 나타나 부호 있는 E비로는 단조 관계를 기대할 수 없다는 점이다(`h27c_targets.csv` E_ratio_oracle). 사후 변경이므로 |log E비| 결과는 탐색적으로 분류한다. 옛 `h27_rule.csv` 의 `spearman_Eratio_vs_be` 열은 실제로는 |log E비| 상관이다.
