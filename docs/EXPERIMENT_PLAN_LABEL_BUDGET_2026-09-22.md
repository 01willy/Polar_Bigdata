# 라벨 예산 프로토콜 실험 계획 (H25–H30) — 사전 등록 (2026-09-22 오후)

**목적**: 논문 흐름 "라벨 있는 지역 → 라벨이 적은 지역 → 라벨 0 지역 → 결론"을 하나의 프로토콜로 잇는다. 라벨 수 n에 따라 어느 부품(E 재적합·물리 유사라벨 증강·잔차 ML)이 언제부터 물리식을 넘는지, 어떤 라벨을 써야 하는지, 라벨 몇 개가 필요한지를 지역과 하위 지역에서 정량화한다.
**전신**: `docs/EXPERIMENT_DESIGN_H18-H24_2026-09-22.md`(§9 결과: 정보·계수·학습 목표 축 기각, 관측 설계 채택), `docs/EXPERIMENT_PLAN_MASTER_2026-09-16.md` 개정 09-21(채점 규약), S-F 희소 라벨 곡선(`m1_sparse_label_curve.py`), H24(`h24_obs_design.py`).
**채점(불변)**: 같은 셀에서 짝지은 ΔRMSE, 분할·반복 짝지음 부트스트랩 95% CI(지역 안), 지역 층화 블록 부트스트랩(지역 평균), 세 채점 병기, 가족별 Holm, 결정 규칙 A/B/C. 절대 RMSE는 항상 채점 셀 집합을 명시한다.

## 2. 공통 설계

- **자료**: `fidelity_base_v3.csv` F4_direct, 입력 x25, 앵커 Stefan. 신규 공변량은 쓰지 않는다(H19 기각).
- **대상 지역 13개**: 주 4지역(레나·캐나다·러시아 W·E) + 하위 지역 9개. 하위 지역은 0.5° 블록 중심 좌표를 k-means(알래스카 k=6, 캐나다 k=3, 레나 k=2)로 묶어 만든다. 라벨 미사용. 이름은 위경도 중심으로 붙인다(예: AK-N1).
- **학습 원천(LORO)**: 대상 하위 지역을 뺀 나머지 전체 라벨 셀. 대상 하위 지역 경계 100 km 이내의 원천 셀은 제외(공간 누설 완화). 앵커 E는 원천에서 최소제곱.
- **A/B 분할**: 대상 안 블록을 셀 수 균형 2분할, 분할 3회(seed 0–2). 풀 = A, 채점 = B(실측·CCI·토양 도일 유효 셀). 러시아 W·E는 |A|≈15라 n ≤ 10.
- **n 격자**: {0, 3, 5, 10, 20, 40, 80, 160, 320} 중 |A| 미만인 값. 반복: 해석적 20, CatBoost 10 × seed 3.
- **선택 규칙**: random, kmedoid(H24 채택). 단계(누적): ① E 수축(κ=10) ② +유사라벨 증강(대상 A 풀에 E_n·√TDD 유사라벨, 라벨 셀은 실측으로 대체, r=10) ③ +잔차 CatBoost(원천 잔차 ∪ 대상 n개 잔차, λ ∈ {0.25, 0.5}, 대상 행 가중 α ∈ {1, 10, 100}).
- **지표**: 셀 가중 RMSE(주), 블록 등가중(보조), Δ 대 물리식(알래스카 E), Δ 대 라벨 전량(A 전체, 같은 단계), 회복률 = (물리식 − 방법_n)/(물리식 − 방법_전량), 손익분기 n = 회복률이 50%를 넘는 최소 n(승률 ≥ 0.75 조건 병기).

## 3. 가설(확인적, 결과 열람 전 고정)

- **H25(계단)**: 고정 프로토콜에서 수준 오차 지역(자체 E/알래스카 E ≥ 1.3)의 손익분기 n ≤ 5, 구조 오차 지역(≤ 1.1)의 손익분기 n ≥ 40. 판정: 13 대상의 손익분기 n과 E 비의 Spearman 상관 < −0.5.
- **H26(대상 라벨 가중)**: α = 10이 n ≥ 20에서 α = 1보다 낮고(짝지음 CI 0 제외, 4 주지역 중 3), n ≤ 5에서는 높거나 같다.
- **H27(필요 라벨 수 규칙)**: 손익분기 n(log)은 라벨 없이 계산한 이질성 지표(대상 공변량 분산의 원천 대비 비, DI 중앙값, 블록 수)로 leave-one-target-out R² > 0.5로 예측된다. 라벨 기반 지표(블록 E 변동계수)는 진단용으로만 병기.
- **H28(라벨 있음 레시피)**: 라벨 있음 조건에서 중첩 선택(다른 지역에서 앵커·모델·λ 선택 → 해당 지역 채점) 레시피 − Stefan ≤ −0.7(AB4, CI 0 제외). 모델 축에서 CatBoost 잔차 − 신경망 최선 잔차의 CI가 0을 포함(신경망 우위 없음).
- **H29(블록 라벨 가치)**: 블록 하나의 라벨을 추가할 때 B 오차 감소량은 그 블록의 실측 표준편차와 양의 상관(캐나다·레나), k-중심이 고르는 블록의 평균 가치가 무작위보다 높다.
- **H30(배포 규칙)**: AOA 밖 셀에 물리식, 안에 잔차 ML을 쓰는 규칙은 직접 ML 대비 최악 지역 오차를 줄이고(4지역 최댓값), 물리식 대비 평균은 같다(CI 0 포함).
