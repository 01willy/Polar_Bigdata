## 3. 단계 설계

### S-A. 데이터 정비 (1일, CPU)
09-15 계획 §4 그대로: Svalbard 매크로 분리, CALM 관측법 태그(지온 유도 68셀 등급 분리), TDD_stl1=0 결측, 분석 스크립트 CI 게이트·집계 열, GTN-P ALT 106 데이터셋 중복 제거 후 편입 검토, 외부 ALT 제품 취득 시도. 산출 `fidelity_base_v3.csv`(기존 행 불변 검증).

### S-B. 재현 게이트 (반나일, CPU + GPU 1)
새 하네스로 기존 표의 대표 수치를 같은 조건에서 다시 산출하고 허용 오차 0.1 cm로 대조한다. 대상: tab:models(MLP 14.37·CatBoost 15.61), tab:physics(Stefan 14.56/22.24), tab:aug(16.5/31.8·18.2/42.0), tab:transfer(13.33·21.26·35.45·21.83), tab:s12(24.11/23.27·22.91/21.68), S11 커버리지 93.4%. **하나라도 재현 실패면 원인 규명 전 다음 단계 금지.** 09-15 계획 V1–V4(선택 효과 판정)도 이 단계에서 수행.

### S-C. 주효과 스크린 (1일, GPU 4장)
기본값(★) 레시피에서 한 축씩만 바꾼다. 축 수준 합 약 26 × 조건 3 × 지역 6 × seed 3 ≈ 1,400 적합 + 알래스카 6-fold ≈ 470 적합. E1(1,188 적합, 37분×4 GPU) 기준 약 1.5시간. 산출: 축별 주효과 표(조건별·지역별, 셀 가중·비가중·중앙값).

### S-D. 상호작용 (1~2일, GPU 4장)
모델 축 G는 S-C 주효과에서 모델 13종을 모두 돌린 뒤(직접 예측·잔차 두 모드), 상위 3종을 S-D로 올린다. 생성 모델 3종(확산·플로 매칭·정규화 플로)은 정확도와 함께 구간 점수(interval score)·커버리지도 기록해 S11 CQR 대비 UQ 이득을 판정한다(H15). S-C에서 축별 상위 2수준(모델은 3수준)을 취해 2^4·3 = 48 조합 × 조건 3 × 지역 6 × seed 3 ≈ 1,700 적합. 여기에 09-15 T0(물리 계수 지도)·T0b(수준·구조 분리)·T2(게이팅)·T3(공변량 이동 대응 DL)을 K·G 축의 수준으로 편입한다. 학습 지역 집합 축(D)은 정보 없음 조건에서만 3수준 교차.

### S-E. 중첩 선택과 확인적 검정 (반나일, CPU)
S-C·S-D 데이터베이스에서 (1) 조건별 최적 레시피를 중첩 선택으로 뽑고(5지역 선택→1지역 채점, 6회), (2) 사전 등록 가설을 채점한다. 기존 H1–H6(09-08), H7–H11(09-15)에 다음을 추가.
- **H12**: 공변량만 조건에서 "앵커+증강+잔차" 중첩 선택 레시피가 Stefan+CCI 앵커 단독보다 낮다(주 6지역 부호검정 + 짝지은 CI). ← 사용자 질문 1의 직접 검정.
- **H13**: 라벨 있음 조건에서 잔차 결합이 앵커 단독보다 낮다(모든 대상 지역).
- **H14**: 학습 지역 집합을 넓혀도(D 축) 정보 없음 전이가 개선되지 않는다(P1 결론 재검).
- **H15**: 생성 모델(확산·플로 매칭·정규화 플로) 잔차의 90% 구간 interval score가 CQR(68.9)보다 낮다(UQ 이득). 점예측 정확도는 탐색적으로만 보고.

### S-F. 희소 라벨 곡선 (반나일)
09-15 §3 F1–F3.

## 4. 결정 규칙 (결과 확인 전 고정)

- **A**: H12(또는 H7–H11 중 하나)가 공변량만 조건 주 6지역에서 유의(부호검정 p<0.05 또는 CI 0 제외 지역 ≥4). 두 번째 의의 = "대상 지도 자료로 적응하는 물리 유도 ML이 새 지역에서 물리식과 위성 제품 결합을 넘는다".
- **B**: 방향 일관(≥5/6) 비유의. 두 번째 의의 = "결합 앵커 + 증강 ML 파이프라인이 새 지역에서 물리식 이하 오차를 붕괴 없이 유지하며 고해상 구조·다중 자료·보정 예측구간을 제공한다". F1 곡선을 마지막에 배치.
- **C**: 방향 불일치. 두 번째 의의 = "희소 라벨 지역에서의 전이·학습".
- S-B 재현 게이트 결과와 V1–V3 판정은 어느 경우에도 원고에 보고.
