# v5 보강 실험 결과 (2026-10-12)

사용자 질문(10-12) 1–3 에 대한 추가 실험. 근거 표는 `data/processed/v5/runs/<tag>/`, 그림 `outputs/figures/paper/v5/Fig8_yearwise.*`, `Fig9_supplementary.*`. 블록 부트스트랩 95 % CI, ΔRMSE 는 음수가 첫째가 낫다는 뜻.

## 1. 질문 1: '지형·토양' 문구의 뜻

지형 6종(Copernicus DEM 30 m)과 토양 9종(SoilGrids 250 m)은 처음부터 주 공변량 집합(F8TS)에 들어 있다. '기후 입력만으로는 이득이 없고 지형·토양이 있어야 생긴다' 는 자료가 없다는 뜻이 아니라, 공변량 집합을 기후 8 → +지형 → +토양 → +MODIS → +SAR 순으로 늘려 가며 잔차 결합(R1)의 이득을 측정한 결과다(블록 CV, R1 − P1, cm). 알래스카 +3.6 → +1.7 → −0.4 → −0.7 → −0.5, 레나 −2.4 → −3.8 → −3.0 → −3.1, 캐나다 +6.1 → −1.1 → −1.7 → −2.1. AppEEARS 자료(MODIS NDVI·EVI·적설)는 '+MODIS' 단에 들어 있고 0.3–0.4 cm 를 더한다. 이번에 더한 입력: NCSCD 토양 유기탄소·젤리솔 비율(0.012°), CAVM 식생 단위(1 km), WorldCover 2021 피복 비율 7종(셀 ±500 m) → 집합 F8TS_X·F8TS_ALL(결과 3절). MODIS 는 2010–2024 전 기간을 다시 요청했다(AppEEARS 6건 접수, 결과 대기).

### 2.3 '동급' 일 때 주장할 수 있는 것
(1) 제품은 학습 지점과 겹치는 셀에서 채점됐고 우리는 공간 블록 밖 예측(OOF)으로 채점됐다. 같은 조건에서 동급이면 실제로는 우리가 낫다. (2) 우리는 연도를 명시한 예측이고 제품은 연도 정합 추출 뒤에도 연간 변화 상관이 더 낮다(Fig 8b: Alaska Δ 상관 R1 0.27 대 Wei 0.15·Liu 0.12). (3) 편향 0 에 가깝다(R1 알래스카 −2.6, 레나 +0.2, 캐나다 −0.6 대 Wei +2.8·+20.9·+12.9, Liu +5.7·+16.6·+16.3). (4) 불확실성 구간·적용 가능 영역·학습 자료 공개가 있다.

## 3. 질문 3: 연도별 평가

### 3.1 연도별로 검증했는가
예. 연도 홀드아웃(V-Y)과 블록×연도(V-BY)가 사다리에 있고, 추가로 (a) 연도별 RMSE·편향(블록 CV OOF, 연도 홀드아웃, 제품), (b) 2개 연도 이상 관측된 셀(알래스카 636·레나 136·캐나다 235)에서 연속 관측 연도 쌍의 Δobs 대 Δpred, (c) 연도 편향 대 그 해 TDD 편차의 관계를 계산했다(`runs/core_cb/yearwise/`).

### 3.2 결과
- 연도 간 변화(다년 셀): Δpred–Δobs 상관은 알래스카 R1 0.27·P1 0.23·D0 0.26, Wei 0.15, Liu 0.12, CCI v5 0.16. 레나 R1 0.25, Liu 0.42(n 99). 캐나다 0.06 안팎. 관측된 연도 간 변화 자체가 TDD 변화와 약하게만 상관한다(알래스카 0.22, 레나 0.12, 캐나다 0.06). 즉 라벨의 연간 변동 대부분은 강제력으로 설명되지 않는 지점 요인(수분·적설·미세지형·측정)이다.
- 연도 편향의 원인(Fig 8a·c): 알래스카 2020·2021 편향 −16 cm 는 페어뱅크스 근처(Creamers Field·Farmers Loop·Permafrost Tunnel) 깊은 활동층 지점을 9–10월 탐침으로 잰 자료이고, 같은 위치의 2014 GPR 8월 값(69–79 cm)보다 85 cm 로 깊다. 같은 셀·같은 해의 8월 대 9월 쌍(19셀)에서 9월이 10 cm 깊고 GPR 대 탐침(586셀)은 차이가 없다(−1.6 cm). 따라서 연도 편향에는 관측 월과 장소 구성이 섞여 있다. 레나 2020(−27 cm)은 'channel' 캠페인(114행, 평균 88 cm)이라는 다른 지형 단위, 캐나다 2023–2024(−40 cm)는 Scotty Creek 화재 교란·비교란 지점(ALT 110 cm)이다. 제품도 같은 해에 같은 방향으로 크게 벗어난다(Wei·Liu 2020 −23~−30).
- 연도 편향 대 TDD 편차: 알래스카 P1 기울기 +2.4 cm/100 °C·d(r 0.43). 더운 해에 과대 예측하는 경향이 있으나 연도 수 13 으로 약하다. 레나·캐나다는 반대 부호이고 장소 구성 효과가 섞여 해석하지 않는다.

### 3.3 불균형에 대한 수정 시도
- 관측 월 정합(TDD 를 관측 월 말까지의 누적값으로, `runs/forcing_obs`): 전체 오차는 거의 같다(블록 CV, 관측 월 정합 − 연도 정합: 알래스카 P1 −0.17 [−0.66, +0.18], Ku −0.20, R1 −0.01; 레나 P1 +0.23; 캐나다 D0 −3.14 [−7.50, +0.17], R1 −1.41). 그러나 늦가을 관측 연도의 편향이 줄고(알래스카 2020·2021 P1 −13.4/−10.8 → −9.0/−6.2 cm, R1 −15.9/−15.7 → −12.6/−12.0), 연도 편향 SD 가 알래스카 6.8 → 6.2(R1)·캐나다 22.8 → 19.0 으로 줄며, 레나 다년 셀의 Δ 상관이 P1 0.12 → 0.20 으로 오른다. 물리적으로 더 옳은 정의이므로 최종 설계의 기본 강제력으로 채택할 것을 권한다(핵심 실험·지도 재실행 약 1시간).
- 연도 역빈도 가중(2014 지배 완화): 효과 없음. R1 블록 CV 알래스카 +0.3 [−0.4, +0.8], 연도별 편향 SD 6.8 → 7.0. 기각.
- 전년 강제력(지연) 특징·고해상 입력·MODIS+SAR(`runs/featsets2`, `runs/featsets3`, 블록 CV R1 − P1): 알래스카 F8TS −0.4 → +전년 −0.4, +MODIS −0.7, +고해상 −0.9 [−2.0, +0.3], +전부 −0.8, +MODIS·SAR −0.6. 캐나다 −1.7 → −1.6, −2.1, −2.2 [−3.4, −1.0], −2.2, −2.1. 레나 −3.0 → −3.1, −3.1, −3.5, −3.5, −3.1. 입력을 더해도 이득은 0.3–0.5 cm 안에서만 커지고 알래스카의 CI 는 계속 0 을 포함한다. 고해상 입력(NCSCD 토양탄소·CAVM 식생 단위·WorldCover 피복 비율)이 가장 큰 추가 이득이다.
- 결론: 연도별 편향은 모델이 아니라 캠페인 구성(장소·월)에서 오므로, 논문에는 (i) 다년 셀의 짝지은 변화 지표를 연간 재현력의 기준으로, (ii) 연도별 편향 표에 캠페인 구성을 함께 적는다.

## 4. 그 밖의 보강
- 확인적 재실행(분할 씨앗 1): 블록 CV 의 모든 Δ(방법 − P1)가 0.2 cm 안에서 재현(캐나다 R1 −1.5 [−3.1, +0.0]). 판정은 분할에 의존하지 않는다.
- 물리식 보강: 토양형 Stefan(Ed)은 알래스카·레나에서 나쁘고 캐나다에서 좋다(26.7 대 P1 29.7). 물리 앙상블(PE, 비음수 가중)은 캐나다 −2.2 cm, 다른 지역 ±0.
- λ 교차검증 선택(R1cv, 학습 겹 안 블록 3겹): 고정 λ 0.5 보다 낫지 않다(블록 CV, 대 P1: 알래스카 +0.0 [−0.6, +0.8], 레나 −3.7 [−8.1, +0.3], 캐나다 −1.6 [−3.1, −0.1]). 고른 λ 는 겹마다 0.25–1.0 으로 흔들린다. 고정 λ 0.5 유지.
- 블록 크기 민감도(R1 − P1, 블록 CV; 0.25°·0.5°·1.0°, 블록 수 알래스카 101·73·57, 레나 24·16·11, 캐나다 33·26·17): 레나 −1.2 [−2.2, −0.4]·−3.0 [−6.1, −0.6]·−1.1 [−3.2, −0.5] 로 모든 크기에서 지지. 알래스카 −1.3 [−2.6, +0.0]·−0.4·−0.5 로 미결정(0.25° 에서 경계). 캐나다 −1.7·−1.7·+0.8 [−1.4, +6.0] 으로 1° 에서 뒤집힌다(블록 17개). 캐나다 판정은 블록 수에 민감하다고 적는다.
- 알래스카 2014 제외 진단(연도 정합 − 기후값, 블록 CV): P1 +0.8 [−0.2, +1.8](전체 자료 +1.4), P0 −0.2, R1 −0.0. 2014 집중 관측은 악화의 절반쯤을 설명하고 나머지는 남는다. 2014 를 빼면 알래스카 RMSE 자체가 21.4 cm 로 커진다(남는 라벨이 더 이질적).
- 물리 앙상블(PE)·토양형 Stefan(Ed): 알래스카에서 PE 가중은 Stefan 100 % 로 수렴(Δ 0), Ed 는 +2.5 [+0.7, +3.8] 악화. 캐나다 PE −2.3 [−4.6, +3.1], Ed −3.1 [−5.2, +3.6](미결정). 레나 ±0.4.
- 신경망 + MODIS 집합(`runs/nn2`, 블록 CV, 대 P1, `deltas_vs_P1_manual.csv`): 알래스카 R1 FT-T −0.5 [−2.2, +1.4], MLP·TabM +1.0(변화 없음). 캐나다 D0 FT-T −5.1 [−6.4, −1.2], R1 FT-T −3.9 [−5.9, −1.4], MLP·TabM −3.1~−4.7(CatBoost R1 −1.7 보다 2–3 cm 더 낮음). 레나 R1 −1.8~−2.7(CatBoost −3.0 과 동급). 관측 월 정합으로 바꿔도 신경망 결과는 ±0.5 cm 안. 결론: 학습기 선택은 캐나다에서만 중요하고 알래스카의 '차이 없음' 은 어떤 학습기·입력으로도 바뀌지 않는다.
- 하지 않은 것: FireALT·CALM PANGAEA 확충 라벨(481셀)은 공변량 추출 파이프라인이 별도라 이번에 넣지 않았다. 교란(화재) 축 분석은 다음 과제다. MODIS 2010–2024 재요청 6건은 AppEEARS 처리 중이다.
