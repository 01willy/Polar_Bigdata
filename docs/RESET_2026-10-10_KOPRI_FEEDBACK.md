# 연구 재설정 (2026-10-10): 극지연 피드백 반영

작성 2026-10-10 09:40 KST. 정본. 10-01 연구 주제(라벨 수별 워크플로, `docs/RESEARCH_OVERVIEW_2026-10-02.md`)와 현행 원고 제목·초록(`paper/manuscript/en/sections/front.tex`)은 이 문서로 대체된다. 수치는 모두 저장된 표에서 읽었고 경로를 함께 적었다.

## 1. 피드백 원문(2026-10-10 사용자 전달, 극지연 회의 10-08)

1. 입력이 연도별로 너무 섞여 있어 올바르게 측정된 것인지 알기 어렵다. 입력의 연도가 명확하지 않고, 어떤 것은 평균을 내서 쓰고 어떤 것은 단일 연도 값을 쓴 것 아닌가. TDD 는 어느 해 값이고 ALT 참값 라벨은 어느 해 값인가. 그것들이 섞여서 들어간 것 아닌가. 극지 연구에서 연도(시간축)는 매우 중요하며 리뷰에서 반드시 지적된다.
2. 출력도 마찬가지다. 현재 ALT 예측 지도는 몇 년 몇 월의 값을 예측한 것인지 없다. ALT 는 특정 지역에 고정된 값이 아니므로 지금 지도는 의미가 없어 보인다. 전체적으로 수정이 필요하다.
3. 가장 큰 문제로, '희소 라벨' 에 너무 초점을 맞췄다. 라벨 0–100개 같은 극소 라벨과 그런 지역에 대한 연구는 근거가 부족하고 워크플로의 설득력이 낮다. 물리 증강과 물리 잔차가 다른 물리 제품이나 선행 연구에 비해 어떤 조건에서 얼마나 나은지 비교 분석하는 편이 낫다. 알래스카처럼 라벨이 많은 지역에 집중하고 라벨이 너무 적은 지역은 제외한, 전문성 높은 논문이 좋다.

사용자 방향: 연구 의의와 목적을 간결하게 하고, 시간축을 명확히 고려하며, 극소 라벨 지역 대신 보유한 여러 방법의 비교 분석과 결과 분석 논문으로 간다. 메일로 요청했던 데이터의 활용도 고려한다.

### 2.4 판정

- 피드백 1 은 사실이다. 강제력은 2015–2020 고정 기후값이고 라벨은 셀별로 다른 해의 값이며, 알래스카에서는 블록과 연도가 교락돼 있다. 연도 정합은 결과를 1–2 cm 바꾸고 방향이 지역마다 다르다. '결론을 바꾸지 않는다' 는 내부 판단은 민감도 수준의 주장이며, 논문의 입력 정의로는 쓸 수 없다.
- 피드백 2 는 사실이다. 지도는 2015–2020 평균 강제력을 2014년 중심 라벨로 학습한 모델에 넣은 결과이고, 어느 해의 ALT 인지 정의하지 않았다. S14 결과대로 어떤 방법도 연간 편차를 재현하지 못하므로, 연도를 명시한 지도는 '연도 Y 의 강제력에 대한 모델 응답' 이며 연간 변동 재현 능력은 따로 보고해야 한다.
- 피드백 3 에 대해 현재 자료의 라벨 수는 알래스카 13,606셀(74블록), 레나 3,037셀(20블록), 캐나다 827셀(36블록)이고 나머지 지역은 200셀 미만이다. 주 분석을 세 지역으로 한정하면 셀-연도 단위 라벨을 만들 수 있는 원자료(ABoVE 지점-연도 22만 행, ALLENA, CALM)가 모두 있다.

## 4. 새 연구 틀

### 4.1 목적(한 문단)

라벨이 많은 세 영구동토 지역(알래스카, 레나 델타, 캐나다 북서부)에서 셀·연도 단위 활동층 두께(ALT) 관측과 같은 해의 ERA5-Land 강제력을 짝지은 시험지를 만들고, 물리식(Stefan, Kudryavtsev), 직접 기계학습, 물리 증강, 물리 잔차 결합, 적층과 기존 공개 ALT 제품 여섯 종을 같은 셀·같은 해·같은 검증 설계에서 비교한다. 어떤 검증 설계, 어떤 기후 레짐, 어떤 공변량 집합에서 물리 기반 ML 이 물리식과 기존 제품보다 얼마나 나은지, 그 이득이 어디서 오는지를 정량화하고, 연도를 명시한 1 km ALT 지도를 산출한다.

### 4.2 연구 질문

- Q1 시간 정합. 연도 정합 강제력은 고정 기후값 강제력에 비해 물리식과 ML 의 오차·편향을 얼마나 바꾸는가. 어느 방법이 연간 편차를 재현하는가.
- Q2 방법 비교. 같은 시험지에서 물리식, 직접 ML, 물리 증강, 물리 잔차, 물리 입력, 적층의 오차는 검증 설계(블록·지역·연도 홀드아웃)에 따라 어떻게 다른가.
- Q3 조건. 물리 잔차 결합의 이득은 기후 레짐(TDD 구간), 지역, 공변량 집합(기후·토양·식생·적설·SAR), 격자 단위·격자 안에서 어떻게 달라지는가.
- Q4 제품 비교. 같은 셀·같은 해에서 CCI v4·v5, Wei 2026, Yi·Kimball 2019, Aalto 2018, Li 2022 대비 우리 방법의 오차·편향·상관은 어떤가.

### 4.3 범위

- 주 지역: 알래스카, 레나 델타, 캐나다 북서부(ABoVE + CALM). 셀 500개·블록 20개 이상을 기준으로 한다. 캐나다는 827셀·36블록으로 기준을 넘으나 단일 연도 비율이 낮고 연도 분산이 커서 결과 표에 따로 표시한다.
- 제외: 러시아 W·C·E, 그린란드, 북대서양, 티베트, 몽골, 알프스, 스발바르, 스칸디나비아. 부록에서도 쓰지 않는다. 단, 러시아 W 야말 라벨(1976–1987)은 2010–2024 강제력 범위 밖이라 어떤 분석에도 쓰지 않는다.
- 시간 범위: 강제력 2010–2024(ERA5-Land 월별, `nh_monthly_2010-2024.nc`). 라벨은 2010–2024 관측만 쓴다(알래스카 ABoVE 2005·2007 관측 681행 제외, 레나 1998–2008 셀 제외, CALM 의 2010 이전 연도 제외).

### 4.4 목표 변수와 입력의 시간 정의(확정안)

- 목표 변수: ALT(c, y) = 셀 c, 연도 y 의 계절 말 최대 융해 깊이. 같은 셀·같은 해의 관측을 평균한다(8–9월 관측, 관측 월을 열로 기록). 셀은 ERA5-Land 격자 안의 라벨 위치(현행 loc_id)다.
- 강제력(연별 8종): 연도 y 의 TDD(월평균 0 °C 초과 달의 도일 합), √TDD, 가장 따뜻한 달 기온, 연평균 기온(y 의 1–12월), FDD 와 가장 추운 달 기온(전겨울 y−1 년 9월–y 년 5월), 토양 0–7 cm 온도(y 의 융해 계절), 적설 수당량(전겨울 최대). 같은 정의로 2010–2024 기후값(15년 평균)도 만든다.
- 정적 입력: 지형 6, 토양 9. SAR 8 은 알래스카 2017년 값이므로 '2017 정적' 으로 표시하고 공변량 집합 축에서만 쓴다.
- 식생·적설 고해상 입력(AppEEARS 완료분): MOD13Q1 NDVI·EVI(250 m, 2015–2020 여름), MOD10A1·A2 적설(500 m, 2014-09–2021-08). 연도가 있는 자료이므로 연별 값과 다년 평균을 둘 다 만든다. 2015–2020 밖의 라벨 연도에는 다년 평균만 쓴다(표시 열).
- 제품: CCI v4(1997–2021 연별), CCI v5(1997–2023 연별), Wei 2026 v2(2000–2024 연별), Yi·Kimball ds1760(2001–2015 연별, 알래스카), Aalto 2018(2000–2014 대표값), Li 2022(2000–2018 대표값). 연별 제품은 라벨 연도의 값을, 대표값 제품은 그대로 쓰고 정합 표지를 둔다. Liu 2024(2003–2020 연별, Zenodo 공개 1.86 GB)는 내려받아 추가한다.

### 4.5 비교 방법(기호 유지)

| 기호 | 방법 | 라벨 사용 |
|---|---|---|
| P0 | 원천 계수 Stefan(E 고정) | 없음 |
| P1 | 재보정 Stefan(E 를 학습 블록에서 최소제곱) | 학습 폴드 |
| Ku | Kudryavtsev(토양·적설·식생 입력) | 학습 폴드(척도) |
| D0 | 직접 ML(CatBoost, 랜덤 포레스트, MLP·TabM, FT-Transformer) | 학습 폴드 |
| F1 | 물리 출력을 ML 입력으로 | 학습 폴드 |
| D1 | 물리 유사라벨 증강 | 학습 폴드 |
| R1 | 물리 앵커 + 잔차 ML(λ 0.25·0.5·0.75·1) | 학습 폴드 |
| S | 여러 물리식·제품의 라벨 가중 적층 | 학습 폴드 |
| Cr 등 | 기존 제품 원값(비교 대상, 학습 없음) | 없음 |

### 4.6 검증 사다리(시험지)

| 단 | 분할 | 답하는 질문 |
|---|---|---|
| V-R | 무작위 셀-연도 분할 | 선행 연구 보고 방식의 상한(참고) |
| V-B | 0.5° 블록 5겹(같은 블록은 같은 폴드, 연도 무관) | 지역 안 공간 일반화 |
| V-Y | 연도 홀드아웃(같은 셀의 다른 해는 학습에 포함) | 연간 변동 재현 |
| V-BY | 블록·연도 동시 홀드아웃 | 새 장소·새 해 |
| V-L | 지역 홀드아웃(3지역, 100 km 완충) | 새 지역(참고, 보조) |

지표는 RMSE, 편향, r, 연간 편차 상관(지점 평균 제거), 블록 등가중 RMSE, 블록 부트스트랩 95 % CI. 비교는 같은 셀·같은 해·같은 폴드의 짝지은 차이로 한다.
