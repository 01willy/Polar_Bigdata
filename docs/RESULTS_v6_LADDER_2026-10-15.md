## 3. 판정(요약)

- 라벨이 적을 때(25–100) 물리 + 잔차 결합이 세 지역 모두에서 물리식과 같거나 낫고, 직접 학습은 알래스카·캐나다에서 물리식보다 나쁘다. 이득의 크기는 알래스카에서는 n 이 적을수록 크고(n 25 −0.9 [−1.9, +0.1], 전량 −0.2 [−0.6, +0.1]), 레나·캐나다에서는 n 이 많을수록 크다(레나 n 25 −0.8 [−2.2, −0.1], 전량 −3.6 [−8.5, −0.9]).
- 물리 유사라벨 증강은 모든 n 에서 재보정 Stefan 과 거의 같다(차이 0 안팎): 유사라벨이 학습기를 물리식으로 끌어당긴다. 직접 학습이 물리식보다 나쁜 조건(알래스카·캐나다, n ≤ 250)에서는 직접 학습보다 낫고(알래스카 n 25 −3.0 cm), 직접 학습이 물리식을 넘는 레나에서는 손해다.
- 새 지역 전이: 대상 라벨 0 에서 직접 학습은 레나 델타에서 무너지고(39.5 cm 대 원천 Stefan 21.5), 25–50개만 더해도 21.3–20.4 cm 로 회복한다. 잔차 결합(원천+n)은 알래스카에서 모든 n 에서 가장 낫고(17.8–17.5 cm), 레나에서는 n ≥ 25 에서 물리식을 넘는다. 캐나다는 원천 직접 학습(24.2 cm)이 가장 낫고 대상 라벨로 E 를 재보정하면 오히려 나빠진다(단일 계수가 맞지 않는 지역).
- 해석: 물리 앵커는 라벨 0–수십 개 구간의 안전장치이고, 잔차 학습의 이득은 라벨이 쌓이면 지역에 따라 커지거나(레나·캐나다) 사라진다(알래스카). 워크플로 권고: 라벨 0 → 원천 Stefan(+원천 잔차), 25–250 → 재보정 Stefan + 잔차, 그 이상 → 지역별로 직접 학습과 비교해 선택.
