# 원고 재구성안 (2026-10-02, 초안)

**성격**: 사용자가 2026-10-01 에 정한 연구 주제(메모리 `research-main-framing`)에 맞춰 원고의 결과 순서와 그림 배치를 바꾸는 안이다. 수치는 `docs/RESEARCH_CLAIMS_WORKFLOW_2026-10-01.md` 의 C1–C7 과 그 원천 판정 절에서만 가져온다. C8 은 WF9·WF10 판정(WF 계획서 5.3)으로 채웠다. 그림 배치의 확정은 사용자 결정 사항이다(8절).

## 1. 바꾸는 이유

현행 초안(`MANUSCRIPT_DRAFT_*_2026-09-30.md`)은 LG 실험의 가설 순서(라벨 곡선, 물리 정보, 최소 라벨, 배치, 라벨 0, 학습기, 배포)를 따른다. 사용자 지정 주제는 다음 두 가지다.
1. 물리 증강과 물리 잔차를 쓰는 ML 이 라벨 수에 따라 희소 라벨 지역과 충분 라벨 지역에서 어떤 능력을 보이는가.
2. 새 지역에서 학습·평가·추가 관측을 어떤 순서로 해야 하는가(워크플로).

무작위 분할의 과대평가는 보조 근거다. 현행 초안에는 WF 실험(지역 내 충분 라벨, 관측 위치 전략, 방법 선택 규칙, 편향 진단)이 들어 있지 않다.

## 2. 제목 후보

1. How many labels does physics-guided machine learning need? Active-layer thickness in new permafrost regions
2. Physics-augmented and physics-residual machine learning for active-layer thickness across label budgets and regions
3. A label-budget workflow for physics-guided active-layer thickness prediction in new permafrost regions

## 3. 서론 흐름(4 문단)

1. 새 지역의 ALT 예측 문제: 관측이 적고 지역마다 Stefan 계수 E 가 다르다(Fig 1b).
2. 기존 연구의 평가 조건: 지역 안 또는 무작위 교차검증, 라벨 조건 하나, 물리 기준선이 없거나 고정 계수 하나. 지역 밖에서 순수 ML 이 Stefan 보다 나빴다는 보고(Gautam 2025, 시험 R² 0.24 대 0.54).
3. 질문: 라벨 수 0–수천에서 물리 증강·잔차 ML 이 재보정 물리식에 대해 무엇을 더하는가, 그 이득은 어디서 오는가, 다음 관측은 어디에 두는가.
4. 이 연구의 설계와 기여: 같은 시험지(지역 홀드아웃 + 100 km 버퍼, 라벨 수 격자, 지역 내 블록 홀드아웃), 사전 등록, 음성 결과 포함, 워크플로.
