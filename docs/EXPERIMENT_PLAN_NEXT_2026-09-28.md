## P1. 대상 라벨 가중 α 잔차 실험(A2 확장, 확인적)

**배경**: F1(구조 지역에서 잔차 ML 이 대상에 적응하려면 수백 개 필요)은 A2 에서 대상 라벨 가중 α = 1 로만 검정되었다. 원천 약 1.6만 행에 대상 320행을 더해도 대상 비중은 2 % 다. 옛 H25(E 수축 앵커, 행 CI)에서 α = 100 은 AL-2 n=80 +0.84 → −0.30, AL-4 n=40 +0.35 → −0.30, LE-1 n=160 +0.03 → −0.84 로 부호를 바꿨고, CA-2·AL-5 는 악화했다. H26 은 감사에서 '불확정'으로 정정되었다.

**설계**(`scripts/3_deep_learning/h31_min_labels_residual.py` 골격 재사용, 새 인자 `--alphas`, `--finetune`):
- 고정: E 처리 = E0 고정(주), κ=10 수축(보조, H26 확정용). 배치 = all_blocks 와 셀 무작위(random) 둘 다(레나에서 all_blocks 가 E 를 1.87 로 편향시킨 문제 때문에 셀 무작위를 주 추출로 둔다). λ = 0.25(0.5 는 같은 적합에서 사후 적용). 대상 14 + Alaska_f0. 분할 3 × 추출 10 × seed 2, A2 와 같은 A/B 분할·추출 인덱스(α = 1 행과 짝지음).
- 요인 α ∈ {1, 10, 100} (CatBoost sample_weight). 추가 1수준 '이어 학습': 원천 잔차 모델을 init_model 로 두고 대상 행만으로 50–200 트리를 더 학습. n ∈ {0, 3, 10, 20, 40, 80, 160, 320} 중 |A| 미만.
- 배포 가능한 확인적 수준: A 블록 내부 leave-one-block-out CV 로 α 를 고르는 중첩 선택(B 블록 미사용). 격자 전체 곡선은 탐색으로 보고.
- 저비용 점검: 위약 대조(대상 라벨을 셔플한 α = 100)로 '가중이 라벨 정보를 쓰는가'를 확인.
- 산출 `data/processed/h4/a3_runs.csv`, `a3_curve.csv`, `a3_minn.csv`, `a3_blocksse.npz`, `a3_meta.json`.

**가설(결과 열람 전 고정)**:
- G1: 채점 블록 ≥ 8 인 구조 대상(레나·캐나다·AL-2·AL-5) 가운데 중첩 선택 α 가 n* ≤ 40 을 만드는 대상이 2개 이상이면 F1 문구를 '대상 가중 없이는'으로 한정하고 잔차 적응 조건을 '가중 또는 이어 학습'으로 바꾼다. 1개 이하이면 F1 을 '가중을 100배까지 올려도'로 강화한다.
- G2: 수준 대상(러시아 W·AL-1·AL-3·CA-2)에서 중첩 선택 α 가 α = 1 대비 악화(블록 CI 하한 > 0)하는 대상이 2개 이상이면 '가중은 지역에 따라 해가 된다'를 결과에 적는다.
- G3(H26 확정): κ 수축 앵커에서 α = 10 − α = 1 의 짝지음 Δ(n ≥ 20, 캐나다·레나 + 하위 지역)를 블록 CI 로 보고한다.
- 위약이 α = 100 실제 라벨과 같은 이득을 내면 결과를 무효로 한다(구현 점검).

**원고 반영**: Fig. 4 에 α 곡선 1종(중첩 선택) 추가 또는 Fig. 4e n* 열 갱신, Fig. 7a 하단 잎 문구, Table 1 A2 열 각주, Table S5. 결과가 어느 쪽이어도 원고 구조는 유지된다.

## P3. 배포 시나리오 시뮬레이션(라벨 0 → 3–40개 → 판정)

**배경(사용자 요구)**: 라벨 0 지역에서 (i) 보정된 구간과 (ii) '어느 지역군이 소수 라벨로 빨리 물리식을 넘는가'를 제시하고, (iii) 3–40개를 어떻게 모을지 권고한 뒤, (iv) 그 시나리오가 실제로 물리식을 넘는지를 대상 지역에서 검증한다.

**이미 확인된 사실(2026-09-28 재계산)**:
- (i) 계층 conformal 90 % 구간은 라벨 0 에서 산출 가능하다(보정 집합 = 다른 라벨 지역). LORO 커버리지 AB4 0.86 [0.80, 0.92], 지역별 레나 0.89·캐나다 0.89·러시아 E 0.93·러시아 W 0.75, 폭 71–96 cm.
- (ii) 라벨 없이 '수준 오차 지역'을 가려내는 지표는 아직 없다. 공변량 지표(SMD·DI·분산비)는 실패했고(H27 LOO R² −0.25), CCI 제품으로 계산한 E 비율도 오라클 E 비율과 무관하다(14 대상 Spearman 0.09, p 0.75; CCI 기준 '수준' 6개 중 실제 수준 1개). 즉 라벨 0 에서의 지역군 구분은 '위험 순위'가 아니라 '적용 영역(AOA) 밖 비율·구간 폭'만 제시할 수 있다.
- (iii)(iv) 3개 라벨 진단 분기는 항상 수축+잔차보다 낫지 않다(F4). 항상 수축(κ=10) + 원천 잔차는 14 대상 평균 −0.60, 악화 6/14(블록 CI 4), 최악 CA-3 +4.3.

**설계**(재분석 위주, `scripts/2_evaluation/h39_deploy_scenario.py`):
1. 시나리오 정의(고정): S0 라벨 0 = 물리 앵커 + 계층 conformal 90 % 구간 + AOA 마스크. S3 = 셀 무작위 라벨 3개 → κ=10 수축 E → 원천 잔차 λ 0.25. S10·S40 = 같은 절차 n=10·40. 각 단계에서 '물리식 대비 Δ 의 블록 CI 상한 < 0' 이면 '넘음', 하한 > 0 이면 '악화', 그 밖은 '동급'.
2. 순차 판정(라벨을 늘려 가며 멈추는 규칙): n 을 3 → 10 → 40 으로 늘리면서, 직전 단계에서 새 라벨로 추정한 E 의 사후 sd(오프셋 MLE)가 임계 이하이거나 잔차 순가치가 0 이하이면 멈춘다. 이 규칙은 A 블록 안에서만 계산(B 미사용)해 배포 가능성을 지킨다.
3. 결과 표: 14 대상 × 단계별 상태(넘음/동급/악화), 필요한 라벨 수, 최종 Δ 와 CI. 수준·중간·구조 분류별 요약. 알래스카 하위 지역 6개는 '지역 내 시나리오', 주 4지역 + CA/LE 하위 지역은 '지역 간 시나리오'로 나눠 보고.
4. 라벨 0 지역군 표시(가능한 범위): 대상별 AOA 밖 비율(a2_shift: 레나 0.37, 캐나다 0.53, 러시아 W 0.11, 러시아 E 0.30, 몽골 1.00, 티베트 0.86), 구간 폭, CCI 와 물리식의 불일치 비율. 이들이 실제 오차·필요 라벨 수와 무관함을 명시(음성 결과).
5. 실행이 필요한 부분: S3/S10/S40 의 셀 무작위 추출은 h25b(random) 행으로 대체 가능하므로 새 학습은 '순차 멈춤 규칙'의 A 내부 통계 계산뿐(CPU 1 h).
6. 가설: SC1 수준 대상 4개는 S3 에서 모두 '넘음'. SC2 구조 대상 8개 중 S40 까지 '넘음'은 3개 이하이고 '악화'는 2개 이하(캐나다·AL-5 는 n=0 효과로 '넘음'이 예상되므로 라벨 순가치 열을 병기). SC3 순차 멈춤 규칙이 항상-40개 대비 라벨 수를 절반 이하로 줄이면서 평균 Δ 차이 ≤ 0.3 cm.
7. 산출 `h4/p3_scenario.csv`, Fig. 7 갱신(a 절차, b 시나리오 결과 매트릭스), 절 3·결론 문단.

## P4. 희소 라벨에서 증강 + 앵커 + 잔차 결합(S4, 탐색적)

**배경(사용자 질문)**: 라벨 0 에서는 M1 이 '유사라벨 증강 + Stefan 앵커 + 잔차'를 시험했다(AB4: 캐나다 −0.10 ~ −0.37, 러시아 W −0.20 ~ −0.67, 레나 +0.02 ~ +0.15, 러시아 E +0.10 ~ +0.50, 비유의). 희소 라벨(3–40)에서는 증강 직접(S2)과 앵커+잔차(S3)를 따로만 시험했고 결합은 하지 않았다. h25b 에서 S2 − S1(증강이 E 수축 위에 더 얹는 양, random)은 AL-4 −0.4 ~ −0.6, 캐나다 −0.1 ~ −2.1, CA-2 −1.2(n=3), 러시아 W −2.1(n=3) 이지만 AL-1 +1.4 ~ +3.8, CA-2 +4.8(n=40) 로 불안정하다.

**설계**(h25 골격, 단계 S4 추가):
- S4 = 대상 A 풀에 E_n·√TDD 유사라벨(r=10, 라벨 셀은 실측 대체) + 원천 실측으로 직접 CatBoost 를 학습한 뒤, 그 예측을 앵커로 두고 원천 잔차 + 대상 n 잔차를 λ 0.25 로 더한다. 비교 = S1(수축), S2(증강 직접), S3(수축 앵커 + 잔차), S4.
- 대상 14, 분할 3, 추출 random 10, seed 2, n ∈ {3, 10, 40}. 블록 CI.
- 가설 T1: S4 − S3 의 14 대상 평균 CI 가 0 을 포함(결합 이득 없음)하면 본문에서 '증강은 라벨 0 전용'으로 정리하고 SI 표 1개로 둔다. 상한 < 0 이면 절 2 에 '희소 라벨 증강 결합' 문단을 추가한다.
- 산출 `h4/p4_s4_curve.csv`.

## P5. 독립 라벨 지역 확충

**배경**: 확인적 평균이 4지역 조건부이고 러시아 W(31셀)가 효과 크기를 주도한다. 지역 수준 검정 p 0.35.

**후보(취득 가능성 순)**:
1. **티베트 고원**: Liu et al. 2023 ERL 자료(NH ALT 2,966 site-year, 티베트 158 site-year 포함)와 Wei & Chen 2026 Zenodo(NH 1 km ALT, 관측 2,196건). 현재 v3 에는 QTP 직접 1셀 + 지온 유도 6셀뿐이라 지역으로 쓸 수 없다. 두 자료의 티베트 탐침·융해 깊이 관측을 셀 집계하면 30–80셀 규모의 새 지역이 될 수 있다. TPDC QTEC 원자료(현재 보유)는 시추공 지온 2–3지점뿐이라 ALT 지역이 되지 못한다.
2. **러시아 추가 지점**: CALM PANGAEA 표에 러시아 78 사이트 중 v3 편입 68셀. GTNP 신규 좌표 4지점(러시아 W)은 D2 표에 편입 후보로 정리되어 있다(`h4/d2_gtnp_new.csv`). 편입하면 러시아 W 평가 셀 12–17 → 16–21.
3. **캐나다 CALM 35 사이트** 중 v3 편입은 10셀(직접 8) + ABoVE 726 셀. 나머지 사이트는 좌표·연도 필터로 제외된 것이므로 재검토(이미 ABoVE 가 캐나다를 대표하므로 이득은 작다).
4. 몽골·중앙아시아 46셀은 지온 유도 라벨이라 직접 탐침 라벨이 있어야 확인적 지역이 된다(CALM 원표의 Mongolia 47 사이트 ALD 열 확인 필요).

**절차**: 자료 취득 → `build_fidelity_base_v3.py` 확장(v3.1, 기존 셀 불변, 새 지역 추가) → M1 정보 없음·라벨 있음 조건과 h25b·A2 를 새 지역에 대해서만 추가 실행(CPU 3–4 h) → AB4 → AB5 로 확인적 집합 확장, 지역 수준 검정 재계산.
**가설 R1**: 새 지역을 더해도 직접 ML 전이 붕괴(Δ > 0)와 소수 라벨 E 재추정 이득의 방향이 유지된다. R2: 5지역 지역 수준 검정에서 H13 레시피 p < 0.10 이면 '지역 간 일반화' 문장을 강화한다.
**주의**: 새 지역은 결과 열람 전에 '확인적 추가'로 등록하고, 편입 기준(직접 탐침 F4_direct, 셀 ≥ 20, 블록 ≥ 5)을 먼저 고정한다.

## P6. 선택 재분석

- **계층 conformal 그룹 확장**: 하위 지역 포함 K ≥ 10 그룹으로 정확 계층 구간이 유한해지는지, 커버리지·폭·interval score 를 6지역 판과 비교. 하위 지역 비독립을 명시.
- **κ 선택 민감도**: κ ∈ {3, 10, 30} leave-one-target-out 선택의 n=3·10 결과(b2 형식). κ=10 이 같은 자료로 정해진 값임을 한계에 적는다.
- **Gautam 2025 설정 재현**: 알래스카 CALM 셀에서 무작위 70/30 · 0.5° 블록 · LORO 로 RF 직접·RF 잔차·Stefan 비교(SI 표 1개). 기존 `m1/cv_scheme_comparison.csv`(무작위 11.55 대 블록 16.10 cm)와 함께.
- **AL-6 n=0 → n=3 급변(+6.02 → +0.88) 구현 점검**: n0 적합과 빈 선택 잔차 적합의 동일성 단위 테스트(P1 위약 대조와 함께).

### 8.2 추가 가설(결과 열람 전 고정)

- **D0(S0)**: 순수 직접 ML이 n ≤ 40에서 물리식을 넘는(블록 CI 상한 < 0) 대상이 14개 중 1개 이하이면 '물리 없는 학습은 희소 라벨에서 물리식에 도달하지 못한다'를 쓴다. 2개 이상이면 해당 대상과 n을 표로만 보고한다.
- **T1(S4)**: P4 원문 유지. S4 − S3의 14 대상 평균 CI 상한 < 0이면 n 160·320·전량으로 확장한다.
- **U1(conformal, 중립)**: 레나·캐나다·알래스카 가운데 n ∈ {20, 40, 80}에서 커버리지가 [0.85, 0.95]이고 폭이 라벨 0 계층 구간보다 좁은 대상이 2개 이상이면 '라벨이 구간을 좁힌다'를 쓴다. 1개 이하이면 '라벨은 커버리지를 맞추나 폭을 줄이지 못한다'를 쓴다.
- **U2(지도)**: 정규화 점수가 기존 계층 구간 대비 AB4 interval score를 낮추고(블록 CI 상한 < 0) 커버리지가 0.80 이상이면 폭 지도를 본문에 둔다. 아니면 '폭은 예측값에 비례한다'를 명시하고 지도는 SI 1장으로 둔다.

### 8.3 알래스카 우선 검증 설계(사용자 요청 2026-09-29)

알래스카는 라벨이 가장 많아(13,606셀, 74블록) 신뢰구간이 좁다. 아래 순서로 같은 절차를 알래스카에서 먼저 확인하고 다른 지역으로 옮긴다. 새 스크립트는 필요 없고 8.1의 순위 2·3에 대상과 원천 설정만 추가한다.

1. **지역 내 모의 신규 지역**: 알래스카 하위 지역 AL-1–AL-6 각각을 대상으로 두고 원천은 나머지 알래스카 하위 지역으로 한다(같은 지역 안 전이, `--exclude-parent` 미사용).
2. **지역 간 모의 신규 지역**: 같은 대상에 원천을 알래스카 밖 지역만으로 한다(`--exclude-parent`). Alaska_f0(A 6,803셀)을 큰 n 참조로 둔다. n 격자는 {3, 10, 40, 160, 320, 1,000, 전량}.
3. **방법 사다리**: S0 순수 직접, S1 E 수축, S2 증강 직접, S3 앵커 + 잔차, S4 증강 + 앵커 + 잔차, α 가중·이어 학습. 1·2 단계의 차이가 '같은 지역 자료가 원천에 있을 때와 없을 때'의 차이다.
4. **이전**: 알래스카에서 블록 CI 상한 < 0을 만든 조합만 레나·캐나다·러시아 W·E에 같은 설정으로 적용한다. 알래스카에서 고른 조합을 다른 지역에서 채점하므로 선택 편향이 없다.
5. **가설 AK1**: 알래스카 지역 내 모의(1단계)에서 넘은 조합이 지역 간 모의(2단계)에서도 넘는 비율이 절반 이상이면 '알래스카에서 정한 절차가 새 지역에 이전된다'를 쓴다. 미만이면 '원천에 같은 지역 자료가 있을 때만 성립한다'를 쓴다.
