\slideheading{4}{연구 목적과 문제 정의}{0.7}

다음은 연구 목적입니다. 두 가지입니다. 첫째, 라벨이 적은 새 지역에서 Stefan 식 단독과 직접 ML보다 정확하고 안정한 물리 결합 기계학습 방법을 찾는 것입니다. 둘째, 라벨 수가 0개부터 수백 개까지 늘 때 어떤 방법을 쓰고 어떻게 평가할지 정하는 워크플로를 지역별로 검증하는 것입니다. 왼쪽은 원천 지역과 대상 지역이며, 대상 지역과 100~km 완충 안의 셀은 학습에서 뺍니다. 오른쪽의 네 방법은 모두 같은 라벨 $n$개와 같은 채점 블록을 씁니다.

\pointat{삽도의 100 km 완충 점선, 오른쪽의 네 방법(원천 계수 Stefan, 재보정 Stefan, 물리 잔차 결합, 직접 ML)과 라벨 수 축}

\slideheading{5}{연구 질문}{0.4}

\slideheading{6}{용어}{0.5}

다음은 용어입니다. 라벨은 현장에서 잰 ALT 관측값으로 1~km 셀 단위입니다. 원천 계수는 원천 라벨로 정한 Stefan 계수이고, 재보정 계수는 대상 라벨로 다시 맞춘 계수입니다. 물리 잔차 결합은 물리식이 남긴 오차를 기계학습이 보정하는 방식이며 이 연구의 제안입니다. 판정은 셀 가중과 블록 등가중의 두 95\% 신뢰구간으로 하고, 차이가 ±0.5~cm 안이면 동등으로 봅니다.

\pointat{‘물리 잔차 결합’ 행, ‘두 가중 신뢰구간’과 ‘동등 범위’ 행}

\slideheading{7}{사용 자료}{0.7}

다음은 사용 자료입니다. 가운데 표는 라벨 출처입니다. 주 4지역은 레나델타 3,037행, 캐나다 750행, 러시아 서부와 동부 31행과 30행입니다. 참조 지역 알래스카는 13,606행이지만 1~km 위치는 343곳, 0.5° 블록은 74개입니다. 공변량은 지형 6종, 기후 8종, 토양 9종, 위성 ALT 2종의 25종입니다. 오른쪽처럼 모든 입력을 1~km 셀에 정렬하였지만, 정보 해상도는 토양 약 5~km, 기후 0.1°에 묶입니다.

\pointat{표의 알래스카 행(13,606 / 343 / 74), 오른쪽 그림의 ‘정보 해상도’ 띠}

\begin{optbox}
새 지역 러시아 중부와 티베트 고원은 1~km 셀 평균 57행과 132행입니다. 라벨 수 $n$은 행 수이고 행의 뜻은 지역마다 다릅니다. 융해 도일은 ERA5-Land에서 계산하였고, 예측은 2015년부터 2020년 기후값에 대한 정적 예측입니다.
\end{optbox}

\slideheading{8}{전체 연구 흐름}{0.5}

연구 흐름은 여섯 단계입니다. 먼저 자료를 1~km 셀로 구축하고, Stefan 식으로 원천 계수와 재보정 계수의 두 기준선을 만들었습니다. 그리고 기계학습을 물리 정보와 결합하는 방식들을 같은 학습기 CatBoost로 비교하였습니다. 모든 방법은 지역 홀드아웃과 라벨 수 격자에서 같은 채점 블록으로 평가하였고, 판정 규칙은 실행 전에 등록하였습니다. 이후 라벨 수별 워크플로와 1~km 지도로 정리하였습니다.

\pointat{단계 ①–⑥ 띠, 아래 주황색 되돌림 화살표(라벨을 더 모으면 앞 단계로)}

\slideheading{9}{Stefan 물리 모델의 뜻}{0.8}

다음은 Stefan 식입니다. 여름에 지면으로 들어온 융해 열량으로 녹는 깊이를 구하는 열수지 해입니다. 열량은 영상 기온의 합인 융해 도일 TDD로 대신합니다. 열전도도, 토양 수분, 밀도, 융해 잠열은 계수 $E$ 하나에 묶입니다. 따라서 ALT는 $E$ 곱하기 루트 TDD입니다. 그림의 왼쪽 아래는 러시아 서부 라벨 셀 하나입니다. TDD 1,537도·일에 실측이 118~cm인데 원천 계수로는 62~cm로 예측됩니다. 계수 $E$가 지역마다 다르기 때문입니다. 오른쪽은 러시아 서부 라벨 10개로 다시 맞춘 예시로, 원천 계수 1.59가 2.11로 바뀌었습니다.

\pointat{가운데 식의 $E=\sqrt{2k/(\rho w L)}$, 오른쪽 그래프의 회색 선(1.59)과 파란 선(2.11)}

\begin{optbox}
$E$의 단위는 cm·(°C·일)$^{-1/2}$입니다. 지역별 기하 평균은 레나델타 1.31에서 티베트 고원 11.03까지 다릅니다. 주 지역의 원천 계수는 1.59에서 1.62로 거의 같은데, 원천의 대부분이 알래스카 셀이기 때문입니다.
\end{optbox}

\slideheading{10}{Stefan 물리 모델과 계수 재보정}{0.7}

다음은 계수 재보정입니다. 재보정 계수 $E_n$은 대상 라벨 $n$개의 최소제곱 계수와 원천 계수의 가중 평균입니다. 수축 강도 $\kappa$는 10입니다. 라벨 몇 개로 계수를 통째로 바꾸면 오차가 커질 수 있기 때문에 원천 계수에 라벨 10개의 무게를 주었습니다. 이를 적용하면 라벨 10개에서 두 계수의 중간이 되고, 라벨이 늘수록 대상 계수에 가까워집니다. 그림은 레나델타 실제 라벨에서 10개를 뽑은 예시입니다. 직선과 라벨의 차이가 잔차이고, 이 잔차를 다음 쪽의 기계학습이 배웁니다.

\pointat{아래 식 $E_n=(nE_{\mathrm{ls}}+\kappa E_0)/(n+\kappa)$, 회색 원천 계수 선과 파란 재보정 선, 주황색 ‘잔차’}

\begin{optbox}
$\kappa$는 앞선 실험에서 정하였고 3과 30은 민감도로 두었습니다. 이 예시의 최소제곱 계수는 1.352, 재보정 계수는 1.486, 원천 계수는 1.619입니다. 판정과 무관한 예시입니다.
\end{optbox}

\slideheading{11}{비교 방법과 모델 구조}{1.0}

다음은 비교 방법입니다. 물리 정보가 들어가는 위치에 따라 다섯 구조로 나누었습니다. 주황색이 이 연구가 제안하는 물리 잔차 결합입니다. 재보정 Stefan 예측 $a$를 앵커로 두고, 학습기 $g$는 라벨과 앵커의 차이인 잔차만 배웁니다. 예측은 $a$ 더하기 $\lambda$ 곱하기 $g(X)$입니다. 잔차 가중 $\lambda$는 0.25, 0.5, 1.0 가운데 고르며 전이 판정 기준은 0.25입니다. 배운 것이 없으면 물리식으로 돌아가도록 하기 위해 이 구조를 썼습니다. 물리 입력 ML은 물리 예측을 입력 열로 넣고, 물리 유사라벨 증강은 Stefan 값을 학습 라벨로 더하며, 직접 ML은 물리 정보를 쓰지 않습니다. 방법 비교는 같은 CatBoost로 하였고, 라벨 0개의 직접 ML은 학습기 10종으로 비교하였습니다.

\pointat{주황색 물리 잔차 결합 줄($\hat{y}=a+\lambda g(X)$), 오른쪽 학습기 열}

\begin{optbox}
CatBoost 설정은 반복 200회, 깊이 3, seed 2개입니다. 학습기 10종은 CatBoost 3설정, 랜덤 포레스트, TabPFN v2, TabICL v2, 신경망 4종입니다. 물리 입력 ML은 학습기가 물리 열을 무시할 수 있는 구조입니다.
\end{optbox}

\slideheading{12}{물리 유사라벨 증강 대조 실험 설계}{0.5}

다음은 증강의 대조 실험 설계입니다. 증강의 이득이 물리 정보에서 오는지, 학습 행이 늘어난 효과인지를 가르기 위해 위약 네 가지를 만들었습니다. 유사라벨의 자리와 수, 학습기, 채점 블록은 같게 두고 값만 바꾸었습니다. 순서를 섞은 유사라벨, 풀 평균 상수, 원천 평균 상수, TDD에 선형인 융해 지수입니다.

\pointat{‘유사라벨 조건’ 다섯 줄, 오른쪽 그래프(물리 유사라벨 − 위약, 음수가 물리 유사라벨이 나은 쪽)}

\slideheading{13}{평가 설계}{1.0}

다음은 평가 설계입니다. a는 지역 홀드아웃입니다. 대상 지역 셀과 100~km 완충을 학습 원천에서 뺍니다. b는 블록 절반 분할입니다. 0.5° 블록을 무작위로 절반씩 나누어 라벨은 노란 블록에서만 뽑고 채점은 초록 블록에서만 합니다. 분할은 다섯 번 반복하였습니다. c는 라벨 수 격자입니다. 0, 3, 10, 40, 160, 320, 1000개와 전량이고 추출도 다섯 번씩입니다. d는 판정 규칙입니다. 두 가중의 신뢰구간이 모두 0 아래면 오차 감소, 모두 0 위면 오차 증가, 네 끝값이 ±0.5~cm 안이면 동등, 그 밖은 미결정입니다. 아래 줄은 절차입니다. 가설과 판정 규칙을 커밋한 뒤 고정 seed로 실행하였고, 재현 관문을 통과한 뒤에 봉인한 표를 열었습니다.

\pointat{b 의 노란 블록과 초록 블록, d 의 네 판정 그림, 맨 아래 ‘등록 → 실행 → 재현 관문 → 열람’}

\begin{optbox}
미결정은 차이를 확인하지 못했다는 뜻입니다. 러시아 서부와 동부는 라벨 블록 셀이 15개 안팎이라 라벨 40개 이상은 레나델타와 캐나다 2지역 평균으로 봅니다. ±0.5~cm는 주 4지역 원천 계수 Stefan RMSE 21.7에서 43.0~cm의 약 1에서 2\%이며 결과 전에 고정한 규약입니다.
\end{optbox}
