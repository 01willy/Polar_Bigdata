# 논문 작성 전 보고 덱 계획

작성 2026-10-04. 이 문서는 `deck/deck_spec_paper_report.json`(이하 스펙)의 사람이 읽는 개요다. 쪽별 근거 경로, 수치 출처, 자리표시, 점검 항목의 전문은 스펙에 있다. 덱 파일(PPTX, PDF)과 그림은 아직 만들지 않았다.

## 1. 목적과 청중

- 청중은 사용자와 공동 연구자·지도교수다. 결과를 처음 듣는 사람도 따라올 수 있게 동기, 도구, 이름 순서로 설명한다.
- 2026-10-02 사용자 요청(전체 결과, 연구 의의, 실험별 입출력 현황, 데이터 처리, 실험별 목적·결과·의미, 전체 워크플로, 논문 작성 방향)과 2026-10-04 추가 실험 등록 현황을 한 덱에 담는다.
- 순서는 원고의 결과 절 순서(평가 설계, 라벨 0개, 라벨 3–10개, 라벨 수십–수백 개, 라벨이 많은 지역, 새 라벨의 위치, 독립 지역, 예측 구간)를 따르고, 뒤에 워크플로·결론·전망과 논문 작성 계획을 둔다.
- 분량은 본편 34쪽(약 34분), 참고문헌 1쪽, 부록 10쪽(질의응답용)이다.

## 2. 따르는 규칙

- 구속 문서: `design/journal_grade_style_guide.md`, `design/slide_archetypes.md`, `design/user_feedback_digest.md`, `design/baseline_audit_2026-10-04.md`, 전역 문체·시각 규칙.
- 머리 문법은 사용자 확정 문법 V(주황 명사구 제목 26 pt, 회색 부제 14 pt 한 줄, 하단 결론 줄 15 pt ExtraBold 45자 이하)다. 상단 주장 줄 문법은 제안 단계라 쓰지 않는다.
- 글씨 상자, 카드, 색 구역, 통계 카드, 아이콘, 곡선 화살표를 쓰지 않는다. 과정은 실제 축 위의 개념 좌표도(9쪽)와 실제 결과 위의 워크플로 경로(26쪽)로 보인다.
- 보이는 글에는 내부 코드(실험 번호, 방법 약호, 자료 표 판 이름, 하위 지역 ID)를 쓰지 않는다. 코드와 파일 경로는 스펙의 `tracking`, `numbers`, `name_map_spec_only` 에만 둔다.
- 결과 문장은 주장 색인(`paper/claims/*/README.md`)의 축소판을 따른다. C2 는 '라벨을 쓰는 보정(재보정 + 잔차)'의 이득으로 좁혔고, 재보정을 넘어선 ML 몫의 관계는 추가 실험 자리표시로 둔다. '안전'은 쓰지 않는다. 지역 내·워크플로 시험에는 '결과 열람 뒤 설계'를 단다.
- 지침 대비 바꾼 값(첫 시안과 함께 보고): 여백 0.52 → 0.667 in, 본문·표 12.5 → 18 pt, A7 표 행 높이 0.50 → 0.75–1.00 in.

## 4. 부별 설명

**표지와 개요**(쪽 1–4). 표지, 연구 의의, 연구 흐름, 라벨 수 구간별 결과 요지.

- 1쪽 연구 결과 종합과 논문 작성 계획: 보고의 범위(결과 종합과 논문 계획)와 자료의 공간 범위를 한 쪽에 보인다.
- 2쪽 연구 의의와 차별성: 표지 바로 다음에 의의와 차별성을 둔다(S-11, MS-02). 기법의 새로움이 아니라 평가 설계·결과·워크플로가 기여임을 밝힌다.
- 3쪽 연구 흐름과 실험 묶음: 연구 전체 흐름과 각 단계의 산출 상태를 한 쪽에 보이고, 실험별 입출력 표는 부록(AP6, AP7, AP9)으로 넘긴다.
- 4쪽 라벨 수 구간별 결과 요지: 사용자가 요청한 '전체 결과'를 앞에서 한 번 보이고, 각 부에서 근거를 보인다. 첫 행을 '직접 ML 실패'가 아니라 물리 정보가 줄인 손해로 쓴다.

**1부 · 자료와 설계**(쪽 5–10, 결과 절 R1). 연구 지역과 계수, 입력 자료와 처리 단위, 평가 설계, 검증 설계에 따른 오차, Stefan 개념, 비교한 방법.

- 5쪽 연구 지역과 Stefan 계수: 새 지역 문제의 두 전제(라벨 수의 차이, 계수의 차이)를 실제 자료로 보인다.
- 6쪽 입력 자료와 처리 단위: 사용자가 요청한 '데이터 처리'를 실제 해상도 축 위에서 보이고, 5부(격자 단위 보정)의 복선을 둔다.
- 7쪽 평가 설계: 공정한 시험지(같은 라벨, 같은 채점 셀, 두 물리 기준선)를 실제 지도 확대로 보인다. 글씨 상자 도식 대신 지도.
- 8쪽 검증 설계에 따른 오차: 왜 지역 홀드아웃으로 평가하는지를 수치로 보인다. 무작위 분할 과대평가는 중심 주장이 아니라 설계의 근거로 둔다(지침 1.1).
- 9쪽 Stefan 기준선과 물리 잔차 결합: 방법 개념을 상자 흐름도 없이 실제 축과 자료로 설명한다(A8). 이후 쪽의 '재보정', '잔차' 용어를 정의한다.
- 10쪽 비교한 방법: 이후 결과 쪽의 방법 이름을 한 번 정의한다(용어 첫 등장 정의, WT-07). 방법 색과 같은 이름을 쓴다.

**2부 · 라벨 0개**(쪽 11–12, 결과 절 R2). 대상별 전이 오차 변화 지도, 물리 유사라벨의 정보 출처.

- 11쪽 대상별 전이 오차 변화: 첫 결과 쪽. 결론 줄은 '직접 ML 실패'가 아니라 물리 정보가 줄인 손해(S-11). 공간 분포를 지도로 보인다(H5).
- 12쪽 물리 유사라벨의 정보 출처: 증강 이득이 물리 정보에서 온다는 위약 대조를 보인다. 단정형 가능 대비(두 CI 판정 일치, Holm 뒤 유의).

**3부 · 라벨 3–10개**(쪽 13–17, 결과 절 R3). 라벨 수 곡선 3단계, 계수 오차와 보정 이득, 결합 구조.

- 13쪽 라벨 수에 따른 오차 변화: A6 첫 단계. 라벨이 적을 때 기준이 물리식이어야 하는 이유를 보인다.
- 14쪽 라벨 수에 따른 오차 변화: 라벨의 첫 쓰임이 계수 재보정임을 보이고, 그 효과가 지역에 따라 다름을 단서로 단다.
- 15쪽 라벨 수에 따른 오차 변화: 재보정을 넘어선 ML 몫이 작음을 보이고 C2 축소와 연결한다.
- 16쪽 계수 오차와 보정 이득: C2 를 좁힌 형태로 보인다: 라벨을 쓰는 보정의 이득은 10개 라벨 진단으로 순위를 가늠할 수 있다. ML 몫의 관계는 미확인임을 밝힌다.
- 17쪽 결합 구조와 라벨 수: 결합 구조의 우열이 라벨 수에 따라 바뀜을 보이고, 라벨 수십 개부터 구조를 라벨로 골라야 한다는 4부로 잇는다.

**4부 · 라벨 40–160개**(쪽 18, 결과 절 R4). 대상 라벨 교차검증 선정.

- 18쪽 대상 라벨 교차검증 선정: 라벨 수십–수백 개에서 방법을 대상 라벨로 고르는 규칙의 근거를 보인다. 비열등과 우세를 n 과 풀을 밝혀 쓴다.

**5부 · 라벨이 많은 지역**(쪽 19–21, 결과 절 R5). 지역 내 라벨 수 곡선, 대회 결과와 줄일 수 있는 오차, 보정량의 공간 분포.

- 19쪽 지역 내 라벨 수 곡선: 라벨이 많은 지역 안에서의 이득 크기를 보인다(작지만 알래스카에서 유의). 대회 결론과의 연결을 다음 쪽에 둔다.
- 20쪽 대회 결과와 줄일 수 있는 오차: 사용자가 반복해 물은 '대회 7.8% 와 이번 결과의 관계'를 같은 축에서 보인다. 두 결과가 같은 방향임을 보인다.
- 21쪽 보정량의 공간 분포: 확정 덱의 '증강 효과 공간 분포' 쪽을 잇는 변화량 지도 쪽. ML 이득의 공간 규모(격자 단위)를 보이고 '고해상 지도' 오해를 막는다.

**6부 · 관측 위치**(쪽 22–23, 결과 절 R6). 라벨 위치 전략 지도, 예산별 전략 비교.

- 22쪽 라벨 위치 전략: 배치 전략의 차이를 실제 지도로 보이고 캐나다 이득을 결론으로 둔다. 특정 지점의 관측 우선순위는 보이지 않는다.
- 23쪽 예산별 전략 비교: 분산 배치 효과의 지역 의존을 숨기지 않고 보인다(C6 정정 반영). 능동 선정 무익을 함께 보인다.

**7부 · 독립 지역과 예측 구간**(쪽 24–25, 결과 절 R7, R8). 독립 지역, 예측 구간.

- 24쪽 독립 지역: 결론이 학습에 쓰지 않은 새 지역에서 유지되는지 보이고, 독립 지역 수의 한계를 함께 밝힌다(결과 절 R7).
- 25쪽 예측 구간: 결과 절 R8(보조). 새 지역에서 보통 ML 구간이 과소 포함되고 지역 단위 보정이 필요함을 보인다. 물리식보다 나은 불확실성은 주장하지 않는다.

**8부 · 워크플로**(쪽 26–28). 라벨 수별 워크플로, 결론, 전망.

- 26쪽 라벨 수별 워크플로: 결과를 라벨 수 구간별 권고로 묶어 실제 값 위의 경로로 보인다(글자 격자·순서도 대신).
- 27쪽 결론: 결론 세 개를 판독 가능한 근거 그림과 함께 보인다. 한계와 전망은 쓰지 않는다.
- 28쪽 전망: 결론 다음에 전망을 따로 둔다(MS-02). 적용 조건과 다음 자료를 쓰고 한계 나열로 끝내지 않는다.

**9부 · 논문 작성 계획**(쪽 29–34). 원고 구성과 분량, 결과 절과 표시 항목, 초록 표기, 추가 실험의 원고 자리, 본문 자리 추가 실험, 남은 결정.

- 29쪽 원고 구성과 분량: 사용자가 요청한 '논문 작성 방향'의 구조와 분량을 보인다.
- 30쪽 결과 절과 본문 표시 항목: 결과 절 순서와 그림 배치 계획을 한 표로 보이고, 결과 지도 의무(PF-02, H5)를 어떻게 채우는지 보인다.
- 31쪽 초록의 시험 결과 표기: 결정을 묻기 전에 규칙과 선택지별 영향을 먼저 설명한다(explain-before-decision). 임시 제목은 노트와 S34 에서 다룬다.
- 32쪽 추가 실험의 원고 자리: 추가 실험 묶음의 상태(등록 완료, 결과 대기)와 원고 자리를 한 쪽에 보인다. 본문·보충 배치는 결과 전에 고정했음을 밝힌다.
- 33쪽 본문 자리 추가 실험: 본문 문장이 어떤 결과에 기대는지 보이고, 결과가 나오면 어떤 문장이 바뀌는지 설명한다.
- 34쪽 남은 결정 사항: 원고 작성 전에 사용자가 정할 것을 기본값과 함께 보인다.

**참고문헌과 부록**(쪽 35, 부록 1–10). 참고문헌, 학습기, 판정 단어, 라벨 0 기준선, 한계, 알래스카 검증 방식, 실험 묶음 입출력, 원천 교차검증, 보충 자리 추가 실험, 기타 결정.

- 35쪽 참고문헌: 덱에서 인용한 문헌을 원고 참고문헌과 대조할 수 있게 둔다(SL-09).
- 부록 1쪽 학습기별 전이 오차: C1 의 학습기 일반성을 한정어와 함께 보인다. 본편 첫 결과 쪽에 두지 않는다(지침 1.1).
- 부록 2쪽 판정 단어와 표지: 덱 전체의 판정 단어를 한 번 정의한다(질의응답용).
